Product research checks

  • When you research products on Google Shopping (Google's product price search page), do not decide from the first page alone.
  • If cheaper products fill the first page, filter by price range. Filtering means showing only results in a chosen price band.
  • Then check that higher-priced versions exist in enough numbers.

Keyword research and listing copy

  1. On Amazon, research keywords with Amazon's own search suggestions. Keywords are the words shoppers type into search.
  2. Put the chosen keywords in the product title (the name at the top of the product page), the description (the main text) and the bullet points (short lines that list features).
  • In 2021, Amazon was described as a pay-for-play system. That means you must pay for ads to be seen. Organic ranking (showing up for free in normal results) was not realistic without paid ads. Plan an advertising budget for Amazon from the start.

Store naming and file metadata

  • Putting the niche keyword in the domain is preferred when possible. A niche is a small topic of products. The domain is the web address, such as yourstore.com.
  • It is preferred, but not required. Creative names that fit the store theme also work well. (2023)
  • Set custom metadata in your PDF documents. Metadata is hidden file information. It can include the author, the affiliated company (the business the file belongs to) and keywords.
  • Metadata supports SEO (search engine optimization, which means making pages easier for search engines to find and rank). It can also later serve as proof of ownership if the file is copied.

On-site SEO in Shopify

  • Site SEO has a separate topic called search engine domination. That topic is not covered here.
  • The main focus here is on-site optimization in Shopify (an online store platform). This means improving the store's own pages.
  • Organic traffic tools are also part of the focus. Organic traffic means free visitors from search results.
  • Free SEO training resources exist as a starting point. They help improve organic search visibility, which means how easily people find the store in free search results.

Traffic estimates and SEO tools

  • Ubersuggest (ubersuggest.com) is a cheap SEO tool. It estimates a domain's organic monthly traffic, meaning how many free visitors a website gets each month.
  • Ahrefs or Semrush are paid SEO tools. They can be used instead if you already pay for them.
  • Findings about traffic sources (where visitors come from) are estimates, not facts. Competitors (other stores selling similar products) may run channels that are hard to detect.
  • Treat search results and SEO tool numbers as a best guess.
  • Record that uncertainty in the comments (your notes in the file).

Local search and listings

  • Local SEO tactics are methods aimed at customers in one area. Examples include citations, which are mentions of your business name and address on other sites, such as local newspapers. These tactics are specialized and rarely move rankings (where you appear in search results) for a national store.
  • Some local practices can still help a national business. They are minor.
  • For Australian searchers, search engines tend to show .com.au domains (Australian web addresses) ahead of.com domains (general web addresses).
  • A local page with quality content (useful, original writing) and links (other sites pointing to it) can outrank overseas listicles for the same term. Listicles are list-style articles, such as "10 best..." posts. Outrank means appear above.
  • Google Business Profile is a free business listing on Google. 2021 view: it is not necessary for a dropshipping store (a store where the supplier ships each order straight to the customer) to rank there. So it does not need to be a priority at launch.
  • Google Business Profile, 2025 view: it is optional for this store model. Leaving it off is unlikely to cause harm.
  • Both views agree: it is not a launch priority.
  • The 2025 view is the more recent guidance.

Feed work and reviews

  • A feed is the product data file that shopping search reads. It holds details such as title, image, price and description.
  • If the store is already optimized for SEO, most of the feed work is already done.
  • Google's organic search (free results) and Google Shopping matching work in similar ways.
  • So the same title, image and description work helps both.
  • Junip is a review app (a tool that collects customer ratings). It can add a dedicated reviews page that gathers all store reviews in one place.
  • The vendor (the company that sells Junip) says this page helps the store rank when people search for reviews of the brand.
