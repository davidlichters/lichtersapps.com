12.18 Static ad design, color and brand graphics

Canva setup and Brand Kit

  • Canva is a beginner-friendly drag-and-drop design tool suitable for creating store graphics without design experience. [L0098.001]
  • The free plan is sufficient for building all store image assets, but transparent-background export is a paid feature (see Logo and icons). [L0098.001, L0098.008]
  • Canva Pro has a 30-day free trial and costs about $12 per month after the trial. It can be cancelled before billing starts. Its Magic Media, BG remover and Animate features are used to create themed ad and email images. [L1115.082]
  • Set up the Brand Kit for consistency: go to Canva Home → Brand Kit → Brand Colors, and add 3 brand colors (black and white can still be used in addition). This speeds up design work and maintains visual consistency. [L0098.004]
  • Use a consistent set of colors and fonts across all designs for one brand. The Brand Kit stops you from restyling each design from scratch and keeps style consistent across assets. [L0754.032]
  • Canva is the tool for creating ad images and graphics. [L0238.012]
  • Canva is a suitable tool for designing product banners and other promotional images. Photoshop also works, as long as the designer is comfortable with the tool. [L0667.050]

Logo, favicon and icons

Logo specifications (Manhattan theme): 800×300 pixels, PNG format, transparent background preferred. [L0098.006]

Create a logo:

  1. Use your domain name words as the logo text.
  2. Edit font, boldness, size, line spacing, and letter spacing.
  3. Keep the design simple: text plus one small icon.
  4. Add the icon via Elements → search → Graphics.
  5. Avoid overly complex logos; keep them clean and readable. [L0098.007]

Transparent background (paid feature): Transparent background export is a paid Canva feature. Free workaround: download the PNG with a white background, use a free online background remover tool, then upload the transparent PNG to Shopify. [L0098.008]

Favicon specifications: 64×64 pixels, jpg or png with transparent background preferred. Shown in browser tabs. [L0098.009]

Create a favicon: Open the favicon Canva template, copy and paste your logo icon into the favicon template, and download as PNG with transparent background if possible. [L0098.010]

Mega menu icon specifications (Manhattan theme): 250×250 pixels, jpg or png format, up to 5 icons supported. [L0098.011]

Create multiple mega menu icon variations: Open the Mega Menu Icons template, create different icon options using Add Page (examples: a letter icon like "S", a wave icon, a surfboard icon), then download all pages at once as a set. [L0098.012]

Icon sources and colors:

  • Canva's Elements panel has a Graphics tab for icons and illustrations and a Photos tab for stock photos. Free stock photos are not available for every niche, so basic or technical products may need images from external stock sites. [L0342.017]
  • Icons for mega menus and USP sections can come from Canva's free graphics library, and some icons allow more than one color. Keep icons consistent in style and color so they look like one set. [L1045.017]
  • Some free Canva graphics can be recolored in more than one color, so a single icon can use two or more brand colors without being drawn by hand. Single-color icons can only be recolored to one color. Check the color count when choosing icons for a multi-color mega menu or logo. [L0342.040]
  • USP icons work best as simple single-color icons on a white or brand-colored background, with a short label. Use the brand palette so they match the rest of the store. [L1045.034]

Pre-footer "Why Buy From Us" icons (Manhattan theme): Less than 285×285 pixels, jpg or png with transparent background, up to 7 icons supported. Examples: Free Shipping, Secure Checkout, Customer Support, Niche/Founder-owned. [L0098.029]

Create pre-footer icons:

  1. Use the icon template.
  2. Elements → search icons → Graphics.
  3. Download as PNGs.
  4. Keep icon style consistent across all icons (same visual vibe and color scheme). [L0098.030]

Banners and product page graphics

Banner without text:

  1. Elements → search niche keyword → Photos.
  2. Drag the image onto the canvas.
  3. Right-click → Set image as background.
  4. Adjust crop and position as needed. [L0098.015]

Banner with text:

  1. Text → add heading.
  2. Optional: add shapes (e.g., a rectangle) behind the text for contrast.
  3. Alternatively, use Canva templates and swap in your own images. [L0098.016]

Import external stock photos into Canva:

  1. Download the image from a stock photo site.
  2. Drag the image into Canva.
  3. Use Uploads → drag onto the design → Set as background. [L0098.017]

Use your own or downloaded photos:

  1. Drag the image file from your computer into the Canva window to upload it, and wait for the upload to finish, which can take a minute for large files.
  2. Go to Uploads and drag the image onto the design.
  3. Right-click the image and choose Replace background.
  4. Canva crops the image to the size the template needs. [L1045.023]

Product page graphic purpose: A promotional banner on product pages for sales, urgency, or coupon codes. It can be updated or removed anytime. Create it using a template with bold brand colors. Text examples: "Huge Sale", "Save 10% with code [CODE]", and an optional expiry date. [L0098.020]

Collection page banner: Use a template, set niche-relevant images as the background, and keep the design simple with no text. [L0098.022]

Button for a banner in Canva:

  1. Open Elements and add a square shape.
  2. Resize the square to fit the button label and set its color to a brand color.
  3. Add a heading with the label (for example "Shop now") and drag it over the square.
  4. Select both elements, use the three-dot menu, and choose Position > Center. [L0342.041]

Outline on text: In Canva, select the text and open Effects to add an Outline around the letters. Test the outline color against the background before using it, because a poor color pairing can make the text harder to read. [L0342.042]

Gradient banner in Canva: Select the banner box, click Colors, and choose a gradient fill instead of a solid black fill, so the banner blends with the image while staying readable. [L0692.056]

Promotional banner on an ad: It must be clearly visible, so use a high-contrast color and a readable font. The banner colors should harmonize with the creative, and the font should match the product page. [L0692.038]

Add a Black Friday banner to a proven winning ad:

  1. Pick an ad that already performs well.
  2. Add a banner at the top with the offer text.
  3. Use a box with a high-contrast color and readable font.
  4. Use a gradient fill instead of plain black if the banner should blend better with the image.
  5. Match the font to your product page so the customer journey looks consistent. [L0692.039]

Discount badges: They should be the most eye-catching element on a sale design, placed so the eye lands on them first. Their color should come from the brand palette, but the badge must stand out against the photo. [L0992.017]

Monthly promotion images: Use Canva for simple designs or hire on Fiverr. Create a few unique images for each month's promotion to use across Display, Email, and Social campaigns. Adjust the aspect ratio slightly for Discovery ads. [L0210.034]

Black Friday and holiday templates: Search Canva for "Black Friday" to find ready-made designs usable as thumbnails and ad visuals. This saves production time when running volume tests. [L0309.002]

Banners for affiliate use (older advice, 2021-22): Banners created for affiliate use can serve as display network ads or on individual websites. A designer may describe their service as AdWords or AdRoll banners, but those same assets work for affiliate banner placements. [L0288.016]

Collection images, blog images and square formats

  • Select one consistent format for all collection images: either banner-style or square. Square images perform better in the homepage grid layout, and standardizing on a single approach eliminates design conflicts. [L0098.025]
  • Create square collection images for the homepage:
    1. Use the square template.
    2. Add 3-6 images (one per collection).
    3. Center the subject of each image so it crops well when Shopify displays it as a square. [L0098.026]
  • Keep blog image sizing consistent by always using the same Canva template for blog posts and blog previews. This ensures visual consistency across your blog. [L0098.028]

Layout and visual hierarchy

  • Design should complement copy, bringing focus to main points and playing with flow to engage readers. Fonts, style, and design matter; aim for legibility and simplicity. Start with a simple design and slowly ramp up complexity if needed. If it feels unbalanced or off, it is. [L0196.049]
  • Ad graphics affect conversion rate because poorly made visuals make a store and its ads look untrustworthy. Learn core design and photography principles before launching many ads instead of rushing the launch. Canva offers free graphic design and video editing courses that help beginners. [L0561.055]
  • If brand weight is low, make the product benefit and offer absolutely clear in one image. Include: product visual, the offer amount, scarcity (event end date), and core benefits. Everything must be readable at a glance. [L0308.012]
  • Eight basic design principles are universally used best practice for harmonious layouts: emphasis, contrast, white space, movement, repetition, proportion, balance and alignment. Apply them together in every creative unless a jarring effect is deliberately wanted. [L0755.012]
  • Emphasis: Make the most important element stand out through color, and minimise others when needed. Decide first what the viewer must see first, such as the offer, the sale tag or the buy-now button, and emphasise that. [L0755.013]
  • Visual hierarchy: Order the elements of the whole layout by importance, and use color, size, placement and direction to show each level. For example, a title in one color, a subtitle in a second color and body text in a third make the reading order clear. [L0755.014]
  • Contrast comes in four types: color contrast, size contrast, type contrast (different font styles) and shape or direction contrast. Contrast is especially important in e-commerce for sale tags, buttons and other elements that must stand out. [L0755.015]
  • Size contrast can change how equal objects look: the same circle looks smaller when surrounded by larger shapes and bigger when surrounded by smaller ones. Judge sizes in context, not in isolation. [L0755.016]
  • Mistake: Stuffing too much information into one design creates cognitive overload, and viewers leave without reading it. Titles pushed against the edge of a layout also make a design look like it has no breathing space. [L0755.019]
  • Movement: The layout should guide the eye from the most important element to the next, such as title to subheading to text to call to action. Arrange elements so this path flows without breaks. [L0755.020]
  • Repetition: Repeated headers, colors, button styles and navigation items signal that elements belong together and create consistency. Use the same format for similar elements across a page or campaign. [L0755.021]
  • Proportion: Larger elements are read as more important than smaller ones, so size is a tool for emphasis. Keep real-world sizes realistic (for example, a product next to a cup) unless oversizing is a deliberate choice. [L0755.022]
  • Golden ratio: A proportion system used to size and place elements so they look harmoniously related, often shown as a spiral. The exact formula is not explained in the lesson and should be verified before use. [L0755.023]
  • Balance: Harmony comes from distributing visual weight across the design, using a center line, diagonal or top-bottom axis. Balance can be symmetrical or asymmetrical, and a large or bold element can be offset by a group of smaller elements on the other side. [L0755.024]
  • Color can create balance in an asymmetrical layout when colors switch sides in a symmetrical way. Elements of similar weight, such as a product and its new version, can balance each other without being identical. [L0755.025]
  • Alignment: Lining up elements to a shared edge, such as left alignment, gives order, improves readability and lets people scan quickly. Misaligned text blocks make a design look sloppy and slow down reading. [L0755.026]
  • Even spacing, consistent alignment and symmetry make a design look balanced and professional. Use the alignment and space evenly tools rather than placing elements by eye. [L0754.030]
  • Symmetry: symmetrical layouts feel ordered and complete, but a design does not need full symmetry. Asymmetrical layouts still feel harmonious when elements of similar visual weight sit on both sides of a central line. [L0755.010]
  • Reading order: Western viewers scan from left to right and from top to bottom, so place the headline at the top left and the most important visual next to it. Put the offer, price and call to action in that order along the path toward the bottom right. [L0755.036]
  • Lines or shapes that shrink towards a central point create a sense of movement into depth. Pointing shapes, such as an arrow or a letter with a directional stroke, pull the eye along a path toward the next element. [L0755.035]
  • Example: A bold headline in bright red on a near-black background creates strong color contrast and draws the eye first. Use this pairing when the headline must be read before anything else on the layout. [L0755.038]
  • Example: A contrasting background panel or box placed behind secondary information, such as a benefits list, makes that information stand out from the main layout. The panel should be clearly different in color from the surrounding area so the eye reads it as a separate block. [L0755.037]
  • Example: A cool blue and a warm orange work well together as a palette. Use the orange as the accent for the promotion or price so it stands out against a blue-based design. [L0755.034]
  • An element can be made more important by giving it a distinct texture or a different shape and style, not only a larger size or a new color. A sale tag or key offer can use this treatment to separate it from the rest of the layout. [L0755.033]
  • Transparency or opacity controls how strongly an element stands out: lower it to push an element into the background and keep higher values for the element that should be emphasized. [L0754.031]
  • Visual hierarchy can be built in 3D with shadows as well as in flat design. [L0341.018]

Break down an existing ad or template and check its design:

  1. Identify which elements are grouped by proximity, similarity or shared space, and which are separated.
  2. Check how much negative space surrounds the product and the main message.
  3. Read the layout in the usual reading order and note which element the eye reaches first, second and last.
  4. Draw a diagonal line across the layout and check whether the visual weight on each side is roughly balanced.
  5. Confirm that the promotion and the call to action are easy to find, and that the layout does not have too many competing elements. [L0755.040]

Grouping and perception (Gestalt principles)

  • Gestalt principles describe how people perceive a whole before its parts, fill in gaps, dislike incomplete shapes, and group things by similarity and difference. Designers use these tendencies to decide how elements are arranged in ads, banners and product pages. [L0755.003]
  • Closure: Viewers mentally complete a shape when the designer leaves gaps or implied lines in negative space. This lets a design use fewer elements while still reading as a complete image. [L0755.004]
  • Common fate: Elements that point or move in the same direction are read as one group. An element that breaks that direction and color pattern stands out from the rest. [L0755.005]
  • Continuation: The eye follows the smoothest line through a layout, so the most important elements should sit along that path. Using this path guides the viewer toward the intended message or action. [L0755.006]
  • Similarity: Elements sharing color, shape or size are grouped even when they are far apart. Making one element clearly different in color, shape or size is a way to make it stand out. [L0755.007]
  • Figure ground: The brain separates a focal foreground object from its background, and some images can flip which part reads as foreground. Use clear foreground and background separation so the product or focal point is immediately readable. [L0755.008]
  • Law of Pragnanz: The brain reduces complex or ambiguous shapes to the simplest known shapes. Adding color or separation can reveal the simple parts inside a complex shape, which helps when designing logos and icons. [L0755.011]
  • Overlapping elements link them more strongly than simply placing them near each other, so a deliberate overlap can signal that two items form one unit. Use overlaps sparingly, because an overlap that crowds the layout reduces readability. [L0755.032]

Depth and shadows

  • Shadows add depth to show importance: a larger, darker and broader shadow below an element makes it look further above the background, which signals higher importance. This follows Google's Material Design logic, and it is often used for sales tags and other key elements. [L0755.028]
  • In Canva, a drop shadow can be set with a lower opacity and a blur to create a lifted, subtle depth effect. Heavy shadows look dramatic, so use them sparingly and only where the lift is meant to signal importance. [L0755.029]
  • Use a three-dimensional layer approach on top of the flat 2D hierarchy: bring important elements forward with shadows and push secondary elements back. This adds a further way to show importance beyond size and color. [L0755.030]
  • Drop shadows create visual hierarchy by making key elements stand out, such as a satisfied-customers counter. [L0341.018]
  • Use a shadow or gradient behind text or key elements to create visual hierarchy and make text easier to read. Use a white gradient behind dark text and a dark gradient behind white text. [L0343.015]

Product graphics and templates

Quick image ad with Canva:

  1. Get a product photo.
  2. Remove the background, which can also be done inside Canva.
  3. Open Canva templates and search by product features or by offer type such as a free gift.
  4. Choose a template, place the product in it and add the offer text.
  5. Make small brand adjustments so the ad looks consistent with your store. [L0692.015]

Build a product graphic in Canva from a template:

  1. Search for the product type in Canva to find product templates.
  2. Open a template that fits the layout you want and replace the text and imagery in it.
  3. Copy a product image from the web and paste it into Canva so it uploads to your Uploads section.
  4. Open Edit photo and run the Background remover on the product image.
  5. Brush out any leftover background or unwanted parts with the brush control.
  6. Position the product near the center of the design using Alt or Option drag and the arrow keys, then add a shadow from the element shadow options.
  7. Add the offer text, group it, and move the group behind the product if it should sit beneath it.
  8. Apply your brand colors from the Brand Kit, and mute harsh colors by adding a gray tone rather than leaving them at full strength. [L0754.027]

Offer badge pattern: A short label such as "Limited edition" or "Free gift" is placed on a shape or band near the product, and it reads as an urgency or bonus signal. Pattern: [short scarcity or bonus word] + [product or offer noun], placed in the top or bottom corner of the image in a contrasting brand color. Example you can adapt: "Only 50 Left" and "Free Carry Case Included." [L0754.028]

Product layouts: Product layouts that work well usually have a product image, space for several short benefits, and a clear call to action. Find inspiration by browsing product templates and copying the structure, not the exact design. [L0754.029]

Them vs Us creative:

  1. Place your product cut-out on the right side of a two-column layout.
  2. Place the competitor product on the left side.
  3. Desaturate or grade the competitor background so it looks weaker than yours.
  4. Add a subtle pattern and a white gradient overlay on top for texture.
  5. Write the product benefits as short points next to your product. [L0343.004]

Photo framing: Use photo framing to show the product being sold. When a model's face takes up most of the image, reposition or reframe the photo so the product stays visible. [L0992.019]

Overlay text on product images: Graphic overlays with text on product images (offer, benefits, social proof) can be used in ad imagery. Google may stop showing an image that contains text, but the product is not banned, so the image is simply not shown. This was being tested as a way to create a strong hero section without scrolling. [L0353.013]

Ad breakdown: See the procedure under Layout and visual hierarchy. [L0755.040]

Color and Photoshop techniques

  • Mixing a color with tint, tone or shade rather than picking a new color keeps related colors consistent across a design. Muting a bright color by adding gray usually makes it easier to read next to brand colors. [L0754.060]
  • Photoshop gradient: The Gradient tool creates an editable gradient on any layer, and clipping it to an object applies it only to that object. Double-click a color stop to change the gradient color. [L0754.049]
  • Blend modes: In Photoshop, blend modes change how a layer interacts with the layers under it: Darken shows only the darker parts, Lighten shows only the lighter parts, and Color Burn or Color Dodge create texture effects such as a moon texture on a shape. [L0754.061]
  • Texture or detail overlay pattern: A texture image placed above a shape with the blend mode Color Burn adds darkness and detail while keeping the base color. Pattern: base shape + grayscale texture above it + Color Burn blend + mask to limit the effect to the area that needs it. Example you can adapt: a cracked stone texture over a dark badge, and a fabric weave overlay over a sweatshirt product shape. [L0754.062]

Color: meaning, mood and balance

Principles

  • Color sets mood, tone and brand perception, so pick the base color first according to the meaning you want to convey and how you want the brand to be perceived. Choose the color meaning deliberately before building the rest of the palette. [L0659.001]
  • Warm colors (red, orange, yellow) feel energetic and attention-grabbing, while cool colors (green, blue, violet) feel calm, relaxing and cooling. Use this split to decide which family fits the emotional effect of a design. [L0659.002]
  • Use a limited number of key principles when building a palette: choose a color for the brand meaning, use neutral colors as backdrops, control contrast with tints, tones and shades, choose a typography that suits the brand, and test colors and type in action. [L0659.044]
  • Adding white, gray or black to a palette prevents colors from clashing and looking like a rainbow. Adjusting how much white, gray and black you add is one of the most effective ways to balance a design. [L0659.023]

Color terms

  • Hue is the base color, and a color can change in lightness through tint (white added), tone (gray added) and shade (black added). Tint, tone and shade are the main tools for adjusting a palette to create balance. [L0659.021]
  • Chroma measures how pure or saturated a hue is, with higher chroma giving more intense colors. Saturation is about removing color, which makes the color look washed out, as opposed to adding white, gray or black. [L0659.022]
  • Hexadecimal color values use six characters, with the first two for red, the middle two for green and the last two for blue. Many page builders, including Shopify page builders, use RGB values with three numbers from 0 to 255 instead. [L0659.030]

Individual colors

  • Red: Red is an intense attention color that can overwhelm quickly, so use it sparingly as an accent. Brighter reds feel more energetic, while darker reds feel more powerful and elegant. [L0659.003]
  • Red across cultures: In Western markets red signals anger, alert, danger and passion, in China it signals prosperity and happiness, and in some Eastern cultures it is worn by brides. Check the target market before using red as a main color. [L0659.004]
  • Orange: Orange signals vibrancy, energy, change and creativity, and it draws attention without the aggression of red. Its typical use is for buttons, alerts and clickable elements, and it can look friendlier and more inviting than red. [L0659.005]
  • Accent colors: An accent color should appear only in small pieces such as links, buttons or a title detail, not flood the whole page. Used this way it draws the eye to clickable or important items. [L0659.006]
  • Yellow: Yellow is the brightest, most energizing and warmest color and is associated with happiness and cheerfulness. Softer or muted yellows feel calm and neutral and are often used as a gender-neutral choice. [L0659.007]
  • Yellow across cultures: Yellow is associated with deceit and cowardice in some contexts, and with hope in Egypt, courage in Japan and merchants in India, so meaning varies by country. Darkened yellows and golds can look antique. [L0659.008]
  • Green: Green stands for growth, new beginnings, renewal and abundance, and it is strongly linked to wealth and stability. Dark green signals affluence and prosperity, bright green feels energizing, and muted olive green feels natural. [L0659.009]
  • Green can also signal envy or jealousy and a lack of experience. It combines the calming effect of blue with the energy of yellow, which makes it suitable for health, well-being and nature-related designs. [L0659.010]
  • Blue: Blue meaning depends strongly on hue and shade: light blues feel refreshing and friendly, bright blues feel energizing, and dark blues signal strength, trust, reliability and peace. Dark blue is therefore a common choice for finance-like or trust-focused brands. [L0659.011]
  • Purple: Purple combines red and blue, so it carries both energy and calm. Dark purple signals royalty, wealth and luxury, while lighter purples like lavender feel romantic, and purple is associated with creativity and imagination. [L0659.012]
  • Purple is the mourning color for widows in Thailand, so check cultural meaning before using it in a target market. [L0659.013]
  • Black: Black is the strongest neutral color and is associated with power, elegance and formality, while negative associations include mystery, death and mourning in many Western countries. Black is widely used for typography and for making images stand out against it. [L0659.014]
  • White: White stands for cleanliness, purity, simplicity and health care, and it works as a neutral backdrop that lets other colors shine. White is worn by brides in the West and represents morning in much of the East, so consider the target audience. [L0659.015]
  • Brown: Brown is hard to balance because of its lightness and darkness, and it is associated with earth, wood, stone, reliability and warmth. Avoid using heavy brown in large amounts, since it can make a design look heavy. [L0659.019]
  • Ivory and beige: Ivory is a tinge of white with cream, and beige is a tinge of brown; both act like grays or neutrals and are used in a similar way to black and white in different shades. [L0659.020]

Neutrals and grays

  • Neutral colors take on the characteristics of the colors around them: gray next to blue feels cooler and gray next to red feels warmer. Use neutrals as backdrops that are shaped by the accent colors placed beside them. [L0659.016]
  • Charcoal gray instead of pure black softens contrast on screen, making white text easier on the eyes while keeping strong readability. Light grays can replace whites and dark grays can replace blacks in layouts and typography. [L0659.017]
  • Gray text on white backgrounds is easier to read and softer than black on white, but contrast must still meet web accessibility standards so that users with weaker eyesight can read the content. [L0659.018]
  • For section backgrounds, use an extremely light tint of the palette color rather than a dark gray, because heavy gray behind colored elements looks jarring. A near-white tinted background separates sections gently against the text. [L0659.041]

Palette patterns

  • Analogous: Analogous palettes use colors that sit next to each other on the color wheel and feel harmonious. Beginners should use analogous palettes, adjusting tint, tone, shade and chroma, because they are the easiest way to build balanced designs. [L0659.024]
  • Monochromatic: Monochromatic palettes use one hue with different tints, tones, shades and chroma levels. They are easy to build and reliable for clean designs. [L0659.025]
  • Complementary: Complementary colors sit opposite each other on the color wheel and create strong contrast. Use one as an accent and not in equal amounts, and tone it down with gray, white or darkening to avoid a jarring result. [L0659.026]
  • Complementary colors must be used carefully, since a complement of a pale pink can clash badly. Darkening or muting the complementary color, or using it only as a small accent, can make it work. [L0659.042]
  • Blue and orange are a complementary pair that works well when orange is kept as an accent against blue. Keeping the design built on similar colors first and only then taking bold contrast steps produces the best results. [L0659.043]
  • Triadic: Triadic color schemes use three colors evenly spaced on the color wheel and are very difficult to get right, so beginners should avoid them. [L0659.027]

Build a palette:

  1. Choose a base color that fits the meaning you want to convey.
  2. Pick neighboring colors on the color wheel or variations of the same color.
  3. Use the color wheel in the design software to add white, gray or black.
  4. Move the color up (towards white) to lighten, down (towards black) to darken, and diagonally from top right to bottom left to add gray.
  5. Test the palette until it looks balanced. [L0659.028]

Tool: Adobe Color can create palettes from color wheel options such as analogous, monochromatic, triad and complementary, and it saves palettes as color schemes. Search by a theme such as nature to generate starting palettes. [L0659.029]

Canva palette suggestions: Canva can read the colors of a placed photo and suggest matching palettes, so product or brand colors can be applied to a layout quickly. Use the suggested palette as a starting point and adjust it to your brand colors. [L0343.042]

Buttons and backgrounds

  • Button colors should stand out against the background and be darker and more saturated than surrounding colors, while avoiding pure black because it is too heavy. A call-to-action such as "Shop now" should be the most noticeable element to support visual hierarchy. [L0659.040]

Apply the palette in practice (procedure):

  1. Start with a color palette in Adobe Color or a similar tool.
  2. Download a font pair, such as a serif title font and a sans-serif body font.
  3. Place a title, subtitle and body text in the design software and set sizes.
  4. Use dark text on white backgrounds, keeping the text readable without being too contrasting.
  5. Lighten or darken colors on dark backgrounds, such as adding white to make text punch out.
  6. Test the palette in action before committing. [L0659.038]

Start simple: Build from similar colors first and only then take bold contrast steps. [L0659.043]

Typography

  • Google Fonts: Google Fonts provides free font families and pairings that can be downloaded as full families. Use them to test typography pairings alongside a color palette before building designs. [L0659.031]
  • Serif and sans-serif: Serif fonts have small decorative strokes called serifs and often look traditional or formal, while sans-serif fonts are cleaner, simpler and more minimalistic. Sans-serif fonts are usually more readable for body text, while serifs often work well for titles. [L0659.032]
  • Font pairs: Font pairs can combine two serifs, two sans-serifs, or a serif with a sans-serif, and a common pattern is a serif for titles with a sans-serif for paragraphs. Each font has its own voice, so choose fonts that match the desired look and feel. [L0659.033]
  • Choose a font pair (procedure):
    1. Identify the niche or desired mood.
    2. Search blogs, font library catalogs or design platforms for font pairings that fit that niche.
    3. Download and test the pairs next to each other.
    4. Adjust font weight, size and layout until the look matches the intended feeling. [L0659.034]
  • Use a plain sans-serif font such as Open Sans for readable ad copy, and replace it with your brand font if you have one. [L0341.011]
  • Use a line height of 1.5 times the font size for good readability and a balanced layout. Most website builders apply this automatically, but adjust it when text feels cramped after increasing the font size. [L0659.035]
  • Font weight affects importance and mood, with heavier weights usually used for titles. Letter spacing should be wide enough for easy reading and should not be too condensed. [L0659.036]
  • Ascenders are the upper parts of letters like f, h and capitals, while descenders are the lower tails of letters such as g and p. Knowing these terms helps adjust line height and text spacing. [L0659.037]
  • In Canva, the logo and headline fonts should match the store: use the heading font for headlines and the body font for body text. [L0992.012]
  • Change any all-caps template text so it fits the brand style. [L0992.012]

Text legibility on mobile and over images

  • Mobile first: Text placed on an image shrinks when the ad is shown on mobile, so keep headlines large and short. Most people see ads on phones, and a very wide banner gets squeezed into a small, thin strip. Square or near-square images keep overlaid text readable. Check text legibility at phone size. [L0341.039, L0343.018]
  • Gradients behind text: To keep overlaid text readable, place a white gradient behind dark text and a dark gradient behind white text. [L0341.017, L0343.015]
  • Dark and light backgrounds: On dark backgrounds, lighten the text color by adding white or more color, because dark text on a dark background is unreadable. On light backgrounds, darken the text instead of using pure white to keep it legible. [L0659.039]
  • Text over a busy photo or video in Canva:
    1. Align the text block to the left edge so it looks clean.
    2. Change the text color to white (or black on light backgrounds).
    3. Add an effect such as a lift or a dark drop shadow, then blur it slightly and lower its opacity if it looks heavy.
    4. If the text is still hard to read, add a gradient graphic (search "gradient" in Canva graphics) that goes from a solid color to transparent behind the text, using black for white text and white for black text, and lower its opacity if needed. [L0755.027]
  • Mistake: Text placed over an image with both very light and very dark areas, such as bright sky above dark buildings, becomes hard to read. Before adding text, check the tones under the text block and fix the problem with a gradient or shadow if the contrast is low. [L0755.039]
  • Text limit: Keep text under about 20% of the image. Above that, Meta still runs the ad but limits its reach or raises the cost per result. [L0649.035]
  • Snapper's grid feature shows how much of the image the text covers, so you can check the text limit before publishing. (Older advice, 2021-22.) [L0799.007]

Packaging and print

Packaging copy prompt:

I'm making custom packaging for [PRODUCT, for example a fleece legging] shipped in a [PACKAGING TYPE, for example a poly mailer, 10 x 13 inch]. Attached are inspiration images of other packaging designs and our brand guideline. Based on our brand voice, give me options for words to print on the packaging in these groups: 1) inside flap or inner message, 2) texture or product callouts that describe benefits in plain, non-technical words, 3) short playful brand-voice lines. Keep every line short, on brand, and suitable for [SEASON OR THEME, for example the cold season]. Then recommend one line for the front and one line for the side, with a short reason for each.

[L0884.021]

Mailer decision case: The lesson chose a 10 x 13 inch poly mailer for leggings and a fleece product because apparel ships well in this format. The packaging design was made for that exact size, and the same process applies to any product type. [L0884.046]

Free-gift ebook visual system: A free-gift ebook can use a consistent visual system: a simple motif repeated on the cover and in the diagrams, a serif font for headings, a sans-serif font for body text, and a monospace font for small labels. This gives a calm, editorial look that suits a health or wellness topic. [L0862.030]

Imagery, emotion and brand fit

  • Emotional messages can be carried by imagery instead of long text, so image and video creatives can lead with feeling and leave the specifications for later. Audiences differ in how they think, some in words and some in pictures, so combining copy with strong visuals reaches more buyers. (Older advice, 2021-22.) [L0611.008]
  • Use 4:5 for feed image and video ads, or 9:16 for TikTok-style vertical video. These are the recommended formats for image and video ads. [L0648.023]
  • Applying brand guidelines to a multi-format template:
    1. Select all artboards in the template and copy them (Cmd+C).
    2. Open the brand guidelines document and paste the artboards there, so all work happens in one file.
    3. Select an element, then pick the brand color from the Selection colors panel; click See all colors if the palette is needed.
    4. Shift-select the artboard titles to apply the same color change to all selected artboards at once.
    5. Select all headline text and switch it to the heading font; select all body text and switch it to the body font.
    6. Change any all-caps template text so it fits the brand style.
    7. Drag the matching logo version (for example the black or black-and-white logo) from the logo panel onto each artboard and align it with the center tool.
    8. Duplicate the brand photos, use Remove Background for a cut-out effect, and adjust brightness and saturation in Photo Filter to match the brand energy.
    9. If a photo crops off the model's head, use Remix > Extend Photo with 9:16 vertical format, then regenerate and remove the background if needed.
    10. Move the photo so the product is clearly visible instead of the face.
    11. Rewrite all copy using the brand voice in ChatGPT, then paste the chosen options into each artboard.
    12. Review each draft for brand fit, then repeat the same process for the next template. [L0992.012]

AI-generated and edited images

  • AI-generated images are often restrictive to edit after generation, so the layout of text and elements may need to be changed in a design tool. Canva can edit an image generated by an LLM or image model, so the workflow does not need to restart in the chat each time. [L0882.029]
  • Edit an AI-generated image in Canva: Open the image in the editor and use Edit image, then Magic Layers to split it into editable layers. Layers can then be removed, moved, swapped for another picture, or given new headline text. [L0882.030]
  • Canva Magic Layers separates an AI-generated image into editable layers. It is used to remove elements, reposition them or replace headlines and offer text without regenerating the whole image. [L0882.031]

Seasonal and holiday ads

Canva steps for a holiday Instagram ad:

  1. Create a design with the Instagram Post size 1080×1080.
  2. Paste the product image with a white background.
  3. Remove the image background with Magic Background Remover.
  4. Add a seasonal background from Magic Media, for example a spooky Halloween background.
  5. Add the text and apply Text Effects. [L1105.001]

Canva is an online design tool for building social media ad images. Its Magic Background Remover and Magic Media features can cut out a product photo and add a seasonal background quickly. [L1105.002]

Procedure for a holiday-themed ad and email image in Canva:

  1. Click Create a design and choose the Instagram post template, a square at 1080 x 1080 pixels. Use it for Facebook, Instagram, and Google remarketing.
  2. Paste a product image from your store into the design and enlarge it.
  3. Click BG remover to remove the white background. This feature requires Canva Pro.
  4. Scroll to Magic Media and enter a prompt such as "spooky Halloween backgrounds" with the filmic style. Click generate image, which returns four variations.
  5. Choose a background, go to Layer, select Send to back, and enlarge it to fill the canvas.
  6. If the background competes with the product, lower its transparency.
  7. Click Text, add a text box, search for a themed font such as Halloween, and set it large.
  8. Paste the promotion text, for example "10% off Halloween", and use Effects > Background for a behind-text box.
  9. Click an element, then Animate, and choose a motion such as moving up.
  10. Click Share and download as an MP4 for Facebook remarketing ads, or as a GIF to embed in emails so the animation plays in the inbox. [L1115.081]

Layout and visual hierarchy

  • Keep creatives clean, clear and simple, because simplicity beats finesse. Unpolished design is acceptable only when it is deliberate or native to the platform, such as memes that match the style of the feed. [L1348.008]
  • Learn five basic graphic design skills for ads: spacing (separating elements), alignment, grouping related items, color and balance. Spacing and grouping are among the most common weaknesses in beginner creatives. [L1348.009]
  • Use a larger opening block or a bold highlight to start the reader. Large opening type draws readers in, and smaller body type later does not stop them once they are reading. Use a bold guarantee or a key claim as the lead-in. [L1366.063, L1366.078]
  • Leave no wasted space in direct response ads. Every line should carry a selling point, and avoid borders or decorative blank areas. Include a coupon as a reminder device when the reader needs to act later. [L1261.065]
  • Returns scale with ad space. Halving a full-page ad's copy area on the same page roughly doubles cost per reply, and doubling the space roughly doubles replies. Justify any extra space or larger type with a traced test before buying it. [L1261.142]
  • Use normal, readable body type in the style of newspapers and magazines. Larger type does not increase response and costs more; louder, bigger type adds cost without adding sales. [L1261.064]
  • Use graphic devices that add voice to the copy, not decoration: bullets, numbering, underlining, bold type, varied type, simulated handwriting, boxes, asterisk lines, yellow highlighter overprint, shaded screens, photographs with text wrapped around them, and many subheads. The copywriter should choose which devices to use and where, not leave that to the artist. [L1370.050]
  • Default to a clean layout for ads. Illustrated letters with photos, charts, cartoons and deliberately messy handwriting can outperform neat letters in split tests, so test a busy version before rejecting it as unprofessional. [L1348.008, L1261.064, L1370.051]
  • For tall, narrow display formats, stack two product images with the same copy in the middle to use the extra space. This avoids empty areas in the layout. (Older, 2021-22.) [L1169.010]

Color and typography

  • Use color only where tests show it pays, such as for food, dessert or fruit that looks more appealing in color. In general, black and white ads perform as well or better. Color chosen to be attractive for its own sake rarely pays. [L1261.072]
  • Pick fonts that fit the brand. Niche-specific fonts (for example Font Space for themed fonts, checked for commercial use) or Google Fonts for readability are both options. [L1363.027]
  • Keep text short and well-spaced. Avoid squeezed lines and cramped line heights. [L1363.027]
  • Comment-card style reference (Facebook-style comment card in the lesson): light gray background, red-accented text and links, and a soft drop shadow, with the card slightly overflowing the image edge for depth. Open Sans Bold was suggested to match the look, but this was an untested guess, so compare against a real reference before copying the style. [L1348.030]

Pictures, art and reuse

  • Use pictures only when they sell better than the same space filled with text, such as showing the product itself or people the buyer admires in a setting they desire. Decorative or eccentric pictures take attention from the offer and should be avoided. [L1261.069]
  • Example: a striking picture that increased an ad's space by 50 percent raised cost per reply by the same 50 percent, with no extra sales. The added cost produced no benefit, so the picture was removed. [L1261.070]
  • Use expensive art only when tests show it earns more than cheaper art. Mail-order advertisers often get good results with simple illustrations. Art cost is small compared with the cost of space, so verify its value with a test. [L1261.071]
  • Pictures can account for one-third to one-half of an ad campaign's cost, so they need the same proof as copy. Some advertisers paid up to 2,000 dollars per drawing; that premium is justified only when a test shows expensive art beats cheaper art. [L1261.155]
  • Reuse the same proven picture across ads when possible. New customers rarely remember a picture from an earlier ad, and repetition lowers cost. Change the picture only when a test shows a new one wins. [L1261.073]

Canva, Snappa and workflows

Tools

  • Snappa and Canva are the recommended tools for creating ad images in multiple sizes. Snappa is used for all ad images, including video cover images. Canva is a long-established alternative. (Older, 2021-22.) [L1238.006]
  • Canva can make ad creatives from basic color theory, balance and graphic design knowledge. Photoshop is not required for good spacing, color and clear messages. [L1348.017]
  • Canva can make a checkout banner at 1500 x 300 px with a logo, privacy/secure icons and payment processor logos. [L1260.026]
  • Canva has a typical Facebook-style comment design, but Facebook comments are harder to recreate, so a designer may need Photoshop for the background fill and text replacement. [L1348.017]
  • If you do not want to design retargeting images yourself, outsource to freelance graphic designers on Fiverr, Upwork or freeup.com. Choose designers with experience in display network or Facebook ad images. (Older, 2021-22.) [L1238.006]

Resizing one master design in Snappa (older, 2021-22)

  1. Open the finished base design. It can be started in any size.
  2. Click Resize in the left menu.
  3. Choose a pre-made size or enter a custom graphic size in width and height in px.
  4. When asked whether to override the current graphic or open a new one, choose to open it as a new graphic. Snappa carries all elements over to the new template size.
  5. Move the text and other elements to fit the new shape. Increase text sizes where there is more space, and adjust spacing.
  6. Resize the product image to fit the layout and place it.
  7. Save the design, then Download it.
  8. For the next size, open the saved design and repeat from step 2. All elements carry across.

[L1169.023]

  • Most static display sizes share similar shapes, so after the first design, resizing takes little time. The tall filmstrip format needed the most re-spacing and took a couple of minutes. Design one master layout and resize it to save the most time. (Older, 2021-22.) [L1169.025]

Building a retargeting image set (older, 2021-22)

  1. Create one image for the new retargeting campaign.
  2. Produce that image in every required size for each network (Google static, Google responsive, Facebook, Twitter, Taboola).
  3. Upload the sized versions to the networks.

The goal is to load one image across all networks without redesigning it each time. [L1238.005]

Rebranding a landing page template for a new niche with Canva

  1. Open the product image in the browser (right click, Inspect) and copy the image URL. Remove the surrounding size and parameter text so the full-size image is loaded.
  2. Paste the image into Canva. Remove unneeded shadows and reflections.
  3. Pick fonts that fit the brand: niche-specific fonts (e.g. Font Space for themed fonts, checked for commercial use) or Google Fonts for readability.
  4. Upload font files to Canva. A zip containing the font files can be uploaded.
  5. Take colours from the product image using Canva's colour suggestions. Use a dark background for a sophisticated look.
  6. Keep text short and well-spaced. Avoid squeezed lines and cramped line heights.
  7. Export the three main graphics as PNG and compress them before upload. The lesson's examples were about 900 KB for two images.
  8. Upload the images to Shopify, then in PageFly choose the fonts and apply them to headings.

[L1363.027]

Banners and display ads

  • On Facebook, text covering the image may not exceed 20% of the image area. Text on Facebook images is optional, but can help text stand out when used. (Older, 2021-22.) [L1238.003, L1238.004]
  • To check the 20% limit, lay a grid overlay over the image in any image tool. [L1238.004]
  • A retargeting image has one job: stop the scroll on social media. It can do this by showing something the viewer has seen before, such as branding or a known product picture, or by standing out visually, for example with contrasting colors or something interesting. (Older, 2021-22.) [L1238.007]

Store graphics and hero images

  • A desktop hero image should be about 1600 px wide and 400 to 600 px tall. A taller hero image pushes the rest of the homepage below the fold, and the customer may never see it. (Older, 2021-22.) [L1310.006]
  • A checkout banner at 1500 x 300 px can carry the logo, privacy/secure icons and payment processor logos. [L1260.026]
  • Landing page graphics: export as PNG and compress before upload, then check the fonts in PageFly under the procedure above. [L1363.027]

Logo, profile and cover images

  • The profile photo is a square 1:1 portrait, direct to camera, warm and friendly. It must not look like a corporate headshot, stock-photo perfection or heavy polish. [L1475.015]
  • Never use a logo or a product shot as the profile picture. [L1475.015]
  • The cover photo uses a 3:1 aspect ratio and shows a warm, aspirational, editorial lifestyle scene from the character's world, such as a desk setup, gym or outdoor space. It may show the character or the scene alone. [L1475.016]
  • Profile and cover photos must contain no product shots, logos or text overlays. [L1475.016, L1476.056]
  • Putting a product shot or a discount graphic on the cover or profile photo immediately signals a brand and undermines the character. Keep those images strictly lifestyle and personal. [L1475.017]
  • Whitelist character page images use two formats: a square 1:1 direct-to-camera profile portrait, and a wide 3:1 lifestyle scene for the cover. [L1476.056]

Letterheads and printed samples

  • A picture on the letterhead must add essential background to the offer, such as the setting of a product's use, because decorative pictures alone may not help. Test a plain letterhead against a pictorial one before you commit. [L1369.075]
  • A colored nature scene printed across the top and one side of a letterhead doubled the orders for a book series offer compared with a plain letterhead. [L1369.076]
  • A small full-color reproduction of the product in the upper left corner of the letterhead added nearly 50 percent to the pulling power of one letter. [L1369.077]
  • When a business was built around one person, a photograph of that person on the letterhead added 10 to 20 percent to the pulling power of the letters. [L1369.078]
  • Tip a small sample of the product onto the letterhead, such as a fabric swatch for a coat or a leather swatch for luggage, so the reader can judge quality. A tactile sample is an effective attention-getter when the product has a visible quality. [L1369.079]

Video thumbnails

  • Thumbnails must be attractive and clearly show what the video will deliver, because YouTube rewards a higher click-through rate, as it does on other Google properties. (Older, 2021-22.) [L1511.012]
  • Preset YouTube sizes: Thumbnail 1280 x 720 px, End Screen 1920 x 1080 px, Channel Art 2560 x 1440 px. [L1169.028]

Text legibility on mobile

  • Put overlay text near the bottom of the frame and shrink it if it is too large, so the main action and the product stay visible. [L1427.073]
  • Check the layout on a phone-sized preview before exporting. [L1427.073]
  • Keep body type normal and readable, not oversized. Larger type adds cost without adding response. [L1261.064]
