19.10 Daily and weekly ad analysis workflow

Reporting layers: snapshot and funnel

  • Split the ad view into two column categories. Snapshot metrics show current performance at one point in time. Funnel metrics show how performance changes as viewers move from awareness to action. [L0008.002, L0640.001]
  • Snapshot columns: ad set name, last significant edit, daily budget, amount spent, result for the chosen objective, cost per result. [L0640.001]
  • Funnel columns: impressions, CPM, 3-second video plays, hook rate, hold rate, unique CTR, unique clicks, cost per click, adds to cart, purchases, conversion rate, ROAS. Together they show where the funnel wins or loses. [L0640.001]
  • Ad analysis builds a picture from inference, not from hard rules. Combine several metrics and reason from the evidence instead of judging by one number. Low spend and early data make single metrics especially unreliable. [L0640.006]
  • ROAS is not a core north-star metric for ad analysis on its own. It summarises return across all user actions and is a major driver of overall profitability. [L0640.013]
  • Purchases and ROAS matter most. Compare ROAS with break-even ROAS: above break-even is profitable, below is not. Soft metrics (hook rate, hold rate, CTR) are improved only when bottom-of-funnel sales are already profitable, or when weak sales need their cause diagnosed. [L0652.010]

Visual flags

  • Format the ROAS column with conditional colours (green, yellow or red) by ROAS value. This shows at a glance which campaigns are profitable against break-even. [L1476.042]

Auction data

  • Ads Manager shows auction overlap, audience saturation and auction competition for an audience. These show how much your own ad sets compete for the same people. [L0648.050]

Daily snapshot check

  • Review profit and loss and ad performance first thing each morning, before working through the task list. Knowing spend and profit before creative work starts keeps daily decisions tied to real numbers. [L1181.026]
  • Keep a reference document with ad metric guidance and annotated example images for the regular ad review. Turn any review action from that document directly into a task so it is not lost. [L1181.029]
  • Each day, review cost per add to cart, CTR, CPC, CPM and the engagement rate ranking for each ad. Cut losers early when soft metrics stay weak. Keep an ad running only if its signals improve from day to day. [L1195.049]
  • Amount spent is the strongest signal of where the platform sees opportunity, so read it before judging. Do not force budget into ads the algorithm is not funding; diagnose why they are not getting spend. Efficiency without scale is a vanity result (for example 10x ROAS on $5 of spend), so look for ads that are both efficient and funded. [L0613.045, L0613.062]

Metrics and targets

  • ROAS = Revenue / Ad spend. Example: 14,580 / 456 = 31.97, while the report showed a ROAS of 31. Confirm your sheet uses the same definition and rounding before setting targets. A ROAS target of 20x means revenue should be 20 times the ad spend. [L1236.022]
  • Blended ROAS is the right level for judging a campaign, together with product profitability. Low ROAS on a product with few clicks is a sample-size problem, not a verdict. [L0969.052]
  • Track ROAS and revenue against separate targets, because each can be missed independently. If ROAS is above target but revenue is below, the account is efficient but lacks volume: bid more aggressively and accept lower ROAS to gain sales. If ROAS falls, find the cause by checking which campaigns or ad sets lost efficiency. [L1236.008]
  • Compare each campaign's actual cost per sale, ROAS and cost per click with the calculated target values before changing anything. If the campaign performs below target, revise the bid, the price or the conversion rate. If it has room below target, you may be too cautious and can bid more aggressively. [L0686.019]
  • A campaign can be above breakeven and still have room to improve. If CPA is too high relative to the target, work on the funnel: ad creative, average order value and landing page. [L0445.010]
  • When CAC looks poor, the ad with the highest spend is still the main signal of what works, and it should guide the next step. Do not judge the whole account by one weak metric. [L1038.013]
  • For an awareness campaign without conversion tracking yet, judge performance on video views and cost per view instead of ROAS or revenue, which cannot be measured yet. Set a cost-per-view KPI, such as 0.05 USD, to check whether the cost of views stays in line. [L1236.023]

Analysis workflow

Ad analysis workflow, in order

  1. Review snapshot metrics first (daily budget, total spend, results, cost per result) to see if the ad is profitable. [L0067.038]
  2. Use funnel metrics to pinpoint where the problem is (attention, interest, desire or action stage). [L0067.038]
  3. Use the ADA framework (named AIDA in L0640.007): check hook rate (attention), CTR (interest), conversion rate (desire), ROAS (action). [L0067.038, L0640.007]
  4. If a weak area is identified, do a creative review against the checklist. [L0067.038]
  5. Form a hypothesis about improvement. [L0067.038]
  6. Create a test ad with a single change, keeping the control. [L0067.038]
  7. Run it for 3 days minimum. [L0067.038]
  8. Evaluate lift. [L0067.038]

Protocol for comparing ad sets

  1. Compare interests against each other using funnel metrics, starting at the top of the funnel (hook rate / attention). [L0640.015]
  2. Move down to interest (CTR), then desire (add to cart, conversion rate) and action (ROAS). [L0640.015]
  3. Note where each ad set falls behind and focus improvement effort on the weakest stage. [L0640.015]

Meta video analysis, in order

  1. Spend distribution: rank ads by amount spent, compute each share of total, utilisation against budget, spend per day and delivery status. Measure how concentrated spend is in the top 3 ads. Check whether new ads are ramping or starved. [L0613.048]
  2. Delivery status: count ads by status, the share of spend on Active ads, and why Learning Limited ads are stuck (audience too small, budget too low, or creative underperforming). [L0613.048]
  3. Ad age: bucket ads and compare performance by bucket. [L0613.048]
  4. Efficiency: compare ROAS and CPA against targets and segment them. [L0613.048]
  5. Funnel: build the cost cascade from CPM to cost per purchase and the stage conversion rates, and find the weakest stage per ad. [L0613.048]
  6. Landing pages: group performance by destination link to see whether a weak page drags down good creative. [L0613.048]
  7. Creative: compute hook rate, retention between marks and completion; find drop-off points. [L0613.048]
  8. Identify the one primary constraint. [L0613.048]
  9. Give next-best-dollar and next-best-week recommendations. [L0613.048]
  10. Write the executive summary and an ad-by-ad scorecard. [L0613.048]

Required inputs before analysis

  1. Brand name, product, price points, average order value, mechanism, primary audience, problem solved. [L0613.061]
  2. Campaign objective, bid strategy, cost or bid cap value, optimisation event, total budget and start date. [L0613.061]
  3. Target ROAS, target CPA, other efficiency targets, break-even ROAS and the current priority (scale, efficiency or both). [L0613.061]
  4. For each ad: hook in the first 3 seconds, main message or angle, format, talent, offer and CTA, and video length. [L0613.061]
  5. The metrics table for each ad. [L0613.061]

  1. Brand and campaign summary. [L0613.060]
  2. Spend distribution. [L0613.060]
  3. Efficiency. [L0613.060]
  4. Funnel diagnostic. [L0613.060]
  5. Creative performance. [L0613.060]
  6. Primary constraint. [L0613.060]

  10. Ad-by-ad scorecards. Each shows a score out of 100 split into spend signal, efficiency, funnel health and creative performance, a 2-3 sentence diagnosis, a recommendation of SCALE, OPTIMIZE, MONITOR or KILL, and specific actions. [L0613.060]

Reading the funnel

Stages

  • Read the funnel in three stages: attention (hook rate on the first three seconds), interest (click-through rate), and desire (conversion rate). A weak stage points to where the funnel breaks down. [L0950.017]
  • Use the AIDA framework to map the funnel: Attention = hook rate, Interest = click-through rate, Desire and Action = conversion rate (add to cart and purchase), and overall result = ROAS. Check the stages in order to find the weakest point. [L0640.007]
  • A high hook rate only shows that viewers pay attention. It does not prove that the traffic will buy. A lower hook rate can still convert well if the audience is the right one, so always read hook rate together with CTR and conversion rate. [L0950.080]
  • Judge a product first by hook rate (look rate) and CTR on ads. If both are low, change the creatives or accept that the product does not attract interest. [L1108.021]
  • Ad performance is judged first by CTR, CPM and CPC. Only if these look healthy should the store and funnel be analysed for weak points. [L1131.015]

Metric combinations

  • Strong attention + interest + desire = strong ROAS. [L0258.022]
  • Strong attention + interest + weak desire = normal ROAS. Suspect an ad-landing-page mismatch, technical problems, high shipping costs, low trust or high price. [L0258.022]
  • Weak attention + good interest + good desire = test new hooks, because the problem is not painful enough. [L0258.022]
  • Strong attention + weak interest + good desire = test messaging in the ad middle section or refine targeting. [L0258.022]
  • CTR and CPC good, but people rarely add to cart or conversion rate is very low: the ad is working, and the store or landing page is the problem. The fix is store messaging, offer or a more educational page, not a new ad. [L1131.016]
  • Hook rate and CTR good but sales missing: the problem is usually the store. Keep working on the store before dropping the product. [L1108.022]
  • CTR and CPC look good but sales are missing: the problem is usually the store, not the ad. Fix the website and offer first, then judge the product by ROAS. [L1173.037]
  • Strong CTR but no sales: the offer is usually the problem and should be changed before the ads are changed. [L1469.003]
  • On TikTok, a CPM of about $5 to $7 is acceptable. If CPM is fine but CTR is low, the problem sits at the creative level. Use CPM, CPC and CTR together to find which part of the funnel fails. [L1377.020]

Creative and iteration

  • When iterating ads: if an ad runs acceptably with one or two improvable elements, replace only those specific elements. If it performs poorly overall, test a completely new concept. [L0258.023]
  • In video retention, a large drop before the 25% mark points to a hook problem. A large drop between 25% and 50% points to weak middle content. A large drop between 50% and 75% points to a problem in the pitch or offer. Strong retention through 75% combined with low completion points to a weak call to action. [L0613.069]

Sessions and sales

  • Read sessions and sales for the same date range together. If sessions rise sharply (for example from about 50 to 100-120 per day) while sales fall to zero, the traffic or the page has a problem. The rise in sessions is not a success signal. [L0950.079]
  • Check whether certain weekdays consistently convert worse for the store before judging a test by one day. One operator found Wednesdays were weak for revenue, so tests should run across several days. [L1315.056]

Diagnosing the primary constraint

Mindset

  • Identify the one primary constraint. More budget does not fix a creative constraint, and more creative does not fix a funnel constraint. [L0613.062]
  • Treat creative as the main lever after Andromeda, and let the platform handle targeting, bidding and budget allocation. [L0613.062]
  • Diagnose the one constraint that blocks scale and focus there; the others are secondary. [L0613.056]
  • More creative does not fix a funnel constraint, and more budget does not fix a creative constraint. Choose the constraint from the symptoms below. [L0613.056, L0613.062]

Next-best-week output

  1. A priority table with focus area, expected impact, effort in hours and timeline (immediate, this week). [L0613.059]
  2. Next 24-48 hours: a kill list with rationale, a scale list with percentage increases, and a monitor list with triggers. [L0613.059]
  3. This week's focus by constraint. For creative: winning patterns, tests and number of new concepts. For efficiency: the funnel stage to fix, changes and test approach. For scale: audience expansions, placement tests and new angles. [L0613.059]
  4. If creative is the constraint, a brief with winning patterns, elements to keep, elements to avoid, and tests with hypotheses. [L0613.059]

  • Judge performance over a seven-day window rather than a single day. In one case an ad switched off after three days was still profitable at about 4 to 5 ROAS across seven days. [L1315.055]
  • Daily Facebook ROAS and profit can swing widely, so a single day or a few days can show a loss on a product that is profitable overall. Judge performance on a multi-day total, such as a 5-day report, before changing a campaign. [L0693.059]
  • Daily results swing up and down, so do not judge performance by single days. Review at a monthly level, and when comparing periods look at the last month against the month before to spot shifts. [L0719.025]
  • Judging performance from a single day's raw numbers is misleading, because daily conversion rates can swing far apart (for example 10.71% one day and 0.72% the next). Compare rolling windows such as the last 30 days against the 30 days before. [L1236.003]
  • Review window depends on business age. A new business should use month-to-month comparisons. A long-running stable business can use a three-month view. Longer data from a new business is skewed by weak early results and can give false conclusions. [L0719.026]
  • For analysis, a time frame of about 90 days is a common starting point for identifying broader business trends. For testing a recent change or a new campaign, a few weeks of data can be enough. The required period depends on traffic volume: high-spend accounts (around $1,000 per day) reach meaningful data faster than low-spend accounts (around $30 per day). [L0721.014]
  • A business that acquires a high level of traffic gets more meaningful data sets from shorter periods than a low-traffic business, so time-frame choices depend on traffic volume. [L0721.022]
  • Check CBO campaigns over a 4-day or 7-day window instead of day by day. Daily results at low budgets swing widely, so judging each day leads to wrong decisions. [L1107.008]
  • Google Ads reporting is not real time, and dates and times follow the account's time zone (GMT-05:00 Eastern Time in the example). Compare daily numbers using that time zone so the days line up. [L1391.022]
  • Sales come in bursts and can pause for a week or more without a clear cause. Do not panic over a slow stretch; check traffic and ad data first. [L1111.154]
  • Check whether certain weekdays consistently convert worse for the store before judging a test by one day. [L1315.056]
  • Account totals can hide weak parts. An account can meet its overall ROAS target while one ad group sits far below target. Break results down by campaign, ad group and ad to find the underperformers. [L1236.026]
  • When analysing a change in results, also check what changed in the business during that period, such as website design, new or removed products, or email marketing campaigns. These can explain the difference. [L0721.015]
  • Digging into every number in detail takes hours that may be needed elsewhere. Only do a deep dive when the headline ROAS is below target, and skip it if the account is profitable and on target. [L0719.027]
  • When reading early-stage data with low spend, be cautious about small differences (1-3%) in metrics like hook rate or CTR. They can easily shift with a few more impressions. Judge such differences only with enough data. [L0067.039, L0640.008]
  • The first-day number does not decide the outcome; the trend does. In the example, CPA across the first days fell from about $104 on day one to about $26 on day two, about $15 on day three and about $4 at the start of day four. [L1124.014]
  • Track Meta ad numbers from the first day of launch, because data guides every decision after launch. [L0491.023]

Kill timing and cutting waste

  • When a campaign is unprofitable, check the ad set and ad level first. One audience or creative can drag down the whole campaign, so kill that ad set or creative. [L0376.021]
  • Cut losers early when soft metrics stay weak. Keep an ad running only if its signals improve from day to day. [L1195.049]
  • Ad age and fatigue: use the age buckets as the trigger for review (see Diagnosing the primary constraint). [L0613.054]
  • Video retention drop-offs show where to fix or cut. [L0613.069]
  • After auditing two weeks of ad spend, about 35 percent of spend was bloat that did not lead to sales. Cutting it and reinvesting into the remaining 65 percent that performed is a practical way to reduce waste. [L0803.035]
  • Remove a country from targeting only after it has spent enough without results, and test the interests that produced sales. [L0349.023]
  • Look for places that waste money to cut, and for places that work to spend more. [L0801.135]

Country, age and gender breakdowns

Breakdown procedure after changing the store and pausing ads

  1. Return to Ads Manager and use Breakdown on each ad. [L0773.025]
  2. Break down by gender. [L0773.025]
  3. Break down by age; compare ranges such as 18-34, 45+ and 65+, and track results in a spreadsheet. [L0773.025]
  4. Break down by country when targeting several countries. [L0773.025]
  5. Break down by placement. [L0773.025]
  6. Focus budget on the best-performing gender, age and countries, and relaunch new ad sets with those settings. [L0773.025]

Country checks

  • Verify that targeted countries actually receive spend. If one country gets no visits despite being set up, reduce or test the countries separately. [L0349.023]
  • When targeting several countries, a country with high spend and low CTR or high CPM is a sign to drop or pause it. The US in Q4 is an example where CPM can be high. Countries with cheap sales (for example one sale on a 3 USD spend) can be prioritised. [L0773.026]
  • If a store's reported CPC is high but CPM is low and CTR is high, one country is usually driving the cost. A per-country breakdown reveals which one is inflating the CPC. [L0773.027]
  • Checking where spend goes after 4 to 5 days: (1) Open the ad account. (2) Use the breakdown button at the top right to see spend by country. (3) If a country has high spend, high CPM and no sales, exclude it from future testing and move budget to the other markets. [L0691.024]
  • Find the best-converting country: (1) Open the sessions report in your Shopify account. (2) Add filters for country. (3) Compare the conversion rate per country. (4) Move budget to the countries that perform best and start a new campaign that targets only the strongest country. [L1176.019]
  • Case: a product test with a 200 USD ad budget produced only 2 sales. The country report showed both sales came from Australia on only 7 USD spend, while the rest of the budget went to the US and UK. The recommendation was to start a new campaign targeting only Australia, because its conversion rate was good. [L1176.020]
  • To compare countries after launching ads, break down store sessions by country in the Shopify analytics report and add the needed columns. Then compare the conversion rate for each market to decide where to scale. [L1185.043]
  • Budget followed the wrong market: most spend went to Australia while the UK had better sales. In a test case 20 spent on UK ads produced six sales, so the UK deserved the larger share of budget. Compare sales and conversion rate per market before deciding where to spend. [L1316.006]

Age, gender and buyer data

  • Gender and age breakdowns reveal where to shift budget. In the example, women aged 45 to 54 performed very strongly, women aged 25 to 34 had lower revenue and a weaker ROAS, and men aged 45 to 54 reached a ROAS of 11.68, above target, which justified bidding more aggressively on that segment. [L1236.012]
  • Of 20 sales from a jewellery test, 18 came from the UK and all buyers were 35 or older, with slightly more women than men. Look at the country, age and gender of buyers to refine the next interest and audience choices. [L1439.046]
  • Check sales data, including the customer's country, age and gender, after each spike to decide the next target audience. Sales by country can reveal an unexpected market. [L1439.047]

Automated and scheduled reports

Report principles

  • A useful paid-traffic report works in two ways: the data needed for a decision should appear within a few seconds, and the insight should stand out without scrolling through raw lists. Reports that need manual effort to pull and format cost time every month and slow down decisions. [L1236.001]
  • Getting a report should take about one second. If building it means downloading data, pasting it into a spreadsheet and formatting it by hand, the setup is wrong. For example, a one-hour manual report done four times a month costs four hours, or up to eight hours if it takes two hours each time. [L1236.002]
  • Build reports from high level to low level: account, then campaign, then ad group or ad, then device and other dimensions. Each step narrows the problem so the optimiser knows where to act without digging through the account. [L1236.019]
  • A good dashboard shows what to manage and the overall health of campaigns, keywords and ads without requiring a login to the ad platform. Both native platform dashboards and spreadsheet dashboards can refresh daily, weekly or even every hour. [L1236.021]
  • AI can analyse ad data, predict trends and suggest adjustments. Using this data is meant to replace decisions based on gut feeling when scaling profitably. [L1459.015]

Automated daily reporting (example)

  • Every morning, pull the previous day's metrics from the ad account (ad spend, impressions, conversions, ROAS), summarise them in plain language, post the summary to a Slack channel, simultaneously append the raw numbers to a master Google Sheet, and automatically update the creative testing spreadsheet. This generates a live executive dashboard that updates itself without you reviewing data. [L0287.019]
  • Zapier connects apps and can automate tasks between them, for example pushing new Shopify orders into a spreadsheet every day. It can potentially move TikTok data into a spreadsheet, but this has to be verified. [L0561.015]

Google Sheets with Supermetrics

  • Supermetrics is an add-on for Google Sheets that pulls ad platform data (such as Google Ads and Bing Ads, and Facebook Ads) into a spreadsheet. A dashboard can combine several platforms, for example summing Google and Bing spend in one top-level cell. It is the recommended tool for building reporting dashboards in Google Sheets. [L1236.005]
  • Account-level Supermetrics setup:
    1. Open Google Sheets and start the Supermetrics add-on. [L1236.014]
    2. Select the AdWords (Google Ads) account and sync it. [L1236.014]
    3. Start at the highest level and work downward. [L1236.014]
    4. Set the date range to the last four months, including the current month. [L1236.014]
    5. Add the key metrics: costs, clicks, conversions, conversion rate and revenue. [L1236.014]
    6. Break the data down by month and show all-time values. [L1236.014]
    7. Sort the output and insert it into the sheet. [L1236.014]
    8. Add a custom metric, cost per view (cost divided by video views), when video campaigns run. [L1236.014]

  1. Choose the last 30 days. [L1236.018]
