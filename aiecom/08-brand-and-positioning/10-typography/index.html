8.10 Typography

Serif and sans-serif basics

  • A serif is a small decorative line or flourish at the end of a letter stroke. Times New Roman has serifs. A sans-serif font has no serifs ("sans" means "without") and looks modern and clean. [L0317.012]
  • A serif font has small flicks at the ends of its letters. A sans-serif font does not. [L1363.061]
  • Sans-serif fonts create a clean, modern look. Serif fonts suggest tradition and formality. [L1071.014]
  • Font classes differ in feel:
    • Monospaced fonts give every letter the same width.
    • Script fonts imitate handwriting.
    • Display fonts are decorative faces meant for headlines rather than long text.
    • Choose the class based on the mood and where the text will be read. [L0659.048]

Choosing headline and body fonts against the logo

  1. Identify whether the logo uses a serif or a sans-serif font. [L0317.012]
  2. Select the opposite style from the logo:
    • If the logo uses sans-serif, choose serif fonts for headings and body text.
    • If the logo uses serif, choose sans-serif for headings.
    • This contrast creates a modern, professional, and visually pleasing result. [L0317.013]

Font pairing

  • Pair a serif font for headings with a sans-serif font for body text, or the reverse, whichever fits the brand best. Replace the template's fonts on all headings and all body text in one batch. [L0992.003]
  • Use one heading font and one body font, with one or two weights each. [L1309.052]
  • Use one high-quality font consistently across the whole store. Consistent colour and font together build brand value. [L1345.042]
  • Pick one typeface family and use it consistently across the brand. [L1071.014]
  • Use default fonts for a store unless a designer is working on it. Mixing many fonts quickly makes a store look messy. (Older: Source A, 2021.) [L0853.045]
  • Use one heading font across the site. A second font for headings is allowed only if it is still readable and not fancy. A bold, chunky font was chosen for the example store to suit its target market. (Older: Source B, 2021-22.) [L1371.015]
  • Source conflict: some units say to use one family throughout the brand [L1071.014, L1345.042]. Others say to use a serif and sans-serif contrast between headings and body [L0317.013, L0992.003]. The sources do not state when to use one family and when to use a contrasting pair. Both approaches are given here as the sources state them.

Procedure to find pairings for a niche:

  1. Search the niche name together with "font pairing" or "luxury font". [L0659.051]
  2. Look at real projects on design platforms such as Dribbble and Behance. [L0659.051]
  3. Use those projects to see how fonts behave together in a finished design. [L0659.051]

Font weights and emphasis

  • Some serif families have no bold weight. A title that needs heavy emphasis should be set in a second typeface with a bold weight. [L0659.046]
  • Check the available weights of a family before committing to it for headlines. [L0659.046]
  • Body font setup in the example store (older: Source B, 2021-22):
    • Use Helvetica as the body font at 18 px, because it is common and easy to read.
    • Set the alternate bold font to Helvetica Bold.
    • Adjust letter spacing or heading fonts to taste. [L1371.013]

Readability and body size

  • Set the base font size to at least 18 px for all body copy. Smaller text is hard to read, and search engines do not favour it. (Older: Source B, 2021-22.) [L1371.012]
  • The font size scale setting is the simplest way to adjust readability across the store. [L1309.052]
  • Choose simple, standard, readable fonts. Avoid decorative, cursive, very thin, or unusual fonts such as Lobster, because they are harder to read. (Older: Source B, 2021-22.) [L1371.014]
  • Text must be clean, easy to read and balanced in structure. [L1044.027]
  • Readability limits decorative fonts:
    • Calligraphic or runic fonts that are hard to read should be used only for accents or images, not for body text.
    • Choose a readable serif (classic, with small flicks) for headings and for text where needed. [L1363.026]
    • Avoid hard-to-read decorative fonts for body text. [L1363.061]
  • Mistake: do not use Comic Sans for website branding. It looks unprofessional, and poor-looking typefaces reduce trust in the store. [L1044.028]

Niche fit

  • Typefaces should fit the niche:
    • Luxury products use luxury fonts.
    • Friendly or playful brands use playful fonts.
    • Corporate or nature brands use clean fonts. [L1044.027]
  • Fonts must match the niche's brand. Playful fonts suit baby or pet products. Elegant serif or thin luxury fonts suit jewellery. A font that changes between niches changes the brand feel drastically. [L1363.023]
  • Luxury typography has moved away from calligraphic scripts toward high-contrast serifs. These combine very thin and very thick strokes with sharp terminals. The style reads as premium in most niches that target affluent buyers. [L0659.050]

Licensing and Google Fonts

  • Use commercially licensed fonts. Check the licence of fonts from Font Space before commercial use. Some fonts, for example ones copied from famous brands, cannot be used commercially. [L1363.024]
  • Prefer Google Fonts for web pages. They are widely available in browsers and render reliably. [L1363.025]
  • If a non-Google font is not installed on a visitor's device, the browser falls back to another font. [L1363.025]
  • Use decorative fonts only in images, where the text is printed into the picture. [L1363.025]
  • Source tension: the body font example uses Helvetica (older: Source B, 2021-22) [L1371.013]. The web rule prefers Google Fonts [L1363.025]. The sources do not reconcile these. Check the licence [L1363.024] and whether the font is a Google Font before using it on web pages.

Setting fonts in the theme and page builder

Shopify theme (Typography settings):

  1. Go to Theme settings > Typography > Change. [L1309.050]
  2. Pick a heading font from Shopify's font library and click Select. [L1309.050]
  3. The change shows in the homepage preview immediately. [L1309.050]
  4. Set the body font under Typography > Body font. The example used Montserrat, with the weight changed from regular to medium for thicker text. [L1309.051]
  5. Set the font scale to 110% to make all text larger. [L1309.051]

PageFly global styles:

  • Set headings, body fonts and colours once under global styles. Changes then push across the whole PageFly site. [L1363.022]
  • Upload brand fonts there, then set headings to the uploaded font. [L1363.022]
  • Colour scheme used in the lesson:
    • Dark for primary.
    • Light and muted for secondary.
    • Light and slightly more vibrant for tertiary.
    • Plus charcoal, white and grey neutrals. [L1363.022]
