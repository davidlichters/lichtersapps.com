8.11 Brand guidelines and AI brand kit

Brand system and consistency

  • A brand encompasses far more than a logo. A complete brand system includes a color palette, typography, visual patterns, textures, and consistent messaging across all touchpoints. This consistency builds consumer trust and makes the business appear professional and cohesive. [L0317.001]
  • Keep colours, shapes, typography and layout consistent across all brand visuals so customers link each element to the brand over time. A recognisable visual set makes the brand look more professional and makes it easy to recall. [L0755.002]
  • Keep the tone, personality and visual identity of the brand consistent across all ads, because regular readers recognize and trust a stable identity. Change only when a test shows a different approach is needed. [L1261.113]
  • After the logo is finished, build a branding deck that defines colors, typography, shapes and textures. This keeps all future graphics and marketing materials consistent with the logo. [L1047.038]

Brand guidelines file: contents and export

  • A brand guidelines document is a PDF containing all brand information: logo files in multiple formats and colors, exact color codes (hex and RGB), font names and pairing rules, visual patterns and textures, and brand voice guidelines. Share this with graphic designers, video editors, web developers, and team members to ensure they create consistent brand work. [L0317.008]
  • A brand guidelines file should hold the brand photography, a moodboard, tone and style notes, brand use rules, the project color palette, typography and a logo panel. Keep the templates in the same file so every asset is built from the same source. [L0992.005]
  • A brand guidelines file with defined colors, fonts, logo, photography and brand voice works as a plug-and-play base. Once it exists, a new template or ad can be assembled in minutes by dropping in those elements. The time goes into building the photography and voice first, not into each design. [L0992.001]
  • Update the brand guidelines file whenever the brand changes, such as a new palette, font or voice, so that every new template is built from current rules. Treat the file as a living document rather than a fixed one. [L0992.028]
  • Logo rule: the company logo comes in three versions that can be used interchangeably and resized as needed, but the logo must never be altered. Use only the official files from the shared brand folder. [L1467.001]
  • Older advice (2021-22): keep the company logo as a PDF in a shared files section so any team member can send it to a vendor or customer who asks for it. Store it alongside the quote and invoice templates, so staff do not have to ask the owner each time. [L1396.067]

Exporting the guidelines for the team and freelancers

  1. Open the completed brand guidelines document in Kittl.
  2. Click the Download button.
  3. Change the file format to PDF.
  4. Select the "Combine into one file" option.
  5. Download and share the PDF with all designers, video editors, developers, and team members. [L0317.022]

Textures and patterns

Creating textures and patterns for the brand guidelines

  1. Open your logo in Kittl.
  2. Duplicate it and move the duplicate to a new "Textures" artboard.
  3. Adjust the duplicate by changing opacity, adding colors, creating gradients, or layering elements.
  4. Create 2-3 different texture variations.
  5. Include these in the brand guidelines document so designers can use them for backgrounds, borders, and decorative elements across materials. [L0317.010]

Brandfetch workflow

  • Get API access from the right page: do not click "Get started" on the brandfetch.com homepage. Always click "Are you a developer? Get API keys" to access the developer dashboard and MCP setup. [L0322.011]
  • The brand context step runs one Brandfetch call on the brand's domain to pull voice, colors and fonts. The result is saved as a brand-kit.json file and a separate voice file, and every later skill uses these as input. [L1361.020]
  • Do not skip the transformation stage (stage 3), where you convert the Brandfetch raw data into a structured brand-kit.json and voice.md. This step is critical to avoiding generic AI outputs. [L0318.006]
  • Converting raw Brandfetch API responses into structured JSON and Markdown files keeps later AI-generated emails, copy, and templates brand-specific (correct colors, voice attributes, and positioning) rather than generic. [L0318.016]

Brandfetch run in one project

  1. Create a new folder in Claude Cowork and set it as your working folder.
  2. Create a new project in Claude Cowork with a descriptive name (e.g., "email mastery course with AI").
  3. In the project chat, invoke the Brand Fetch MCP using a prompt like "Using the Brandfetch MCP, research www.example.com.au".
  4. Let the MCP fetch and display visual identity (logos, colors, fonts, social links) and brand context (tagline, mission, target audiences, voice attributes, style).
  5. Review the output for contradictions between longDescription and actual product range, and note any data quality issues.
  6. In the same project, use a mapping prompt to transform both Brandfetch responses into brand kit.json and voice.md files using the field mappings provided.
  7. Save both files to your project folder.
  8. Optionally, visit the brand's website directly with Claude in Chrome to verify fonts, currency, and positioning details. [L0318.008]

Data quality checks

  • When Brandfetch returns an unclaimed profile (which is normal for most brands), treat colors and fonts as scraped estimates, not authoritative brand standards. Verify the actual typefaces and design details by visiting the site directly with Claude in a browser. [L0318.004]
  • Using Brandfetch data as fully authoritative when the profile is unclaimed leads to inaccurate colors, fonts, and category descriptions. Always cross-reference with the actual website and live product listings. [L0318.012]
  • Always validate that Brandfetch data, especially currency and product categories, matches your actual business. Example: if Brandfetch returns USD pricing but your domain is.com.au, verify whether you actually sell in AUD and correct the data. [L0318.005]
  • Data quality score: the Silk The Label unclaimed profile scored 0.28. This is relatively low and indicates that colors and fonts were scraped rather than verified by the brand owner. [L0318.015]
  • Worked example, Silk The Label: primary #5f021f (deep burgundy/oxblood), accent #ffffff (white). Fonts: Helvetica (title), custom body font (exposed as Shopify CSS variable --font-body-family, not directly readable). Logo available as PNG (820x96, transparent) and SVG. [L0318.014]
  • If Brandfetch returns incomplete data (new or very small brand), ask the user directly for details rather than letting Claude guess or invent brand information. Do not allow Claude to invent missing brand data. If Brandfetch cannot detect a field (e.g., heading font) or returns incomplete information, request the data from the user instead of generating a value. Always verify colours, fonts, and links with the user before finalizing the JSON file. [L0322.009, L0322.012]

Brand kit JSON and voice file

Prompt for the brand kit and voice file (verbatim)

Develop your brand identity and communication style for email marketing through a structured workflow, saving all outputs to your brand folder. Begin by using Brandfetch to retrieve your website's branding data: logo, color values in hexadecimal format, typeface selections, and social media connections. If Brandfetch returns limited information-which is typical for recently launched businesses-ask directly for the details rather than assuming. Never guess at brand attributes or rely on outdated cache; always verify by asking when uncertain. Create a JSON file called brand-kit.json in the brand folder using this exact structure: a brand object containing name, domain, tagline, and description; a positioning object with value proposition; a visual object with logos, three hex colors (primary, secondary, accent), and font details split by type (title, body); a meta object listing the URL and social platform accounts such as Facebook and Instagram; an industries field; and a location object with city and country. Verify the extracted colors directly against your live website, paying special attention to the primary hex code that styles your primary buttons, and confirm that both fonts and all shop and social links are current. Remove any inaccuracies. Determine your brand voice by asking how your organization should be perceived (options ranging from friendly to formal, or playful to premium), collecting 2-3 email or product description samples you consider successful, then drafting voice.md in the brand folder that documents a concise voice statement, 4-6 defining voice characteristics, representative language patterns your team uses, and a brief list of communication practices to avoid.

[L0322.006]

  • Worked example, Silk the Label (www.silkthelabel.com.au): Brandfetch returned the logo, primary colour #5f021f (deep burgundy), location (Brisbane, Australia), and Instagram/Facebook links. The user confirmed the hex code matched their main button colour and provided 2-3 email examples. Claude then drafted voice.md with tone attributes matching those examples. [L0322.007]
  • Both output files are mandatory before proceeding to the next course module. Email generation and product descriptions cannot be on-brand without both files. [L0322.010]
  • File naming varies across sources: "brand-kit.json" is the name used in the template, "brandkit.json" appears in the mandatory-files rule, and "brand kit.json" appears in the transformation rule and mapping table. Use brand-kit.json, as named in the template. [L0322.006, L0322.010, L0318.006, L0318.009]

[L0322.014]

  • Converting the mapped data into a brand kit and voice file ensures the brand's voice, colors and positioning carry into everything written from it. [L0318.016]

Keeping work inside one project

  • Keep all brand kit work (prompt, Brandfetch data, JSON, voice file revisions) inside one Claude Project so the model maintains full context. Splitting work across separate chats breaks context continuity and triggers hallucination. [L0322.008]

Applying guidelines to templates and assets

  • Keep every template in the brand palette. Pick each color from the document's brand colors rather than the template defaults. Apply the same color system across all formats so social, email and web assets look like one brand. [L0992.002]
  • Brand guidelines are a guide, not a rulebook. Small deviations from the palette are acceptable when they improve fit, for example shifting a pink accent toward a purple already in the brand. Check that the change still reads as the brand. [L0992.004]
  • The brand's main colour must appear in every rebranded layout, and that colour should stay consistent across the batch. If the brand uses a different colour from the reference, ask Claude to rewrite the instruction so it uses your colour. [L0794.024]
  • A logo or brand name on a generated ad is optional. Leaving it off gives more room for the product message. Remove any brand line that repeats the headline or crowds the layout. [L0794.025]

Setting up email template branding in Shopify Email

  1. Open the Shopify Email settings and scroll to the template branding section at the bottom.
  2. Click Customize.
  3. Upload the store logo in the logo field.
  4. Enter the store name in the store name field.
  5. Choose the same font used in the Shopify theme settings in the typography field.
  6. Set the colors to match the theme settings: the text color, the button and link color, and the color for labels and outlines.
  7. Save all settings. [L1307.012]
  • Email template branding should match the store's website: same logo, colors, and fonts. Once it is set in the template branding, all future email automations and campaigns use it by default, so it only needs to be configured once. [L1307.013]

Reference style set (Source A, a different brand, as an example of the format)

  • Brand fonts: body text and tagline use Gotham Book, with Montserrat Light as the free alternative. The website font is Proxima Nova, and the logo font is Jenna Sue. [L1467.002]
  • Brand colours: logo Red #e91e47 and logo Yellow #f7e100. Body text is dark grey #484341 instead of black. Buttons and links use Light Blue #17dbe1. The wordmark is True Black #000000. [L1467.003]
