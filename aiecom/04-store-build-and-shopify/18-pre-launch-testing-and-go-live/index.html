4.18 Pre-launch testing and go-live

Readiness before paid traffic

  • Optimize the store for conversion before any paid traffic is sent to it, because visitors who arrive at a store that is not ready cannot be converted and the advertising budget is wasted. [L0582.015]
  • Older advice (2019): set up and optimize the Shopify store before spending money on ads, so paid visitors land on a working store. [L1002.028]
  • Before a campaign goes live, make the store attractive. A better offer and a better-made website can outperform a competitor's store selling the same product, and weak competitor stores show room for improvement. [L1161.043]
  • Run the full pre-launch checklist before sending any paid traffic, so mistakes in the theme, product page, bundles or checkout are fixed before money is spent on clicks. [L1324.002]
  • If the store is not ready when a video goes viral, sales are lost and the store must be rebuilt in a hurry. Build a working store before the content has a real chance to take off, especially without web-building experience. [L1380.039]
  • Set a deadline for the store to be live within one week, and check each store task on the deadline day. [L1431.010]
  • Publishing a store before launch carries no risk, because you are the only visitor until you send traffic. Keep the store unpublished only if you prefer not to test it yourself. [L0934.094, L0934.165]
  • Build the store in this order before launch (older advice, 2021-22 source label Source C; no date given):

Store setup order before launch [L1288.001]:

  1. Set the store name.
  2. Activate payments: Shopify Payments, PayPal and Clearpay.
  3. Add products and make sure the stock count is set.
  4. Set up shipping.
  5. Set up policies.
  6. Connect the domain.
  7. Set up markets for UK, Australia and US.
  8. Choose and set up the theme.
  9. Build pages with Pagefly.
  10. Build the homepage.
  11. Build the product page.
  12. Build the About us page.
  13. Build the Contact us page.
  14. Set up the header.
  15. Set up the footer and menus.
  16. Set up checkout.
  17. Add reviews with Ryviu.
  18. Set up Tag Manager.
  19. Set up Google Analytics (GA).
  20. Set up GA4.
  21. Review all Shopify settings.
  22. Check whether redirects from the testing site are still active. [L1288.001]
  • Leftover redirects from the testing site can keep visitors away from the live store, so they must be checked before launch. [L1288.003]
  • When conversion is below 1 percent with a lot of traffic and few add-to-carts, the offer, theme and checkout are the first suspects. Have someone review the checkout process and the offer for friction before running more ads. [L1316.040]

Store access and password protection

  • Disable the protection before beginning supplier outreach (Module 4), because suppliers must be able to review the store during initial contact without a password. [L0076.002, L0834.130]
  • Keep Shopify Payments turned off until real products are live, so nobody can place an order. [L0834.130]
  • Launching while the demo password is still active leaves the storefront hidden from visitors and ad traffic. Remove the password before sending any traffic. [L0393.023]
  • A password left on blocks customers and can get your Google Merchant Center and Google Ads accounts suspended. It is often switched on during supplier work and forgotten, so check that it is off before launch. [L1145.018]
  • While the online store is password protected, visitors without the password cannot see any pages. The Pages screen shows a banner, Online store is password protected, with a Disable password button that must be used before launch. [L1264.007]
  • While password protection is on, visitors who open the store address see an Opening Soon page with an email sign-up field instead of the shop. [L1292.032]
  • While a store is protected, visitors see an Opening soon page with an email signup field and a link for the store owner to log in. A theme published behind this password is not visible to the public until the password is removed. [L1330.025]
  • Remove the storefront password once the demo store is complete, so the store becomes publicly accessible. [L0532.007]
  • The store is only publicly live after the password toggle is switched off and saved. Switching it off without clicking Save does not complete the step. [L1294.005]

Where to find the setting (the label varies by source and Shopify version):

Source Location Setting
L0393.006 Online Store > Preferences > Password protection Turn off the password for the store
L1294.003 Online Store > Preferences First setting shown is Store access, currently set to Password protected

L1292.020 Online Store > Preferences Disable password can be used once the store is ready to launch
L1292.031 Online Store > Themes Banner Online store is password protected with a Disable password button

Removing the password, step by step [L1294.004]:

  1. Log into your Shopify account.
  2. Click Online Store.
  3. Click Preferences, located at the bottom of the Online Store section.
  4. In the Store access setting, which shows Password protected, toggle the switch off.
  5. Click Save.

After saving, the store is live and anyone who opens the store URL can view it. [L1294.004, L0076.001]

  • Speed score is not calculated while a store is protected. The speed score becomes available 1 to 3 days after protection is disabled, so the store stays hidden from speed measurement until protection is removed. [L1292.020, L1292.032]

Removing the password with a paid plan, step by step (older advice, 2021-22) [L0370.010]:

  1. Open Online Store > Preferences in Shopify admin.
  2. Click "Select a plan" to end the free trial, since the password cannot be disabled without a paid plan.
  3. Choose a plan; the Basic Shopify plan is the recommended starting plan, at USD 29 per month when billed every 30 days.
  4. Add a payment method (a credit card is required); the trial days still remaining are kept before the first charge.
  5. Return to Online Store > Preferences.
  6. Under Password protection, turn off "Enable password" and click Save.
  7. Check the storefront in a separate browser or private window to confirm the "Opening Soon" password page is gone.

Link and content checks

  • Click-test every link on the site and confirm each one opens the correct destination with no 404 errors, in this order [L0167.004]:
  1. Header menu links, including every item and every dropdown item.
  2. Homepage collection sections, opening each collection.
  3. Every other linked section or button on the homepage.
  4. Footer links, especially the Quick Links and policy links.
  • Click every link on the homepage, the collection pages, the about page and the policy pages. [L0855.179]
    1. Fix or remove any link that goes nowhere, is broken, or reloads the same page.
    2. Remove placeholder text and theme default labels, such as generic collection names, left over from installing the theme.
    3. Check that each product category matches what the store says it sells, and that the policy pages are rewritten for this business.
    4. Confirm that the contact method, shipping time and return policy are all filled in.

Note: L0855.179 is listed above as a single procedure with five steps; the numbering in the source is 1 to 5, with the click-test as step 1.

  • Before going live, check for glaring issues such as broken links, product pages missing information, mispriced items and empty collections. The store should look professional from the first day. [L1446.022]
  • Check the About Us page and the rest of the site for typos before turning on ads. [L1068.045]

Critical elements: prices, buttons and add-to-cart

  • A product page with the price and compare price accidentally hidden produced 40 add-to-carts and only 4 purchases for one student. Always verify that critical information is visible. [L0067.031]
  • A missing or unclear add-to-cart button is a technical oversight that can silently kill conversions. Verify that all buttons and fields work before running ads. [L0067.032]
  • A product listing that shows a price of $0.00 or a broken price looks like a bug and kills trust. Test the product page and cart before sending paid traffic. [L0657.039]
  • Older advice (2019): check the store before turning on ads, in this order [L1068.045]:
  1. Make sure the checkout works.
  2. Make sure all links in the header and footer work.
  3. Make sure every add-to-cart button works.
  4. Check the About Us page and the rest of the site for typos.
  5. Once confident, turn the ads on.

Mobile and cross-device checks

  • Check the store on mobile first, because most shoppers buy from phones and desktop views often look weaker. Make sure the layout looks trusting and polished on a phone. [L0657.037]
  • Check the store on a phone as well as on desktop, because the mobile layout can look much better or worse than the desktop version. [L0656.022]
  • Review a store on a phone in portrait view, not only on desktop, because desktop layouts can hide gaps where a product photo or GIF fails to fit. Count the taps needed to reach the real product page on the phone as well. [L0530.034]
  • Check the mobile version separately from the desktop view at every stage of editing, because mobile is the main traffic source. Confirm that images, icon bars, reviews and FAQs look clean on mobile before publishing. [L1324.004, L1331.039]
  • A product title shown vertically on mobile after Add to cart, while the cart shows it horizontally, looks broken and can cost a sale. A likely cause is a font size set too large for mobile. [L0837.005]
  • Shopify checkout appears as a dropdown order summary on mobile but displays differently on desktop. [L0255.026]
  • Scroll the whole page on mobile before linking the store from TikTok, to confirm that the lower half loads and that text and images display correctly. Most visitors arrive on their phone. [L1380.056]

Mobile-first store review, step by step [L0530.015]:

  1. Open the store on a phone and count the clicks to reach the actual product page; a product page that takes around five clicks is a weakness.
  2. Make sure the product page comes first on the page, with the product image, title, price and add to cart above everything else.
  3. Move the product details, refund policy, and long text blocks below the main product information.
  4. Place customer reviews above the email signup section and the footer.
  5. Keep the footer last, and remove the "Powered by Shopify" credit only if your theme allows it.

Cross-device check before launch [L0552.054]:

  1. Before launch, open the store page and every ad creative on a Windows PC and on a Mac.
  2. Check the page on an iPhone and on an Android phone.
  3. Fix any layout or visual differences before spending on ads, because a page can look correct on one device and broken on another.
  • Older advice (2019): run a test purchase on desktop and on mobile to confirm orders go through, and check on mobile that all content stays visible and usable. [L0356.020]

Test orders and checkout

  • Place a test order before launch to check that the whole store works as intended. Reviewing it in the Shopify admin shows what a real customer order will look like. [L1302.001]
  • Test order in Shopify [L1302.002]:
  1. Open the store and go to the cart.
  2. Remove most of the extra products, since a test does not require buying several units.
  3. Go to checkout and enter any email address that uses the domain example.com.
  4. Enter dummy shipping information.
  5. Click Complete order.
  6. Open the Shopify admin, go to Orders, and check that the test order appears.
  • In Shopify Admin > Orders, a test order shows payment status payment pending, because it is not a live order and receives no payment. Its fulfillment status starts as unfulfilled. The list also shows the sales channel (Online Store), the order amount and the shipping method (here free shipping). [L1302.004]
  • Before launching ad campaigns, place a full test order on your own store with your own credit card, going through the entire checkout. Check that every step works, then cancel the order, since the money returns to your account. [L1126.028]
  • Test the payment flow on a new store [L1381.047]:
  1. Place a real dummy order on your own store.
  2. Cancel the order or issue the refund in Shopify.
  3. Confirm the refund arrives quickly, which one seller reported as within seconds.

  • Note on refund timing: L1126.028 says the money returns to the account after cancelling, while L1381.047 reports one seller's refund arriving within seconds. Both describe the same test; the refund timing depends on the payment provider and is not guaranteed by either source. [L1126.028, L1381.047]

  • Older advice (2020): create a $1 test product on the store, add it to the cart, and go through a complete checkout, on both desktop and mobile. Then verify that the order confirmation appears and that the payment gateway processes without errors. This validates that checkout works before driving traffic. [L0268.019]

    1. Create $1 test product on store.
    2. Add to cart and go through complete checkout.
    3. Test on both desktop and mobile devices.
    4. Verify order confirmation appears.
    5. Confirm payment gateway processes without errors.

  • When you create a test product to check the cart flow, turn off quantity tracking for it so you can add it to the cart from the storefront. This setting is only for testing and is not a recommended way to run a live product. [L1326.027]

  • Test the checkout with a real sale before scaling ad spend, so you know orders can be completed end to end. [L0823.015]

  • Run the test before expecting any orders, because a store that looks finished can still fail at checkout. [L1324.003]

Compliance review

  • Before launch, check the store against the pre-launch compliance checklist. A second reviewer can look at the same checklist on the live store to catch items that were missed. [L0970.166]
  • Link all policy pages in the store footer before running any ads, for Google compliance. [L1446.030]
  • Legal pages must exist before traffic: refund policy and shipping policy, with company name and email address. [L1345.073]
  • Update the Legal section in Shopify Settings and make the Contact Us page list phone number, email and postal address. [L1145.051]
  • Rewrite the policy pages for this business, not the theme defaults. [L0855.179]
  • Link Privacy Policy, Terms of Service and Contact Us in the header and footer. [L1145.051]

Viewing the store as a customer

  • When you view your own store while logged in as admin, Shopify displays a bar stating that the store is not live and checkout is disabled. Use an incognito window or a different browser to see the customer view. [L0255.025]
  • Shopify's bottom ribbon that reads Dropship appears only for admins logged into the Shopify admin while previewing the store. To confirm what customers see, open the storefront in an incognito window or while logged out of Shopify. [L0837.060]

Launch readiness check, in order [L1446.030]:

  1. Confirm that at least two suppliers are onboarded and their products are uploaded to the store.
  2. Link all policy pages in the store footer before running any ads, for Google compliance.
  3. Complete the conversion optimization module so the store is optimized for conversions.
  4. Check for broken links, product pages with missing information, mispriced items, and empty collections.
  5. Have a family member or friend who has not seen the store shop it while you watch. If no glaring problems remain, launch.

Family-member test, in order [L1446.023]:

  1. Ask a family member or friend who has not seen the store to shop it as if buying one of your products.
  2. Sit beside them while they browse and watch where they click.
  3. Ask what stands out, what is not working, and what is confusing.
  4. Thank them and make the changes they point out.
  • Launch when the store works and has no obvious red flags. Have a friend or family member test whether they would buy from it, and check that the cart and checkout work. (Older advice, 2019.) [L0356.026]

Checklist before sending traffic [L1345.073]:

  1. Payment processor: at least one payment method that accepts credit cards, plus PayPal for top markets.
  2. Markets: all target countries are active in Settings > Markets, and a test checkout works in each.
  3. Shipping prices: default rates are deleted, custom rates are set, and shipping is free or clearly priced.
  4. Legal pages: refund policy and shipping policy exist, with company name and email address.
  5. Checkout page: trust badges and payment icons are added, and taxes are disabled where no tax is charged.

Traffic spikes and viral moments

  • Before a large influencer post goes live, check that the store can handle a traffic spike. One brand saw more than 3,000 people shopping at once, compared with a normal load of 20 to 100 visitors. [L0790.014]
  • A store that went viral was shut down by Shopify two to three days after the first viral sales, when order volumes were large. Customers reported they could not purchase, the seller noticed through comments, and the store was restored within about one hour, though more than $5,000 in sales was estimated to be lost during that hour. Shopify also requested paperwork such as proof of inventory once orders reached tens of thousands. [L0352.038]
  • Check the comments on your videos regularly, because customers writing that they cannot buy is an early warning of a store shutdown. Shopify may also restrict accounts when order volume is very high. [L0352.039]
  • A broken product link in a viral video or post sends traffic nowhere and directly reduces conversion. Check the link in every post before and during a viral moment. [L0655.005]
  • Shipping or checkout issues on the store page can cost sales even when a video goes viral. Check the product page and checkout flow every time before promoting. [L0655.006]
  • After adding the link to the bio, check it regularly to confirm the landing page and product page load without errors, since an error can appear after the link is applied. Fix any errors in Shopify when they show up. [L1380.040]

Zero-sales and add-to-cart diagnostics

  • Checking a product that gets add-to-carts but few sales [L0660.020]:
  1. Check which payment methods are offered at checkout, including credit card and PayPal.
  2. Check that the checkout works without errors.
  3. Check the pricing point against the market.
  4. Check the website speed.
  5. If these are fine and sales are still low, the product is probably not good enough, so test a different product.
  • Checkout test for a store with zero sales after add-to-cart [L0361.031]:
  1. Check the shipping setup in Shopify and confirm that shipping rates are correct.
  2. Check the market setup if you sell to several countries and confirm that each target country is active.
  3. Try to check out with two random addresses in each target country, for example USA and Canada.
  4. If checkout fails for those addresses, fix the setting that is blocking customers.
  • Use this order when ad metrics are good but there are no sales, although add-to-cart and checkout ratios are healthy [L0774.007]:
  1. Check the shipping options and whether shipping is being charged to the customer.
  2. Check the markets: make sure every country you run ads to is enabled in Shopify Markets (Settings > Markets), because customers from a country that is not activated cannot choose it at checkout and abandon the cart.
  3. Check that the payment providers work: create a 95% discount code for yourself and test a payment through PayPal, Shopify Payments or Stripe, whichever you use.
  4. If a payment provider fails the test, uninstall it and install it again, which fixes setup problems in many cases.
  • A common cause of zero sales with healthy funnel numbers is a targeted country that is not activated in Shopify Markets, so checkout cannot offer shipping to that customer. Check the country list against the countries in your ad targeting. [L0774.008]
  • Review the drop-off rate at each step in analytics to find the bottleneck. Check in this order [L1225.040]:
  1. Check the homepage.
  2. Check the collection page.
  3. Check the product page.
  4. Check the cart.
  5. Check checkout.
  • A high bounce rate, for example 87 percent, is normal for ad traffic landing on product pages. Use Lucky Orange screen recordings to see why visitors leave and fix what causes it. [L0665.040]
  • Diagnosis order when funnel numbers are weak: the offer, theme and checkout are the first suspects, as stated in the conversion section. [L1316.040]

Post-launch maintenance

  • Constantly update the store as you learn: change the header, footer and apps, and optimize the product page as more visitors arrive. A store needs ongoing maintenance rather than a single build. [L1444.043]
  • Check the store on mobile at every stage of editing, since mobile remains the main traffic source after launch. [L1331.039]
  • Keep checking the store links and product pages after launch, especially after changes to the bio link or the header and footer. [L1380.040, L0855.179]
  • Re-check the store's speed score once the store is public. The score becomes available 1 to 3 days after protection is disabled, and a B grade is not a reason to pause sales. [L1292.020, L1446.019]
  • A new Shopify store is password protected by default and shows a coming-soon page to visitors who are not logged in, asking for a password instead of showing the storefront. [L1294.001]
