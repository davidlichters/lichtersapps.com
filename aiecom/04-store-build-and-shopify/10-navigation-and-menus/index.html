4.10 Navigation and menus

Menu basics in Shopify

  • Menus are managed in the Shopify admin under Content > Menus [L0092.001, L1319.002].
  • Older course material (2021-2022) gives the path as Online Store > Navigation [L1303.013, L1320.001].
  • Menu items can link to collections, products, pages, blog posts, the homepage, the search page, policy pages, or external URLs. Choose the link type in the item's Link field before saving [L1319.016, L0092.002, L1320.007, L1320.009].
  • Menu item names are free text and do not have to match the linked page or collection. A refund policy can be listed as Returns/Exchanges [L1319.017, L1320.009].
  • Policies appear under the Policies heading in the link search once they exist [L1320.007].
  • Shopify does not allow a menu item without a URL [L1009.014].
  • Create all collections, pages, and policies before building menus, because menu items can only link to existing items. This includes shortcut collections such as Bestsellers and On Sale Now [L1319.019].
  • When searching for a collection in the link field, copy its exact name from the collections list and paste it. The search matches text, so a near-miss can return the wrong result [L1320.014].
  • Give each menu a unique name. Two menus with the same name cause confusion [L1285.028].
  • Each menu gets a handle generated from its title in lowercase with hyphens, for example main-menu. The theme uses the handle to find the menu, so the default handle is what the theme looks up [L1303.015].
  • The header menu title is not displayed on the storefront and can keep a plain internal name. Footer menu titles appear as visible headings and must read as meaningful labels such as Company or Products [L1303.033].
  • Save after every change, because lost connections can discard unsaved work [L1303.018].
  • Save, then refresh the storefront. Menu changes can take a minute or more to appear [L1319.006, L1320.002, L1320.003].
  • Menus show on the live site only after the theme loads them, so check the live page to catch missing links early [L1303.035].
  • Before replacing a menu, take a screenshot of its items so the original structure can be rebuilt [L1010.012].
  • Deleted menu items can be re-added at any time, so removing a wrong item is not a lasting error [L1320.003, L1320.012].
  • The arrow beside a parent item in the menu editor collapses or expands its sub-items. This only helps while editing and does not change the storefront [L1319.018, L1320.013].

Default menus in a new store

  • Sources differ on how many menus a new store starts with. One source says three default menus, and most themes include at least three menu spaces (a main menu and two footer menus) [L1319.003]. Another says two default menus: Footer menu and Main menu [L1320.001]. Check the menu list in your own admin.
  • The default main menu contains Home, Catalog, and Contact [L1326.008].
  • The default footer menu is initially labelled Search [L1320.005].
  • In older (2021-2022) default setups, the default footer menu loads the main menu items, which is not useful in the footer. Replace it with purpose-built footer menus [L1303.026].
  • If a theme has different menu locations, the menu positions change but the same menu types can still be built [L1319.003, L1319.020].

Planning the three menus

  • Shopify menus organize site navigation in headers and footers, so visitors can find products and important pages without deep browsing [L0092.003].
  • Menus link to collections, pages, policies, search, and external links. Menus are organized by place: the main menu runs across the header and can hold dropdowns, the sidebar menu filters products on collection pages, and footer menus hold links at the bottom of the site [L0092.002, L1320.008].
  • Build three menus for a professional store [L0092.004]:
    • Main Menu: product navigation at the top, using collections.
    • Footer Menu: category and promotional links.
    • Quick Links Menu: required pages and policies.
  • The Manhattan theme supports all three menus by default. Other themes typically support similar menu structures [L0092.013].
  • The Source A theme uses Main menu, Footer menu, and Secondary footer menu. These are assigned to the header and footer positions separately in the theme customization [L1320.010].
  • The menu structure does not need to be perfect and can change as the store evolves [L0092.008, L1319.008].
  • Navigation and collections are temporary at an early stage. Revisit and adjust all menus and collections just before launch so they match the products actually on the site [L1303.029].
  • There is no required number of top-level items or dropdowns in a main menu. Build the structure from the real product categories and expect to change it as the catalogue and suppliers grow [L1319.008].
  • Older (2021-2022) reference structure for a store with five collections:
Menu Location Purpose Items
Main menu Header Product category navigation Five collections, with optional dropdown subcategories
Top Bar menu Very top of the site Business and policy pages About Us, Contact Us, Shipping, Easy Returns, Privacy and related pages
Company footer menu Footer Company and legal pages About Us, Privacy, Terms of Service, Contact Us
Products footer menu Footer Entry points to categories The same five collections, no dropdowns
Shopping info footer menu Footer Buying information Shipping, Easy Returns, Price Match

[L1303.028]

Building the main menu

Adding top-level category links

  • Basic procedure, from the Main Menu in Content > Menus [L0092.005]:

    1. Open Main Menu.
    2. Leave Home as the first item.
    3. Click Add Menu Item.
    4. Name the menu item after its collection.
    5. Set the link type to Collection.
    6. Select the matching collection.
    7. Click Save.

    [L0092.005]

  • Alternative procedure for the same task, with the default Home item kept [L1319.004]:

    1. Go to Shopify Admin > Content > Menus and open Main menu.
    2. Keep the default Home item.
    3. Click Add menu item.
    4. Enter the item name (for example Surfboards).
    5. In the Link field, choose Collections, search for the matching collection, and tick its checkbox.
    6. Click Save.
    7. Add each category the same way, one item per collection.
    8. For a dropdown, add the sub-category item the same way, then drag its dot handle to the right so it nests under the item above.
    9. Repeat nesting for every sub-category that belongs to that parent.
    10. Click Save, then refresh the storefront to check that the dropdown shows under the parent item.

    [L1319.004]

  • Older alternative (2021-2022) for five collections [L1303.016]:

    1. Go to Online Store > Navigation and click the title of the main menu.
    2. Delete the default items you do not want, such as Home and Catalog.
    3. Click Add menu item.
    4. Enter the name exactly as it should appear on the site, matching the collection name.
    5. In the Link field, search for the collection by name or paste its link, then select it.
    6. Click Add.
    7. Repeat steps 3 to 6 for each of the five collections.
    8. Click Save menu.

    [L1303.016]

  • Second alternative [L1320.002]:

    1. Open the Main menu in Online Store > Navigation and remove unwanted items (for example Contact and Catalog) with Delete or Remove.
    2. Click Add menu item, search the category name, and select the matching collection. Leave the filter collection with tags field empty and click Add.
    3. Click Save menu, then refresh the storefront.
    4. To create a dropdown sub-item, add the item as a normal menu item, then drag its dot handle to the right under the parent item. It then appears as a submenu with a small arrow icon.
    5. Repeat for each subcategory, save, and verify on the store by hovering over the parent.

    [L1320.002]

  • Renaming an existing item: in Online Store > Navigation, change Catalog to Collections, click Apply, then click Save [L1326.008].

Deciding on Home

Sources disagree on the Home item:

  • Keep Home as the first item, as in the default main menu [L0092.005, L1319.004, L1326.008].
  • Remove Home from the main menu. Open Content > Menus, open the main menu, click delete on the Home item, then click Save. The homepage still works without the link [L0972.016, 2025].
  • Source E advice: put Shop first, before Home. Do not highlight Home, because the aim is to send visitors into the shop. Keep the logo as a homepage link, since clicking it already returns to home [L1225.023].
  • Use Shop-first when the aim is to send visitors into the shop, and keep Home when it is a sensible entry point. Both are described in the sources without a stated rule for choosing between them. [L0972.016, L1225.023]

Ordering and shortening the header

  • Order header categories from left to right by sales, with the best-selling category first and the weakest last [L1325.010, L0551.026 (older, 2020)].
  • In a new store, make an estimate and change the order later based on sales data [L0551.026 (older, 2020)].
  • Only lead with a category that is clearly the top seller [L1325.010].
  • Shorten the header menu. Start it with a Shop item that opens a dropdown listing the main product categories by plain names, such as bracelets, earrings, necklaces, rings, and blankets. Avoid vague category names that visitors cannot interpret [L1325.011].
  • Keep the menu as simple as possible and include only links customers will actually use. Look at top competitors, then check your own menu from a customer's point of view to decide what to remove [L0551.027 (older, 2020)].
  • Use the header space for navigation to categories and collections, not for policy links, to maximise navigation options [L0255.020 (2025)].
  • Place the logo on the left of the header so the menu takes less space and does not cover product titles [L1225.023].
  • Test the menu for hover sensitivity bugs before scaling traffic. A product page navigation that forces a visitor into another product page when the cursor hovers over the menu blocks the shopping experience [L1225.024].
  • Each top-level link can be a plain link, a standard dropdown, or a mega menu, depending on how many subcategories it has. The choice should follow how the shopper navigates the store [L1010.013].
  • The main menu supports plain links and dropdowns, which is enough for an early demo store [L1018.001].

Store types and special items

  • A store with only three main navigation items (Shop Now, Track Your Order, and Support) is missing category links. Adding dropdown links for each product category helps visitors find what they want [L0351.046].

  • Place Subscribe and Bundles in the main top navigation so the recurring and multi-pack options are visible on every page. This keeps higher order values one click away instead of buried in a single product page [L0524.068].

  • When a store is built around one product category, the top navigation should link straight to the product types within it, such as dress types. Add-on products do not need to take up navigation or homepage space [L0838.021].

  • In a gift store, build navigation and homepage sliders by recipient group, and show the best sellers for each group under its own heading. Questions such as what people buy for men, women, parents, or grandparents each get their own section [L0355.007].

  • Adjust the main navigation to the products you actually have after supplier approvals, because categories from the demo store are often incomplete. Every product must be reachable from the main menu through a category, subcategory, or product type [L1145.009].

  • Add a main menu item called Brands or Our Brands. Its dropdown lists every approved brand, and each entry links to a brand collection that contains only that brand's products [L1145.010].

  • Preinstalled collections that Shopify creates by default do not need to be added to the main menu. Keep the main menu limited to the product categories you actually sell [L1319.009].

  • When the store is live and a collection is empty, remove it from the menus instead of deleting it. Add it back once it contains live products [L0971.053].

  • In a one-product store, put a direct link to that product in the header. Visitors on any page can then return to the product page in one click [L1326.010].

  • Procedure to add a single product link to the header of a one-product store [L1326.009]:

    1. Go to Products and create the product, using the product name as the title and uploading its image.
    2. Go to Online Store > Navigation and open the Main menu.
    3. Add a menu item and name it with the product name.
    4. Select the Products option and choose the product.
    5. Click Apply, then Save.
    6. Open Online Store > Themes > Customize and confirm the product link appears in the header.

    [L1326.009]

  • To show a collection link in the navigation, add it as an item in the menu under Online Store > Navigation. The collection link then appears in the header menu [L1326.020].

  • Do not send store visitors to Amazon links, because customers who leave for Amazon are lost sales. Accepting Amazon Pay as a payment method on your store is fine [L0551.028 (older, 2020)].

Dropdowns and nesting

Creating a dropdown

  • Nesting a menu item: drag the dot handle on the left side of the item to the right, and it becomes a sub-item of the item directly above it. A nested item shows as a dropdown under its parent in the storefront, with a small arrow beside the parent [L1319.005].

  • Older method (2019): click the menu item that should be the sub-category, drag it slightly to the right under its parent item, then click Save. The sub-items then appear when you hover over the parent item [L1068.041 (older, 2019)].

  • Older note (2020): nested navigation menus are created by dragging each item where you want it to appear. Nested menus are available in any theme; a custom menu requires an app [L0468.063 (older, 2020)].

  • Procedure for building a dropdown in the main menu, from the 2025 course [L1116.014]:

    1. Go to Content > Menus > Main menu.
    2. Open the parent item, for example Accessories, to see its nested items.
    3. To test or reposition, drag a child item out with its drag handle so it becomes top-level, then click Save.
    4. Drag the item back under the parent so it sits as a nested child. Hold it while moving, then click Save.
    5. Reload the storefront and confirm the parent item now opens a drop-down.

    [L1116.014]

  • Older procedure (2021-2022) for dropdown subcategories [L1303.019]:

    1. In the menu editor, click Add menu item and enter the name of the sub-item, such as a product subcategory.
    2. Link the item to a page or collection. If no page exists yet, a placeholder # link can be used, but it only makes the item appear and sends visitors to the homepage.
    3. Drag the new item up and slightly to the right so it sits directly beneath the parent menu item.
    4. Repeat for each subcategory.
    5. Click Save menu.

    [L1303.019]

  • Pattern for a dropdown: the parent item links to a collection, the subcategory items are nested under it, and a final sub-item named All [category] links back to the parent collection [L1320.011].

  • Example structure built in the lesson [L1319.007]:

Menu item Level Links to

Surfboards Top level Surfboards collection
Hybrid Surfboards Under Surfboards Hybrid surfboards collection
Shortboards Under Surfboards Shortboards collection
Mid-Length Boards Under Surfboards Mid-length boards collection
Long Boards Under Surfboards Long boards collection
All Surfboards Under Surfboards Surfboards collection (catch-all link)
Swimwear Top level Swimwear collection
Bathing Suits Under Swimwear Bathing suits collection

All Swimwear Under Swimwear Swimwear collection (catch-all link)

The swimwear items are demo examples to show the nesting method and are not a product recommendation [L1319.007].

  • Surfboard example from the same lesson: nest Hybrid Surfboards, Shortboards, Mid-Length Boards, Longboards, and All Surfboards under the main Surfboards item, and nest Bathing Suits, Wetsuits, and All Swimwear under Swimwear [L0092.007].

  • Procedure to add sub-items under Surfboards and check them [L0092.006]:

    1. Add additional menu items for sub-collections.
    2. Drag sub-items slightly to the right under the main item to nest them as dropdown items.
    3. Save the menu.
    4. Refresh the store to confirm dropdown behaviour.

    [L0092.006]

  • Checking a dropdown: hover over the top-level item in the live preview. A mega menu opens a multi-column panel with sub-groups, while a standard drop-down shows a simple list of links [L1018.017].

  • To restore a moved or wrong item: drag it out again to move it back to the top level. Items can be deleted and re-added at any time [L1320.012].

Price and filter dropdowns

  • To build a By Price dropdown in the main menu [L1320.004]:

    1. Add a menu item named By Price and link it to Products > All products, because no price collection exists under that name.
    2. Under it, add one sub-menu item per automated price collection, using the exact collection names (for example the under $100 range and the 100 to 500 range). Drag each one to the right so it nests under By Price.
    3. Save the menu and refresh the store. Visitors clicking By Price land on all products and can filter by price in the sidebar.

    [L1320.004]

Placeholder links in dropdowns

  • Shopify does not allow a menu item without a URL. If the collection for a subcategory does not exist yet, point the item to an existing related collection as a placeholder and replace the link once the real collection is live [L1009.014].
  • A placeholder # link on a dropdown item sends visitors to the homepage. Replace every placeholder with the real collection or page link before launch, or delete the item [L1303.020].
  • If a collection does not exist yet, a mega menu section can be left unlinked or linked to a temporary collection, and the link should be updated once the real collection is live [L1009.007].
  • In a live store, menu items should not all point to the general category page as placeholders. Each option needs its own collection, for example a beginner collection built from products tagged beginner, before the option is linked [L1010.008].

Footer menus

Building the footer

  • Procedure from the Shopify admin [L1319.010]:

    1. Go to Shopify Admin > Content > Menus and open Footer menu.
    2. Keep the default Search item.
    3. Click Add menu item and name it after the main category, for example Surfboards.
    4. Link it to the matching collection in the Collections list, and tick the checkbox.
    5. Add more common shortcuts the same way, such as Bestsellers and On Sale Now, each linked to its collection.
    6. Click Save and refresh the storefront to check the footer.

    [L1319.010]

  • Another procedure with a different example set [L0092.009]:

    1. Open Footer Menu.
    2. Remove or keep the default Search link.
    3. Add these menu items: Surfboards (collection), Best Sellers (collection), On Sale Now (collection).
    4. Save changes.
    5. Refresh the store to confirm updates.

    [L0092.009]

  • Starting footer content in one course [L1320.005]: rename the default footer menu (initially labelled Search) to the store name, for example Shaka Surfboards. Starting items are Search, the main niche category collection (for example Surfboards), the New Arrivals collection, and the On Sale Now collection. Save the menu. These four items are described as a sufficient starting point.

  • Footer menus should contain common shortcuts such as bestseller and sale collections, the main product niche, and the search item. The exact contents can change over time and depend on your store [L1319.011].

  • Footer links from an ecommerce course example: FAQ, Return and Refund Policy, Terms and Conditions, Shipping Policy, Delivery Times, Privacy Policy, and Contact Form. The example store also had a Sign Up and Save email box offering early access and special discounts [L0347.024].

  • The store footer menu must link all five required pages (shipping, returns, privacy, terms, and contact us) so they are easily accessible [L0377.018].

  • Older (2021-2022) footer setup [L0681.008]:

    1. Create the three footer menus in the navigation settings beforehand, for example Company, Our Products, and Useful Info.
    2. In the footer section, open each menu block and click Change.
    3. Select the matching menu (Company, Our Products, Useful Info) and click Select.
    4. Verify that each block now lists real pages or collections that exist on the site.

    [L0681.008]

  • Older example content from the same course store [L0681.009]: the Company menu has About Us, Contact Us, Privacy, and Terms of Service. The Our Products menu has the product collections set up for the store. The Useful Info menu has Shipping, Easy Returns, Price Match, and Why Buy From Us.

  • Footer menu rules (older, 2021-2022):

    • Create at least two, and preferably three, footer menus, each with its own distinct title. Avoid generic titles such as Footer menu or Main menu [L1303.025].
    • Footer menus must stay flat, with no dropdown submenus, because nested items look poor in the footer [L1303.027].
    • Footer blocks display only the top-level links of a menu. Any drop-down items added to a footer menu will not appear on the live store, so build footer menus with the links that should be visible directly [L0681.017].

  • Many themes support a second footer menu displayed in an additional column [L1320.008].

  • Footer menu titles appear on the site as visible headings [L1303.033].

Secondary footer and policy menus

  • A secondary footer menu is created via Online Store > Navigation > Add menu, named Quick Links. Typical items are About Us (Pages > About us), Privacy Policy and Terms of Service (both under the Policies section in the link search box), and Contact Us (Pages > Contact us) [L1320.006].

  • To replace the footer quick links with a policy menu [L1326.014]:

    1. Go to Online Store > Navigation and create a menu named Our policies.
    2. Add the policy pages to that menu.
    3. In the theme editor, open the footer and click the menu block.
    4. Click Change menu and select the Our policies menu.
    5. Click Save.

    [L1326.014]

Quick Links and policy pages

  • Quick Links menu must contain these items in this exact order [L0092.010]:

    1. About Us (Page)
    2. Returns / Exchanges (Refund Policy)
    3. Shipping (Shipping Policy)
    4. Privacy Policy (Policy)
    5. Terms of Service (Policy)
    6. Contact Us (Page)

    [L0092.010]

  • Procedure to build the Quick Links menu [L0092.011]:

    1. Click Create Menu.
    2. Name it Quick Links.
    3. Add menu items in this order: About Us (Page), Returns / Exchanges (Refund Policy), Shipping (Shipping Policy), Privacy Policy (Policy), Terms of Service (Policy), Contact Us (Page).
    4. Use Pages or Policies when selecting link types.
    5. Save the menu.

    [L0092.011]

  • Second Quick Links procedure, with the policy and page sources spelled out [L1319.012]:

    1. Go to Shopify Admin > Content > Menus and click Create menu.
    2. Name the menu Quick Links.
    3. Click Add menu item, name it About Us, and link it to the About Us page in the Pages list. Tick the checkbox.
    4. Add an item named Returns/Exchanges and link it to the refund policy in the Policies section.
    5. Add an item named Shipping and link it to the shipping policy in the Policies section.
    6. Add an item named Privacy Policy and link it to the privacy policy in the Policies section.
    7. Add an item named Terms of Service and link it to the terms of service page.
    8. Add an item named Contact Us and link it to the Contact Us page in the Pages list.
    9. Click Save.
    10. Refresh the storefront and check that all six links are present.

    [L1319.012]

  • Policy pages (refund, shipping, privacy, terms) must be selected from the Policies section. About Us and Contact Us are normal pages selected from the Pages list. Choosing from the wrong list links to the wrong page [L1319.014].

  • Quick links menu in the footer: select the correct menu in the theme customizer footer settings, and it will appear [L0836.051 (2024)].

  • In the menu setup, the header menu must be set to Main menu, and the footer Quick links block must be set to the Quick links menu via Change menu [L1285.028 (2024)].

  • Older top bar menu (2021-2022) [L1303.024]:

    1. Go to Online Store > Navigation and click Add menu.
    2. Enter a title such as Top Bar menu.
    3. Add menu items linking to your business pages, such as About Us, Contact Us, Shipping, Easy Returns, and Privacy.
    4. Click Save menu.
    5. Make sure the theme supports a top menu before expecting it to appear on the site.

    [L1303.024]

  • The top bar menu runs along the very top of the site, but only appears if the theme supports it [L1303.014].

  • Terms of service and privacy policy pages should appear in more than one navigation location, such as a dropdown under the company item, the top bar, and the footer. Ad platforms may refuse to run traffic if they cannot clearly see these legal pages, so redundancy removes any doubt [L1303.034 (older, 2021-2022)].

  • The phone number, Privacy Policy, Terms of Service, and Contact Us links must appear in the header and footer of the site. Google checks for these, so missing links can cause approval problems [L1145.011 (older, 2021-2022)].

  • Conflict on policy links in the header: the 2025 advice says header menus should use their space for categories and collections, not policy links [L0255.020]. Older advice (2021-2022) puts policy and business pages in the top bar and the header, and ad review requires the legal links to be visible [L1303.024, L1145.011, L1303.034]. Use the top bar for policy and business pages, and keep the header main menu for categories, as the newer advice describes.

  • Menu links may not appear immediately on the website after saving. This is normal, and final menu placement occurs during theme customization [L0092.012].

  • A newly saved menu may not show in the correct spot on the storefront right away. Check the menu placement in the theme settings before assuming the menu is broken [L1319.015].

Mega menus

Deciding whether to build one

  • Do not build mega menus for a demo store. Mega menus are expanded menus showing categories, skill levels, colours, and price ranges. Build them later, when real products are added [L0102.007].
  • A mega menu shows a dropdown as a multi-column panel that splits categories into sub-groups such as product type, level, or colour. It only pays off once the store has many real products with sizes, colours, or prices, so it can wait until then [L1018.002].
  • In the Manhattan theme, the header settings contain an Add mega menu option. The desktop menu type can stay on mega menu, but adding the mega menu block is optional at the start and can be deleted again [L1018.003].
  • Setting up detailed mega menus before any products are live means the menu will show empty or placeholder content, and links may point to the wrong place. Add the mega menu once products with variations are uploaded and collections exist [L1009.008].
  • Mega menus make product variations such as size, colour, weight, or skill level easy to reach from the top menu. Customers get to the right product page faster, which tends to raise conversion rate. The feature is most useful once supplier products with several variations are on the store [L1009.009].
  • A store can have several mega menus, for example one per main category, plus additional ones for subcategories such as stand-up paddle boards or car racks. Only the main niche category needs a mega menu to start [L1010.011].
  • The mega menu is a multi-column dropdown in the Shopify header. It lets shoppers browse by category, type, skill level, or colour from the hover state of a top-level link, and it is meant to make the store easier to navigate and find products in [L1010.001].

What a mega menu is in the Manhattan theme

  • In the Manhattan theme, a mega menu is a built-in dropdown option under the header settings in the Theme Customizer. It turns a top-level menu item into a wide panel that shows subcategories, filters, and featured products. It does not replace the standard menu, and only the items you choose need to be converted [L1009.001].
  • The Manhattan theme includes built-in mega menu support through the Add mega menu option under Shopify Admin > Online Store > Themes > Customize [L0102.012].
  • Each mega menu affects only the item it is linked to. The other dropdowns keep their standard look, and each one needs its own name, link, sections, and featured products [L1009.012].
  • A mega menu supports up to six columns, though fewer can be used [L1010.006, L0146.008]. Each mega menu can have up to six columns [L0146.008].
  • A mega menu allows up to six sections, which can fill the full width of the screen. Use only as many sections as help customers filter and find products, because adding more can clutter the menu [L1009.006].

Fields in the mega menu settings

  • The Manhattan theme's Theme Customizer under Header > Mega menu has these fields [L1009.003]:
    • Mega menu name (set to the collection name).
    • Mega menu link (the collection the top-level item links to).
    • Enable mega menu one item (switches the feature on).
    • An image and title for each section.
    • A link for each section title (can be left blank if no collection exists).
    • A select-menu field where a Shopify menu is chosen for that section.
    • At the bottom of each mega menu, you choose up to two products to feature.
  • Each section must be switched on with its own toggle. The first toggle is labelled Enable mega menu one item, and the following sections use the same pattern (Enable mega menu two item, Enable mega menu three item, and so on), up to six sections in total [L1009.011].
  • Each mega menu column is configured separately. Enable a mega menu item, which reveals a small caret, then choose an image for the column, set its name, and select the menu it links to. The column name is the heading in the dropdown, and the linked menu's items appear beneath it [L1010.005].
  • When a mega menu item is enabled in the theme editor, it is linked to the main menu by default. Change that link to the menu meant for the column, such as a Skill Level menu, before saving, or the column will show the wrong links [L1010.018].

Creating the mega menu

  • Shopify places new mega menus on the right by default because it treats them as new menu items. To control placement, create a new menu first, then assign it to the header [L0146.005].

  • A newly created mega menu is placed on the far right of the header, after all existing menu items. Shopify does not allow drag-and-drop reordering of menu items, so moving it next to Home requires changing which menu the header uses [L1010.003].

  • Procedure in the Shopify theme editor [L0146.002, L0146.004]:

    1. Go to Shopify Admin > Online Store > Themes and click Edit theme to access the store theme editor [L0146.002].
    2. In the theme editor, click Header, click Add mega menu, name it (for example Surfboards), and link it to its main collection [L0146.004].

  • Procedure to place a mega menu directly after Home [L1010.004]:

    1. Go to Content > Menus and create a new menu with a Home item (linked to the homepage) and a category item (linked to the category collection).
    2. Save the new menu.
    3. Go back to Online Store > Themes > Edit theme and open the Header section.
    4. In the menu field that currently says main menu, select the new menu and save.
    5. Click Add mega menu, name it, link it to the category collection, and save.

  • Second procedure to place a mega menu after Home [L0146.006]:

    1. Go to Content > Menus.
    2. Click Create new menu.
    3. Name it (for example Mega Menu).
    4. Add Home, linking to the homepage.
    5. Add your main category, linking to its collection.
    6. Save the menu.
    7. Go to Online Store > Themes > Edit theme > Header.
    8. Change the Menu dropdown from Main menu to the new menu name.
    9. Save changes.

  • After assigning a new menu to the header, click Add mega menu, name it, and link it to its collection to place the mega menu directly after Home [L0146.007].

  • Setup in the Manhattan theme Theme Customizer [L1009.002]:

    1. Open the Theme Customizer and go to Header > Mega menu.
    2. Rename the default mega menu item to the name of the collection it belongs to, for example surfboards.
    3. In the mega menu link field, select the matching collection so that clicking the top-level item opens that collection.
    4. Turn on Enable mega menu one item and click Save.
    5. Refresh the published store to check the change. At this point the panel shows only the featured product until sections are added.
    6. Create the section content (images, titles, linked menus) in the mega menu settings.
    7. Assign the menus you created in Shopify to each section and click Save after each change.
    8. Refresh the storefront and hover over the menu item to check the result.

  • Mega menu setting in the 2025 course: a mega menu can be deleted from the Header section of the theme editor and rebuilt from scratch. This is a quick way to restart a menu layout that has become tangled, without repairing each column individually [L1010.023].

  • The theme editor preview can show old values after a save. Check the mega menu on the live storefront after saving and refreshing the page, rather than relying on the editor's preview [L1010.021].

Building the columns and sections

  • Prepare one small image per mega menu section before you configure the mega menu. The section image field only lets you choose images that are already uploaded. Using a different colour for each section helps you tell them apart [L1009.015].

  • Prepare one image for each mega menu column before building the menu, because the theme editor asks for an image for every column [L1010.020].

  • Create the menus that feed a mega menu section [L1009.004]:

    1. Click Create menu in the mega menu section selector, which opens Shopify's Menus page.
    2. Give the menu a name that matches the section, for example surfboards.
    3. Click Add menu item for each subcategory, enter the item name, and link it to the matching collection using the Add button.
    4. Add as many items as help visitors find products easily. Keep item names and collection names consistent.
    5. Click Save menu.
    6. Return to the Theme Customizer, open the mega menu, and select the new menu for the section. If it does not appear, refresh the page and make sure the menu was saved.
    7. Click Select, then Save.

    [L1009.004]

  • Procedure to fill a mega menu column with sub-links [L1010.007]:

    1. Go to Content > Menus and create a menu named after the column, for example Surfboards.
    2. Add one menu item per option, each linked to its own collection, for example Hybrid, Shortboards, Mid-length Boards, and Longboards.
    3. Save the menu.
    4. Return to the mega menu, open the column, click Replace, and select the new menu.
    5. Save and refresh the page to confirm the links show under the column heading.

    [L1010.007]

  • Procedure to fill a mega menu column, with a different sequence [L0146.009]:

    1. In the mega menu editor, rename the column (for example Surfboards by Type).
    2. Select an image for the column.
    3. Create a new menu with the column name.
    4. Add menu items (for example Hybrid Surfboards, Shortboards, Mid-Length Boards, Longboards).
    5. Link each item to its corresponding collection.
    6. In mega menu settings, assign this menu to the column.
    7. Repeat for other columns (for example Skill Level with Beginner and Pro; Color with Blue, Yellow, Red).

    [L0146.009]

  • Procedure to add another section to an existing mega menu in the Manhattan theme [L1009.013]:

    1. Open the Theme Customizer, go to Header > Mega menu, and open the mega menu for the top-level item.
    2. Scroll down and enable the next section toggle, for example Enable mega menu two item.
    3. Select an image for the section from the images already uploaded.
    4. Enter the section title.
    5. Link the title to its collection, or leave the link empty if the collection does not exist yet.
    6. Select the Shopify menu that should appear under the title.
    7. Click Save, refresh the storefront, and hover over the top-level item to check the result.

    [L1009.013]

  • After creating mega menu columns, go to Content > Menus, edit the Mega Menu, add the remaining links (for example Swimwear, Essentials, Car Racks) as simple menu items, then save [L0146.011].

  • To restore the other top-level links after switching to the new menu [L1010.012]:

    1. Go to Content > Menus and open the menu used by the header.
    2. Click Add new menu item and search for each collection you want, such as Swimwear, Essentials, and Car Racks.
    3. Check the items off and save.
    4. Refresh the storefront to confirm the links appear in the header.
    5. Before replacing a menu, take a screenshot of its items so the original structure can be rebuilt.

  • The menu selector in each mega menu section lists the default Shopify menus, such as Main menu and Quick links, plus any custom menus you have saved. A new menu appears only after it has been saved in Shopify, and the Theme Customizer may need to be reloaded before it shows up [L1009.017].

  • A Shopify menu that is not yet filled or saved may not show in the mega menu selector. Refresh the Theme Customizer after creating a menu, and check that the menu was saved before expecting it to appear [L1009.005].

  • A menu created under Content > Menus does not appear in a mega menu column's menu selector until the list is refreshed. If the new menu is missing, reload the theme editor and check again before assuming it was not saved [L1010.019].

Theme settings for menus

Header settings

  • Header > Menu lets you choose which navigation menu appears in the header. The default is Main menu. Click Change to select another menu created earlier in Shopify's navigation settings [L0775.022].
  • The header menu is linked to the main menu by default and should stay linked [L1018.001].
  • Header > Desktop menu type offers Mega menu, Drawer, and Dropdown. Mega menu is the option used in the example. Drawer turns the menu into a hamburger icon that opens in a side panel [L0775.023].
  • The desktop menu type offers mega menu (the default in this example), drawer, and a third option. Drawer shows a hamburger icon and opens the menu in the sidebar [L1309.018].
  • Header menu typography: the menu font size is 14 by default, and font weight 500 is the usual setting for menu text, where weight means boldness. Change the size only if your chosen font looks too small or too large at 14 [L0775.025].
  • Navigation menu colour scheme used in the example: background black, first-level link white, sub menu background white, sub menu link blue, sub menu border pink, active link white [L1309.022].

Checking and troubleshooting

  • After saving a menu, reload the live storefront to confirm the new items and any dropdowns appear as intended [L1303.035].
  • Mega menu not appearing: check the Shopify theme customizer to confirm the mega menu option is selected, then compare with the support screenshot [L0836.052 (2024)].
  • Test the menu for hover sensitivity bugs before scaling traffic [L1225.024].
  • In the 2025 course, check whether a top-level item is a mega menu by hovering over it in the live preview [L1018.017].
  • Refresh the storefront after saving. Menu changes sometimes take a minute or more to show on the live store, so refresh before judging the result [L1320.003].
  • Save, then refresh the page. Changes in the menu editor only show on the storefront after you click Save and refresh [L1319.006].
  • Shopify menu link search: use the exact collection name to avoid a wrong match [L1320.014].

Common mistakes

  • If you save without dragging items to the right, every item stays on the top level and no dropdown appears [L1319.006].
  • Menus with placeholder # links send visitors to the homepage [L1303.020].
  • Mega menu columns showing the wrong links usually mean the column's menu link was left on the main menu [L1010.018].
  • Linking to Amazon sends shoppers away and loses sales [L0551.028 (older, 2020)].
  • Footer menus with nested items show only top-level links on the live store [L0681.017 (older, 2021-2022)].
  • The default footer menu loads the main menu items, which is not useful in the footer [L1303.026 (older, 2021-2022)].
  • Choosing a policy or page from the wrong list links to the wrong page [L1319.014].

Menus and navigation structure

Site structure and levels

A typical e-commerce site has three levels, with the homepage at the top:

Level Page Position and links
1 Homepage Root domain entry point; links to all level 2 pages through the main menu, bottom navigation, and search bar
2 Collection pages (Shopify: collections) Grouped product tiles; each tile opens a product page
2 Single pages (Shopify: pages) About Us, Contact Us, Shipping Policy, Privacy Policy, Terms of Sale, Returns Policy; linked from the homepage and navigation
2 Blog page Lists blog posts; each post opens its own page
3 Product pages Reached from collection pages; use one template for all products
3 Blog posts Reached from the blog page; created only after launch

[L1463.013]

When navigation matters

  • Site navigation matters most when the store has many products (product numbers in the hundreds or more) or a large amount of content besides product pages. [L1522.003]
  • A single-product store needs little navigation beyond getting shoppers to that product. [L1522.003]

Header menu

Keeping the header short

  • Keep the header menu short when the store sells one main product or only a few items, using just the essential links such as shop, collection, or the product itself. [L1326.026]
  • Stores with many product categories can add more header menu entries to help visitors find each group. [L1326.026]
  • Keep the top menu minimal, for example only Shop and Contact. A focused layout keeps the visitor's attention on the product description and the buying decision. [L1345.054]

Changing the header menu

  1. Create the new menu under Online Store > Navigation with its own items. [L1326.025]
  2. Open the header section in the theme editor under Online Store > Themes > Customize. [L1326.025]
  3. Change the menu setting from Main menu to the new menu. [L1326.025]

Search bar in the header

  • Place a large, prominent, sticky search bar in the site header. Returning visitors often land on the homepage looking for a product they already viewed, so the search bar gets them there fastest. [L1522.004]
  • The search bar should show dynamic results as the shopper types, displayed in a dropdown under the bar. [L1522.005]
  • Avoid sending shoppers to a separate search results page because it adds a step. [L1522.005]

Footer menu and quick links

Setting up the footer menu

  1. Go to Content > Menus. [L1331.034]
  2. Create or select a footer menu. [L1331.034]
  3. In the theme editor, open the Footer section and the Menu - Quick links block. [L1331.034]
  4. Select the footer menu instead of the main menu, since the main menu has only three items. [L1331.034]
  5. Add links to About us, a product page, Contact us, and the policy pages. [L1331.034]
  6. Save and refresh the preview to confirm the links appear. [L1331.034]

Breadcrumb navigation

  • Breadcrumb navigation, the line of links along the top of product and collection pages, adds internal links and should be kept on. Some store owners turn it off because they dislike its look, and that is a mistake. [L1465.021]
  • In most Shopify themes, breadcrumb navigation is an on/off option in the theme's settings. [L1465.022]
  • If a theme has no breadcrumb navigation at all, have a developer add it, which is usually not a major coding job. [L1465.022]

Further details

  • To add a mega menu in Shopify, go to Online Store > Themes > Edit theme, open the Header section in the left panel, and click Add mega menu. Name it and set its link to the relevant collection, such as the main category collection. [L1010.002]

  • Shopify menus organize how shoppers move through the store by linking to collections, pages, policy pages and blog posts. Each theme places menus in fixed spaces, so the menus you build are shown in those spaces. [L1319.001]
