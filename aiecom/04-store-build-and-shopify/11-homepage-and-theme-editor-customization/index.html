4.11 Homepage and theme editor customization

Theme editor access and basic rules

  • The Theme Customizer is Shopify's built-in visual editor for changing a theme without touching code. It adjusts the website font, color scheme, layout and store content from a side panel on the customized themes page. [L0595.001]
  • Use the Customizer's built-in settings for everyday look changes first. Go into the theme's HTML/CSS only for structural changes the Customizer cannot make. [L0595.002]
  • Avoid editing theme code unless a change truly cannot be made in the Customizer. Opening the code editor by accident means you are in the wrong place for ordinary design work. [L0595.003]
  • Admin path: Online Store > Themes > Customize. The Source A Manhattan theme must be installed to use this path. [L0595.006]
  • Steps to open the theme customization pages:
    1. Log in to the Shopify account. [L0595.005]
    2. Click Online Store in the Shopify admin. [L0595.005]
    3. Click Themes. [L0595.005]
    4. Find the installed theme named Source A Manhattan. [L0595.005]
    5. If it is the currently published theme, click the Customize button. [L0595.005]
    6. If you are upgrading from another theme and Manhattan is not yet published, find it in the list of unpublished themes further down the page and click Customize. [L0595.005]
    7. The side menu that opens lists the elements you can edit, and changes made there alter what visitors see on the store. [L0595.005]
  • Before opening the theme customization pages, the basic store should already have its menus, some collections and a demo product in place. The Customizer then turns that bare structure into the finished look. [L0595.008]
  • To open the homepage editor, go to Online Store > Themes, confirm the active theme is the one you are building, and click Customize. Check that the page dropdown at the top of the editor says Homepage before making changes. [L0775.002]
  • In the sidebar, hovering a section highlights it on the page, and clicking an element in the preview opens its settings. Each section can be hidden with the eye icon or removed with delete, and sections can be reordered by dragging the six-dot handle. [L0775.003]
  • The left sidebar mirrors the homepage layout from top to bottom. Hovering a section name highlights it on the live preview, and clicking an element on the preview jumps to that section in the sidebar. [L0101.018]
  • Click Save after every change in the theme editor, then reload the live product page to confirm the change appears, because the preview does not always show the final result (for example end dates or hidden blocks). [L0976.015]
  • Theme settings apply to the whole store, including fonts, buttons and header. Section settings only affect the section they belong to. Each section's color scheme dropdown uses the color schemes defined in Theme settings > Colors, so one color change updates every section that uses that scheme. [L0775.063]
  • Collection pickers in the collection list and featured collection sections only show collections that already exist. Create and fill the collections under Products > Collections first, then add them to the homepage. [L0775.064]

Order of work and time budget

  • Budget 60 minutes to complete the full homepage customization when image assets are already created, because the work is primarily asset placement. [L0101.013]

  • Work through the homepage in this order:

    1. Upload all images to Files. [L0775.062]
    2. Set logo and favicon. [L0775.062]
    3. Set colors and typography. [L0775.062]
    4. Set layout and buttons. [L0775.062]
    5. Set header, sticky header and menu colors. [L0775.062]
    6. Configure slideshow, collection list, featured collection, pre-footer and email signup. [L0775.062]
    7. Hide unused sections. [L0775.062]

    After each step, save and check the preview on desktop and mobile. [L0775.062]

  • The same work can also be read as an outline of four blocks: homepage and general customizations, menu customizations (header and footer menus), collection page customizations (layout and visuals), and product page customizations (layout and settings). [L0100.002]

  • Theme customization transforms a Shopify store from its default basic template (gray/white/black appearance) into a branded store by applying image assets and making layout and settings adjustments within the theme editor. [L0100.001]

  • Advanced web design changes are optional final tweaks for a store that already performs well and needs extra gains. They are not necessary to get initial results. [L0544.007]

  • Shopify's native editor is moving toward more page-builder flexibility, such as moving elements without code. This reduces the developer work needed for simple layout changes. [L0709.007]

Global settings: logo, favicon, colors, typography and layout

  • Set desktop logo width to 200 pixels in Theme settings > Logo. The default is usually acceptable. [L0101.009]
  • Increase page layout width to 1600 pixels in Theme settings > Layout for a wider, more spacious presentation. [L0101.010]
  • To make the page narrower instead, go to Online Store > Themes > Customize, click the gear icon for Theme settings, and open Layout. Type a value into Page width or drag the slider. Spacing and padding are controlled in the same theme editor section. [L0471.007]
  • Note on width (2024 advice versus the 1600 setting): the 1600 value is for a wider look, while the Page width field from the same Layout section is the way to narrow it. [L0101.010, L0471.007]
  • Keep the global palette to 2-4 colors, using brand hex codes and the roles in the Colors list. [L0101.001]
  • Keep the color changes in Theme settings > Colors, since every section's color scheme draws from there. [L0775.063]

Theme settings: search, pop-ups and custom CSS

  • Open the theme customizer, click the gear icon labelled Theme settings to reach the additional features, and work through the settings in the order they appear in the panel. [L0973.003]
  • In the Manhattan theme settings panel, the sections appear in this order: Search behavior, Email pop-up settings, Exit pop-up, Cross-sell, Social proof pop-up, the Source A tracking option, and Custom CSS. Review them from top to bottom, and click save after changing the tracking option. [L0973.016]
  • Search behavior: keep search suggestions enabled and turn on showing the product price within those suggestions. This setting controls what happens when visitors click the magnifying glass and search the store. [L0973.004]
  • Custom CSS field: paste code here to change how the store looks when the theme editor has no native option for it. Use it only for appearance changes that cannot be made in the normal theme settings. [L0973.014]

Social media links

  • Remove default social media URLs from Theme settings > Social media if you do not have active accounts, because suppliers must not click social icons that lead to Shopify default pages. [L0101.003]
  • Turn off footer social media icons if you do not have real social profiles yet. Never send suppliers to a store with dead or placeholder social links. [L0102.008]
  • Footer social icons in the Manhattan theme only appear for social channels that have a full URL entered in the theme customizer. Check each link, including the full https:// address, and save. [L0836.050]
  • Footer > Show social media can stay enabled even with no links, because the social icons only show real links. Add links later through the gear icon, in the social media fields, and make sure the show-link option is on. If no social pages exist yet, delete the empty links. [L0680.005]
  • Do not lead the header navigation with social media links such as Facebook, Instagram, Twitter, YouTube or Pinterest. Shoppers who came to buy should first see shop pages, collections and product categories. [L1098.010]

Header

  • In Shopify Admin, navigate to Online Store > Themes > Customize. Select Header from the left sidebar. Ensure your Menu setting references Main menu. Confirm that your Desktop menu type is configured to Mega menu, the standard theme default. [L0102.001]
  • Header > Sticky header with the Always on option keeps the menu bar visible while visitors scroll. A related option shrinks the logo on scroll and is useful when the logo file is large. [L0775.020]
  • Sticky header set to Always on keeps navigation visible while scrolling, because customers can always access the menu without scrolling back to the top. [L0101.007]
  • Header > Desktop logo position offers Top left, Top center, Middle left and Middle center. Top left is the common default for most stores. [L0775.021]
  • Header > Show separator line adds a thin line under the header and is on by default. Turn it off if you want a cleaner header. [L0775.024]
  • Header mobile layout lets you move the logo to a different position on phones, such as center or left, separately from the desktop position. Always save, then open the store on a phone to check the result. [L0775.032]
  • The header in the Source D theme editor has a Menu type setting (for example Sticky header), a Separator line option, an Enable top border option with a color set to Use Theme Colors, and a Middle left position set to Main Menu. Scroll up behaviour is controlled by the On scroll up option. [L1013.014]
  • Header contact details, as in the default setup: add service hours (optional), add an email, and replace with a phone number in a later module. [L0101.001]
  • Customize header colors: Header > Navigation menu color, update Background color, Link colors, Dropdown background, Dropdown link colors, Border colors using only brand palette, save. [L0101.001]
  • A large header logo that pushes content down wastes vertical space. Use the empty header space for a short message that helps the buyer, such as free personalized note cards included with every order. [L0355.008]
  • A header that only says "welcome to our store" is lazy and generic and wastes the top of the page. Replace it with a call to action or a scarcity message. [L0530.019]
  • Fast themes often ship with demo homepages and headers that are not built for conversion, such as social media icons first in the header and oversized hero slideshows. Right after installing a theme, reconfigure the header, homepage and collection layout for shopping instead of keeping the demo structure. [L1098.025]
  • Older method (2020): changing the header so the logo sits in the same row as the menu was done by editing code. Open the theme editor and the code editor, change the header code by copying and pasting the required code, or hire a Shopify developer on Upwork if not comfortable with code. [L0852.089]
  • Native option versus older code method: the 2020 approach used header code, while the current Desktop logo position setting in the Header section offers Top left, Top center, Middle left and Middle center without code. [L0852.089, L0775.021]

Announcement bar

  • Default setup hides the announcement bar by hovering over it in the sidebar and clicking the eye icon. [L0101.001]
  • If the theme has a built-in announcement bar section, build the bar there by entering the text and the code in the theme's customization settings. Use a separate app only when the theme does not offer this or when another solution is preferred. [L0531.009]
  • An announcement bar at the top of the store can show a sitewide promotion, for example a 10 percent discount. Competitor stores use it to push a current offer on every page. [L0600.011]
  • Use the Quick Announcement Bar app only if you want different promotions shown on different supplier pages. A theme's built-in announcement bar is enough otherwise. Older advice (2021). [L0834.049]
  • The coupon code bar at the top of the store is edited in Shopify admin under Store, then Store settings. If it still appears after the theme is changed, check the store settings first. Older advice (2020). [L0468.064]
  • In the header bar editor, the text font size can be increased, but the bar height cannot be set directly. If no adjustment is possible at all, the app or theme should be checked for a problem. Older advice (2019). [L0960.003]

Conflict on announcement bar, by purpose:

  • Hide it while building, if there is no promotion yet [L0101.001]
  • Use the built-in bar for a single sitewide message [L0531.009, L0600.011]
  • Use an app only for different messages per page [L0834.049]

Homepage structure and what to show

  • Homepage structure, in order:
    1. Show one hero value proposition at the top that states the core benefit for the target audience. [L0524.014]
    2. Link straight to best sellers and the product range. [L0524.014]
    3. Give a short explanation of what the product does and how it differs from alternatives. [L0524.014]
    4. Offer bundles and subscriptions to lift average order value. [L0524.014]
    5. Add testimonials and social proof. [L0524.014]
    6. Add authority logos from recognised media in the niche, placed higher up the page. [L0524.014]
  • Arrange the homepage sections in the same order as the demo store of the theme. Copying the working layout reduces setup time. Older advice (2020). [L0664.039]
  • The home page should not replace the product page. If the home page is the only page a visitor sees, the shop is set up wrong and conversion suffers, so the product should be the main page of a single-product store. [L0530.016]
  • Group the homepage around one clear store theme. A homepage that mixes unrelated categories, such as gag gifts, surf, apparel and novelties with no gift theme, looks random and makes navigation hard. [L0355.006]
  • A store must make sense within seconds to visitors arriving from a Facebook ad, a Google ad or any other source. Navigation, logo and copy should together show who the store is for and what it sells. [L0355.012]
  • For a single-category fashion store, organize the homepage into collections by dress type, each with a hero image showing a person wearing the items. This gives visitors a clear path into the collections and makes the store look like one focused range. [L0838.023]
  • A homepage layout example uses square collection images in rows of three, followed by a row of three more, with a best-sellers collection placed next to the main product collections. Six square homepage images are needed for that layout. [L0342.027]
  • Homepage collection tiles can be arranged in rows of three, for example six tiles in two rows, with the most popular collections such as a best sellers collection placed where customers see them first. [L1045.031]
  • Unused default Shopify sections, such as an empty video section or a promotions box with no content, should be removed from the homepage. Leftover empty sections add clutter and signal an unfinished store. [L0355.011]
  • Competitor layouts will not map one to one onto a different theme. Rebuild the same section type with your own theme's settings, and keep the purpose of each section, such as proof, FAQ or transformation, even when the design changes. [L0600.009]
  • Video carousels and slider sections are built into almost every Shopify theme, especially Atlas and Shrine. Use the sections your theme already offers rather than custom development when recreating a competitor layout. [L0600.008]
  • Quick navigation section above the main banner, as taught for the Source E course:
    1. Display 5-6 visual category shortcuts. [L0197.021]
    2. Style them to resemble Instagram story cards, a visual pattern shoppers recognize. [L0197.021]
    3. Include current sales and new product promotions. [L0197.021]
    4. Position the section above the fold for immediate visibility. [L0197.021]
  • Recently viewed products can be enabled in the theme editor under the Recently viewed products section (Settings > Enable recently viewed products). This setting applies to both collection pages and product pages. It is useful for returning customers but shows nothing until a visitor has viewed products. Older advice (2021-22, Source B's theme). [L0370.002]

Slideshow (hero)

  • Steps to set up the homepage slideshow:
    1. Open the Slideshow section in the editor. [L0775.033]
    2. Delete extra blank slides and keep one. [L0775.033]
    3. Click the first slide, select an image, click Done. [L0775.033]
    4. Enter the heading, subheading, button label and button link, then set the desktop and mobile content position. [L0775.033]
  • Full default slideshow steps: use 1 slide only, delete blank slides, Slideshow > Slide height select Adapt to first image, keep full width, add hero image asset, add Heading (example: primary collection focus), add Subheading (benefit-oriented), Button label (example: Shop Now), link button to relevant collection, position content (example: bottom right), align text (example: right), adjust button colors if needed, save. [L0101.001]
  • A new Shopify slideshow comes with three blank slides. For a supplier demo store, one slide is enough, and you can add more later with Add a slide for new suppliers or seasonal sales. [L0775.034]
  • Slideshow settings include Full width or Grid layout, Slide height set to adapt to first image (or small, medium, large), and pagination as dots or numbers. Auto rotate can be set to change slides every 3, 5 or 9 seconds, and animation style controls the transition. [L0775.035]
  • Slideshow accessibility field holds a short description of the slideshow, which screen readers announce to visually impaired visitors. Something like a slideshow about your brand is sufficient. [L0775.036]
  • Slide content settings include Heading, Subheading, Button label, Button link, Desktop content position, Desktop alignment, Show container on desktop, Button color, Button text color, and mobile alignment. In the example, the content sits bottom right, aligned right, and the button label is Shop, linked to a collection. [L0775.037]
  • Button text must contrast with the button color. If you change the button color to a dark brand color, also set Button text color to white. Otherwise the label becomes unreadable on the slide. [L0775.038]
  • Preview the slideshow on a phone after making changes and adjust the mobile alignment if the text covers the image. Save only after the mobile view looks right. [L0775.039]
  • Slideshow images that are cut off on the store are usually the wrong size for the slot. Crop or resize images to the required dimensions before uploading them. Older advice (2019). [L0960.048]
  • A hero image is one image shown on both mobile and desktop, so you cannot upload separate versions. To enlarge it on mobile, make the image taller in pixels, which also enlarges it on desktop. [L0972.020]
  • Hero slideshows should follow the conversion layout above, not the demo structure. Oversized hero slideshows are a demo default to replace. [L1098.025]

Featured collection

  • Featured collection section settings include Heading (example: What's trending in surfing), Collection (example: Best sellers), Number of products (4) and Number of columns (4), so four products show in one row. [L0775.046]
  • Display 4 products in 4 columns in the featured collection section on the homepage for balanced visual proportion. [L0101.011]
  • A featured collection section displaying real products directly on the homepage makes the store appear like an active, inventory-carrying business, which is necessary for both supplier approval and customer confidence. [L0101.008]
  • Product card options in the featured collection let you show or hide a secondary image, vendor and product rating. The sale badge position and its color scheme are set here. Quick view opens a product in place with an add to cart button when turned on, or sends the visitor to the product page when turned off. [L0775.047]
  • Use 5 to 10 products for best sellers, top rated and staff picks sections on the homepage. This is 2023 advice and differs from the 4-product featured collection setup above, so apply it to those sections specifically. [L0964.098, L0101.011]

Image banner

  • Image Banner section on the homepage: hide if you don't have content ready. Use this section for buyer's guides or featured content. [L0101.020]
  • Image banner section settings include the image, Banner height (adapt to first image), Desktop position (middle center), a Container toggle that adds a background box behind the text (off makes text sit directly on the image), heading, description, two buttons with labels and links, and Image behavior (None or ambient movement). Pre-footer trust columns

  • Pre-footer section holds several columns, each with an image, header, description and optional link. Set the color scheme to Background 1 (white) for a clean look on a white page. [L0775.056]
  • Configure pre-footer: add 4 columns with icon and short benefit headline (example headlines: Free Shipping $100+, Surfer Owned & Operated, Fast & Secure Checkout, Easy Returns), add links only if pages exist, set background to white if cleaner, save. [L0101.001]
  • Only link pre-footer columns to pages that already exist. Leave a column unlinked until its page is created, because broken or placeholder links look unprofessional when a supplier clicks through. [L0775.057]
  • Link policy pages such as shipping and returns in the pre-footer once they exist. Until then, a temporary link to an existing page such as terms of service is an acceptable fallback, and should be replaced later. [L0775.058]
  • Pre-footer trust column pattern: a short benefit headline followed by one reassuring sentence about how the benefit is delivered. The headline is 2 to 4 words, and the description names the concrete promise. [L0775.059]
    • Example: Free returns for 30 days, Refunds go back to the original payment method within 5 business days.
    • Example: Secure payment, Checkout is encrypted and card details are never stored on our site.
  • The Source A theme supports up to seven USP icons in the pre-footer section, and fewer can be used. Each USP should state something that sets the store apart, for example free shipping, a price match guarantee, a women-owned or veteran-owned business, a secure checkout, or 24/7 customer service. [L1045.033]
  • Conflict on pre-footer column count: the Source A homepage procedure uses 4 columns, while the Source A theme supports up to seven USP icons. Use 4 for the standard setup and up to 7 when that theme is in use. [L0101.001, L1045.033]

Footer: placement, structure and rules

  • The footer is a global section that appears on every page of the Shopify store, including the home page. It is edited in the theme editor under the Footer section. Its menu blocks, payment icons, language and currency selectors, small footer text and rich text blocks are all configured from there. Older advice (2021-22, Source B's theme). [L0681.002]
  • Footer setup in Shopify, using the Manhattan theme:
    1. Open Shopify admin, go to Online Store > Themes, click Customize. [L0680.001]
    2. Confirm the theme is Manhattan. [L0680.001]
    3. Stay on the homepage view, scroll to the bottom and click the footer section. [L0680.001]
    4. Set the main footer settings (color scheme, localization, payment icons, social media). [L0680.001]
    5. Set the top and bottom padding. [L0680.001]
    6. Edit the first column as Contact us. [L0680.001]
    7. Edit the second column with the store name and its linked menu. [L0680.001]
    8. Edit the third column as Quick Links and link its menu. [L0680.001]
    9. Edit the fourth column as the newsletter signup. [L0680.001]
    10. Click Save, open the live store, refresh it and check the footer. [L0680.001]
    11. Adjust the logo size if needed, save again, then exit the admin. [L0680.001]
  • Footer setup in the theme editor, in this order (alternative sequence with the same goal):

Slideshow and hero banner

Hero banner principles

  • A homepage banner should show the customer's outcome or passion, so a visitor immediately sees they are in the right place. Its main job is to state what the business does for the customer, and a temporary promotion is a secondary use. [L1310.001]
  • A hero banner needs four elements: a title, a subheader, social proof such as review counts or numbers of items saved, and a call to action. A missing call to action is one of the most serious gaps. [L1225.025]
  • Homepage banner pattern:

    [Store name] introducing [top-rated or number one rated] [product] for [customer type] in [country], paired with a benefit-driven image, followed by a short section on why the product helps and what the store stands for. It works because the visitor instantly sees the brand, the product and a clear benefit. Example one: Lumora introducing the top rated travel pillow for frequent flyers in Germany. Example two: Brinelo introducing the best rated desk mat for home offices in the UK. [L1217.040]

  • Homepage structure for a niche store begins with a banner that matches the feeling of the exact customer. Most traffic arrives via ads directly to product pages, so keep the page clean and branded. [L1158.028]

Slideshow settings (Manhattan and Superstore themes)

  • Slideshow layout: full width (used in the example) or grid. Slide height set to Adapt to first image so the image is sized correctly. Options small, medium and large exist. [L1309.025]
  • Pagination can be dots or numbers. Auto rotate can change slides every 3, 5 or 9 seconds. Set mobile content to show below images, and give the slideshow a short accessibility description. [L1309.026]
  • Slide content: heading and subheading go on top of the image, the button label is Shop, and the button link points to a collection. Desktop content position bottom right and alignment right were used in the example. [L1309.027]
  • Slideshow content settings let you set the button colour and the button text colour separately. A container background can be shown behind the text on desktop. Choose a button text colour that contrasts with the button colour so the label stays readable. [L1309.071]
  • Slideshow section margins add space above or below the whole section. Use them to adjust the gap between the slideshow and the sections around it. [L1309.067]
  • Keep one slide for the demo store. Delete the blank default slides and add more with Add slide later for new suppliers or sales events. [L1309.028]
  • Buttons in image banners and slideshows look faded or nearly transparent while they have no link. Their full colour shows only after a real destination, such as a collection, is set in the button link field. [L1309.063]
  • Slideshow settings in the Shopify theme editor include Enable slideshow, Autoplay slideshow, Autoplay slide duration and Slideshow height. The image field recommends 1800 x 1000 px. (Superstore theme, 2021-2022, older advice.) [L1310.017]
  • A slide's BUTTON 1 has the fields Label, Button, Link and Style, and Style is set to Primary. Clearing the Label field hides the button. The same panel holds the Heading, Subheading, Text color and Text alignment (Left) fields. (Superstore theme, 2021-2022, older advice.) [L1310.037]
  • Older advice (2021-2022) states that homepage sliders should not be used. JavaScript slows the page, and the cited figure says about 96% of customers never see the second slide. A single hero image at the top of the homepage is enough. [L1266.023]
  • Older advice (2021-2022) for the early-stage store: the slideshow is used as a single static hero image, which is fixed in the section list. [L1371.006]
  • Conflict: the older no-slider advice [L1266.023] and the single-static-hero advice [L1371.006] both point toward one image, while the Manhattan setup keeps a slideshow with one slide [L1309.028]. A one-slide slideshow matches both; a multi-slide rotation is what the older advice warns against. [L1266.023, L1371.006, L1309.028]
  • Four small images side by side on desktop should stack vertically on mobile. On a phone they become too small to read and can trigger Search Console accessibility errors. Keep the stacking instead of forcing a side-by-side layout on mobile. [L1287.024]

Collection lists and featured collections

Collection list

  • Collection list settings (Manhattan theme): heading "Shop our featured collections" in a small heading size, image ratio set to Adapt to image so mixed image sizes fit, and desktop columns set to 3. [L1309.029]
  • Text overlay on, placed bottom left, overlay colour teal from the brand palette, text white. Enable view all lets mobile visitors swipe through extra collections. [L1309.030]
  • Adding collections:
    1. Click Collection and choose a collection with Select.
    2. Click Add collection to create a new row for more items.
    3. Repeat until all collections are set, then Save. The example used six collections in rows of three. [L1309.031]
  • Superstore theme setup (2021-2022, older advice):
    1. Add the Collection list section and set the heading to Our Featured Collections.
    2. Set Desktop section spacing to 100 px (the maximum) and Mobile section spacing to 60 px.
    3. Keep four collections per row and delete any extra blocks.
    4. For each block, click Change, select a collection that has products, and click Select so its product image loads automatically.
    5. If a collection has no products, upload a custom image of a similar product type. Otherwise it shows a blank image.
    6. The collection title fills in automatically. Overwrite it with a custom title if needed.
    7. Click Save. [L1310.028]
  • A collection without products shows a blank image in the featured collections section. Use a custom image as a temporary placeholder and replace it with real supplier products when the store goes live. (Superstore theme, 2021-2022, older advice.) [L1310.029]
  • A simple homepage can feature the newest collection and a section with trending products. These two sections give a first-time visitor a clear starting point. [L1325.016]

Featured collection

  • Featured collection (Manhattan theme): change the heading to a short phrase such as What's trending, select a collection such as Bestsellers, and show 4 products in 4 columns. Product card options include secondary image, vendor and rating. [L1309.033]
  • Quick view shows a button that opens product details in place with an add-to-cart option. If turned off, the button leads straight to the product page. [L1309.034]
  • Sale badge: the product card settings include a sale badge position, a sale badge colour and an editable badge text. The badge defaults to a dark gray background and can be switched to a theme accent colour such as the pink accent. [L1309.065]
  • Keep featured collections linked only to collections that exist and contain products. [L1310.029, L1309.009]
  • The Featured collection section in the Superstore theme started with a beige background set by the theme. A white background is acceptable, and a light contrasting background can break up a long white homepage. Either can be changed in section settings. (2021-2022, older advice.) [L1310.042]

Image banners and image-with-text sections

  • Image banner (Manhattan theme): set the image as background, banner height Adapt to first image, desktop position middle center, container turned off so text sits directly on the image, and buttons linked to a collection once it exists. [L1309.035]
  • Image banner > Image behavior: None keeps the image still. Ambient movement makes the image move very slowly, which draws the eye to the banner. [L1309.036]
  • Highlights banner (Superstore theme, 2021-2022, older advice): desktop section spacing starts at 36 px and mobile at 20 px, with banner text centered. The tested build raised desktop spacing to 60 px. [L1310.039]
  • Create the destination pages first, such as Shipping, Contact us, Returns and Price match guarantee, before building Highlights banner blocks. Each block link must point to an existing store page. (2021-2022, older advice.) [L1310.038]
  • Shrine theme Image with text settings: Heading, Text, Link button, Image or Video, Media height (Adapt to media), Color schemes (Content color scheme and Section color), Desktop layout (Full page width) and Remove section. Use autoplay mp4 video that is muted and looping instead of GIFs or animated WEBPs. [L1331.025]
  • Icon Bar: each icon uses the Check available icons search, so search for a soft word like pillow first. If no icon matches, scroll to the custom icon option and paste the icon code to replace the icon. [L1331.026]
  • Shrine sections such as Image with text have a Display section ID field. Paste that ID into any button link so the button scrolls to the section, or use it to merge two sections. [L1331.042]
  • Logo list for shipping carriers as proof: go to Online store, open Customize for the theme, click Add section, search for Logo list and add it, then upload the logos. You can delete the text to make it smaller, change the size, background and padding, and drag it to any position. [L1287.025]
  • Logo lists can show well-known customers. This is useful for business-to-business products. [L1265.008]

Pre-footer trust columns

  • Each pre-footer column has an image, a header, an optional description and a link. The example used a gray background, changed to background 1 (white) for a cleaner look. [L1309.037]
  • Pre-footer trust column pattern: each column pairs an icon image with a short benefit header that tells the visitor why the store is reliable, such as shipping threshold, origin or checkout security. Example 1: Free shipping over 75 dollars. Example 2: Secure payment at checkout. [L1309.059]
  • Security cues such as trust badges belong on the cart and checkout pages as well. They reassure shoppers at the point where they decide to pay. [L1522.021]
  • Homepage section for a single-niche store includes trust signals and a risk-free message. [L1363.055]

Footer

Footer structure and content

  • Footer structure in the theme editor: Brand description, Text column (contact information), Useful links column, and Legal links column with Privacy Policy, Shipping policy, Refund policy, Terms of service and Contact information. Upload a footer logo from the library and link each policy page. [L1188.042]
  • Add footer text by opening the footer section, clicking Add block, and choosing Text. Write the About Us text with the brand mission, email address and business address, then click Save. [L1326.013]
  • Add a footer logo by clicking Add block in the footer section and choosing the Image block. Upload the logo, increase its size so it is clearly visible, and click Save. [L1326.016]
  • The footer should contain a customer care section with the links visitors look for, plus an about section. Visitors who land on a product page see the navigation first and scroll to the footer next, so it must support them. [L1325.022]
  • The footer should contain a get-in-touch section, support hours, support email addresses, a live chat link and links to social media pages. Footer links to unrelated pages make the store look untrustworthy. [L1346.011]
  • Footer editing is done in the same customizer sidebar and is a separate step. Cookie consent is a pop-up set in the same sidebar and can be switched on or off. [L1309.039]
  • Do not link any section or footer item to a page that does not exist yet. Suppliers clicking dead links see a broken store, so leave link fields empty until the target page is created. [L1309.009]
  • Repeat the Highlights banner near the bottom of the homepage with a different background color than the footer, so two identical colors do not sit next to each other. Use a second color from the brand palette. (Superstore theme, 2021-2022, older advice.) [L1310.035]

Pages and blog (Manhattan theme)

Editing a page template

  • Open the theme editor, click the template dropdown at the top, switch from home page to Pages, and select the default page (the About Us page) to edit it. A separate Contact page template also exists. [L1265.002]
  • In each page's settings in the Shopify admin, adjust padding, margin and width (full width or narrower, centered). [L1265.002]
  • Each page type has its own template in the theme editor. To give a page different sections than the default page or the contact page, create an additional page template instead of changing the existing ones. [L1265.009]
  • Add a logo list with a heading such as "Brands we've worked with" by clicking Add section and adding logos one by one. [L1265.002]

Blog listing and posts

  • Make sure blog posts are published and visible, because hidden posts do not show in the listing. [L1265.002]
  • Blog listing settings: choose Grid or Collage layout. Collage shows the newest post at the top, while Grid shows posts evenly. Featured images are recommended to be shown, and image height can be set. Show or hide date and author, and set card or standard layout in theme settings. [L1265.002, L1265.004]
  • Card or standard layout and the background colour under post titles are set in the theme settings and are separate from the grid or collage choice. [L1265.011]
  • Blog posts template: adjust padding, margin, page width, featured image size (Adapt to image keeps the uploaded size), title, date and author visibility, and the share link. [L1265.002]
  • With Adapt to image, the featured image becomes full size based on the uploaded image size. Keep the page width unchanged so it matches the rest of the site. [L1265.003]
  • Keep the blog post page width at the theme default. A narrower width makes the post text noticeably less wide on large monitors and stops it from matching the rest of the site. [L1265.013]
  • Blog post pages show a share link by default that lets readers copy the post URL. Keeping it visible is recommended. Hiding it is possible but not advised. [L1265.012]
  • Add an Email signup section to the blog posts template: enter a heading, click Save, optionally change the accent color, then Save again. [L1265.002]
  • Hide Rich text and Blog posts sections in the first version of a store with no content yet. Enable them later when content exists. [L1309.038, L1309.001]

Cart page

Manhattan theme cart setup

  • To edit the cart, open the Theme Customizer, click the page dropdown at the top and scroll to the cart entry. The checkout entry is in the same dropdown but cannot be edited; only the cart can be changed. [L1450.001]
  • Customers reach the cart either by clicking the cart icon after adding a product or by being sent straight to the cart, depending on the add-to-cart behaviour in the product page settings. The cart page must therefore work as a standalone step before checkout. [L1450.002]
  • The default cart page keeps the header, the mega menu built earlier and the footer. These global elements can stay without changes. [L1450.003]
  • Items section: shows the products the customer has added. Its padding and margin controls move the content up or down. No changes are needed in a default setup. [L1450.004]
  • Subtotal section: shows the subtotal, the checkout button and the order special instructions field. Its padding and margin can be adjusted the same way as the Items section. [L1450.005]
  • Cart note: in the cart's theme settings it can be enabled or disabled. When disabled, the order special instructions text disappears from the cart page after saving and reloading the store. [L1450.006]
  • Keep the cart note enabled. Customers sometimes write notes there, and these are saved to the Shopify order information. Disabling it removes a channel for useful customer requests. [L1450.007]
  • Do not modify or hide the checkout button, because customers with items in the cart must always be able to proceed to checkout. [L1450.008]
  • Additional blocks such as a countdown timer or a coupon are added inside the cart template through the add block option. Each block is placed by moving it in the customizer, and its colours and text are set in its own settings. [L1450.010]
  • Adding extra content such as rich text sections to the cart page is usually unnecessary and can distract buyers from checkout. Add sections only when there is a clear reason. [L1450.018]
  • Cart page setup order:
    1. Open the Theme Customizer and select cart in the page dropdown.
    2. Check the Items and Subtotal sections and adjust padding or margin only if spacing needs fixing.
    3. Open Theme settings and keep the cart note enabled.
    4. Leave the checkout button unchanged.
    5. Add any optional blocks such as the urgency timer or the coupon only when they are needed.
    6. Click save and reload the storefront to check the result. [L1450.009]

Cart page content and checks

  • Check the cart page by adding a product from the storefront and opening View cart, because the cart page is empty until a product is added. Text on the cart page can be changed through the theme's default content settings. [L1326.021]
  • Optimise the cart page, which many stores neglect, because it is where shoppers start to doubt the purchase. Add USP messaging, shipping details and upsells there, presented the same way as on the product page. (2021-2022, older advice.) [L1522.019]
  • Reconfirm unusual shipping requirements on the cart page as well as on the product page. Upsells that some shoppers missed on the product page can also be shown on the cart page. [L1522.020]
  • Cart in the Superstore theme needed no change in the early-stage settings order. [L1371.043]

Smart Cart (Source E, 2025-2026)

  • Layout choice at creation is Single Column or Double Column. A Double Column cart gives cart line items a dedicated area, which suits carts with long item lists such as parts and accessories. The layout can be switched later without starting over. [L1231.011]
  • Advanced settings pull typography from the Shopify theme's typography settings. The title heading level can be changed, for example from H1 to H2, to get the wanted font without custom CSS. The cart title can also be hidden entirely, for example to place a store logo with custom CSS. [L1231.014]
  • The country field in Smart Cart v2 suggests matching countries as you type, so merchants do not need to know the two-letter ISO code. In v1 this code had to be typed in directly. [L1231.029]
  • The order notes component collects a gift message or special instructions. These notes appear in the order attribution section on the right side at the top of the Shopify order, not under the line items. [L1231.052]
  • The cart subtotal has singular and plural label fields, and the item count can be inserted with a variable. Keep the subtotal label simple, since heavy changes are rarely needed. [L1231.054]
  • The Express checkout block in the Smart Cart editor is only a placeholder and does not appear as text on the live store. The buttons that show depend on the accelerated checkout methods connected in the Shopify admin and the express checkout preferences set there. They can display as separate buttons in a row instead of one combined block. [L1231.061]

Homepage structure and order of work

Principles

  • The homepage is the first page visitors see on the root domain and the hub of the site. It should introduce the business, state what is good about it, give reasons to buy, and introduce the products sold. It connects to all other pages through the main menu, the bottom navigation and the search bar. (2021-2022, older advice.) [L1463.003]
  • In high-ticket dropshipping the reseller sells the same products as other sites, so the homepage must sell the business as well as the products. Customers compare where to buy as well as what to buy. At launch the competition is on identical products; a brand's own products come later. (2021-2022, older advice.) [L1463.002]
  • A weak store design holds back sales even when ads perform. Improve the store before running ads, with better images and a clear layout. [L1439.039]
  • Homepage imagery must match the store's product type. Show people using the products and link to the category collections of that product type. [L1346.008]
  • A homepage that mixes lifestyle photos unrelated to the products confuses visitors and makes the store look incoherent. [L1346.009]
  • Shopify core components are the announcement bar, header, footer and the main page types (home, product, collection, cart, blog and checkout). Set up these components before adding more content. [L1326.001]
  • The home page can stay simple with two or three sections: a banner related to the current product, the product itself, and a benefits section with badges such as priority shipping and money-back guarantee. [L1412.049]

Homepage structures by store type

  • Niche store (procedure, as the lesson describes it):
    1. A banner that matches the feeling of the exact customer.
    2. An About Us or mission section telling the brand story.
    3. One or two sections for the main product.
    4. A collection of products. Keep it clean and branded, since most traffic arrives via ads directly to product pages. [L1158.028]
  • Single-niche store, in this order:
    1. Headline with the offer and a big benefit, such as a percentage discount.
    2. Striking product visuals.
    3. Review badge that links to the reviews section.
    4. One customer testimonial.
    5. More product images.
    6. A best-sellers section with a link to each product the visitor can choose.
    7. Trust signals and a risk-free message.
    8. Benefit copy describing what the product does for the customer. [L1363.055]
  • Tested Superstore theme homepage section order (2021-2022, older advice):
    1. Utility bar
    2. Header
    3. Slideshow
    4. Highlights banner
    5. Featured collections (Collection list)
    6. Image with text overlay
    7. Featured collection (product grid)
    8. Search
    9. Highlights banner (repeated near the bottom)
    10. Footer [L1310.034]
  • Early-stage high-ticket dropshipping store section list (2021-2022, older advice):
    1. Announcement bar (fixed).
    2. Utility bar (fixed).
    3. Header (fixed).
    4. Slideshow used as a single static hero image (fixed).
    5. Highlights banner.
    6. Collection list.
    7. Image with text overlay.
    8. Featured collection.
    9. Footer (fixed). All other default sections such as Grid, Rich Text and Testimonials can be removed. [L1371.006]
  • Conflict between structures: the tested Superstore order has 10 positions and the niche procedure has 4 (plus banner). The early-stage order has 9. Use the niche structure for a single-product ad landing store [L1158.028, L1363.055] and the Superstore order as an example of a full multi-section homepage [L1310.034]; the older 2021-2022 orders are examples, not requirements. [L1310.034, L1371.006, L1158.028]
  • Start a new Shopify store's public home page from the basic template, which has an Image with text overlay section and no images or design. It is changed from the storefront preview using the Edit home page option, as part of the design work after account setup. [L1314.022]

Supplier-ready demo store setup (Manhattan theme)

  • Time: a full homepage customization of a new Shopify theme takes about one hour when the brand images are already finished. [L1309.002]
  • At the supplier-approval stage the homepage only needs to look credible and work. Advanced mega menu, product card and blog settings can wait until the store is live. [L1309.003]
  • Procedure:
    1. Upload all prepared images in one batch under Content > Files > Upload files, select them all and click Open.
    2. Go to Online Store > Themes and confirm the Manhattan theme is active.
    3. Click Customize and check that the dropdown at the top reads Homepage.
    4. Open Theme settings (gear icon) and set logo, favicon, colors, typography, layout, buttons, social media and contact details.
    5. Open Header and set sticky header, logo position, menu, menu type, separator line, menu fonts and navigation colors.
    6. Edit the Slideshow: keep one slide, add image and text, link the button to a collection.
    7. Edit the Collection list: heading, columns, overlay, then add collections and their images.
    8. Edit the Featured collection, Image banner (only if needed), Email signup and Pre-footer.
    9. Hide Rich text, Blog posts and the Announcement bar until they are needed.
    10. Edit the footer and cookie consent, click Save after each section and check the homepage on desktop and on a phone. [L1309.001]
  • Uploading images to Content > Files does not link them to any section. Each image still has to be selected inside its section; the upload only makes them available in the picker. [L1309.005]
  • Imagery and sections should be finished in a supplier-approval demo as credible placeholders; the full store can be refined after launch. [L1309.003]

Build order for the initial site (Superstore theme, 2021-2022, older advice)

  1. Set up the homepage with the business message and links to the main sections.
  2. Set up the collection page template once so every collection uses the same settings.
  3. Set up the product page template once so every product uses the same settings.
  4. Create all single pages (About Us, Contact Us, policies, terms) and link them into the navigation.
  5. Leave the blog untouched until after the business has launched. When steps 1 to 4 are done, the site is ready for the next stage. [L1463.014]

Social links

  • Add social media links in theme settings, next to the logo, colors and contact details. Social media is part of the Supplier-ready demo procedure at step 4. [L1309.001]
  • Leave social media until launch, then add Facebook, Pinterest, email address and Instagram. (2021-2022, older advice.) [L1371.043]
  • The footer should link to social media pages, and links to unrelated pages make the store look untrustworthy. [L1346.011]

Hiding vs deleting sections

  • Deleting or hiding a section is reversible in the customizer, but deleting removes its settings. For a first version it is safer to hide sections with the eye icon than to delete them. [L1309.008]

  • Hide Rich text and Blog posts in the first version of a store with no content yet, and enable them later when content exists. [L1309.038]
  • Removing a section: click into it, click the three dots at the top of the panel, and choose Remove section. [L1371.004]
  • In a Shopify theme the header, announcement bar, utility bar and slideshow sections are fixed and cannot be removed, and the footer is always part of the site. Only the optional sections in between can be removed. (Superstore theme, 2021-2022, older advice.) [L1371.005]

Checkout branding

What can be changed

  • The Shopify checkout cannot be fully redesigned because Shopify controls it for security, using 256-bit encryption. Store owners can only add a custom logo, a background image of about 1000 x 400 px, and some color and button changes. (Older advice, 2021-2022.) [L1371.031]
  • Shopify Plus (about 2,500 USD per month) is required to customize the checkout. Otherwise the checkout is the same for all Shopify stores. Within that limit, upload the brand font in Shopify so it appears at checkout, set the logo in the checkout settings, and use a logo with trust signals such as free shipping or a money-back guarantee. [L1363.030]
  • Conflict on access: one source says full checkout customization requires Shopify Plus [L1363.030], while another describes adding a checkout banner under Settings > Checkout without naming a plan [L1259.034, L1260.041]. Check your plan before you promise a custom checkout.
  • Conflict on size: the checkout banner is 1500 × 300 px [L1259.034, L1260.041], while the older source gives a background image of about 1000 × 400 px [L1371.031]. Use 1500 × 300 px for the checkout banner under Settings > Checkout; use the 1000 × 400 px background only where the older Superstore-era guidance applies. [L1259.034, L1260.041, L1371.031]

Checkout banner and trust elements

  • Shopify checkout image: go to Settings > Checkout and add an image (checkout banner). Recommended size is 1500 × 300 px. Create it in Canva with custom size 1500 × 300, add the logo, and add trust badges such as Privacy Protected, Secure Checkout and Satisfaction Guaranteed from Canva's Elements section. Add payment icons (Visa, Mastercard, PayPal) and optionally a 30-day money-back guarantee. [L1259.034, L1260.041]
  • Case: a store that changed nothing except adding checkout trust elements (secure checkout, guarantee, payment logos) moved from a conversion rate of 0.29% to 2.15% in one day, with an Add to Cart rate around 8%. [L1260.042]

Checkout settings procedure (Superstore theme, 2021-2022, older advice)

  1. Open Checkout in the theme settings.
  2. Upload the logo as a custom image, set it to Medium size, and place it in the center.
  3. Leave error messages red.
  4. Change the button color to match the site buttons and the accent color to the main brand color.
  5. Click Save before leaving the editor, because unsaved changes are lost. [L1371.032]
