4.7 Theme selection, installation and migration

Theme basics and where themes sit in Shopify

  • A Shopify theme controls how the store appears, how pages are structured, and how customers interact with the site. Shopify provides the backend functionality, and the theme provides the presentation and user-experience layer. [L0071.001]
  • The theme controls the storefront that visitors see and how it behaves. Products and store content stay the same when the theme changes, and themes are installed as ZIP files through the Shopify admin. [L0974.007]
  • Free and paid themes both change how the storefront looks and functions, while products and store content stay the same. A theme is therefore a separate layer from the store's catalog and settings. [L0974.009]
  • A theme sets the overall design, the page structure, and how far the store can be customized. Any installed theme can be changed to fit the store. A theme is a structure and does not include product images or content. [L0975.001]
  • A developer builds the base theme and supplies all site code. The store owner adds branding (colors, images, a few settings) through the theme editor instead of coding from scratch. [L1292.002]
  • A theme provides the basic site layout and structure. After installing it, add your own branding, colors, and fonts. [L0912.009]
  • Themes are managed under Online Store > Themes (the path is written as Sales channels > Online store > Themes in one source). The page shows the active theme and an Add theme button, and the Theme library lower down lists all uploaded themes. [L1292.001, L0975.002]
  • The Themes page has a Visit theme store link near the bottom. The theme store lists free and paid themes, and paid themes are generally better built than free ones. [L0975.004]
  • The Themes page also links to Free themes and the Shopify Theme Store. [L1292.001]
  • The Customize button opens the theme editor, where most store layout and branding work happens. [L1292.001, L1292.011]
  • An unpublished theme shows Customize and Actions buttons. Use Customize only when editing. [L1292.011, L1292.008]
  • A store can hold several uploaded themes, but only one can be published and shown to visitors. [L0975.012]

The default theme on a new store

  • New accounts receive the free theme Dawn, which is the active theme from the start and stays active until another theme is published. [L0975.003]
  • Dawn is Shopify's free default theme and a common base for a first store. [L0552.055]
  • The course store in one source used Dawn. The source advised keeping the store simple at first, because the offer and product images matter more than design complexity. [L0492.026]
  • Older (2021-22): the course material of that period says a new store starts with the free theme Debut, which shows only placeholder text and images with no branding, so it must be customized before launch. [L1292.005]
  • Where sources disagree on the default, use Dawn for current accounts and Debut only for stores described in the older 2021-22 material. [L0975.003, L1292.005]
  • The free default theme without customization looks very basic. Changing only the header while leaving default colors in other sections creates an inconsistent look that signals a beginner. [L0656.016]

Choosing a theme: criteria

  • Start with a lightweight theme for site speed. The 2022 advice recommended the Charlotte theme (older). [L0272.011]
  • Speed is one of the first things to check when comparing themes. Check a theme on stores that already run it and run speed tests on those stores before buying. [L0853.006]
  • Check when the theme was last updated and how long its developer has supported it. Themes untouched for four or five years can produce errors with the current Shopify framework. (Older, 2021.) [L0853.007]
  • Use a mobile-responsive theme, because most purchases now happen on phones. A web-only theme loses sales to competitors and needs a full rebuild. [L0826.012]
  • Mobile traffic can be 80 to 90 percent of visits, so the theme should work well on phones out of the box. Mobile-only design changes that differ from desktop need a developer, so make them only when a specific error or problem appears. [L1287.023]
  • Check every key page at laptop-width screens as well as desktop and mobile. If the theme stops at a fixed maximum width, the side margins stay cramped and the white space that keeps the page readable disappears. Choose a theme that scales to wide screens. (Older, 2021-22.) [L0409.051]
  • Prefer a theme with minimal, clean code. Theme and app code quality varies, and some popular-looking themes are coded inefficiently and slow the page. (Older, 2021-22.) [L1266.026]
  • Choose a theme with built-in features so fewer third-party apps are needed, since fewer apps generally means faster pages and fewer plugins to maintain. (Older, 2019.) [L1086.060]
  • A premium theme is worth choosing over a free one when it already includes conversion elements, because the store then needs fewer paid apps to provide the same features. [L1330.001]
  • Before buying a paid theme, check that it supports the features you need, such as bundles with variants and free gift offers. Themes that lack these features may force a costly workaround. [L1173.019]
  • Give the person building the store clear written requirements. Make sure the theme is installed correctly and reviewed before launch, because a poorly installed theme can make a store look messy. [L1173.020]
  • Choose the base theme with your planned amount of custom work in mind. A simpler base with fewer built-in features can be easier to customize heavily than a feature-rich theme. (Older, 2021-22.) [L0949.066]
  • A dropshipping-focused theme can be more efficient than comparing many general themes, because the theme affects both conversion and setup effort. Treat claims about higher conversions as unverified until tested on your own store. [L0974.010]
  • Manhattan is built specifically for the high-ticket dropshipping model and is optimized for higher conversions and supplier-ready presentation. It includes features that usually require paid apps, which reduces setup cost and complexity compared with choosing and buying individual apps. [L0071.002]
  • The higher-conversion claim for Manhattan is a vendor statement. Test it on your own store. [L0974.010]
  • A dropshipping-focused theme (2020, older) can be customized in every element. The same theme works for an elegant brand look or a playful one, and it is a free download for stores built on the blueprint. [L0852.116]
  • Pick a theme you expect to be happy with long term, because switching themes costs time that could go to revenue-generating work. Themes from established vendors that do what you need are a sound choice. (Older, 2021.) [L0853.088]
  • Buy themes only from the Shopify Theme Store or from established theme vendors. Unverified theme code can contain malicious code and cause problems later. (Older, 2021.) [L0853.087]
  • Choose a theme from the Shopify theme store or from a trusted, certified developer. A developer who builds themes full time, with a team of about 3 to 5 people, is a stronger choice than someone who sells a theme as a side project. [L0390.040]
  • Before adopting a third-party theme, check community discussions about the vendor's support quality, because poor support can leave customizations broken. Search the store owners' Facebook group for the theme name to see what other users report. (Older, 2019.) [L0356.066]
  • Shopify planned to separate theme design from store content, so a theme could be replaced without rebuilding all content. Once available, this would make theme updates faster and reduce the need for third-party page builders such as PageFly or Shogun, which may become less useful as native features improve. [L0390.039]
  • A brand that takes branding seriously usually needs a custom build from a design file, for example a pixel-perfect conversion of a Figma design into a Shopify store. Prototyping in a page builder first and then having a developer make a polished version is a common approach among high-revenue brands. [L0709.006]
  • A plug-and-play store theme gets a high-converting store running fast instead of building a website from scratch. It reduces development time so the focus can move to marketing and sales. [L1251.030]
  • Shopify beginners do well with a theme that has many built-in features and handles most of the layout work. Its graphics are simple to make and upload and need little design skill. Other themes need their own graphic sizes, so confirm the chosen theme first. [L0342.038]
  • For beginners without web design experience, the Source A theme is a strong choice because it has many features and needs little design work from the merchant. Its graphics are simple to upload because the theme handles much of the layout. [L1045.002]
  • Free Shopify themes suitable for beginners include Sense, Refresh and Dawn. They are found under Online Store > Themes and can be used right after sign-up. [L1313.003]
  • The course material pointed to Refresh as a starting theme for a first build. [L0552.055]
  • Winning Hunter's Sales Tracker Details page shows which Shopify theme a competitor store runs, next to its launch date and shop URL. Note the theme when you study a competitor's build, because it shows what a working store layout looks like on that platform. [L1164.050]

Free versus paid

  • A free theme is enough for conversions unless a paid theme has built-in functionality you cannot get elsewhere. Beautiful design alone does not drive sales, and speed plus trust matter most. (Older, 2021.) [L0834.041]
  • Premium paid third-party themes, some costing around 500 dollars, are not needed to start. A free theme is enough, and the theme is not what makes a store profitable. (Older, 2021.) [L0801.095]
  • Premium themes are worth the cost because they are highly customizable, load fast and come with strong support. A store with many products benefits most from these features. [L0921.010]
  • Out of the Sandbox themes are recommended for large-inventory stores when the budget allows. [L0921.009]
  • Upgrading to a paid premium theme was seen as sensible once the store earns good revenue. One source bought a premium theme for about 200 USD with a 20 USD discount. [L0694.029]
  • Premium Shopify themes from paid developers can retail for around $300. Budget for this if the theme is not included free with a course or purchase. (Older, 2021-22.) [L0912.015]
  • Off-the-shelf premium themes are a far cheaper route than a fully custom theme, which can cost thousands of dollars. [L1292.030]
  • Free line item property code snippets exist online and can be added to a Shopify theme by hand. [L0709.004]
  • Ecomify Pro was a one-time payment of $249 at the time of the lesson, while Lite was free. Upgrades to the next major version were announced as small fees of about $50 instead of a new $249 payment. [L0709.017]
  • Check the current price on the store page before buying. Sale prices can differ from standard prices. [L1292.039]
  • Where sources disagree on premium prices, the values differ by source and date: about 180 USD for a Theme Store listing (older 2021-22 material); about 300 USD for a comparable premium theme (same period); about 200 USD for a premium theme bought at a discount (Source C); 300 to 500 USD for Out of the Sandbox themes (Source A); and about 500 USD for the high-end paid themes that a free theme replaces. Treat each figure as the price at the time of its source. [L1292.007, L0694.029, L0912.015, L0921.009, L0801.095]

Where sources disagree

  • Manhattan access: one note dated 9 November 2023 tells you to find and download Manhattan from the Shopify Theme Store. Other units say Manhattan is available only to members of the program. Use the members' download link from the lesson. [L0081.001, L0975.005, L0071.004]
  • Charlotte versions: Charlotte 1.0 was the original download from the blueprint's module 3, lesson 3.1 [L0665.028]. Version 1.3 is the latest downloadable version, released 21 February 2022 [L0963.035]. Earlier versions can be updated to it as a new theme [L0963.035].
  • Source A version: the newest Source A theme was last updated 12 December 2022 [L0804.039]. A later source named version 1.3 as current and said the course downloads carry it [L0941.037].
  • Charlotte or Manhattan for an existing store: a new store should use Manhattan, but an existing store on Charlotte does not need to be switched. [L0966.061, L0975.006, L1114.030]
  • Speed: older advice (2022) recommended Charlotte for speed. Later advice says Manhattan is somewhat faster than Charlotte. Use the newer comparison when choosing for a new store. [L0272.011, L0966.061]
  • Premium value: for large-inventory stores, premium themes are worth the cost. For a starting store, a free theme is enough. Use the premium argument only when the store has the volume or features to justify it. [L0921.010, L0834.041, L0801.095]
  • Publishing a new theme: publish straight away only on a brand-new store with no other active theme in use. On a store that already has visitors and sales, keep the theme unpublished until setup is finished. [L0975.015, L0975.014, L0975.010]
  • Password-protected stores: a new store can be published while still password protected, so visitors cannot see the live site until a custom domain is connected. [L1292.010, L1330.005]

Download procedure for Manhattan

  1. Click the Manhattan theme download link provided in the lesson.
  2. Review the theme details on the page if desired.
  3. Scroll to the bottom of the page.
  4. Check the box to confirm your membership status.
  5. Click Download Manhattan to download the ZIP file to your computer.
  6. Log into your Shopify account.
  7. Click Online Store in the main menu.
  8. Click Themes.
  9. Click Import Theme in the top right corner.
  10. Click Upload a zip file.
  11. Upload the Manhattan ZIP file by clicking Add File to select it from your computer, or drag and drop the file.
  12. Click Upload File.
  13. Wait for the installation to complete; Manhattan will appear in your Theme Library.
  14. Click the Publish button on the Manhattan theme (note: newly uploaded themes are not automatically published).
  15. Confirm that Manhattan is now set as your active theme and appears at the top of your theme list.

Fixing a zip download on a Mac

  • On a Mac, downloading a.zip file can automatically extract it into a folder. The folder shows as a blue folder icon instead of a zip icon. Uploading that folder fails because Shopify needs the.zip file. [L0975.008]
  • Older (2021-22): if macOS unzipped the theme, re-zip the folder, since other folder types fail to upload. [L1292.008]
  • Fix a Mac download that was extracted into a folder:
  1. Right-click the blue folder.
  2. Choose Compress with the theme file name (for example Source A Manhattan) from the menu.
  3. Use the new.zip file that macOS creates for the upload.

[L0975.009]

Uploading a zip file

  • Upload a theme to Shopify (current procedure):
  1. Go to Online Store > Themes and open the Theme library.
  2. Click Add theme.
  3. Click Upload zip file.
  4. Drag the.zip file into the upload area or select it, then click Upload file.
  5. Wait while the message Installing theme appears; this takes about 30 seconds while Shopify processes the file.
  6. Check that the new theme appears in the Theme library with its name and version number, for example Manhattan version 2023.
  7. Click Publish only if the store has no active theme in use yet, which is the case for a brand-new store.

Draft versus published

  • Install a new theme as unpublished, adjust it while unpublished, then publish it when ready. Installing a theme directly onto a live store can break the site. (Older, 2021.) [L0247.088]
  • When a new theme is uploaded it goes live only as a draft, so the current live store is not changed. The draft can be customized and then published when it is ready. (2024.) [L0360.019]
  • A new Shopify theme is installed as a draft that only you can see. Design it in the draft, then publish it. Installing a new theme does not carry over the design edits of the old theme. Apps and products do carry over. (Older, 2021.) [L0834.038]
  • Upload a new theme as a draft first, so the live store is not affected while you check it. [L0470.053]
  • Uploading a theme as a draft does not change the live store. If the new theme is published by mistake, you can republish the old theme to revert. Themes do not update automatically in the background once installed. [L0804.040]
  • Publishing a new theme on a store that already gets traffic and sales, before its customization is finished, can change the live site unexpectedly. Finish setup and customization before publishing. [L0975.014]
  • Publish a new theme right away only when the store is brand new and no other theme besides the default free one is in use. If the store already has visitors and sales, keep the new theme unpublished until the remaining setup steps are complete. [L0975.015]
  • Publishing a new theme replaces the current active theme immediately. Until a custom domain is connected, the store can remain password protected so visitors cannot see the live site. [L1292.010]
  • The replaced theme stays listed in the Theme library. It can be published again if the new theme needs to be reverted. [L1292.040]
  • Shrine Pro setup includes publishing the theme while the store is still password protected. This is the step where the theme goes live behind the password. [L1330.005]
  • Do not change a working theme just to upload products. Uploading products is the same process for any theme, so a redesign suggested for that reason is unnecessary. [L0808.024]
  • A live store with traffic does not need to switch to a newly released theme. Upgrades only improve usability and should be adopted when convenient, not as an urgent change. [L1114.030]
  • Switching themes is not urgent. An older Source A theme can continue to be used until you have time to change it. Changing to a newer theme later will not break the store if it is not published before testing. [L0934.092]
  • Changing the theme often disrupts traffic and conversions, so design changes should be made deliberately and mostly during a later conversion-rate optimization phase rather than repeatedly. (Older, 2021-22.) [L1292.004]
  • Avoid editing the site's code early on. Custom code changes are worth it only once the business is selling and growing, and the theme editor covers the launch phase. (Older, 2021-22.) [L1292.003]
  • Test a new theme without changing the live store:
  1. Go to Online Store > Themes.
  2. Add the theme zip to the theme library. It appears as a draft and does not change the store.
  3. Click Customize on the draft and edit and preview it.
  4. When it is ready, click Publish to make it the live theme.

[L0665.026] (Older, 2022.)

  2. Upload it in Shopify admin as an unpublished theme.
  3. Preview it and make changes.
  4. Keep the current live theme until you decide to publish the new one, at which point the current theme becomes a draft.

Switching themes

  • Switching themes requires redoing customizations such as colors and homepage images. Products do not need to be rebuilt. (Older, 2021.) [L0247.089]
  • Switching themes takes only a few clicks, but custom colors and custom code do not carry over automatically. The effort depends on how far the store has been changed from the default theme. (Older, 2019.) [L0960.072]
  • When switching themes, products, collections, blog posts and pages are kept. Logo, menus, colors, fonts, homepage images and homepage layout must be set again. (Older, 2022.) [L0665.027]
  • Switching themes changes the look, not the data. Products, pages and blogs remain. The new theme needs only skinning (colors, logos, images) before publishing. Test the new design in draft mode first. (2024.) [L0806.034]
  • Switching themes does not change your products, but theme customizations such as layout changes must be applied again in the new theme. (Older, 2021.) [L0968.034]
  • A theme switch to a newer Shopify theme does not require rebuilding the store. Content pages and product pages carry over, but colors and image placements need to be reset in the new theme. (2023.) [L1114.029]
  • A new theme migration keeps products, pages and content, but cosmetic items must be reset. These include color scheme, logo, homepage images and layout. (Older, 2021.) [L1112.043]
  • Switch an established store to a new theme only if you need functions it offers. New stores can start on the newest version, while stores already running well can wait for the final release. (Older, 2021.) [L1112.042]
  • The Charlotte theme is not expected to be replaced soon, and no major update is planned in the near term. A new theme was expected around a year out, and the current one stays supported. (Older, 2022.) [L1281.059]
  • Changing themes (for example Charlotte to Manhattan) has no one-click migration. The practical method is to keep both theme editors open side by side, on two monitors or in a split screen, and move settings over manually. (2024.) [L0805.036, L0805.062]

Updating a theme

  • A new theme version is not an automatic update to an existing store. It has to be uploaded and installed like any other theme, so plan the switch and test the store before going live. (Older, 2019.) [L1086.068]
  • Theme updates are not applied automatically. The developer notes what changed and how to apply it, because automatic updates could break a customized store. (Older, 2022.) [L0854.067]
  • Before updating a Shopify store theme, confirm which theme version is installed and ask support whether the update will keep your customizations. Do not assume a theme update will leave custom changes intact. (Older, 2020.) [L1088.094]
  • Upgrading a theme without losing the live store (2020):
  1. Open the Shopify admin.
  2. Go to Online Store, then Themes.
  3. Upload the newest version of the theme.
  4. Adjust colors and layout in the draft, which does not change the live store.
  5. Click Publish only when the draft is ready.
  6. If needed, republish the previous theme.

[L0664.035] (Older, 2020.)

  • Theme upgrades reset design choices such as colors and layout, but products and content stay. Plan time to restyle after upgrading. (Older, 2020.) [L0664.036]
  • Use the newest version of the store theme, which is at least as recent as the last couple of months. Older themes can be upgraded, but the upgrade means redoing the design. (Older, 2020.) [L0664.037]

Shrine Pro setup

  • Premium themes are worth choosing when they include conversion elements, so the store needs fewer paid apps. [L1330.001]
  • Shrine Pro was chosen because it has the most sections of the Shrine theme versions. One license is enough for one store. [L1330.004]
  • The email address entered at checkout for a Shrine license must be correct, because the license keys are delivered to that address. A wrong address can prevent access to the keys. [L1330.007]
  • Set up a premium Shrine Pro theme in Shopify, in this order:
  1. Open the Shrine Pro page and click Get started.
  2. Select one license, because only one store is being built, and click Add to cart.
  3. Click Checkout.
  4. Check that the email address entered at checkout is correct.
  5. Accept the terms and conditions, click Complete purchase, and then click Continue.
  6. Open the email from Shrine that contains the license keys, and click Open Shrine Dashboard.
  7. If there is no Shrine account yet, click register and create an account, then log in.
  8. Click Next step, then click Add key, and enter the license key to activate it.
  9. In Shopify, go to Settings > Domains and copy the myshopify.com URL.
  10. In Shrine, go to Settings > Accounts > Whitelist your URLs and paste the myshopify.com URL into the Shopify URL field, with https:// in front.
  11. Copy the custom domain of the store from Shopify Settings > Domains and paste it into the Main URL field, with https:// in front. If a second website URL exists, add it in the Secondary URL field the same way.
  12. Click Save and generate token, then copy the authentication token and store it safely.
  13. Download the theme zip file from Shrine.
  14. In Shopify, go to Online Store > Themes, click Import theme, upload the zip file, and select the Shrine Pro theme file. Wait until the upload has finished. To import the theme, go to Online Store > Themes, click Import theme, upload the zip file of the Shrine Pro theme, and wait for the upload to finish.
  15. Click Publish to make the theme live, even though the store is still password protected.
  16. Click Customize to open the theme editor and add sections.
