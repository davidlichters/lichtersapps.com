4.14 Product page design and templates

Product page structure and conversion layout

  • Build the product page in this order: product title and images, a bold Buy now or Shop now button directly under the product with an Add to cart button above it, bundles, upsells and urgency elements, a short description with bullet points (more images than text, simple words), customer reviews, then the footer. [L0352.008]
  • Customers land on product pages rather than separate landing pages, so optimise each product page as the main landing page and build it to convert traffic directly. [L0468.073]
  • Once ads are running, send traffic to the product page rather than the homepage, because visitors can see the product and buy it immediately. [L0562.029]
  • For a quick test, a minimal viable landing page is enough. Get the page live and tested first, and improve it from customer feedback after launch rather than aiming for a perfect design first. [L0552.018]
  • Shopify's Dawn theme includes an instant add-to-cart button for collection pages. Enable it in the theme settings; no app is needed. [L0562.028]
  • Place the satisfaction guarantee high on the page, after the key product information, so it reduces purchase risk early. Visitors close to buying often wonder what happens if the product disappoints. [L0524.015]
  • Show scented or sensory products in a context that suggests the experience, such as on wood or among natural elements. Product images should be sharp and show the product in use. [L0524.016]
  • Use tabs to compress long information instead of forcing a long scroll. Keep purchase options, reviews and key facts easy to reach from the top. [L0524.017]
  • Add a question section below the reviews and keep the brand answering questions. This shows active support and gives visitors answers without leaving the page. [L0524.020]
  • Show the offer clearly: product price, local shipping and delivery time, and bundle deals. State that stock is held in-country. [L0492.027]
  • Competitor copying: copying a competitor's product page exactly can outperform a heavily edited version in some stores, with higher CTR and lower CPM. In one case, extra editing and polish reduced sales. Results vary by product. [L0660.021]
  • Test each added feature (for example a sticky add-to-cart bar, a gift option or colour swatches) separately to see whether it increases sales, and check these features when comparing themes. [L0709.049]
  • Include product identifiers such as SKU, UPC or part number in a dedicated section, so customers can search for the item by part number. [L0855.099]
  • For fashion stores, add a size guide. Size problems were a likely cause of a chargeback on one fashion store even though a size guide was present. [L0660.019]

Mobile product pages

  • A long block of text before the product image on mobile hurts the first impression. Lead with visuals and the buy action, not paragraphs of details. [L0530.018]
  • Mobile needs an adaptive layout that rearranges content for the device, not a shrunk desktop page. Keep the product name, what it does or smells like, testimonials and the quantity selector above the fold. [L0524.018]
  • Check the mobile version of a page separately from desktop. Sections, images and paragraphs may display differently or be missing on mobile. Cross-check and add missing elements to the mobile layout. [L0321.036]
  • When a PageFly product page differs between desktop and mobile, check each section on both versions. Where layouts differ, apply the same customisation on mobile by selecting the image and pasting the text. [L0363.031]
  • Layout options in the Shopify theme editor (older, Source B 2021-22): 3 columns, 2 columns with medium image, and a further 2-column option. The 3-column layout shows as multiple columns on desktop only; mobile always stacks into one column. A two-column layout with a medium image is the traditional e-commerce layout and a sensible default. [L0370.003]

Headline, offer and trust elements

  • Standard Shopify product page (older, Source B 2021-22): the product title stays the H1 for SEO and sits at the top with price and image. The headline placed above the product description becomes the H2 and must not replace the product title. [L0416.009]
  • Traditional sales page (older, Source B 2021-22): the headline is the H1 and the first element a visitor sees. The price usually comes at the end of the sales message on this page type. [L0416.010]
  • Landing pages need a strong offer, several trust elements such as reviews and guarantees, and persuasive copywriting. The source refers to five key elements but does not list them. [L0637.037]
  • Free gift on a product page (older, 2021):
    1. Lead the product description with text about the product, because search engines read the opening text.
    2. Below the main text, embed a large image that says the gift is free, shows the gift and states its value.
    3. The image should make clear the customer receives the gift free when ordering from the store. [L0469.040]
  • Product-page graphics such as feature icons can be made by a designer and hard-coded into the site instead of installing an app. Back up the code before editing, or hire a developer on Upwork to do it (older, 2021). [L0469.041]
  • Duplicated description text (the same text appears in the description and the specifications section): contact a Shopify developer. Find Shopify-certified developers on Fiverr.com or StoreTasker.com, and check spam folders for replies. [L0276.062]

Product information settings (theme editor)

  • Product Information block, recommended settings:
    • Enable sticky content on desktop: On
    • Desktop media width: Medium
    • Constrain media to screen height: On (Original)
    • Advanced settings are not needed at this stage. [L0104.005]
  • Product Information subsection settings:
    • Variant Picker: Pills
    • Quantity Selector: Enabled
    • Sharing buttons: Enabled
    • Description placement: Next to Add to Cart button
    • Buy Buttons: Show dynamic checkout buttons: On
    • SKU label: "SKU" [L0104.006]
  • Price on product pages cannot be hidden. When a Compare-at price is set, it automatically displays crossed-out pricing to show the discount. [L0104.007]
  • The product title is pulled from the product name and cannot be edited in the theme customizer. The vendor field is dynamic and updates automatically when real supplier brands are added. [L0104.008]
  • For demo stores, hide these Product Information subsections: Expiring Coupon, Estimated Delivery, Promo Image/Sale Banner, Inventory Status and Trust Badges. [L0104.009]
  • Related Products section: it displays "You may also like" and lets you edit section text, layout, colours and number of products shown. For demo stores, use the eyedropper/hide icon to hide it temporarily and re-enable it later. [L0104.010]
  • Stock levels on product pages:
    1. Open Online Store > Themes > Customize.
    2. Use the drop-down at the top (Home page) and choose Products > Default product > Product information.
    3. Click the eye icon next to Inventory status to hide it.
    4. Do not delete the element, so it can be restored later. [L0472.029]
  • Inventory numbers can be entered in Shopify even when they are not live. A placeholder value per product (for example 10 or 100) lets the inventory status be hidden on product pages while the back end still tracks stock. [L0472.030]
  • Shopify has no built-in field for product availability dates. Add the availability or backorder date as text on the product page (2020, older). [L0468.065]
  • Shopify free-shipping badge: go to Online Store > Themes > Customize > Products, select a product and look for free shipping under availability. If it is not there, it may have been added to custom code or another setting, so ask Shopify support. [L0856.063]
  • Product page template edits for notes: under the theme's product template, add a note near the Add to cart button. For a back-order note, insert it in the product template near that button. [L0856.068]
  • PDF manuals (2022, older): upload the file to the Files section in Shopify, then add a link to it on the product page or in the description. [L0249.026]
  • Product comparison table (2020, older): build a simple table with attributes in rows and products in columns. No specialised app is required. [L0245.077]
  • Editing product templates: in the theme editor, the product template shows as Default product. Add, remove or reorder the variant selector, quantity selector, product recommendations and announcement bar in the sidebar, then preview before publishing. [L0600.042]
  • Customising colours with custom CSS (for example the colour of struck-through MSRP prices):
    1. Ask ChatGPT or another AI tool to generate CSS for the specific change.
    2. Copy the generated CSS.
    3. In Shopify, go to Online Store > Themes > Customize > Custom CSS.
    4. Paste the CSS and save and publish. [L0255.074]
  • Quantity selector: if a supplier sells in a fixed quantity, set the default quantity selector to the most common purchase amount. Base the default on what top competitors show (2021, older). [L0834.039]

Product information: custom input, files and line item properties

  • The file upload option in the theme lets customers upload files directly from the product page, for example a design or photo for a custom product. This avoids a separate app for collecting files. [L0709.020]
  • Line item properties store customer input, such as an engraving name, and display it on the Shopify order. A standard supplier order usually carries only variant details, so the property must be mapped to the supplier's API to reach them. [L0709.002]
  • Line item properties can be generated dynamically from Shopify metafields, which store extra product or customer data. The supplier's system must recognise the parameter it receives, or the data is lost. [L0709.003]
  • Developers are still needed for complex functions such as a bundle builder, which page builders like Replo and PageFly generally cannot produce. Simple landing pages and stock themes with page builders can be enough for brands that do not focus on branding. [L0709.005]
  • A simple custom engraving or name field built by a developer was roughly estimated at about $30. A complicated setup or a poorly built theme can cost much more. This figure is a rough guess, not a quote. [L0709.045]

Descriptions and formatting

  • Expandable sections in the Manhattan theme (Heading 6):
    1. Shopify Admin > Products > select the product.
    2. Highlight section headers (for example Key Features, Why You'll Love It, Specifications).
    3. Change the heading format to Heading 6 (H6).
    4. Remove divider lines between sections.
    5. Click Save. [L0104.002]
  • Heading 6 creates expandable sections in the Manhattan theme. This keeps long descriptions readable and organised. [L0104.001]
  • Creating expandable tabs with Heading 6:
    1. In the product description editor, highlight a section heading (for example Description).
    2. Click the formatting dropdown (currently showing Paragraph).
    3. Select Heading 6.
    4. Click Save.
    5. Repeat for other sections (Key features, Specifications).
    6. Click Preview. Sections now collapse and expand when clicked. [L0036.023]
  • Heading 6 formatting with Manhattan presents long product information cleanly without overwhelming customers. It improves both usability and page digest. [L0036.024]
  • Expanded state in Manhattan: the first section (the description) displays expanded by default. All other sections display collapsed and expand only when clicked. [L0036.031]
  • Optional Description toggle: add a new heading labelled Description, set it to Heading 6, and place it above the main product description. [L0104.003]
  • Theme customisations apply to all product pages:
    1. Shopify Admin > Online Store > Themes > Customize.
    2. Change the page selector from Home page to Products > Default Product.
    3. Make customisations, which then apply to all product pages. [L0104.004]
  • ChatGPT-generated descriptions with bullet points often display with misaligned or badly spaced bullets when pasted into Shopify's description editor. Fix this by highlighting the affected text, removing the bullet formatting from the editor menu, and reapplying the bullets. [L0219.019]

Expandable tabs, accordions and policy blocks

  • Typical product page tabs: description, specifications, shipping info, warranty and price match guarantee. Copy the supplier's warranty text, but swap the contact email for your own. [L0808.002]
  • Built-in tabs: the new Charlotte theme includes product tabs, so no tab app is needed. An alternative tab app costs about $5 per month. [L0665.041]
  • Tabs built with the theme's own code (2021, older) keep the page lighter and faster. Use apps only for features too hard to code directly. [L0853.110]
  • Accordion setup in Visually (Source E 2025-26):
    • Auto-expand the details accordion on page load only for first-time visitors.
    • Leave the details collapsed by default for returning customers.
    • Implementation requires 3 clicks in Visually. [L0197.015]
  • Policy blocks in the Manhattan default template (2024):
    1. Shopify Admin > Online Store > Themes > Customize.
    2. Change the dropdown from Homepage to Products.
    3. Click into the Default Product template.
    4. Click Add Block and select Collapsible Row.
    5. Drag it under the product description.
    6. Change the title to Shipping Policy or Price Match Policy.
    7. Add the content text in the editor.
    8. Choose an icon (checkmark, heart, etc.).
    9. Click Save.
    10. Repeat steps 4 to 9 for additional policies. Because this is the default template, it applies to all product pages. [L0253.006]
  • Policy information (2025): to add policy information, go to the theme editor, click customise, select the collection or product template and add sections using rich text or collapsible content. Include financing, customer support, return policy and price match information as expandable sections. Drag them below the product images and save. [L0255.019]
  • Accordions can hold an extra paragraph, such as a free shipping reminder placed below the description and dimensions. This is a theme-level change and usually needs the theme developer. [L0855.181]
  • Tabs on product pages compress long information and keep purchase options, reviews and key facts near the top. [L0524.017]
  • Duplicated descriptions in the default product layout: see L0276.062 under Product page structure.

Supplier-specific product page templates

  • Create a template per supplier:

    1. In the theme editor, click the Default product template.
    2. Click Create template.
    3. Name the template after the supplier (example: Brand B).
    4. Base it on the Default product template.
    5. Save the new template.
    6. Expand Product information.
    7. Enable and edit the Estimated delivery settings.
    8. Set a custom delivery window for this supplier (example: 7-14 days).
    9. Save changes. [L0139.009]

  • Assign the template to products:

    1. Go to Shopify Admin > Products.
    2. Select a product from the target supplier.
    3. Scroll to the Theme template field.
    4. Select the correct template name for that supplier (example: Brand B).
    5. Save the product. [L0139.010]

  • Product templates control estimated delivery dates, coupon display variations and other layout and content changes as needed. [L0139.011]

  • Slower or custom-made products that cannot be returned: go to the theme editor, duplicate the default product page template, rename the copy (for example custom made or supplier), change the delivery estimate and returns text there, then assign that template to the affected products. [L0360.018]

  • Shipping or lead-time differences (2021, older):

    1. In the theme code, duplicate the product page template.
    2. Give the copy a clear name, such as product page template followed by a number.
    3. Change the tabs or shipping-date information in the copy.
    4. Assign the new template to the products with longer shipping times. [L0671.077, L0671.214]

    Note: L0671.077 and L0671.214 are identical units and are merged here.

  • Warranty templates (2024):

    1. Go to Shopify Admin > Online Store > Themes > Customize.
    2. Switch to Products.
    3. Click Create Template.
    4. Name the template after the supplier and warranty type (for example Supplier ABC 90-day).
    5. Click Create Template.
    6. Add Block > Collapsible Row.
    7. Rename it to Warranty Information.
    8. Add the warranty details in the content editor.
    9. Save.
    10. Repeat for each warranty duration (90-day, 1-year, 3-year, 5-year).
    11. Assign each product to the correct template from the template dropdown on the product page.
    12. Multiple templates allow different warranty information on different products. [L0253.023]

  • Product page template without free shipping (2025):

    1. In the theme customizer, open the product page template.
    2. Click Default product, then Products, scroll to the bottom and click Create template.
    3. Name the new template, for example no free shipping.
    4. Change every reference to free shipping on the page (such as an offer saying free shipping) to a different offer, for example 10% off.
    5. Save and check the page for any other free shipping references.
    6. Assign this template to all products from the brand that cannot ship free.

    The announcement bar can still say that most products ship free. [L0857.059]

  • Free-gift offer placed elsewhere on the page (2025):

    1. Go to Products and create a template based on the default product page, named for the offer.
    2. Click Add section, choose Image with text and drag it to the desired position.
    3. To add a block under the discount code, hover over the expiring coupon block, click the plus and add a block with text or custom liquid.
    4. Save, then assign the template to the products that should show the offer. [L0667.035]

  • Shipping selection dropdown (2019, older): default to free curbside drop-off at $0, with paid options such as in-home delivery at $100 and second-floor delivery at $300, explained next to the dropdown. [L0663.071]

  • Copy warranty text from a supplier but swap the contact email for your own. [L0808.002]

Variant descriptions and variant selection

  • Decide whether variants appear on one page or on separate product pages by checking the top two or three future competitors in the niche and copying their approach. Default to one page with variations when the leaders use variants (2022, older). [L0429.023]
  • Standard and premium versions with different materials and build quality: look at how the top Google Shopping results display them, and copy their structure (one page with variants or separate pages) but write your own words (2019, older). [L0467.042]
  • Bold Product Options (2019, older): an app that lets customers choose custom sizes and materials on the product page. Preset option values can update the price in real time, while free-text entry may not. Check with the app's support before relying on it. [L0467.047]
  • A single Canva image of colour swatches does not let customers click a colour and add that variant to the cart. Clickable swatches need variant options built into the product, typically through an app (2025). [L0837.059]
  • Set up variant-specific descriptions in this order:
    1. Create a variant metafield named "Variant description" with type Rich text.
    2. Create a snippet named "variant-description" and paste the complete corrected snippet code into it.
    3. Create a new product page template, hide the "Description" block, add a Custom Liquid block and paste {% render 'variant-description' %} into it.
    4. Assign the new product page template to every product that has variants. [L0621.001]
  • The variant metafield "Variant description" (type Rich text) stores formatted text separately for each variant. The snippet reads it as custom.variant_description and outputs it with the metafield_tag filter. [L0621.003]

  • The Direct Buy button shows payment providers based on the visitor's device. On iPhone, Apple Pay is offered by default. On Android, it can offer Google Pay, PayPal or Shopify ShopPay. [L0339.002]
  • Place Add to cart and Buy now side by side under the price, and show an express payment button such as PayPal below them. Buyers can then pay without going through the cart first. [L0600.043]
  • Direct payment button setup: it needs no manual setup in the template. It is dynamic code that tells Shopify it is a direct payment button and works with the device's available payment providers. [L0339.010]
  • After changing PageFly template settings: 1. Save the page. 2. Publish the page. 3. Export the template. [L0339.009]
  • Quantity: the default quantity selector can be set to the most common purchase amount (see L0834.039 under Product information settings).

Bundles, upsells and related products

  • Recommendation grid (Source E 2025-26): display product recommendations on product detail pages as a 2x3 grid (2 columns, 3 rows) instead of a single-row slider showing only 2 items. Add a magnifying-glass zoom feature and label the block Curated for you, which signals data-driven logic, rather than Recommended by us, which signals manual curation. [L0197.003]
  • Related Products: use the section when offering add-on products that complement the main item. [L0104.011]
  • Recommendation blocks such as You may also like are common on competitor product pages. Add them once the store has enough products to recommend. [L0600.012]
  • Bundles (Source D 2026), steps:
    1. Install the Kaching Bundles app from the Shopify App Store.
    2. Create a 2-pack and a 3-pack bundle offer.
    3. Generate a niche-specific ebook using Claude.
    4. Design the ebook in Canva.
    5. Add the ebook as a free bonus.
    6. Highlight the bonus on the product page.
    7. Test and track the change in average order value (AOV). [L0860.017]
  • Bundle settings in Kaching: Settings > Let customers choose different variants for each item. Turn it off when the product has no variants. The related toggles Hide unavailable variant options and Show variant selection for single quantity deal bar are in the same settings. [L0861.009]
  • Settings > Cart > Skip cart and go to checkout directly sends customers straight to checkout after adding a bundle. It is available but not required for the setup. [L0861.010]
  • A gift product that shows Out of stock or is unavailable blocks the bundle from offering the free item. Check the gift product's inventory and make sure it is available before the bundle is published. [L0861.027]

Buttons and cart behavior

  • For a simple single-product store, the main button can read 'Add to bag' or 'I want it now' and send the visitor straight to checkout. This skips the cart page, which can be a point where visitors leave. [L1345.055]
  • A sticky button lets a visitor who is already convinced act immediately instead of scrolling back or leaving. Without a visible call to action, visitors who are almost ready can leave before they buy. [L1345.058]
  • Case: a store's add-to-cart rate was lower than expected, and visitors who read the product but did not see a button on mobile were leaving. Action: a sticky add-to-cart button was added to the mobile product page. Result: the add-to-cart rate rose by about 25%. [L1345.057]
  • (Older, 2021-22) Disable the Quick shop button in the Shopify theme product settings. Quick shop opens a popup with product details and adds JavaScript that slows the site even when customers do not click it, so customers should go to the full product page instead. [L1371.020]
  • (Older, 2021-22) Show the dynamic checkout button in the Shopify theme product settings so each customer sees their preferred payment method, such as PayPal or Apple Pay, from those available on the store. Set the Add to cart button to Enable on desktop only. [L1371.021]

Keeping the page live with zero stock

Page builders: PageFly and GemPages

Choosing a builder

  • Custom page builders such as PageFly or GemPages let you change background colors and layout to highlight offers more than theme settings do. Use the theme's own options first if they are enough for the highlight. [L1345.018]
  • PageFly is a page builder used to create product pages in Shopify. Build one product page, duplicate it for each new product, then rewrite the copy and replace the imagery. This keeps a multi-product test store consistent without rebuilding each page. [L1428.027]
  • PageFly landing page templates are used to build high-converting product pages with proven copywriting structure and trust elements. [L1436.039]
  • PageFly is used to build landing pages for the store. It helps improve the store's look without needing advanced design skills. [L1439.038]

Duplicating a proven page

  1. Import a page via Pages (import the template as in the course's import video).
  2. Select the page checkbox and choose Duplicate to copy it for a new product.
  3. Assign the copy to that product.
  4. Duplicate a proven page and tweak it only slightly for products in the same niche, so products can be launched quickly. [L1363.032]
  • PageFly gives one free page publish. Each additional page costs about 20 USD. PageFly support may reduce this for e-commerce students who plan multiple Shopify stores; the lesson reported this worked for at least one student. [L1363.033]
  • When removing a PageFly element, check that it is removed on all devices (desktop and mobile), because it can remain on one device. [L1363.034]
  • On a single-niche store, use global styles (font families and colour scheme) in PageFly so one change updates every page. On a general store testing many products, set custom colours on each page or element instead, so each product can get its own colours quickly. [L1363.062]

Workflow and drafts

  • Sketch the mobile and desktop layouts in a design tool before building in PageFly. Design tools such as Canva or Photoshop let you export the images straight into PageFly. [L1462.021]
  • PageFly is opened from the Shopify admin under Apps, then PageFly. Saving a page keeps the draft, but changes only go live when the page is published, so keep test pages unpublished until the layout is finished. [L1462.053]
  • Test pages in PageFly should stay unpublished while you work on them. Save them as drafts and do not publish until the layout is finished. [L1462.052]

PageFly layout system

Grid and sections

  • Web page layouts are built from stacked rows, and each row holds side-by-side columns. Grid systems usually use 12 columns because 12 divides cleanly into both 3 and 4 columns. [L1462.001]
  • Stacking many sections on mobile makes a landing page very long and tiring to scroll. Decide early which blocks can share a row with two or more columns on mobile. [L1462.004]
  • Uneven grids are built by splitting a row into proportions, such as one full-width row, or a 50% column next to a section split into two 25% parts. Combining rows and nested columns creates complex layouts. [L1462.005]

Building a two-column product section

  1. Click Plus, then Layout, and insert a two-column row.
  2. Select the row and, in the General tab, turn off Fixed width so the section runs edge to edge.
  3. In the General tab, turn off the row's column spacing, which PageFly adds by default.
  4. Remove the row's top and bottom padding.
  5. Select each column and set its background color under Styling > Background color, using a six-digit hex code.
  6. In the first column, add the heading, the star rating icon, the rating text and the review images. Set images to block where they must stack, or to inline and fixed width where they must sit side by side.
  7. In the second column, add the product title, the price, the description and the product images, then adjust the image widths.
  8. Add inside padding on the columns, not on the section, so colored column backgrounds stay full-bleed.
  9. Switch between desktop, laptop, tablet and mobile views and adjust the padding and column counts for each device. [L1462.022]
  • Column background color is set under Styling > Background color, where a hex code can be typed into the field. Use the same hex code for other elements that should match the accent color, such as star icons or borders. [L1462.025]
  • If a column has a background color, padding applied to the parent section pushes the colored background away from the edges. Put the inside padding on the column itself instead. [L1462.026]

Spacing and the box model

  • In the box model, padding is the space inside an element between its content and its border, and margin is the space outside the element that separates it from neighbouring elements. [L1462.007]
  • In PageFly, set padding and margin under the element's Styling tab. Enter one value for all four sides, or enter separate values for top, bottom, left or right. [L1462.008]
  • In PageFly, edits made on desktop cascade down to tablet and mobile unless a smaller device has its own value. Edits made on mobile do not flow back up to desktop. [L1462.009]
  • If a mobile value is left empty, PageFly applies whatever padding or margin you add on mobile to that element. To remove inherited spacing on mobile, enter 0 for that value explicitly. [L1462.010]
  • Text placed directly against a border looks cramped. Add inside padding so the content sits clear of the edge. [L1462.012]
  • An inner block groups several elements so one margin or padding value moves them as a single unit. Use this to center a text stack or to space a group of elements from the element above. [L1462.028]
  • A common starting value for inside padding on mobile in PageFly is 15 px on each side. Adjust the value for each individual layout rather than applying it everywhere. [L1462.043]
  • Excess inside padding in a narrow column squeezes text onto too many lines. Reduce the padding on smaller devices before reducing font sizes. [L1462.042]

Borders

  • Borders are set under Styling > Border, where you can choose a color, a width and which sides get a border. Border radius rounds the corners, and the More settings option gives the radius value. [L1462.011]
  • To place a border on only one side of a PageFly element, set a border width and color for that side and make the other three sides transparent or zero. This leaves a single accent line, such as a vertical bar on the left of a review or feature block. [L1462.054]

Display, image and text sizing

  • Block elements take the full width of their container and stack on top of each other. Inline elements sit next to each other on the same line and only take the width they need. [L1462.013]
  • Inline elements do not accept custom height and width values. Inline-block elements sit side by side like inline elements but accept width and height settings. [L1462.014]
  • Images are inline by default, but PageFly displays them at 100% width. To place several images next to each other, set the image width yourself or switch them to inline display. [L1462.015]
  • To set a fixed image width in PageFly, select the image, open the General tab, and set Enable for width to yes. Then enter a pixel value, for example 100 px for a small logo or icon. [L1462.016]
  • Set PageFly image alignment under Styling to left, center or right. Setting text align to center on a row centers all text and inline elements inside that row. [L1462.017]
  • Use a heading for the page title and smaller headings for sections. Set font family, bold, and size under the element's typography settings to build a clear hierarchy. [L1462.027]
  • Set an embedded video to a 4:3 aspect ratio in the General tab for a shorter, wider frame. Choose a different ratio if the layout needs a taller video. [L1462.044]
  • Applying display flex to an image in PageFly can crop the image when the image has a minimum width. After switching an image to flex, check the preview and adjust its width or switch it back to block if it is clipped. [L1462.055]
  • A review line on a product section can be built from three inline items in one row: a small star icon, a text line with the review count, and a logo. Give the images a fixed pixel width, such as 100 px for small icons, and add a 10 px margin on each side to space them evenly. [L1462.059]

Positioning

  • Position relative moves an element away from its original spot using top, bottom, left or right values, and the space it occupied stays reserved. Negative or positive margin, by contrast, moves the elements below it as well. [L1462.033]
  • Position absolute fixes an element inside its nearest container, and that container must have position relative. Without a relative parent, the absolute element will not stay where you place it. [L1462.034]
  • Position static is the default for every element. Set an element back to static to reset positioning that was previously changed, for example on mobile. [L1462.035]
  • Set an element to position fixed with top 0 and left 0 to pin it to the top of the browser window. This makes a sticky navigation bar that stays visible while the visitor scrolls. [L1462.031]
  • A PageFly element set to position fixed may not appear at all until it has a width. Setting a width, such as 50%, makes it visible so the position can be checked, and the width can be changed afterwards. [L1462.056]
  • Use margin and relative positioning for most element placement, because they keep the surrounding layout predictable. Reserve position absolute for small elements inside a container that is already sized and set to position relative. [L1462.058]

Flexbox, grid and centering

  • Set display to flex under the element's Styling tab to turn it into a flexbox container. Then use flex direction (row, row reverse, column, column reverse), align items, align content and justify content to control position. [L1462.036]
  • Flexbox creates fluid layouts that wrap items onto the next line when they reach their minimum width. This suits forms such as name, email and submit fields, where the layout should adapt to the screen size. [L1462.037]
  • Grid gives precise control over proportions and placement, while flexbox gives easier control over direction and alignment. Use grid for fixed column layouts and flexbox when items need to reverse order or center easily. [L1462.038]
  • To center content vertically and horizontally in PageFly, set the container to display flex and set align items, align content and justify content to center. This replaces margin-auto and padding hacks. [L1462.039]

Reorder columns for mobile so the title appears above the product image:

  1. Select the row and set its mobile columns per line to 1 so the columns stack.
  2. Under the row's Styling tab, set display to flex.
  3. Set flex direction to column reverse so the second column appears first.
  4. Remove any column padding that is too wide for the narrow screen, then set padding of 15 px on each side as a starting point.
  5. Check the layout in mobile preview and adjust the spacing. [L1462.040]

Mobile and device checks

  • Check every device view after each change, including desktop, laptop, tablet and mobile. A layout that works on a wide screen can squeeze text into narrow columns on smaller screens. [L1462.041]
  • On mobile, change review text or other inline items to block display when they spill past the screen edge. Block display forces each item onto its own line and keeps the text inside the container. [L1462.057]

Backgrounds and sliders

  • Set a background image on a column under Styling > Background. Choose cover to fill the area, set background repeat to no repeat to stop tiling, and center the image position so the main subject is visible. [L1462.046]
  • Opacity applies to the whole element, so lowering it on a background image also fades the background color set on that same element. Pre-darken the image in a design tool with a semi-transparent black overlay instead, and export it. [L1462.048]
  • The PageFly slideshow element holds slides, and each slide can be duplicated after styling. The General tab controls the navigation style, the partial items display, rewind and auto play. [L1462.049]
  • Showing a partial next slide in a slideshow signals to visitors that the content scrolls, which encourages them to swipe or click through the remaining items. [L1462.050]
