Holiday site banner pattern: a seasonal sale headline plus a coupon code that the customer enters at checkout. Formula: [Holiday] sale, enter coupon code [CODE] to check out. The code is unique to the holiday, so you can track its sales, and the banner catches first-time visitors from paid ads. Example 1: Winter sale, enter coupon code WINTER20 to check out. Example 2: Summer sale, enter coupon code SUNNY15 to check out. [L0467.044]

Setting up a holiday sale on the store:

  1. Create a coupon code that is unique to the holiday sale.
  2. Add the sale to the homepage image slider.
  3. Show a banner strip across the whole site with the sale name and the coupon code.
  4. Check that first-time visitors from Google Ads will see the banner.
  5. Link the sale to a dedicated collection page with all the holiday offers. [L0467.045]

Create the pop-up coupon in Shopify:

  1. Go to Discounts in the Shopify admin and click Create discount.
  2. Select Amount off order.
  3. Enter the discount code and name (example: save five).
  4. Set the value as a fixed amount of $5.
  5. Set the usage limit to one use per customer so the code cannot be reused repeatedly.
  6. Click Save discount. [L0476.007]
  • Add a short product quiz when the catalogue is large, so visitors who feel overwhelmed by choice get a recommended product after a few questions. [L0524.019]

Create the expiring discount code in the Shopify admin:

  1. Open Discounts in the sidebar of the Shopify admin.
  2. Click Create discount code.
  3. Enter the code name, for example save 10.
  4. Choose the discount type Percentage.
  5. Enter 10 as the discount value for 10%.
  6. Keep all products selected and apply it to all products in all collections.
  7. Leave minimum requirements unset.
  8. Set customer eligibility to everyone.
  9. Leave usage limits unset.
  10. Leave the end date empty; a start date may be set.
  11. Click Save discount code. [L0531.011]

Preparing the store for each promotion window:

  1. Replace the notification bar with the current offer.
  2. Swap the exit-intent overlay to show the offer.
  3. Create a custom product page for a bundle, or modify the existing product page if the offer is small.
  4. For an event, create a content page with the details and eligibility rules.
  5. Add a progress tracker such as Bold Sales Motivator if the offer depends on a cart threshold.
  6. Update the promotions page with the offer, if you use one. [L1204.049]
  • Keep one static promotions page and swap its content when a promotion starts, since this is easier to remove later. Bundles and bonus gifts should get their own page, so they can be removed without affecting the rest. Event pages that may rank in search can stay live and later become evergreen content. [L1204.051]

Closing a promotion, done manually after the window:

  1. Set the notification bar back to the default offer.
  2. Restore the previous exit-intent overlay.
  3. Remove bundle or bonus content from product pages and return them to their default state.
  4. Replace the offer on the promotions page with the default offer or the next offer.
  5. Turn off progress trackers such as Bold Sales Motivator, so no shopper reaches a goal that unlocks nothing. [L1204.052]

Create a standard order discount code in the Shopify admin:

  1. Open the Discounts section in the Shopify admin. No discounts exist by default.
  2. Click Create discount.
  3. Choose Amount off order.
  4. Select discount code instead of automatic discount.
  5. Enter the code name, for example save 10.
  6. Choose percentage (the usual choice) or fixed amount, and enter the value, for example 10%.
  7. Under minimum requirements, enter a minimum order value such as 2000, or leave it at no minimum.
  8. Under customer eligibility, restrict the code to specific customer segments if needed.
  9. Set maximum discount uses: 5 total, 10 total, or once per customer, or leave it unlimited.
  10. Keep the combination with other promotions turned off.
  11. Keep the start date at the current date and time, or set a later start.
  12. For a time-limited promotion, set an end date.
  13. Click save discount. [L1322.001]

  • Shopify offers four discount types: amount off products, amount off order, buy X get Y, and free shipping. Amount off order is the type used most often for order-level discount codes. [L1322.002]

  • A demo store does not need discount codes. Create them once the store is live and taking real orders. [L1322.004]

  • On the Shopify checkout page, the customer sees a discount code field, enters the code, and clicks apply. In the demo, a 10% code gave a 319.60 dollar discount, which implies an order subtotal of about 3196 dollars. [L1322.012]

  • A store can hold as many discount codes as needed, and all of them are listed together in the Discounts overview. This allows one-off codes for individual buyers to be managed alongside general promotions. [L1322.013]

Test a discount code on the storefront before sending it to a buyer:

  2. Open the cart and go to the checkout.
  3. In the discount code field on the checkout page, enter the code.
  4. Click apply and check the discount amount that appears for the order. [L1322.021]

  • On-site upsell positions are: (1) on the product page, shown before Add to cart; (2) on the cart page, shown before checkout (pre-checkout upsell); (3) after payment but before the thank-you page (post-checkout upsell), which inserts an extra page into the checkout flow. [L1409.004]

  • Shopify checkout supports at most two levels of post-purchase upsells; after two offers the customer must land on the thank-you page. [L1410.027]

Post-purchase structure (the monster funnel), in order:

  1. The customer buys the main item and completes payment.
  2. Show the first upsell.
  3. If accepted, show the second upsell; if declined, show the first downsell.
  4. If the second upsell is accepted or declined, show the thank-you page.
  5. If the first downsell is accepted, show the thank-you page; if declined, show the thank-you page. [L1412.027]

  • Shopify checkout allows at most two levels of post-purchase upsells, so you cannot show three or four offer pages before the thank-you page. Plan the funnel with a maximum of two offers plus a downsell path. [L1412.028]

  • Enable a post-purchase funnel in Shopify under Settings > Checkout. Scroll down to the post-purchase page section and select Reconvert upsell and cross-sell. The page may take a while to load after the change. [L1412.029]

  • Change post-purchase discounts under Discounts and shipping in the upsell app. You can switch the discount between percent and fixed amount per unit, change the timer, and edit the button text. [L1412.033]

  • A gift card of 80 Swiss francs was sold, and buyers received a code by email. Around Christmas, three to five gift cards were sold, many of them were never redeemed, and that amount became revenue. Gift cards sold poorly outside peak gifting periods but can add revenue during Christmas. [L1439.037]

  • Create an automatic discount in the Shopify store so that when two specific products are both added to the cart, one of them is given free. The customer does not need a code. [L1469.006]

  • Do not show a review widget that states a product has no reviews. A visible zero-review signal (negative social proof) suggests nobody has bought it or that it is not good, so hide the widget until reviews exist. Most Shopify review apps allow the widget to be hidden when a product has zero reviews. [L1522.010]
