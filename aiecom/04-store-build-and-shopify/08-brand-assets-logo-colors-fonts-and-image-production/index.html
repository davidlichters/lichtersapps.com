4.8 Brand assets: logo, colors, fonts and image production

Setup order and file preparation

  1. Check the theme's image sizes before you design anything. Each Shopify theme needs its own graphic sizes, and files made for one theme may not fit another [L0098.002, L0342.009, L1045.001].
  2. Designing without checking the theme's dimensions produces files that crop, stretch or do not fit [L1045.038].
  3. Look up the theme's sizes in the theme backend and resize to them before uploading. Oversized images can push section titles down the page [L0665.029].
  4. The theme is called "Manhattan (Source A)" in one unit and "Source A" in others. The size figures below come from both names, so confirm they match your theme before you use them [L0098.002, L0342.008, L1045.001].
  5. Upload all brand images in bulk before you edit the theme: Shopify admin > Content > Files > Upload files. Uploaded files are not linked to any section automatically, but you can pick them later in the theme editor without uploading again [L0775.001, L0857.058].
  6. For bulk uploads, use the Files section for many images at once. Large uploads can run in the background while you keep working. Image links can also go into the product CSV instead [L1111.063] (2020, older).
  7. Note the download folder and file name as soon as you save a file. Some computers save to Downloads and others to the desktop [L0342.012, L1045.013].
  8. Shopify and Canva both ask for files, so keep the Canva originals. Canva stores finished designs under All designs and you can download them again without rebuilding [L0342.013].
  9. Store graphics change with sales, holidays and new collections. Refresh them regularly, and keep the Canva files so the set can be updated quickly [L0342.037, L1045.035].

Setup order for the theme (Source E, 2025-26):

  1. Open Online Store > Themes, click Customize, and go to Theme settings > Logos.
  2. Upload the main logo, then the mobile logo.
  3. Check the logo in the mobile preview before you continue. About 90% of store traffic is typically on phones [L1331.001].
  4. Go to Theme settings > Colors and paste the brand hex codes into the existing color fields [L1331.001].
  5. Go to Typography, upload the font file, and paste its link into the font field [L1331.001].
  6. In Logos, select the favicon and upload the favicon file made from the logo [L1331.001].
  7. Save after each step and refresh the preview [L1331.001].

Canva work

Free plan limits

  • On the free plan, the Transparent background option in the download menu is greyed out. A PNG downloads with a white background. Transparent PNGs need the paid plan [L1045.011].
  • The white PNG shows as a white box around the logo on any coloured section of the site. Either remove the background before uploading, or use a paid plan with transparent download [L0342.010, L1045.011, L1045.037].
  • An existing template cannot be resized on the free plan. To get a different banner shape, create a new design [L0342.021, L1045.021].

Working in Canva

  • Start from a template for each asset type, then change text, colours and images to fit the brand. The template links are faster than building from scratch [L1045.036].
  • Text: select the text and use the text colour (A) icon to choose a brand colour. Use the highlight options for font, bold, letter spacing and line spacing [L0342.032].
  • Centring: select several elements, open the three-dot menu, and choose Position > Center [L0342.032].
  • To use a photo as a banner background: search the Elements panel under Photos, drag the photo onto the design, right-click it (or two-finger click on a trackpad), choose Set as background, then move the image to the right position [L1045.020].
  • Once a photo is a background, you can move it inside the frame to position the subject. For example, lower it so a person's head is not cut off at the top [L1045.047].
  • Supplier product photos can be uploaded to Canva the same way as stock photos. This makes all images in a set crop to the same size [L1045.024].
  • Canva's built-in Photos library has many free images for popular niches such as surfing. For niches with few usable stock images, such as basic furniture or mechanical products, download photos from Pexels, upload them to Canva and use them like built-in photos [L1045.046].
  • For a website banner, search the Canva templates for "website banner" and use that size as the starting format. Check the result on mobile first, then adjust the desktop version [L1219.020].
  • Canva is enough to create a simple logo and to edit ebook covers and branding at the start, without a designer [L0871.020].

Ebook assets (tools)

  • Use Canva's ebook template: search "ebook", choose a cover, type the title and author name, and export it for the store [L0513.025].
  • Placeit creates 3D book mockups. Upload the Canva cover, set the book colour to match (for example black), and download the mockup. This needs a subscription [L0513.026].
  • Pexels.com provides free stock photos for ebook covers. All images are free except those from iStock [L0513.027].

Logo and favicon formats

Logo formats

  • Shopify accepts SVG for logos. Upload the SVG to the logo settings rather than a pixelated image [L0952.036].
  • PageFly also accepts SVG uploads for logos and icons [L1462.018].
  • SVG can be enlarged up to ten times without losing sharpness, because it is built from mathematical shapes and angles [L0952.037].
  • PNG is pixel-based and loses quality when enlarged. Use PNG as the fallback logo format where the platform does not accept SVG [L0952.038].
  • Export logos with a transparent background, so they work on white, dark and dark-mode websites without a visible box [L0952.039].
  • Upload PNGs with transparent backgrounds to PageFly, so the logo sits on any section colour without a white box [L1462.018].
  • When a logo goes in a header, export only the logo selection with no extra page margin, so the header height is not affected [L0952.040].
  • Logo for the Source A theme: 800 × 300 px, PNG, transparent background [L0075.001, L0342.008].
  • Fill the artboard close to its edges, with the logo filling the template almost edge to edge at the right proportions. This prevents empty margins or wrong shapes when uploaded [L0342.008, L1045.010].
  • Keep the logo simple. A text-plus-icon logo is easier to read at small sizes and looks more professional. A logo that is too detailed or showy is hard to read on the site [L1045.039].
  • A designer logo can be very large, for example 1527 × 518 px, which loads slowly at full size. Crop the surrounding white space, then resize to about 500 px wide while keeping the rectangular shape. This suits the header and checkout (Source B, 2021-22, older) [L1371.046].
  • Pixel dimensions describe width by height, not file size. A 40 × 40 px image is 40 pixels across and 40 pixels down. Logos and favicons are sized by these pixel dimensions, usually with the Resize function in the editing tool (Source B, 2021-22, older) [L1371.045].

Favicon

  • Favicon size: 64 × 64 px, JPG or PNG, transparent background [L0075.001].
  • The favicon is the small icon in the browser tab. Using the same icon as the logo is the simplest, most consistent choice [L1045.015].
  • Create the favicon in Canva:
    1. Open the favicon template from the Source A templates and click Use Template [L0342.014, L1045.014].
    2. Copy the icon from the logo design, paste it into the favicon template, and centre it [L0342.014, L1045.014].
    3. Click Download and keep PNG. On the free plan the file keeps a white background, because transparency is not available. JPEG is an alternative and also keeps the white background [L0342.014, L1045.014].

Logo and favicon in Shopify

Uploading the logo

  1. Open Theme settings (gear icon in the left sidebar), or go to Online Store > Themes > Customize > Theme settings > Logo [L0775.005, L0954.014].
  2. Under Logo, click Select image and choose the file from Files. Alternatively, in the header section, open the logo setting in the theme settings and upload the file [L0775.005, L0954.014, L1326.007].
  3. Click Done and check the header preview. Adjust the size until it displays correctly [L0775.005, L0954.014, L1326.007].
  • The default desktop logo width is 200 px. Change it only if the uploaded file is noticeably larger or smaller, and check the preview [L0775.006].
  • The logo appears in the store header after upload [L0954.014].
  • In one example store, the logo height was set back to 100 after being enlarged. The logo should be neither so large it crowds the header nor so small it is hard to read. Mobile uses the same logo image, but its size is set separately [L1371.047] (Source B, 2021-22, older).
  • In Source D' theme, footer logos are chosen the same way as header logos [L1188.004].

Uploading the favicon

  1. Open Theme settings > Favicon.
  2. Click Select image and choose a small version of your logo, or another image that represents the store.
  3. Click Done [L0775.007].
  • If the favicon is not replaced, the browser tab shows Shopify's default logo instead of your brand. Setting it takes under a minute and matters even for a demo store [L0775.008].

Brand and metadata

  • Shopify Settings > Brand: logo, brand colours, slogan and description are added after the logo and colours are created. Social media pages are linked here later [L1305.038].
  • Add your logo and update the metadata with your store information. This helps the store look distinct from copycat stores [L0920.026].

Source D theme settings

  • Theme settings > General Settings contain Logo, Colours, Typography, Button Styling, Navigation Buttons, Brand information, Search behaviour, Animations and Cart Drawer options. Logo images are chosen with the Select from library button [L1188.004].

Colour palettes

Shopify colour fields

  • Theme settings > Colors contains: Solid button label, Accent 1, Accent 2, Secondary text, Outline button, Background 1, Background 2 and Price for you save. Click a swatch and type a six-digit hex code [L0775.010].
  • The Source E example set includes Text and Background 1 and 2 as well as the fields above [L1331.002].
  • Example A (Source A): Solid button label white; Accent 1 brand pink; Accent 2 brand teal; Secondary text black; Outline button brand blue; Background 1 solid white; Background 2 light grey [L0775.011].
  • Example B (Source E): Solid button label #FFFFFF; Accent 1 #6D388B, used for solid buttons; near-black #121212 as the dark contrast colour [L1331.002].
  • Keep the theme's default dark and light colours in their roles. Replace only their values with brand colours, so the store stays consistent [L1331.003].
  • Changes show in the homepage preview as soon as you click Save. Scroll through the preview after each change to check buttons, backgrounds and text [L0775.014].

How many colours

  • Use a solid palette of 2-4 brand colours for a professional, trustworthy look [L0101.019].
  • Avoid too many colours. Pick a few and reuse them across buttons, menu links, borders and banners, rather than a unique colour for each element [L0775.013].
  • Keep one accent colour for buttons. If you use a gradient, reuse the same accent rather than pasting new colours each time [L1331.003].
  • Gradient options exist for accent colours, but a simple store can leave them off and use solid colours only. Leaving Accent 2 at no colour is valid when no second accent is needed [L0775.012].

Choosing colours

  1. Search Google Images for "colour palette" [L0355.010].
  2. Pick a palette whose colours already fit together [L0355.010].
  3. Copy the colour codes from that palette [L0355.010].
  4. Use those codes as the website colours, so the whole design matches [L0355.010].
  • Match colours to the audience. For an older audience, minimal design with white and grey backgrounds and black text usually works better than bright colours [L0656.020].
  • A simple, clean store uses a header announcement bar and a limited set of recurring colours. The example store used green, white and grey consistently [L0657.036].
  • Use the store's colour scheme in AI prompts for section graphics if the section should match the site [L1075.028].

Problems

  • A near-black page background makes black product photos disappear into the page. Use a background colour that contrasts with the product images on any page showing dark products [L1225.090].
  • Footer colours are set in Theme settings > Colors, scrolled to the bottom. The Footer group contains: Background, Headings, Text, Text link, Text link hover, Menu list link, Menu list link hover, Additional menu link, Additional menu link hover and Copyright text. Social icon style is set in the same section, with the options Light on dark or Dark on light. Adjust the copyright text colour so it matches the rest of the footer [L0681.001].

Brand redesign sequence (Source E)

  1. Upload the new logo to replace the old one.
  2. Open Theme Settings > Colors and update all colour codes with hex codes from the brand guidelines.
  3. Open Theme Settings > Typography and change the heading and body fonts to your paired fonts.
  4. Rewrite the website copy in brand voice: screenshot each section, paste it into ChatGPT, rewrite it in brand voice, and copy it back to Shopify.
  5. Preview all changes and publish [L0317.021].

Typography

Where to set fonts

  • Theme settings > Typography sets the font for all text on the store by default. Click Change, search Shopify's font library, select a font and click Select [L0775.015].
  • Shopify path: Theme Settings > Customize theme > Typography [L0317.015].
  • For each page type (homepage, collection page, product page), open the theme settings and choose the page type. Change fonts and styles page by page from the dropdown (2020, older) [L1111.062].

Font choice and speed

  • System fonts, such as Helvetica, New York, system_ui and SF Mono, are pre-installed and load fast. Downloaded fonts, such as Abel, Abril Fatface, Acme, Alegreya, Poppins and Playfair, load more slowly because visitors must download them. Prioritise system fonts for faster page load [L0317.015].
  • The Shopify font list shows Sans-serif, Serif and Mono fonts, which load faster, and "Other" fonts, which are downloaded to the visitor's computer and can slow load times. Prefer the faster fonts (Source B, 2021-22, older) [L1371.016].
  • Adding too many fonts and colours quickly makes a store look messy [L0775.013].

Pairing

  • Set the body font to Montserrat or a similar clean, readable sans-serif for accessibility. Choose a distinct display font for the heading font, to create visual hierarchy and brand distinction [L0101.015].
  • Typography includes a Font size scale, which enlarges or reduces all text proportionally. It also includes Body font with weight options such as regular, italic, medium and medium italic. A 110% scale and medium weight are example values that gave bolder, more readable body text [L0775.016].
  • Heading font size is a percentage. It defaults to 130% in the Manhattan theme. Setting it to 100% makes product titles smaller [L0966.056].
  • A light body font weight can make product descriptions look faint. Take a screenshot before you change the font weight [L0971.052].

Using a brand font

  1. Download the free Deja Vu Serif font (or your brand font) and unzip it [L1331.004].
  2. Upload the TTF file in Shopify admin under Content > Files [L1331.004].
  3. Copy the file link and paste it into the theme's font field, so the store font matches the logo font [L1331.004].
  4. Upload a few options and compare them before choosing [L1331.004].
  • Brand Fetch can report font data wrongly for Shopify sites. Custom fonts often appear as CSS variable names, such as --font-body-family, not real typeface names such as Helvetica or Georgia. Visit the live website or inspect the theme CSS to find the real font. Do not assume the variable name is the typeface [L0318.022].

Layout and buttons

  • Theme settings > Layout sets the page width. The default is 1200 px and it can be raised to 1600 px. A wider page only shows on larger monitors, so 1200 px is a safe default [L0775.017].
  • Theme settings > Buttons controls border thickness, opacity, corner radius and transparency for all buttons. The same area includes Variant pills (product variant display), Inputs (for example search box size), and Product and collection cards. Default values are fine for a beginner store [L0775.018].

Banners and slideshow images

Sizes

  • The table gives 1800 × 400-900 px height for slideshow and image banners [L0075.001].
  • For the Source A theme, the standard homepage banner is 1800 × 600 px. Banners are full-width graphics used as slideshow images [L0342.018, L1045.018].
  • A custom banner shape can be made in Canva, for example 1800 × 900 px [L0342.021, L1045.021].
  • Shopify's slide image field shows a recommended size of 1800 × 1000 px. This differs from the 1600 px hero width in the older PicMonkey procedure below. Compare the theme's hint with the size you prepared, and choose the one that fits your slideshow height before uploading [L1310.041] (Source B, 2021-22, older).
  • For a wide hero banner, a 1000 × 500 px result is workable. A 624 × 628 px square cannot fill a full-width banner and should be rejected for that slot, even though it suits a square image area [L1310.040] (Source B, 2021-22, older).

Text on banners

  • The theme can place text over banner images itself. Banners can be plain photos with no text added in Canva [L0098.014, L0342.019, L1045.019].
  • Add text to banners only when a design-level message is wanted [L0342.019].

Hero banner procedure (PicMonkey, 2021-22, older)

  1. Search a stock source for an image that reflects the outcome your customer wants [L1310.016].
  2. Check the image dimensions and reject images too small for a full-width banner [L1310.016].
  3. Download the image and open it in PicMonkey [L1310.016].
  4. Use Smart resize to set the width to 1600 px, and reduce the height to between 400 and 600 px [L1310.016].
  5. If one dimension is still too large, crop the side you do not need, keeping the main subject [L1310.016].
  6. Download the edited image [L1310.016].
  7. Compress it in ImageOptim [L1310.016].
  8. Upload it to the Shopify slideshow [L1310.016].

Collection images

Sizes

  • Collection page banner: 1600 × 400 px, JPG [L0075.001].
  • Homepage collection image: 800 × 800 px, JPG [L0075.001].

Collection page banners

  • Collection page banners are plain banner-format images with no text. Each collection gets one, uploaded to that collection. They act as atmospheric backgrounds at the top of each collection page [L1045.028, L0342.023].
  • They can show lifestyle scenes, zoomed-in details, or colour and fabric swatches that match the products [L1045.028].
  • Each collection can have its own image. A more specific one (for example living room couches versus living room chairs) helps buyers recognise the category [L0342.023].
  • Before suppliers are connected, generic lifestyle photos are enough for collection banners. Product-specific images can replace them later, and collection images can be refreshed when new products or suppliers are added [L0342.024].

One image for two places

  • A collection's image is shared between the collection page and the homepage. The same collection cannot show different images in each place [L0342.025, L1045.029].
  • Use either the long collection banners or the square homepage collection images, not both for the same collections [L0342.025, L1045.029].
  • Expecting one image on the homepage and another on the collection page does not work. Plan one image per collection [L1045.040].
  • Homepage collection images are square. A long banner reused on the homepage is cropped from its centre, so place the main subject in the middle of any image used in both places [L0342.026, L1045.030].

Product page graphics, blog images and pre-footer

Product page graphic

  • Size: 1600 × 200-600 px height, JPG or PNG. PNG needs a transparent background [L0075.001].
  • The product page graphic appears directly above or below the Add to Cart button. Add, change or remove it depending on the season or whether a sale is running [L1045.025].

Blog images

  • Size: 1600 × 900 px, or any 16:9 ratio, JPG [L0075.001].
  • Blog images are optional. Create them in Canva only if your store uses blog posts or blog previews [L0098.031].
  • For featured blog tiles, you can use templates with text overlays instead of plain image backgrounds [L0098.032].
  • Keep the same size across all posts so the blog layout stays consistent. A blog template can carry a title over the image, and each post can use a different background image [L1045.032].

Pre-footer

  • Size: less than 285 × 285 px, JPG or PNG. PNG needs a transparent background [L0075.001].

Mega menu icons

  • The Source A theme supports up to five mega menu icons. Each icon is a separate page in one Canva design. Downloading the design produces a separate image file for each page [L0342.015, L1045.016].
  • Size: 250 × 250 px, JPG or PNG, transparent background [L0075.001].
  • Create them in Canva:
    1. Click the mega menu icons template in Canva [L0342.016].
    2. Open Elements, add an icon (for example the favicon icon or a wave), make it full size, centre it and set its colour [L0342.016].
    3. Click Add page and repeat for each additional icon, up to five in total [L0342.016, L1045.016].
    4. Click Download. Each page downloads as a separate image file [L0342.016].

Product photo sourcing and editing

Why photos matter

  • Ecommerce sites depend on images for two core functions: brand identity (logos and graphics) and product visibility, which lets buyers make informed purchase decisions [L0300.008].
  • Images are often the largest elements on a page and the biggest contributor to load time. Compress them offline before upload. Compression apps are less controllable than a dedicated offline tool [L1266.015].
  • Poor product images are a common reason stores do not convert. Find better images before concluding the product is weak [L1345.028].
  • Lifestyle images help buyers see the product in use and increase trust. A landing page needs good-quality product and lifestyle images, which make the brand look better and more trustworthy [L1382.028].

Supplier and stock images

  • Supplier and stock images come in varying dimensions and file sizes. They usually need editing or resizing to fit specific layout sections [L0300.009].
  • Image sources to check, in order: Pexels, Pixabay, Google Images, Alibaba, AliExpress. If no good image exists, look for a very similar product. Instagram hashtag research can also reveal raw user photos for the niche [L1345.029].
  • Check whether the store's product photos are the seller's own. Matching backgrounds, tables and hands across several images show the owner shot them, which is stronger than generic supplier photos. Use this as a quality check when the store looks different from the supplier listing [L0530.035].
  • Put your own brand name on copied product photos before publishing. This makes them your store's assets, not identical copies of a competitor's [L0600.010].
  • Supplier product photos can be downloaded from the supplier's website. If the file type is not JPEG, convert it with a free online converter, found by searching for the file type conversion (2020, older) [L1111.075].
  • Generic lifestyle photos are enough for collection banners before suppliers connect [L0342.024].

Editing yourself or outsourcing

  • During setup, editing single images yourself with PicMonkey is often faster than coordinating with a freelance designer. It is practical to learn basic image editing skills early (Source B, 2021-22, older) [L0300.010].
  • Standard editing sequence: edit images in PicMonkey by resizing, cropping and adding text as needed. Then selectively compress the larger files with platform-specific tools: ImageOptim for Mac, or Windows' built-in compression [L0300.012] (Source B, 2021-22, older).
  • Cropping or resizing in PicMonkey does not change the original file on your computer. Download the edited version as a new file. Download as PNG to keep a transparent background [L1371.044].
  • For bulk processing, outsource it. Give a freelancer a Photoshop automation or batch script that resizes each image, places it on a white background if needed, and compresses it. The speaker paid about $10 per 100 images for this, which he called one of the cheapest things to outsource (Source B, 2021-22, older) [L1456.023].
  • Fiverr retouchers can be hired for about $5 to $10 per image to change backgrounds, add pop, and clean up pixelation [L1345.031].
  • AI image tools such as DALL-E (transcribed as "Dahl") can create or edit product images that look realistic [L1345.031].
  • DALL-E can create new images for a print-on-demand store, and can edit an existing product photo and produce variations from the same source image [L1416.006].

Supplier file preparation (2021-22, older)

  1. Rename the file to include the supplier name, product description and model number. Default file names are often gibberish [L1456.020].
  2. Give multiple images of one product distinct file names by adding a word such as front, back, side or in use [L1456.020].
  3. Set the alt text. It can match the file name, but it is a separate field. Apps that copy the title to every image produce duplicate alt text. That is weaker for image search than unique alt text, but better than none [L1456.020].
  4. Resize the image from 2000 × 2000 px to about 800 × 800 or 1000 × 1000 px. This keeps good resolution while loading fast on mobile [L1456.020, L1456.021].
  5. Save as JPEG, which is smaller than PNG [L1456.020].
  6. Compress the image again with a compressor such as ImageOptim on Mac [L1456.020].

Background and layout

  • Keep the background white if the image is not a full-size lifestyle shot [L1163.016].
  • Put no text on the image, except branding that is on the product itself [L1163.016].
  • Apply a unique alt tag to every image, and give every image file a descriptive file name [L1163.016].
  • Product images in a grid should share the same proportions, such as square. Mixed sizes in a grid usually come from the dimensions of the uploaded files, not from a theme setting, so resize them to match [L0971.088].

Product image sizing rules

Target sizes (sources disagree)

  • Ideal size: 800 × 800 px, square, not rectangular (Source B, 2021-22, older) [L1163.008].
  • Minimum size: never smaller than 600 × 600 px. Smaller images may stop a product from being advertised on Google Shopping (Source B, 2021-22, older) [L1163.008].
  • Minimum size: at least 1000 × 1000 px. Smaller images look pixelated when customers enlarge them (2023) [L0970.058].
  • Both values apply to different needs. The 600 px minimum is about Google Shopping eligibility. The 1000 px minimum is about on-site enlargement quality, and is the more recent advice [L1163.008, L0970.058].
  • Maximum: do not exceed 1000 × 1000 px. Larger files slow the site, and mobile users cannot see the extra detail, so oversized images hurt site speed, conversions and SEO (Source B, 2021-22, older) [L1163.009].
  • A 1024 × 1024 px size was suggested for product images in 2020. It was not confirmed, so check the exact size with the platform or your support contact before uploading the full set [L0961.049].
  • A 1:1 template works for uniform images. Place a rectangular image on an 800 × 800 canvas and scale it as large as possible without distortion. Square images are not required, but uniform sizes look better side by side (2023) [L0470.089].
  • A 500 × 500 px canvas was the example Canva size for a product image design [L0036.032].
  • A square product image at 1080 × 1080 px fits square product tiles and social-style grids. Prepare images at this ratio before upload [L1462.045].

Very large and very small files

  • Very large supplier images, such as 8000 × 8000 px, slow page loading. Resize them before upload, and keep them at a size that still meets the 1000 × 1000 px minimum [L0970.059].
  • Product images at 2000 × 2000 px are too large and slow the page on mobile. Resize them before upload [L1456.021] (Source B, 2021-22, older).
  • Product photos above about 1 MB are too large and should be compressed. Slow opening of image files or slow uploads is a sign that compression is needed (2019, older) [L1002.022].
  • Product images above roughly 3000 × 3000 px are usually more than a website needs. A 10,000 × 10,000 px image can be reduced to 1000 × 1000 px with no visible loss on desktop or phone, and about ten times less data (2019, older) [L1002.023].

Consistency

  • All product images on the site should share one consistent size and shape. Mixed sizes make collection pages look messy. Some advertising channels, especially Google Shopping, also require standard image dimensions (Source B, 2021-22, older) [L1163.007].
  • Do not resize all product images to one identical size. Suppliers send different aspect ratios, and forced sizing causes cropping. Compress the files to reduce file size instead [L0972.021].
  • Do not convert product images to different aspect ratios (square or landscape) in bulk. Resizing without keeping proportions crops important parts or distorts the image [L0278.035].
  • Shopify's product grids and collection layouts depend on consistent proportions, so resize product images to the recommended sizes before upload [L0665.029].

AI image prompts

Product photo prompt (studio)

Run this prompt with the product name filled in:

Act as a professional product photographer shooting for a high-end Shopify storefront. Create a photorealistic image of this item: [PRODUCT NAME GOES HERE]. These requirements are mandatory and must be followed exactly. The backdrop is flat pure white at #FFFFFF, with no gradient, no texture, no scenery, no floor line, no horizon, and no shadow reaching the frame edges. The item sits centered and fully in view with nothing cut off, shows true-to-life proportions and scale, and displays realistic materials and fine detail in a brand-new state. Logos may appear only if they are generic or unbranded. Light it with soft studio lighting from several directions, with shadow only directly beneath the object. Keep contrast high and edges crisp, in the style of catalog photography comparable to Amazon, Shopify, or premium brand listings. Shoot from a front three-quarter angle, slightly rotated for depth. Deliver ultra-high resolution, sharp focus, no motion blur, no artistic filters, no stylization, and a fully photographic look. Exclude people, hands, props, any text, watermarks, branding overlays, and reflections of the camera or the room. The final image should read as if it came from a professional product studio and be ready to upload directly to a Shopify product page.

[L0536.001]

  • Before running the prompt, replace [PRODUCT NAME GOES HERE] with the exact product name plus its key visible traits (colour, material, size category), so the image matches the real item [L0536.001].
  • For sets or multi-part products, place every part together in one frame and keep each part fully visible [L0536.001].

Hero shot prompt (uploaded item)

Create a square picture of the uploaded item on a plain, pure white backdrop. Position the item in the middle of the frame with soft shadows that give it a sense of depth. Since this is the product's primary hero shot, keep it sharp, evenly lit, and free of any text, props, or background scenery.

Product fidelity: reproduce the item's exact form, dimensions, colour, texture, and surface finish. Do not invent branding or packaging that is not present in the uploaded photo. If the uploaded photo already displays a logo or label, leave it exactly as it appears.

[L0887.033]

  • The two prompts disagree on shadows. The studio prompt allows shadow only directly beneath the object, with no shadow reaching the frame edges [L0536.001]. The hero shot prompt asks for soft shadows that give depth [L0887.033]. Use the studio prompt for catalogue-style listings with strict rules. Use the hero shot prompt when you start from the supplier's own photo and need to keep its branding and details exactly [L0536.001, L0887.033].
  • The studio prompt allows generic or unbranded logos only [L0536.001]. The hero shot prompt keeps any logo or label already in the uploaded photo unchanged [L0887.033].

AI graphics for store sections

  • AI image generation can make visuals for sections that have no product photo, such as a free-shipping banner. It can also cover product pages, blog posts, and About Us or Contact Us pages. Describe the section's message and the scene or graphic you want. Review the result for accuracy before publishing [L1075.028].
  • If the section should match the site, include the store's colour scheme in the prompt [L1075.028].

Compression and file formats

Targets

  • Compress images to the smallest possible file size while keeping visual quality. Slow-loading images hurt the site [L0300.002].
  • Uploading uncompressed images of several megabytes significantly slows the site and reduces conversion rates [L0300.003].
  • Product images: under 300 KB, ideally under 50 KB, with quality as close to the original as possible. Compress with TinyPNG or Photoshop before upload [L1345.032].
  • Product photos above about 1 MB should be compressed (2019, older) [L1002.022].
  • GIFs: compress below 800 KB. They can reach 1 MB, but the target is 800 KB. For product pages, create GIFs from one to three second clips of existing video ads [L1345.033].
  • Animated GIFs load slowly. A 1.5-5 MB GIF converted to WebP becomes roughly 200-500 KB [L1382.033].
  • JPG, PNG and GIF converted to WebP can reduce a 1-2 MB image to around 200 KB or less. Start with product images, because they load first [L1412.043].

Tools

  • Compress before upload with tinypng.com for one-off images, or with an image compression app that does the same job [L0963.043].
  • On Mac, ImageOptim compresses images offline [L0300.012, L1310.016, L1456.020].
  • Smart SEO app or SEO app: reduces file sizes to improve page load speed without cropping or distorting images (Source A, 2025) [L0278.041].
  • Conflict on apps: Source B (2021-22, older) advises against Shopify apps that resize and compress images on-site. They slow the store, some run scripts that hurt speed, and some lose quality. Process images outside the store instead [L1456.022]. Source C advises against installing an app only to compress images, because it adds code for little benefit. Use an online converter instead [L1412.053]. Source A's 2025 recommendation of Smart SEO is the more recent advice, and it applies when you want on-site compression [L0278.041].

Conversion procedure (without an app)

  1. Search for a bulk PNG or JPG to WebP converter website [L1412.044].
  2. Upload all product images and GIFs at once [L1412.044].
  3. Download the converted files, which usually come as one zip [L1412.044].
  4. Upload the WebP images to the store one by one [L1412.044].

Formats

  • Save as JPEG for product photos. JPEG is smaller than PNG [L1456.020].
  • Use PNG only when the image needs a transparent background [L0709.011].
  • Prefer progressive JPEG unless the image needs a transparent background, in which case use PNG [L0709.011].
  • Resize and compress images for each device. Use Liquid in the theme to serve smaller sizes where needed. Choose file type and quality as needed [L0709.011].
