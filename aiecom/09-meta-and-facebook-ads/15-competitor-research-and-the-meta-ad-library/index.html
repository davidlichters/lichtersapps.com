9.15 Competitor research and the Meta ad library

Opening the Ad Library and searching

  • The Meta Ad Library is a free, public Meta tool that lists the active ads of any Facebook or Instagram page, including video and image ads, sorted from newest to oldest by start date. Use it to study competitor creatives, offers and how long each ad has run. [L0667.009, L0675.007, L1008.001]
  • It is the public archive of Facebook and Instagram ads. Combined with the filters of a brand tool, you can search it by country, language, niche, media type, days running, page active ads and ad creation date. [L0374.039]
  • Anyone can see every running ad, and sellers cannot remove their ads from it, so it shows competitors that third-party tools may not show or may hide. [L0335.046]
  • The library shows which ads run, their run dates and their creative angles. It does not show sales results, and some ads show no shop button or product details. Use it to study hooks, formats and angles, not as proof that a product sells. [L0552.051, L0549.018]
  • It does not show likes, comments or shares of an ad. For engagement, check the advertiser's posts for high like counts or use a spy tool that tracks an ad over time. [L1108.016]
  • For most ads the public library does not show CTR or spend, so filters by high CTR or high spend may not exist there. Judge candidates by visible signals such as engagement, comments and run length, and verify which data fields the library actually displays before filtering. [L1252.025]
  • It does not show which countries an advertiser targets. Use other tools or store and ad data to find target countries. [L1176.012]
  • Each ad card shows a Library ID, the platforms it runs on, the page name, the date it started, its running time and a line such as "3 ads use this creative and text". [L1474.013, L1474.018, L1249.019]

Basic search procedure

  1. Open facebook.com/ads/library (or search "Facebook Ads Library"). [L0204.010]
  2. Select "All ads" from the dropdown menu. [L0204.010]
  3. Search for the competitor brand name or page name. [L0204.010]
  4. If the page name does not appear in the dropdown, paste the competitor website URL instead. [L0204.010]
  5. Click "View ads" to display all active or recent competitor ads. [L0204.010]
  6. Record ad copy and creative patterns that repeat across 2 or more campaigns, since repetition indicates performance. [L0204.010, L0204.011]
  7. Note the headline, primary text structure and opening hooks the competitor uses consistently. [L0204.010]

Filter settings

  • Set Active status to Active ads so only currently running campaigns appear. [L1249.018]
  • Set the Language filter to English (US) so results come from the English-speaking market you target. [L1249.018]
  • Set the country to United States and the category to All ads when researching a US competitor. [L0855.180]
  • The Active status filter is set to Active by default. Ads marked Inactive appear with that label. Set the filter to see only running ads, then read the Running Xd label on each card. [L1474.019]
  • Standard search settings: Active status Active; Ad type All ads; Country ALL; Media type All. Enter the product or niche keyword in the search field. [L1474.014]
  • Use Show EU data for EU transparency information on an ad. Some ads carry a note that they are not active for some audiences because they did not meet certain requirements. [L1474.017]
  • Use Save on a keyword search to return to the same list of competitor stores later. [L1249.020]

Keyword searches for products

  • Enter one keyword at a time. Multiple keywords joined together are not supported. [L0678.018, L0678.019]
  • Search word variations, such as singular and plural forms and synonyms (for example shoe, shoes, sneaker, sneakers), since different ads use different wording. [L0678.018, L0678.019]
  • Filter by active ads, then review the results to find products being advertised. [L0678.019]
  • A keyword search counts every ad that matches the word. The result number is broad and is not the exact count of one product's ads. [L0707.004]

Verifying a tool's numbers

  1. Note the product's active ad count in the research tool. [L1185.005]
  2. Open the same product in the Facebook Ads Library. [L1185.005]
  3. Confirm that the listed ads are marked active and that the number matches. [L1185.005]
  4. Check which countries the ads run in. [L1185.005]
  5. Check the start date of the newest ad to confirm the product is still being tested or scaled. [L1185.005]

Verifying demand for a product

  1. Open the Meta Ad Library and search the product keyword or the brand's page name. [L1479.011]
  2. Set Active status to Active ads and the country to United States. [L1479.011]
  3. Check the Platforms icons to see where each ad runs. [L1479.011]
  4. Note the Started running on date and the Library ID of each ad. Ads running for weeks or months are the strongest signal. [L1479.011]
  5. Count the brand's active ads, then scroll to the bottom to see older tests. [L1479.011]
  6. Open See ad details to read the full copy, the creative and the landing page link. [L1479.011]

Winning Hunter filters for the Meta Ad Library

  • Winning Hunter's Meta Ad Library is the platform's main feature, labelled Meta Ads Library (recommended). Unlike ad spy tools that rank by likes and comments, it shows the ads themselves, so use it for ad research. [L0892.022]
  • Filters, in order: Countries, Language, Video length (0s to 3600s), Niche, Media type, Page type, Apps, Themes, Reach (Views), Ad copy length (characters, 0 to 50000), Low Impressions, Days Running (0 to 365), Product Price Range (0 to 5000), Store Traffic (Monthly Visits), Ad creation date, Page Active Ads (0 to 10000), Last seen date, Product/Collection Creation Date and Page creation date. [L0892.023]
  • Further options: Sort By (Updated or Last Seen), Dropship Ads, Advertorials, Native ads, Quiz Funnels, Supplements, Top Branded, EU adspend, Save current filters and Reset. Use Save current filters for searches you run often. [L0892.024]
  • Themes and Apps narrow pages by Shopify theme (for example Dawn, Impulse or Impact) and by installed apps. Checkout integration filters such as Checkout Champ or Lasso/Whop checkout find stores that run a particular checkout provider. [L0892.036]
  • A brand page has source switches for Meta Ads, Ad Library and Facebook Post Ads, plus a Global Ads or EU/UK Only toggle. Use EU/UK Only when the planned market is Europe or the UK, so regional ads are not mixed with global ones. [L0892.038]

Filter minimums

Days running at least 7 days Removes short tests [L0374.038]
Page active ads at least 200 Shows pages with scale [L0374.038]
Ad creation date within the last 90 days Shows ads still working [L0374.038]

Finding newly launched Shopify pages

  1. Open the Page creation date filter and set the range to the last 30 days. [L0892.025]
  2. Add the Shopify platform and the checkout filters you need, such as Apps or Themes. [L0892.025]
  3. Sort by Last Seen and review the new pages that run ads. [L0892.025]

Reading ad cards and detail views

  • An ad card shows EST. SPEND, REACH, number of countries, active ads for the page and Est. Product Revenue. [L0892.029]
  • The ad detail view adds running days, duplicates, format, gender, age range, first seen, last seen, landing page and estimated monthly traffic. [L0892.029]
  • Quick actions: Find Competitors with, Visit Store, Page Ad Library, Download Video, Track Store, Fulfill with Ecomm..., Download Thumbnail and Transcribe ad with.... They move you from an ad to the store, its library page or its files in one step. [L0892.030]

Tracking a competitor brand

Winning Hunter brand tracking procedure

  1. Copy the brand name or page name from the competitor's ad. [L0772.027]
  2. Open Winning Hunter Brands, search for the name and click Follow. [L0772.027]
  3. On the brand's page, use the View Page or Ad Library link to open the brand's Meta Ad Library page and note the total results (130 in the example). [L0772.027]
  4. Return to Brands and paste the Meta Ad Library link into the add-brand field so the tracker can gather the brand's live ads. [L0772.027]
  5. Wait for the data to fill in, then review the brand's top hooks, angles and landing pages. [L0772.027]

Brand tracker details

  • The Brands list shows each tracked brand's media mix as counts and percentages for video and image ads. It shows at a glance whether a competitor relies on video or static creatives. [L0772.042]
  • On a brand's detail page, the Global Ads and EU/UK Only switch limits the data to that scope. Visit Page opens the store page, Save saves the brand, and Ad Library opens its Meta Ad Library page. A Growth indicator shows whether the number of launched ads is Stable or changing. [L0772.043]
  • Filter to active ads and read each ad's start date to judge how long it has run. A long run of active ads signals a working creative. [L0772.032]
  • The Meta Ad Library, Pinterest Ads library and TikTok Ads library each show a competitor's active ads. Open the brand in Brand Tracker for its full ad set. [L1164.030]
  • The Top Ads view ranks ads by ad rank with up to 10 placements. You can sort by Top Ad rank, Most Reach or Longest running. Rank #1 is the best, so a lower rank number means stronger performance. [L1164.031]
  • On product cards, the number of active ads and the number of countries show how heavily a product is tested. A product with hundreds of active ads across dozens of countries has been tested far more than one with a handful, so start from the most heavily tested products. [L1164.053]

Count discrepancies

  • The active-ad count in Winning Hunter can be lower than the total results on a Meta Ad Library page for the same advertiser. In the example, the library showed 130 results while Winning Hunter counted 124 active ads. Check both numbers when judging a competitor's scale. [L0772.046]
  • A brand with around 130 active ads has likely validated its creatives and is a good reference. Use the ad count as a quick quality check. [L0772.033]

Competitor research procedure

  1. Open the competitor's page in the Meta Ad Library. [L0524.034]
  2. Review the active ads and filter for video ads to see the dominant format. [L0524.034]
  3. Note each ad's hook, the problem it names, the proof it uses and the offer. [L0524.034]
  4. Group the ads by angle, such as education, identity, social proof or offer. [L0524.034]
  5. Save the strongest ads to a swipe board for reference. [L0524.034]
  • Use the Ad Library to see which ads competitors run, how long they have run and where the ads send people, such as an advertorial or a product page. [L1131.020]
  • Look at ad copy and video or image together when judging a winner. The Ad Library shows both the product and the winning creative, so it can reveal which hook or angle to copy with the product. [L0638.021]
  • Set a list of 15 to 25 potential products from the Ad Library, then rank them by your defined product criteria. [L0638.022]
  • Test products one by one. Some are tested by only one or two sellers and are not yet covered by spy tools. [L0638.022]
  • Set a starting age range with an ad spy tool:
    1. Look up the product in the ad spy tool. [L0678.043]
    2. Note the age range that competing advertisers target. [L0678.043]
    3. Use that range only as a reference point for your own test. [L0678.043]
    4. Keep the test broad, for example 18 to 65+, and narrow the age range only after sales data shows which group performs best. [L0678.043]

Signals of a winner

Run time

Run time Reading Source
Under two weeks Weaker signal of success [L0639.026]
7 days or more Filter floor that removes short tests [L0374.038]
One month or more Likely profitable and worth studying [L0639.026]
Weeks or months Stronger signal than a new ad; use as layout reference [L0794.028, L1479.012]
Many months Strongest signal; study these first [L1164.033]
  • An ad that keeps running for weeks or months is likely profitable, because advertisers do not keep paying for ads that lose money. Use run length as proof that the creative and offer work. [L1479.012]
  • Long-running ads show which creatives the advertiser keeps. Check run dates and active ad counts on each ad card. [L1164.033]

Duplicates and creative count

The thresholds below come from different lessons and describe different things. Apply each where it fits; they are not interchangeable.

Count of ads or ad sets with the same creative and text Reading Source
Same copy in 2 or more campaigns at once Copy is performing; the advertiser would not keep investing otherwise [L0204.011]
10 or more ads Likely in the scaling phase; product probably works [L0638.019]
10 to 15 ads by one brand Creative is usually being scaled [L1382.051]
13 or more ad sets with identical text Clear winner; treat as proof rather than a guess [L0638.020]
15 or more ads Winning creative; sellers do not repeat weak creatives this often [L0638.019]
  • The Ad Library count reflects how many ad sets use a creative, because one ad set cannot run the same ad twice. The campaign structure is campaign, then ad set, then ad. The count of ad sets is the signal to read. [L0638.018]
  • Sellers usually scale a single creative only after the product has become profitable. Many identical ads from one advertiser point to a proven winner. [L0895.029]
  • Duplicates on an ad show how many other advertisers use the same creative. Several duplicates mean the product or angle is already being copied. [L0892.028]
  • A large number of active ad variations for the same product, and the same video running repeatedly over a long period, is a strong sign of profit. Repeated runs show the advertiser keeps spending because it returns money. [L0707.005]

Active ad counts and scaling

  • Track how many active ads a competitor runs over several days. A jump, for example from about 50 to about 100 active ads in one day, signals many new launches and scaling. A competitor usually scales only a profitable product, so many new ads on one product is a strong signal. [L0335.007]
  • Count active ads per single creative, not the total on the page. A page can show around 500 active ads overall while one creative runs only about 31. Only the per-creative count shows real scaling. [L1177.055]
  • A competitor who launches new ads every day is actively scaling, which is a stronger signal than a static number. Check the start dates of the newest ads to see whether launches continue. [L1177.056]
  • A competitor starting many new ads in a short time often signals a funnel being tested. [L1131.020]
  • In the 2025 example, a brand with about 71 active ads that started in early July was still testing. The main brand behind the same product had about 650 active ads and was clearly scaling. [L1479.013]
  • Large page counts are a filter tool: 200 active ads minimum for a page to show scale, 80 minimum to find large established competitors. [L0374.038, L0892.026]

Page age

  1. Search the page name, or the store URL if the name does not turn up the page. [L0335.006]
  2. Open one of the page's ads, then go to the About section to read the creation date. [L0335.006]
  3. Read the page creation date in the About section, then open Page transparency on the page to see its ad activity. [L1177.054]
  • A page created within the last few months that already runs many ads signals a new competitor testing a trend. An old page with a warmed pixel and large purchase history gets better delivery and is harder to beat. [L0335.006]
  • An older page is a stronger sign of success, but a new page with well-performing ads can still be worth testing. [L1176.014]
  • A competitor whose page was created recently has not yet built a large purchaser audience in its pixel, so a new entrant starts on roughly equal footing. This is a useful plus but not a mandatory requirement. [L1183.019]

Still running

To check whether an ad is still running:

  1. Open the ad in the Ad Library. [L0335.017]
  2. Set the comments sort to Newest. [L0335.017]
  3. Look for comments from the last 24 to 48 hours. If comments still arrive, the ad is probably running and likely profitable. [L0335.017]
  • Check that a competitor's ad is active before deciding to test its product. [L1176.013]
  • To check a competitor's ad activity, open facebook.com/ads/library, select All, then All ads, and search for the page name. The results show that page's active ads. [L1177.053]
  • The Facebook Ad Library lists a competitor's active ads and run dates, which shows how a store is scaling on Facebook. [L0871.071]
  • For a product, check three things before deciding whether to test it: the active ad count, the date the ads started and the countries they run in. [L1171.051]
  • The Facebook Ad Library is the basis for counting how many ads a competitor runs for one product. [L1174.024]

Engagement

  • Shares are the most useful engagement signal on a competitor's ad. Likes and comments can be bought cheaply, while shares are hard to fake. A product with a high share count is stronger proof of concept than one with many likes alone. [L0335.004]
  • Many ads have comments turned off, so few comments or likes do not necessarily mean weak demand. Check sales data on AliExpress or other sources before judging a product by ad engagement. [L0706.023]

Spend and reach estimates

  • Winning Hunter ad cards show an estimated spend and estimated reach for each ad. Read the two together to see which ads a competitor keeps funding, but treat both as estimates, not the advertiser's real spend. [L1164.052]

Market signals

  • Competitor videos with sold-out messages, strong urgency or call-to-action text often indicate paid ads. Check the store page for ad-style elements to confirm. [L0352.052]
  • When many competing stores run ads for the same product at once, do not assume the market is closed. A market can support several stores; only giant brands such as Apple or Amazon are real exceptions. [L1176.018]
  • Political advertisers cannot switch ads off freely, so an active political ad does not prove profitability. Use active status and run duration as a profit signal only for ordinary, non-political ads. [L0639.045]

Copying cautions

  • Copying a competitor's ad exactly does not reproduce its results, because their pixel data, audience pocket and timing differ from yours. The variables you control are your creative and your landing page. [L0639.033]
  • Competitors who seem to succeed with simple drop-shipping videos often have an older pixel with accumulated data, or they launched when competition for the product was low. Running the same video without that data or timing usually produces nothing. [L0639.034]
  • Copying competitor ads and stores is a valid starting point for beginners but not a guaranteed success. If copying fails, change the angle (different problem, audience or context) rather than repeating the same creative. [L0640.035]
  • If a copied ad or store does not sell, possible causes include the competitor having a longer-running pixel with more data, entering the market earlier, or an audience saturated with the product. The response is to test a new angle, not repeat the same copy. [L0640.052]
  • Replicating winning creatives is a useful shortcut, and the winner can be adapted with a local voice-over or local captions for a new market. [L1382.051]
  • Launch new concepts with the competitor's ad only as a shortcut, then move on to your own content. [L1345.083]

Ripping creatives

Ripping images from long-running ads

  1. Open the Meta Ad Library and search for the competitor page with the most active ads. [L0794.027]
  2. Set Active status to Active ads. [L0794.027]
  3. Set Media type to Images and memes. [L0794.027]
  4. Set the Impressions by date range longer if older ads should be included, then Apply. [L0794.027]
  5. Sort by total impressions. [L0794.027]
  6. Open each ad and note its Started running on date. [L0794.027]
  7. Right-click the image and save it to the desktop, or inspect the page and copy the image address when saving is not possible. [L0794.027]

Video ripping

  • Upload downloaded videos directly to Meta Ads Manager without any editing. The same clean files can also be uploaded to TikTok Ads. [L1252.012]
  • The time from ripping a video to launching the ad is about one to two hours. This speed is a main reason to use ripped creatives for early tests. [L1252.015]
  • Facebook is stricter than TikTok about reused video. Replace copied videos with your own content as soon as a concept is proven, and use copied material only for short tests of one to two days. [L1345.083]

Choosing which layouts to copy

  • Large established brands can run plain image ads and still sell, because brand recognition, customer lifetime value, referrals and organic demand do much of the work. A new store cannot rely on that. It should copy the structure of ads that perform, not the simplicity of big-brand ads. [L0794.029]
  • Use long-running ads as layout references when building new creatives. [L0794.028]

Choosing products from the research

  1. Build a list of 15 to 25 potential products from the Ad Library. [L0638.022]
  2. Rank the products by your defined product criteria. [L0638.022]
  3. Check run length, active ad counts, creative counts and countries for each product using the signals above. [L0638.019, L0638.020, L1164.053, L0374.038]
  4. Test the products one by one. [L0638.022]
  5. Use the Ad Library's product, creative and copy data together when choosing the hook for each test. [L0638.021]
