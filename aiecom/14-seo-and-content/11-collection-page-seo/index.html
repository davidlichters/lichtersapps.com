14.11 Collection Page SEO

Order of Work for Collection Pages

Collection pages are the most important pages for e-commerce SEO and should be treated as money pages. More category pages rank than product pages, and category pages usually convert better than individual product pages. [L1389.010]

Collection pages can rank organically in Google for free, so they deserve the same SEO work as product pages. Their images, descriptions, URLs and meta tags should be set up early, because collections are usually fewer than products and the work is quick. [L0368.001]

Shopify collections have no description by default, so adding one gives shoppers and search engines extra information from the start. This is a fast gain for stores that have only a few collections. [L0368.021]

Collection pages can rank for specific phrases, such as custom concrete countertops. Adding a custom section or category to a store can bring in buyers who already want to spend more. (Older advice, 2021.) [L0801.087]

Each collection must go through the same sequence. Completing it for only some collections leaves the rest without the benefit. [L0368.019]

  1. Image optimization
  2. Descriptions with keywords
  3. Template layout
  4. URL and handle
  5. SEO title and meta description
  6. JSON-LD [L0368.019]

Indexing and Site Structure

Build one collection page per category and make it the content-rich, SEO-optimized version. Do not build two versions with and without content, because one strong page concentrates ranking signals. [L0667.033]

Before publishing a collection page, decide whether it should be indexed and where it fits in the site navigation. If it does not fit into the site structure, set it to noindex. (Older advice, 2021-22.) [L0367.001]

Collection pages built only to receive paid traffic are often orphan pages with no internal links. Since such a page is not meant to rank organically, noindexing it avoids diluting the SEO value of the rest of the site. (Older advice, 2021-22.) [L0367.002]

If a collection page should rank organically, it must be linked into the site structure, and it needs the same on-page optimization as any other indexed page. (Older advice, 2021-22.) [L0367.003]

Apply these collection page optimizations to new pages. Do not rewrite collection pages that already rank well. (Older advice, 2021-22.) [L0367.020]

Collection Names and Search Intent

Collection pages target searches for a product type rather than a specific product, which is middle-of-funnel search intent. The focus keyword should match that intent. (Older advice, 2021-22.) [L0367.004]

Build category collection pages with buying-intent names, such as a generic collection for the product type and a for-sale collection. Turn each collection into a landing page so it ranks, and place your product at the top as the recommended choice. (Older advice, 2021-22.) [L0768.007]

Keyword Research for Collections

To set the collection name and keyword, follow this procedure. [L0251.035]

  1. Decide on your collection name based on the exact product type (e.g., 'Bamboo Standup Desks').
  2. Go to Google and type your collection keyword.
  3. Review the top organic search results to understand content expectations.
  4. Scroll to the bottom of Google results and check 'Related searches' for long-tail keyword variations.
  5. Incorporate these related keywords into your collection description and metadata. [L0251.035]

The keyword list comes from prior keyword research. The main keyword matches the collection name, and related keywords are added to it. [L0368.004]

To find related keywords for a collection, search the main keyword with modifiers such as 'best' and 'for beginners' (for example 'best hybrid surfboards' and 'hybrid surfboards for beginners') and note the variants that come up. Use these variants in the collection description and meta tags next to the main keyword. [L0368.020]

Images and Media

Reduce image file size and dimensions on collection pages to improve page load speed. This benefits both search engine rankings and user experience. [L0177.001, L0178.001]

In a demo store, optimizing four collection images cut the total from 3.6 MB to just over 1000 KB, saving about 2.6 MB. Image compression is worth doing for collection pages, but a fast theme and few apps matter more for page speed. [L0368.003]

Compress any additional images on the collection page as far as possible. Give each one a unique file name and unique alt text. (Older advice, 2021-22.) [L0367.009]

Give every image in the description area a unique file name and unique alt text. (Older advice, 2021-22.) [L0367.005]

Videos in the description area should use a thin load, which keeps the page load time low. (Older advice, 2021-22.) [L0367.021]

Descriptions and Content Length

Add descriptive text to collection pages as an SEO element. [L0178.002]

Collection descriptions should contain at least 300 unique words. (Older advice, 2021-22.) [L0367.014]

Each H3 section should carry about 100 words of copy. A collection page built on the full wireframe therefore needs several hundred words of unique text, not a few lines. [L0883.003]

AI-generated section copy often comes out at around 30 words, roughly a third of the target length. Expand each section to about 100 words, because shorter copy does not carry enough relevance to rank. [L0883.004]

Collection pages often have little meaningful content, so search engines can classify them as thin content. On a large site with many such pages, this can dilute overall SEO efforts, keep pages from being indexed, or leave indexed pages underperforming. (Older advice, 2021-22.) [L0367.015]

Thin collection pages made of a title, a product grid and only a few lines of text rarely rank. Only very large, well-known brands can rank such pages on brand authority alone, so smaller stores must add relevant on-page copy. [L0883.001]

Add some content to collection pages so they are not considered thin or duplicate content. Only a small number of collection pages should be made cornerstone pages, because if every page is treated as important, none stands out. (Older advice, 2021-22.) [L1465.037]

The fear that adding content to a collection page makes products harder to find is not supported by evidence, as long as the content is genuinely valuable to the user. (Older advice, 2021-22.) [L0367.016]

Valuable collection content helps the buyer decide which product in the category fits them. It can compare brands, explain price ranges and configurations, and show which option suits the buyer's usage conditions and experience level. (Older advice, 2021-22.) [L0367.017]

A collection page for one equipment category could explain which brands suit beginners versus advanced users, outline the price tiers, and describe which configuration works best for a given terrain or usage style. This guidance lets visitors reach the right product faster and gives search engines clear context about the page. (Older advice, 2021-22.) [L0367.018]

Helpful collection content gives search engines a clear signal of what the page is about. If competitors do not provide similar content for the same category, a page with it may be able to outrank them. (Older advice, 2021-22.) [L0367.019]

Keyword Placement and Count

The focus keyword should appear 3 to 5 times in the collection description. [L0177.002, L0178.003, L0368.004]

The focus keyword should appear 5 times on the whole page. Headings, body text, image file names, image alt text and links to products on the page all count toward this. Collection pages often reach the count easily because product titles listed on the page can contain the keyword. (Older advice, 2021-22.) [L0367.012]

The focus keyword must appear at least once in the first 100 words of plain text on the collection page. Plain text on the page is recommended. (Older advice, 2021-22.) [L0367.011]

Layout and Copy

Use this layout from top to bottom. [L0883.002]

  1. H1 = the exact target keyword, with no variation.
  2. Short description directly under the H1, about one to two sentences stating what the products do, placed above the product grid.
  3. Product grid.
  4. Descriptive copy below the grid, opening with an H2 that contains the target keyword in some form (an inverse phrasing such as 'Running Shorts for Men' for 'Men's Running Shorts' is acceptable).
  5. Three H3 headings, each covering one unique selling point.
  6. About 100 words of copy under each H3.
  7. 3 to 5 internal links in total, acting as a mini navigation. [L0883.002]

Collection titles should be tagged as H1 and serve as the page title. Place the focus keyword at the front of the title where possible. (Older advice, 2021-22.) [L0367.006]

Headings in the collection description area should be H2 tags and must not carry a link. (Older advice, 2021-22.) [L0367.010]

Collection pages must display visible breadcrumb navigation. (Older advice, 2021-22.) [L0367.007]

The collection title must be visible above the fold on mobile, since it is the main signal that tells visitors they have reached a page matching their search. (Older advice, 2021-22.) [L0367.008]

Collection page content should use 18pt font, short sentences and short paragraphs. (Older advice, 2021-22.) [L0367.013]

URLs and Handles

Collection URLs (the handle in Shopify's search engine listing) should match the collection name with dashes between words, for example /hybrid-surfboards, not run together. If an existing handle does not match the collection name, change it to match. [L0368.011]

The page URL should contain the focus keyword and be short. (Older advice, 2021-22.) [L0367.022]

Descriptive URLs that include the target keyword improve click-through rate from search results. [L0177.003]

Meta Title and Meta Description

To set the SEO title, meta description and URL in Shopify, use this setting. [L0368.012]

In Shopify admin, open the collection, scroll to Search engine listing and click Edit. The fields are SEO title, SEO description and Handle (the URL). Use these fields to set the title, meta description and URL. [L0368.012]

SEO title formula for collections: main keyword + qualifying phrase for sale + a shipping benefit, e.g. [Main keyword] for Sale | Free and Fast Shipping. Adding these qualifiers turns the title into an ad-like snippet that gets more clicks. Example in the same pattern: Standing Desks for Sale | Free Delivery in 3 Days. Example in the same pattern: Ergonomic Office Chairs for Sale | Free Returns and Fast Shipping. [L0368.013]

The page meta title should be unique, include the focus keyword, and be kept short. (Older advice, 2021-22.) [L0367.023]

The page meta description should be unique and include the focus keyword. (Older advice, 2021-22.) [L0367.024]

Create custom meta descriptions for each collection page instead of using defaults to maximize click-through rate from search results. [L0177.004]

Rich snippets displayed on collection pages in search results increase click-through rate by showing additional product or collection information. [L0177.005]

Improve click-through rates on collection pages from search results by optimizing page URLs, writing persuasive meta descriptions, and implementing rich snippets that display additional information in search results. [L0178.004]

A generic meta description or title gives Google no reason to rank the page or show it to searchers. Adding the category, shipping and trust signals makes the search listing more attractive and raises click-through rate, which is the main reason to improve listings. [L0368.015]

The page title and meta description in a collection's search engine listing are what Google displays in search results for the keywords on your site. They can be left empty during the initial setup and filled in during the SEO phase. [L1312.012]

AI-generated meta tags are a starting point only. Review them and edit them before publishing, since a generic listing is worse than no listing at all. [L0368.017]

Filling in unique meta descriptions for all collections as a box-checking task will not bring visitors this week. Duplicate meta descriptions do not penalize pages, so this work should wait behind changes that affect clicks and rankings. [L1269.024]

Reusing the homepage social share description (OG description) across collections creates duplicate metadata. Give key collections their own descriptions as part of the targeted rewrite work, not as a blanket task. [L1269.027]

Prompts and Templates for Collection Copy

Use this prompt to draft a collection description. [L0177.007]

Create a product collection description optimized for search engines. The copy should target [COLLECTION NAME] and strategically incorporate these search terms: [KEYWORD 1, KEYWORD 2, KEYWORD 3].

[L0177.007]

Use this prompt to draft the description from your keyword research. [L0368.005]

Act as an SEO specialist and draft an e-commerce collection description for [collection name], working in these keywords: [keyword 1], [keyword 2], [keyword 3], [keyword 4]. Take the primary keyword as the collection's name and swap the keyword placeholders for the related keyword list from your research. Review the result, keep the parts that work, and reword whatever feels stiff so it reads naturally and reflects what the collection really contains instead of using it as-is.

[L0368.005]

Use this template for the opening line of a collection description. [L0177.006]

Acquire [Collection Name] from [Brand] without delay. Complimentary shipping and protection apply to your entire [Products] order. Purchase immediately to unlock a complimentary [bonus] offer.

[L0177.006]

Use this template for a meta description draft. [L0368.014]

Buy [collection name] now from [brand] and enjoy free shipping plus insurance on every one of our [related keywords]. Place your order today to get a free bonus. (Optional: delete the bonus line if no bonus applies.) Fill the placeholders with the collection name, brand name and related keywords from your research, and use the result as a draft to revise rather than publishing it word for word.

[L0368.014]

Use this prompt to write the full collection page copy in the wireframe layout. [L0883.015]

You are an ecommerce SEO copywriter. Write search-optimized collection page copy for the brand [BRAND NAME], based only on the product catalog and brand facts below: [PASTE PRODUCT CATALOG AND BRAND FACTS]. Target keyword: [TARGET KEYWORD].

Follow this exact structure:
- H1: the target keyword, unchanged.
- Short description under the H1, 1 to 2 sentences, placed above the product grid.
- [PRODUCT GRID] placeholder.
- H2 that contains the target keyword or a natural inverse of it.
- Three H3 headings, each naming one unique selling point.
- About 100 words of copy under each H3.
- 3 to 5 internal links to these URLs: [LIST OF COLLECTION AND BLOG URLS].

Before writing, search Google US for the target keyword with the Firecrawl MCP, analyze the top 10 results, and list the entities they cover (related terms, features, use cases, activities). Work the relevant entities into the copy where they fit naturally.

Style rules: write in active voice, do not use em dashes, remove unnecessary fluff, and avoid these words: [BLACKLIST OF AI-TYPICAL WORDS].

Facts: use only facts from the catalog above. If a size, material, claim or certification is missing, write [PLACEHOLDER: missing fact] instead of inventing it.

Output: the copy in the order above, each section labeled with its heading level and word count, followed by a list of the internal links used and any section under 90 words.

[L0883.015]

To have AI write a collection page in your exact layout, attach a screenshot of the wireframe (H1, product grid, H2, three H3s with copy) to the prompt and tell the model to base the page on it. Submitting the image gives the model the structure directly, which works better than describing the layout in words. [L0883.030]

Before running a collection copy prompt, state what each H3 section must cover, such as inseam lengths, liner type, fabric, pockets or other real product features, and the roughly 100-word length per section. Without these details the model fills the sections with generic claims that need heavy rewriting. [L0883.031]

On-Page Checklist

Run the full checklist for every new collection page, in this order. (Older advice, 2021-22.) [L0367.005]

  1. Decide whether the page should be indexed and where it fits in the site structure; if it does not fit, set it to noindex. [L0367.001]
  2. Choose a focus keyword and its relevant synonyms. [L0367.004]
  3. Show visible breadcrumb navigation on the page. [L0367.007]
  4. Tag the collection title as H1; it is also the page title. Place the focus keyword at the front of the title where possible. [L0367.006]
  5. Make sure the collection title is visible above the fold on mobile. [L0367.008]
  6. Compress any additional images as far as possible. [L0367.009]
  7. Make headings in the description area H2 and do not attach a link to them. [L0367.010]
  8. Use the focus keyword at least once in the first 100 words of plain text. [L0367.011]
  9. Use the focus keyword 5 times on the page in total. [L0367.012]
  10. Format collection page content in 18pt font with short sentences and short paragraphs. [L0367.013]
  11. Write at least 300 unique words for the collection description. [L0367.014]
  12. Give every image in the description area a unique file name and unique alt text. [L0367.009]
  13. Give videos in the description area a thin load. [L0367.021]
  14. Make the page URL contain the focus keyword and keep it short. [L0367.022]
  15. Make the meta title unique and include the focus keyword. [L0367.023]
  16. Make the meta description unique and include the focus keyword. [L0367.024]

Apply the checklist to every collection page as follows. (Older advice, 2021-22.) [L0367.025]

  1. Run through the full collection page checklist every time a new collection page is created.
  2. Tick off each item before the page goes live.
  3. If someone else creates collection pages for you, give them the checklist and check that every item is ticked on each page.
  4. If a page skips checklist items, ask why and have it corrected. [L0367.025]

Where Sources Differ

Keyword count: the description should carry 3 to 5 uses of the focus keyword [L0177.002, L0178.003, L0368.004], while the whole page should carry 5 uses [L0367.012] (older, 2021-22). Both apply, because they measure different things: the description and the full page.

H1 wording: the H1 must be the exact target keyword with no variation [L0883.002], while the focus keyword should sit at the front of the title where possible [L0367.006] (older, 2021-22). Both fit when the title equals the keyword itself.

Meta descriptions: write unique ones for each collection [L0177.004, L0367.024] (older, 2021-22). Waiting is advised for filling them in across all collections as a box-checking task [L1269.024]. Apply the unique-description rule to new pages [L0367.020] (older, 2021-22) and to key collections in the targeted rewrite [L1269.027]. The search engine listing fields can stay empty during initial setup and be filled in during the SEO phase [L1312.012].

Image compression: compress images as a priority [L0177.001, L0178.001]. A fast theme and few apps matter more for page speed than compression alone [L0368.003].

Word count: at least 300 unique words for the description (older, 2021-22) [L0367.014] are consistent with about 100 words per H3 across three H3s, which gives several hundred words [L0883.003].
