16.5 Building Google audiences (Google Ads and GA4)

Account structure and setup order

  • Google Ads and GA4 must be linked before remarketing audiences can be built from website data. Setup order: (1) link Google Ads to Google Analytics, (2) set up data settings in Google Analytics, (3) update data retention in Google Analytics, (4) create remarketing audiences. [L0165.001]
  • Create remarketing audiences early, even before any remarketing campaign is running, because they keep filling with users over time. An audience created later starts empty. [L1520.008]
  • Google Ads Audience manager builds remarketing audiences from site visitors, app users, YouTube users and customer lists, and shows where each audience can be applied. Google also auto-creates some audiences there. [L1242.008]

Google Ads: data segments in Audience manager

Concepts

  • A data segment is a group of people who completed an action on the website, such as visiting a page or buying. Saving them as segments lets you target each group separately later. [L0420.006]
  • A newly created audience does not show its size immediately. It can take several hours to populate. Only then does Google Ads show how many people it contains and can be targeted with remarketing ads. [L0420.005]
  • The segment name is only for the account owner to recognise the audience later. It does not need to be perfect; choose a clear name that shows what the segment contains. [L0420.012]

Naming

  • Name the website visitor segment so it identifies the store, the audience and the time window, for example "Store name, visitors 30 days". [L0420.003, L0420.013]
  • Name the buyer segment in the same pattern, for example "Store name, purchase 30 days". [L0420.013]
  • Use names that show the lookback window and the purpose, for example "540 day retargeting list for search". [L1242.005]

Step-by-step: create the two data segments

  1. Sign in to Google Ads. [L0420.013]
  2. Open Tools from the left-hand menu. [L0420.013]
  3. Select Shared library, then Audience manager. If Shared library is collapsed, expand it with the caret beside it. [L0420.013]
  4. Under Data segments, press the plus icon to start a new remarketing list. [L0420.002, L0420.013]
  5. Choose Website visitors. [L0420.002, L0420.013]
  6. Type a name for the visitor audience, such as "Store name, visitors 30 days". [L0420.013]
  7. Leave Segment members set to anyone who viewed a webpage in the last 30 days. [L0420.003, L0420.013]
  8. Keep the pre-fill option switched on, which adds people who visited in the past 30 days, so the segment starts with existing visitors. [L0420.004, L0420.013]
  9. Click Create segment and allow several hours for the audience to fill. [L0420.004, L0420.005, L0420.013]
  10. Press the plus icon again and select Website visitors. [L0420.013]
  11. Name the buyer audience, for example "Store name, purchase 30 days". [L0420.013]
  12. Change Segment members from Visitors of webpages to Visitors of a page with specific tags. [L0420.007, L0420.013]
  13. Search for Google Shopping and confirm that add to cart, begin checkout and purchase are all listed. These events are installed through the Google Shopping feed app. [L0420.007, L0420.013]
  14. Select the purchase event labelled "purchase in category". [L0420.013]
  15. Set the membership duration to 30 days. [L0420.010, L0420.013]
  16. Click Create segment. [L0420.010, L0420.013]
  17. Check that both data segments appear in the list. [L0420.013]

Finding the audience

  • To find the remarketing audience under Audience segments, search for the customer exclusion audience name, then scroll to the bottom of the list. The three most recently created audiences appear there, and the 30-day website visitor audience is the middle one of the three. [L0733.026]

Google Ads: website visitor audiences by URL rule

Create the audience

  1. Open Audience manager by typing "audience manager" into the search bar at the top right of Google Ads. [L1242.002]
  2. The Remarketing tab opens by default. Click the plus sign. [L1242.002, L1242.003]
  3. Select Website visitors. The other options are app users, YouTube users and customer list. [L1242.002]
  4. Enter an audience name. [L1242.002]
  5. Choose a visitor rule: [L1242.002]
Visitor rule Restriction options
Visitors of a page URL match type only
Visitors of a page who also visited another page Can be restricted to specific dates or tags
Visitors of a page who did not visit another page Can be restricted to specific dates or tags
  1. For "Visitors of a page", pick the URL match type and enter the URL. The options are Contains, Equals, Starts with and Does not contain. [L1242.002, L1242.003]
  2. Turn on the option to include people from the previous 30 days. [L1242.002, L1242.003]
  3. Set the membership duration to 540 days. [L1242.002, L1242.003]
  4. Add a description. Copying the audience name works. [L1242.002]
  5. Create the audience. [L1242.002]

Rule warning

  • A single slash (/) as the URL rule matches all visitors to the site. Use it only when a broad audience is intended, and use specific URLs for narrower audiences. [L1242.004]

GA4: audiences for non-purchasers and exclusions

Concepts

  • GA4 creates two default audiences, All users and Purchasers. They can stay in place and do not need to be deleted to create new audiences. [L1520.009]
  • Audiences in Google Analytics are segments of website users defined by past behaviour, such as visitors in the last 30 days or buyers in the last 7 days. They are created and managed in GA4 and later used to show remarketing ads. [L1520.007]
  • Include and exclude settings are now combined in one GA4 audience. No separate exclusion setting is needed: edit the audience and set include (website visitors) and exclude (customers) together. [L0274.027]

Step-by-step: create the three non-purchaser audiences

  1. Open Audiences from the left-hand navigation, or via Admin (gear icon, bottom left) and then Audiences in the property column. [L1520.011]
  2. Click the blue New audience button. [L1520.011]
  3. Choose Non-purchasers (users that have not made a purchase) as the audience basis. [L1520.011]
  4. Rename the audience, for example Website visitors exclude customers 7 days. The default name is "Non-purchasers". [L1520.011]
  5. Set the Membership duration to 7 days. The form defaults to 30 days. [L1520.011]
  6. Review the exclusions, which include anyone who has made a purchase, and the estimated audience size. [L1520.011]
  7. Click Save. [L1520.011]
  8. Click New audience again, choose Non-purchasers, rename it Website visitors exclude customers 30 days and keep the Membership duration at 30 days. Click Save. [L1520.011]
  9. Click New audience again, choose Non-purchasers, rename it Website visitors exclude customers 180 days and change the Membership duration from 30 to 180 days. Click Save. [L1520.011]

Reference: names and durations

Audience name Membership duration
Website visitors exclude customers 7 days 7 days
Website visitors exclude customers 30 days 30 days
Website visitors exclude customers 180 days 180 days

[L1520.012]

Form layout

  • In the GA4 new audience form, the Membership duration field, the audience name field and the Save button are all at the top of the form. [L1520.017]
  • For each of the three non-purchaser audiences, only the name and the Membership duration change. All other settings stay as they are. [L1520.017]

How membership duration works (7-day example)

  • A user who visited without buying stays in the audience for 7 days. They drop out on day 8 if they do not return. [L1520.013]
  • A new visit restarts the 7-day count. [L1520.013]
  • A purchase removes the user from the audience. [L1520.013]

GA4: purchasers exclusion audience

Step-by-step: exclude existing customers from a 30-day visitor audience

  1. In GA4, go to the Audiences list. [L0274.025]
  2. Click the three dots on the audience, for example 30 Day Website Visitors. [L0274.025]
  3. Click Edit. [L0274.025]
  4. Set the membership duration to 30 days. [L0274.025]
  5. Click Include and choose website visitors, 30 days. [L0274.025]
  6. Click Exclude and choose users with purchase. [L0274.025]
  7. Click Save. [L0274.025]
  • Excluding purchasers prevents wasting spend on existing customers. [L0274.025]

Data sources for audience building

Google Analytics page conditions (Source B, 2021-2022, older advice)

  • Google Analytics page conditions in the Audience Builder offer the operators contains, exactly matches, starts with and ends with. [L1390.045]
  • Facebook website URL rules offer contains, equals, doesn't contain and at least one contains. [L1390.045]
  • Use contains with a short URL fragment unless you need one exact page. [L1390.045]
  • Audiences built in Google Analytics can also be used with Google Optimize 360 to target users who return to the site. This is an additional use beyond Google Ads and Display remarketing. [L1390.048]
