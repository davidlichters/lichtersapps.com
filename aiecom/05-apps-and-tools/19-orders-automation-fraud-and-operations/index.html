5.19 Orders, automation, fraud and operations

Automation principles and sequencing

  • Automate only after you have processed orders by hand for a few days to a few weeks and understand each step. Automating steps you do not yet understand produces the wrong logic. [L0934.056, L0934.171]
  • Use Zapier for simple automated flows. Hand tasks too complex to automate, such as detailed product uploads, to virtual assistants. Use human assistants for multi-step tasks. [L1441.019]
  • Automation can recover abandoned sales through follow-up and retargeting, monitor order status and trigger customer reviews, distribute content to social channels, instantly complete repetitive tasks, maintain customer records, transcribe media files, and generate new content. [L0236.008]
  • In practice, automation can recover abandoned carts, track all order statuses, automatically request and collect product reviews, post new content to social media without manual work, and execute any repetitive business task in seconds without additional instruction. [L0285.005]
  • Zapier is the central automation engine. It connects Shopify, Facebook, LinkedIn, Google Sheets, Trello and Slack to manage orders, communications, content distribution and customer tracking without manual intervention. [L0236.007]
  • Zapier connects apps and automates steps. One example used it to send new orders to Trello and to send automatic emails based on quiz results on the website. It looks intimidating at first but can be learned. [L0337.034]
  • Shopify is the core platform of a dropshipping store and the base all automations connect to. Its data (orders, customers, products) is the starting point for most automation work. [L0437.001]

Platforms, costs and choice of tool

Shopify Flow

  • Shopify Flow is a free app that simplifies building and editing automations compared with the Messaging app interface. Install it via Marketing > Automations > Install. [L0282.005]

Zapier basics

  • Zapier (zapier.com) connects applications with automated workflows called "Zaps". [L0283.003]
  • Each automation is a Zap made of one trigger and one or more actions or steps. [L0737.005]
  • Zapier supports hundreds of pre-built integrations. Connect each platform once (for example, enter the Shopify subdomain); the connection stays active for all future Zaps that use that platform. [L0286.032]
  • Authentication with each platform is required once, after which the connection is maintained permanently. [L0286.005]
  • Zapier's screens and terms change over time. Check each step against the current Zapier and Shopify interface before following older setup instructions. Older (2022). [L1281.127]
  • Zapier's Premium plan costs $20 per month. [L0286.005]
  • The free plan does not include the Shopify integration. The plan that includes it costs $20 per month and is the only paid tool in this basic automation stack. [L0437.007, L0437.008]
  • The 2023 comparison cites Zapier at $50 per month. Use $50 as the 2023 price point for that comparison, and the $20 Premium figure for the plan with the Shopify integration. Check the current price before budgeting, because the sources differ. [L0251.061, L0286.005, L0437.008]
  • The 2023 lesson's comparison table lists IntegralMat at $19.99 per month and IFTTT as alternatives. Both provide similar capabilities for connecting applications, automating email, data transfers and notifications. Compare pricing and the specific integrations you need before choosing. [L0251.061]
  • The Source E comparison describes Zapier per-automation cost as "a couple dollars per automation per month". [L0287.003]

Zapier Gmail triggers and Slack actions

  • Zapier offers four Gmail-based triggers:
    • New Email & Polling: activates when messages arrive in your specified mailbox.
    • New Email Matching Search Polling: restricts triggering to emails that meet search criteria you define, such as a specific sender domain.
    • New Label & Polling: fires when you apply a label to an email.
    • New Labeled Conversation & Polling: triggers once when a label is first added to an email thread. It does not re-trigger if more messages appear in that thread. [L0287.007]
  • When you test a Gmail trigger, Zapier automatically loads your previous emails from that mailbox as sample data. You do not need to trigger events manually; Zapier retrieves recent historical emails so you can check the logic before publishing. [L0287.017]
  • Slack actions available in Zapier workflows include:
    • Retrieve Thread Message: extracts all messages from a specific conversation.
    • Send Channel Message: posts to public channels, with optional delivery scheduling.
    • Send Direct Message: routes private messages to a user or yourself through Slackbot, and supports scheduled sending.
    • Send Private Channel Message: targets restricted channels.
    • The integration also supports message deletion, channel creation, reminder scheduling and channel lookup. [L0287.008]
  • Zapier's Slack integration sends real-time private messages containing lead details when forms are submitted, giving immediate visibility on mobile or desktop. [L0284.007]
  • Zapier's Attachments setting: when connecting to services that send file attachments, you choose whether attachments auto-open for processing or remain clickable links for manual team review. [L0286.039]

AI steps in Zapier

  • In Zapier's AI by Zapier step, models marked with a Lightning icon (such as GPT-4-1 mini and GPT-4-1 nano) are free to use. You do not need a paid OpenAI API account or your own ChatGPT credentials for them. [L0287.005]

Why an API matters

  • An API is the connection tool that lets one application command another. Zapier uses APIs to connect Gmail, ChatGPT and Slack. Each integration works because the API gives the automation platform permission to trigger actions in that app, such as creating a task in ClickUp, sending a message in ChatGPT or posting a Slack message. [L0287.002]

[L0287.003]

  • If you are brand new to automation, start with Zapier because it is the most intuitive. After gaining experience with several automations, move to Make.com to reduce costs. Switch to N8N only when you have many dozens of automations running at once and want to self-host to eliminate platform fees. [L0287.004]
  • Plan to switch from Zapier to Make.com when you have dozens of automations running at once. At that scale, Zapier's per-automation monthly costs add up significantly, while Make.com's pricing becomes more economical. Move to N8N only at very large numbers of automations or if you focus on AI agents. [L0287.015]
  • Make.com handles basic data transformations more awkwardly than Zapier. Splitting or reformatting text, converting code between formats, and transforming timestamps between time zones each require extra steps. These small friction points add up in complex automations, so Make.com feels slower despite its lower cost. [L0287.016]
  • N8N is the only one of these platforms that supports self-hosting. You run the whole platform on your own computer or laptop instead of N8N's cloud servers, so all processing stays on your device. Self-hosting is possible because N8N is open source. It removes monthly subscription costs, making it free or very inexpensive once you run many automations, unlike Zapier and Make.com, which charge per automation. [L0287.013]
  • N8N has the best AI agent functionality of the three main platforms. If you focus heavily on AI agents, N8N is the superior choice despite its steep learning curve, which requires knowledge of APIs, webhooks, JSON and MCP. [L0287.014]
  • Make.com is the mid-tier option and N8N the developer option; the platform guidance above applies to IFTTT as well, which the 2023 comparison lists as a Zapier alternative. [L0251.061, L0287.004]

Abandoned cart alerts to Slack

Purpose and timing

  • Slack sends real-time notifications to desktop and smartphone apps. Use it to alert the shop owner or a team member the moment a cart is abandoned, so the phone follow-up can happen within minutes. [L0281.004]
  • A real-time Slack notification each time a customer abandons checkout lets the store owner follow up immediately. Slack works like Discord for team alerts. [L0471.002]
  • Zapier checks Shopify every 5 minutes for new abandoned carts and forwards customer data directly to Slack. [L0281.005]
  • Maximum latency between cart abandonment and the Slack notification is 5 minutes. [L0281.006]
  • Set "Abandoned cart age in hours" to 0 in Zapier's Shopify trigger. This sends the notification immediately on abandonment, with no delay. [L0281.009, L0286.009]
  • The Zapier wait setting for cart data should also be 0 hours, so the data arrives immediately. [L0737.006]

Who receives the alert

  • The Slack recipient can be anyone on the support team: the shop owner, a virtual assistant, an employee or a family member helping with phone follow-up. Choose who receives the Slack message when you configure the automation. [L0281.008]
  • The Slack free plan receives real-time Zapier notifications, including abandoned cart alerts with customer name, phone number, email, order value and checkout link. [L0286.006]

Slack message settings

  • Auto expand links: no.
  • Link username and channel names: yes. [L0281.010]

Message template

Hi [Customer First Name], [Customer Last Name] just abandoned a cart with the value of [Cart Value]. [Customer First Name] can be reached at [Customer Phone Number]. The order was for [Product Name], and it would be shipping to [Shipping State]. Here is their abandoned checkout URL: [Abandoned Checkout URL]. Good luck on the call.

[L0281.012]

Example message

  • The Slack bot can be named Steve, with a tuxedo emoji as its profile picture. It alerts the team when customers abandon checkouts. Each message should include customer name, cart total, phone number, product details, shipping destination and the checkout link. Example output: "Hi, [name], John Smith just abandoned a cart with the value of $49. John can be reached at 55555. The order was for an official Source A hoodie, and it would be shipping to New York. Here is their abandoned checkout URL. Good luck on the call." [L0281.014]

Setup procedure

  1. Create a new Zap in Zapier.
  2. Select Shopify as the trigger source.
  3. Choose "New abandoned cart" from Shopify trigger options.
  4. Authenticate with your Shopify store login credentials.
  5. Set "Abandoned cart age in hours" to 0.
  6. Click "Test this step" to verify connection with an existing abandoned cart from your store; if none exist, manually create and abandon a test order in Shopify.
  7. Add an action by clicking the plus symbol to create a new step.
  8. Select Slack as the action platform.
  9. Choose "Send a channel message" as the Slack action.
  10. Authenticate with your Slack login and select your Slack workspace.
  11. Create a new Slack channel for these notifications (e.g., "Steve") or select an existing channel.
  12. Click in the message text area to customize the notification.
  13. Use the plus button next to the text field to insert dynamic data fields from the abandoned cart: customer first name, customer last name, cart value, customer phone number, product name, shipping state, and abandoned checkout URL.
  14. Write the message: Hi [First Name], [Last Name] just abandoned a cart with the value of [Amount]. [First Name] can be reached at [Phone]. The order was for [Product], and it would be shipping to [State]. Here is their abandoned checkout URL: [URL]. Good luck on the call.
  15. Set "Bot name" to a custom name (e.g., "Steve").
  16. Select a bot icon to represent the automation in Slack.
  17. Verify that "Auto expand links" is set to no and "Link username and channel names" is set to yes.
  18. Click "Continue" to preview the message based on your test abandoned cart data.
  19. Click "Send test to Slack" to verify the message displays correctly in your Slack channel.
  20. Once verified, turn the Zap on by clicking the toggle switch at the top (default is off).
  21. The automation now runs continuously: Zapier checks for new abandoned carts every 5 minutes and immediately sends a Slack message with all customer data.

[L0281.011]

Related follow-up options

  • Zapier can connect Shopify so that an abandoned cart automatically places the customer into a Minichat Messenger sequence. The connection is set up once and then runs automatically. [L1243.018]
  • Zapier automates follow-ups for abandoned checkouts. Keep the subscription only if it brings sales. If it does not pay for itself after a while, cancel it and follow up manually. [L0806.047]

Abandoned cart logging in Google Sheets

Overview

  • Zapier connects Shopify to Google Sheets without code. [L0737.005]
  • Google Sheets (free) automatically logs customer information from Zapier when carts are abandoned or orders are placed. It captures email, name, phone, creation date, contact status and recovery status for team visibility. [L0286.008]

First Zap: new abandoned cart creates a sheet row

  1. Log into Zapier and create a new zap.
  2. Set the trigger to Shopify and choose 'new abandoned cart'.
  3. Connect the Shopify store and select the store to link.
  4. In the options, set the wait time before data is passed through to 0 hours so the data arrives immediately.
  5. Add an action: click the plus, click action, and choose 'create spreadsheet row' in Google Sheets.
  6. Log into your Google account to connect it to the zap.
  7. Select the spreadsheet 'abandoned cart tracking sheet' and the worksheet 'abandoned carts'.
  8. Map every field (date, name, phone number, email, cart value, products, shipping, link to cart) to the matching data from the test order.
  9. Click continue, then click test this step.
  10. A successful test pushes the data into the sheet, and the phone team receives a Slack notification at the same time.

[L0737.006]

Rules for the sheet

  • Zapier matches each mapped field to a sheet header by name. Headers must be typed exactly as the fields are named in the mapping. Mismatched headers stop the correct data from landing in the right column. [L0737.007]
  • Leave the Recovered and Notes fields unmapped in the create-row step. Team members fill these in by hand, and mapping them would overwrite or pre-fill fields that need human input. [L0737.008]
  • Run the test step with a test order before activating a zap, so you can confirm each field lands in the correct column. Fix any mismatch before the automation runs on real carts. [L0737.009]
  • Choosing the wrong spreadsheet or worksheet in Zapier sends rows to the wrong place. A worksheet can have any name, as long as the correct one is selected in the zap. [L0737.010]

Second Zap: paid order updates the sheet

  1. Create a new zap and name it along the lines of 'paid order to update abandoned cart Google tracking sheet'.
  2. Set the trigger to Shopify and choose 'paid order' instead of 'new abandoned cart', then select the store.
  3. Add a step called Search in Google Sheets to look for an existing row.
  4. Select the spreadsheet 'abandoned cart tracking sheet' and the worksheet 'abandoned carts'.
  5. Set the search column to Email and match it against the email of the latest paid order.
  6. If no matching row is found, nothing happens and the zap ends without changing the sheet.
  7. If a matching row is found, add an update action for that row and fill the Recovered column with the date of the purchase.
  8. Keep calls and notes manual; only the Recovered date is automated.

[L0737.011]

  • The paid-order Zap matches the sheet only by exact email address. A customer who places the paid order with a different email will not have the Recovered column updated. Enter the recovery date by hand in that case. [L0737.020]

Order flow: Shopify to suppliers

Trigger rules

  • Use the Shopify trigger "New Paid Orders" so the automation runs only after an order is marked paid. Rejected or unpaid orders do not trigger it. Refunds require cancelling the order separately. Older (2021). [L0469.062]
  • Zap 1 trigger conditions: payment status marked as paid; order status any; fulfillment status any. This fires once, when payment is first marked as paid, not repeatedly. [L0292.005]

Vendor filtering

  • The vendor filter Zap uses Shopify as the order source, Filter by Zapier for vendor matching, and Gmail for sending email. You already have Shopify and Gmail; you only need a Zapier account. [L0283.003]
  • When you set up the vendor filter, Zapier pulls sample orders from your Shopify store and displays all available data fields (vendor name, product name, SKU, customer details and more). Use these samples to build and verify the filter condition, for example "line item vendor text exactly matches Source A merch", before the Zap processes live orders. [L0283.015]

Multi-product orders

  • Zapier order processing can handle orders with multiple products. The lesson demo used a single-product order, so adjust the workflow to process each line item in a multi-product order. Older (2020). [L0961.079]

Fulfilment handoff

  • Zapier is used for most store automations, including order forwarding to suppliers. Shopify's Mark as fulfilled action and Klaviyo tracking emails complete the process from order to customer notification. Older (2020). [L0468.078]
  • Zapier can automate order processing to suppliers. Choose whether it automatically captures payment or only pre-authorizes, based on how often you run into inventory issues with suppliers. Older (2021). [L1090.059]

Payment capture

  • Use "Authorize but not capture" payments in Shopify's payment settings. The card is checked for funds but not charged until the team verifies stock and captures the payment, after which the order is processed. [L0964.074]
  • Setting path: Settings > Payments > Payment capture. Set to "Authorize only" (Authorize, do not capture). Verify stock, then capture the payment and process the order. [L0964.075]

Order status boards in Trello

Overview

  • Trello (Trello.com) is a free visual project management tool with a Boards → Lists → Cards hierarchy. Cards can be dragged between lists manually or moved via Zapier automation. It gives a visual overview of order progress without daily administrative work. [L0292.002]
  • Trello can track orders on cards, with automation that moves a card to delivered after a set delay. [L0359.054]
  • Trello can show where each order sits in the process, from order placed to shipped, as order volume grows. [L0970.085]
  • Trello can be used to organise tasks as boards and cards. In an automated setup, it can track orders and collect customer review requests so nothing is missed. [L0437.005]

Five-list structure

Order List name
1 Paid orders
2 Sent to supplier
3 Shipped orders
4 Delivered and pending review
5 Reviewed

Orders progress through these lists as fulfilment stages change. [L0292.003, L0286.007]

Two-Zap workflow

  • Order tracking automation runs Shopify → Zapier → Trello. Two Zaps handle the workflow: Zap 1 creates cards when orders reach paid status; Zap 2 moves cards to shipped when fulfilment status changes. This removes manual card creation and movement. [L0292.004]
  • Zap 1 (Shopify paid order → create Trello order card): card name "Order [order number] [order date]". The description includes customer info (name, email, date placed), order info (product name, brand, SKU), customer notes (if entered at checkout) and ship-to (full address). Board: select your board. List: paid orders. Position: top, so new cards appear above existing cards. [L0292.006]
  • Zap 2 (Shopify shipped order → move Trello card): trigger "Order update in Shopify", with payment status paid and fulfilment status shipped. Action: search for the existing order card in Trello and move it to the shipped orders list. Cards transition from paid orders to shipped when Shopify marks fulfilment as shipped. [L0292.007]
  • Card data auto-populates from Shopify with order number, customer details, SKU, notes and shipping address. [L0286.007]
  • Before activating a Zap, click Test This Step to verify it. For Zap 1, a successful test creates a sample card on your Trello board, confirming the Shopify-to-Trello connection. For Zap 2, the test demonstrates card movement. Review the result, then click Finish or Turn On. [L0292.014]

Card fields and comments

  • Each Trello card has two date fields for follow-up deadlines, for example "customer will send product photo by October 29". When a deadline passes, Trello sends reminders to team members to check whether the promised follow-up was completed or needs escalation. [L0286.038]
  • Use the comment section of a card to record order status changes, backorder dates and follow-ups, for example "Contacted supplier on backorder until October 29". Each comment is timestamped with the team member's name. [L0286.026]

Alternative board

  • Asana can serve as the order board. New orders land automatically in the first column, and the VA moves each card to the next column as its status changes. Each card carries a due date, and overdue follow-ups show in red, so the owner can spot them without asking. Asana also handles task assignment to team members and to the owner. [L1473.003]

Shipment tracking and customer notifications

AfterShip overview

  • AfterShip is a Shopify app for delivery tracking. Once connected, Klaviyo can trigger emails on the delivery event, so the post-delivery request goes out at the right moment. [L0417.017]
  • AfterShip (or a similar fulfilment tracking app) connects to Klaviyo and provides order triggers such as shipped, out for delivery and delivered. These triggers drive the shipping and UGC emails. [L0605.008]
  • AfterShip is a parcel tracking platform that shows the status of shipments and can send tracking updates to customers. It is useful when orders ship from suppliers with limited tracking information. [L0985.002]
  • AfterShip automatically emails customers each time tracking updates, for example dispatched, in transit, out for delivery and delivered. Configure how many emails are sent and when in the app, then enter tracking numbers in the Shopify order dashboard. [L1285.039]
  • AfterShip sends branded tracking emails at each stage of delivery, such as out for delivery, delayed and delivered. The low-cost plan cost about one dollar per month for the store in the lesson. It is recommended for every store as a way to reduce "where is my order" questions. [L0910.029]
  • A tracking-notification app such as AfterShip can replace about four separate customer contacts per shipment: in transit, arriving in the destination city, out for delivery and delivery attempt missed. Enter the tracking number once, and the automated updates handle these messages for every order. [L1515.046]
  • AfterShip is used for order tracking notifications sent to customers. Older (2022). [L0665.042]
  • AfterShip is a Shopify app that automates tracking emails to customers and provides an embed code for a tracking page on the store. Older (2022). [L1281.088]

Free tracking sites and carrier tracking

Zapier in customer forms

  • Typeform creates forms and surveys. It integrates with Zapier as an alternative to WuFu for collecting custom product requests. [L0284.005]

Content distribution and social media limits

Transcription

  • Rev.com transcription costs $1 per minute of audio or video content. [L0286.021]
  • Zapier uploads new videos or audio files to Rev.com automatically and notifies the team in Slack when transcripts are ready. This removes manual upload and tracking steps. [L0286.022]

Platform limits

  • Blog automation should target only Facebook and LinkedIn, because Zapier templates format content natively for these platforms. Twitter, Instagram and Pinterest automation produces posts that look non-native and manufactured rather than intentional. [L0312.003]
  • Zapier automates blog distribution by connecting WordPress or Shopify blogs to Facebook and LinkedIn. New posts publish automatically to selected pages, formatted natively for each platform. [L0312.001]
  • The automation includes a 5-minute delay after a blog post is published. This gives time to catch and fix errors before the post goes out to social media automatically. [L0312.006]
  • When posting to multiple Facebook pages in one automation, add a 3-minute delay between posts to different pages, so followers are not overwhelmed by simultaneous posts. [L0312.007]

WordPress procedure

  1. Create a new zap with WordPress as the trigger.
  2. Select the trigger event as 'new blog entry'.
  3. Connect your WordPress account and select your blog or website.
  4. Add a delay action set to 5 minutes.
  5. Add Facebook Pages as an action, select 'create a page post'.
  6. From the dropdown, choose which Facebook page to post to.
  7. Build the template: add opening text (e.g., 'new e-commerce lifestyle podcast'), then use the plus button to insert the blog title, body and URL as dynamic fields.
  8. Select the blog URL as the link to share.
  9. Turn on the automation.
  10. To post to additional Facebook pages, add another action after the first Facebook post with a 3-minute delay, then add another Facebook Pages action with the same template.
  11. To add LinkedIn, add another action with LinkedIn as the platform and include the title, body and content URL.

[L0312.009]

Shopify blog procedure

  • Zapier's Text Formatter, with the event "convert HTML to markdown", removes HTML tags, meta tags and code from Shopify's blog summary field, so the content displays cleanly on social media. [L0312.012]
  • Without converting HTML to markdown, social posts from Shopify blog content display HTML code and meta tags, such as charset declarations and closing HTML tags. The content looks unprofessional and is hard to read. [L0312.013]
  • The featured image from the blog post is included automatically in the published Facebook post, with no extra configuration in the template. [L0312.016]
  1. Create a new zap and name it (e.g., 'Source A merch blog to social').
  2. Set Shopify as the trigger.
  3. Select the trigger event 'new blog entry'.
  4. Connect your Shopify account by selecting it from the dropdown.
  5. Choose which blog category to monitor for new posts (default is 'news'); if you have multiple blog categories, select the correct one from the dropdown.
  6. Click continue and test the trigger to verify it finds your blog posts.
  7. Add Zapier's Text Formatter as the next action.
  8. Select Text as the formatter type.
  9. Choose the transform option 'convert HTML to markdown'.
  10. Click into the input field, scroll down, and click 'show all options'.
  11. Select 'summary HTML' as the input to convert (this is the blog excerpt shown on your homepage, not the full blog post).
  12. Test the formatter action to confirm the HTML has been removed.
  13. Add a delay action set to 5 minutes.
  14. Add Facebook Pages as the next action.
  15. Select 'create a page post' as the event.
  16. Choose which Facebook page to post to.
  17. Build the post template: type static text (e.g., 'new blog post is live'), add line breaks, then insert the blog title, the converted summary output (from the Text Formatter step, not the raw summary HTML), and the URL.
  18. For the URL: manually copy the base URL up to and including the blog category path (e.g., 'yoursite.com/blogs/news/') and paste it in the link URL field, then insert the blog post handle field from the Shopify trigger to create the complete working URL.
  19. Click continue and test the action.
  20. Verify the post appears on your Facebook page with the correct text, summary and clickable link.

Fraud screening and chargebacks

Shopify's built-in protection

  • Shopify's built-in fraud protection screens orders as low or high risk. Some merchants add ClearSale for extra protection, though one speaker found Shopify Payments sufficient. Older (2020). [L1111.080]
  • Shopify's built-in fraud analysis flags high-risk orders when Shopify Payments is in use. Flagged orders should be cancelled and refunded rather than processed. Older (2020). [L0468.080]
  • Shopify's built-in fraud labels flag orders as "high risk" and list the reasons. Stolen cards are not covered by this flag, so a high-risk flag does not prove a fraudulent card. Check the reasons before cancelling. [L0472.039]
  • The two sources conflict on flagged orders. The 2020 advice cancels and refunds them. The 2025 caution applies before you act: a flag is a signal, not proof. [L0468.080, L0472.039]

Third-party screening apps

  • Signifyd is an order-fraud screening app for Shopify stores. It approves or declines orders and can guarantee protection against chargebacks on approved orders. [L0430.003]
  • Signifyd is a third-party order guarantee app. It reviews orders for fraud and reimburses the merchant for approved orders that turn out to be fraudulent. It is optional and adds cost per order. Older (2020). [L0468.081]
  • Signifyd and ClearSale are third-party fraud screening apps that charge different percentages per order. They are an alternative to Shopify's built-in fraud protection and should be compared by rate and order volume. Older (2019). [L0960.010]
  • ClearSale is a Shopify app that checks orders for fraud. If it approves an order that later becomes a chargeback, ClearSale reimburses the seller for a fee. Its protection is a paid service. [L0472.038]
  • ClearSale can be used as chargeback insurance for orders it approves. It reimburses the merchant for fraud chargebacks on approved orders, at about 1 percent per order. It is optional and was not used by that source's own team. Older (2022). [L0665.044]
  • The 2022 source quotes about 1 percent per order for ClearSale. The 2025 source gives no rate and describes a paid service. Use the rate quoted in the current ClearSale offer when you compare options. [L0665.044, L0472.038]

Chargeback insurance

  • A chargeback insurance service that works with Shopify can add protection against unauthorised purchases. The lesson recommended it without the speaker using it personally. [L0934.173]

Chargeback handling with Disputely

  • Disputely alert fees appear on the Shopify billing statement rather than as a separate invoice. The alert prices shown were $16.00 and $25.00 each. [L0351.052]
  • Disputely is a chargeback handling app. Its charges are lower and its approach friendlier than the alternative, so the lesson uses it. Disputifier (Smart Chargebacks) is the more expensive alternative. [L1327.034]
  • In Disputely Billing, the RDR section has fields to add BIN/CAID and ARN entries. The RDR setting must read "Not active". Disputely support can change it when asked by email. [L0351.053]

Returns, package protection and checkout add-ons

Loop Returns and Checkout Plus

  • Loop Returns is return and exchange software that drives refunds into exchanges and keeps money in the business. Its Checkout Plus add-on charges a return fee at checkout. [L0955.039]
  • Checkout Plus used to be named Offset and was renamed. The two names refer to the same product. [L0955.042]
  • Loop provides an online calculator for return fee and Checkout Plus economics. Its sales reps can run a deeper analysis of a brand's numbers. [L0955.041]
  • Package protection can be sold as a standalone product through partnerships. Loop has announced an in-house version for coming months. [L0955.043]
  • Gorgias, the help desk, shows the Checkout Plus line on the order because it is a Shopify product. A support agent can check whether a customer was charged a fee they should not have paid. [L0955.044]

Wonderment

  • Wonderment is an order tracking tool that Loop acquired about a year before the lesson. It now sits in Loop's portfolio as Loop order tracking and works with Loop Returns. [L0955.040]

Market availability

  • Checkout Plus and Wonderment are sold mainly to brands in the US, Canada, the UK and Australia, with some use in New Zealand and mainland Europe. Confirm the app supports your target market before planning a launch there. [L0955.058]

Store continuity and data

  • Rewind backups can export everything from a Shopify store, including products as CSV, before you close or stop paying for the store. The export can later be used to rebuild a similar store. [L0804.052]

Financing

  • Shopify Capital is a cash-flow financing option that can fund stock purchases. Lending facilities can be tight at times, which can cause cash-flow problems for a brand that must buy a lot of stock. [L0660.022]
