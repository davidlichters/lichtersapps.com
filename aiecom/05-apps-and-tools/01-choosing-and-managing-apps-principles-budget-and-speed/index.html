5.1 Choosing and managing apps: principles, budget and speed

Principles for choosing apps

  • Use an app only for a feature that would be too hard to code yourself. Build simple features with on-site code, because fewer apps usually mean faster pages. (older advice, 2021) [L0853.089]
  • Before installing an app, check whether it solves a concrete need at your current stage. Apps added because others use them or because they look new usually add cost and load without benefit. (older advice, 2021-22) [L1298.001]
  • Install only the apps you need at your current stage. Add more as the business grows and your market calls for specific functions. (older advice, 2021-22) [L1300.003]
  • Think of apps like smartphone apps: you add one for a specific job. [L1300.002]
  • Shopify apps are add-on software built by outside developers and listed in the Shopify App Store. Each app adds one function when it is needed, so the store owner does not build that function from scratch. (older advice, 2021-22) [L1300.001]
  • For a store with a limited budget, an app is usually cheaper than custom development. A feature such as live chat built from scratch can cost thousands of dollars and is often less polished than a finished app from a specialist company. (older advice, 2021-22) [L1300.002]
  • Installing an app usually replaces custom development. Features that once required a developer paid thousands of dollars can often be added with a few clicks and no coding. [L1301.010]
  • Shopify's built-in features cover most of what a new store needs, so only a few apps are required at the start. Installing extra apps before you need them adds cost and complexity. [L1250.020]
  • Shopify is the only paid software that is a must-have at the start. Canva's free version is fine, and Stripe Atlas can help set up a US company if you run the business from abroad. [L0934.054]
  • No apps are required at the start of the setup. Settings > Apps lists installed apps. [L0096.015]
  • The Shopify App Store offers thousands of apps that extend store functionality beyond the built-in features, such as marketing and SEO tools. [L1313.006]
  • When you consider switching a tool, compare the new tool's functions with what your current tool does for you. If the new tool covers everything at lower combined cost, consolidate. If the old tool does a job the new one cannot, keep it. (older advice, 2021-22) [L0949.024]

Deciding which apps to install at each stage

Setup and foundation

  • When setting up a new Shopify store, do not install apps yet unless the current setup step calls for them. Install each app when the stage of the build that needs it arrives. This keeps the store lean and avoids paying for unused subscriptions. [L1301.015]
  • At the foundation stage, install only the apps the store needs for its current products and sales. Do not install all apps at once. [L1327.043]
  • Fulfillment-agent apps, for example for a 3PL, are often not installed manually because the agent provides its own integration. [L1327.043]
  • Channel apps for Google and Meta are added later, when the store starts advertising on those platforms, not during the initial store build. [L1301.016]
  • Review collection apps are also added at a later stage, once the store needs them. [L1301.016]
  • Beginners do not need SMS marketing, SMS, email or retargeting apps when starting. Focus first on getting views, sessions and sales, and add them later once traction exists. [L0820.034]
  • Install only the Ultimate Sales Boost app and one fulfillment app (such as DSers, CJ Dropshipping or an all-in-one fulfillment app) on a new store at the start. [L0820.035]

Roles of the core tools

  • Klaviyo, SMS Pump and Tidio serve different roles. Klaviyo handles email retention and signup capture. SMS Pump handles SMS abandoned checkout and upsell/win-back. Tidio handles live chat with the visitor during checkout and chatbots for cart recovery and order-status questions. [L0477.033]
  • Essential Shopify apps for dropshipping cover four jobs: fulfillment, currency conversion, product reviews, and email/SMS marketing. Optional apps add live chat, a sticky add-to-cart bar, and average order value (AOV) boosters such as bundle or quantity-break apps. [L0635.001]
  • Klaviyo is the choice with the deepest Shopify integration. Every extra connector is another point where something can break. (older advice, 2021) [L0469.061]

  • Mobile app builders are only worth building when the product has a high repeat purchase rate (e.g. supplements), since push notifications then bring customers back. For normal store products, a mobile app is hard to maintain and gets little traction. [L0472.043]

Currency converters

  • A currency converter is required whenever the store does not use Shopify Payments, so customers see prices in their local currency. [L0635.002]
  • Shopify Payments already converts currency automatically once a market such as Germany is enabled. [L0635.002]
  • Bucks Currency Converter is recommended because it is free. Other currency converter apps perform the same function. [L0635.016]

Free plan first and budget

Rule order

  1. Start every new tool on its free plan and check whether it covers the need. [L0337.045]
  2. Move to a paid plan only when volume or features force it. When you do, pick the lowest-priced tier that fits the current usage. [L0337.045]
  3. Start every app on its free plan, confirm it delivers value, and only then upgrade. (older advice, 2021) [L0469.058]
  4. Test a paid app during its free trial and measure the extra revenue before paying. (older advice, 2021) [L0469.057]

Price points and budget limits

  • Shopify apps recommended in one 2020 lesson cost less than about $20 per month each. Install them gradually as you reach each step, rather than all at the start. (older advice, 2020) [L0358.034]
  • A 2021 source said that at about $10 per month, a useful upsell app usually costs little compared with the revenue it can add. (older advice, 2021) [L0469.057]
  • Easy Tabs - Product Tabs by NexusMedia costs $5 per month with a 7-day free trial. (older advice, 2021-22) [L1300.007]
  • Use both price points as examples only. Check current pricing, because some tools have been rebranded and repriced. [L1283.083]
  • Free or low-cost apps with many five-star reviews are an acceptable choice for page speed or image SEO. [L1283.083]
  • Shopify apps in the App Store are either free or paid, and the listing page shows which. Apps developed by Shopify are free to add to a store. [L1301.011]
  • For a basic automation stack, the free versions of Slack, Trello and Google Sheets are sufficient. There is no need to pay for their team or upgraded plans. Paid upgrades should only be considered when a specific limit is actually reached. [L0437.009]
  • Starting ad research: a research tool budget of about $150 per month on ad testing usually gives more experience and data than the tool itself. A paid research tool is more useful once the business is already making money. [L1172.020]
  • To begin testing a product you only need a store, an Ad Library reference and a product list. Additional tools are not necessary at the beginning. [L1172.021]
  • Ahrefs (SEO research) and SimilarWeb (traffic estimates) are paid tools that are optional for a new dropshipping store. Their discounts, including on Black Friday, do not make them necessary. [L0471.021]
  • AI tool costs add up. Each tool in a stack may cost about 10 dollars per month, so a stack of several tools can reach around 100 pounds per month. Justify each tool by the return it gives. [L0353.034]

Cost traps

  • Apps that do not lead to sales should be cancelled, because they add monthly cost without return. [L0359.056]
  • A free-gift app with a plan of about 20 USD ended up at almost 100 USD per month once usage fees were added. Check usage-based fees before choosing an app. [L0694.028]
  • Remove costly bundle or gift apps once revenue is good enough to switch. [L0694.028]
  • Some apps offer a free trial or free plan badge in the listing, but billing starts after the trial. Check whether the trial or free tier ends in a paid plan. (older advice, 2021-22) [L1298.039]
  • Bundle discounts from the Kaching app page grow with the number of apps installed: 10% off with 2 apps, 20% off with 3 apps, and 30% off with 4 or more apps, applied to all installed apps. Check the exact terms and whether the discount applies to your plan before counting on it in a budget. [L0861.042]
  • Shopify's app bundle discount as shown in the admin in 2026: 2 apps installed gives 10% off, 3 apps gives 20% off, and 4 or more apps gives 30% off. [L0862.017]
  • Use Bold Product Options and Bold Product Upsell on stores where the functionality is needed. Do not use Bold Discounts. Use promo codes promoted on the store instead of storewide discounts. (older advice, 2021) [L1279.043]
  • Do not pay for a tool before sales arrive. Several starter apps have free trials, so avoid paying before sales arrive. [L1380.036]
  • A currency converter app was switched off in a test without a visible change in conversion rate, because most ads targeted the US and the store sold in USD. Such apps can conflict with other apps, which may be a reason to remove them. [L0694.027]

Vetting an app before installing

Search and compare

  1. Open the Shopify App Store from the Shopify admin. [L1301.008]
  2. Type the feature you need into the search bar, for example wishlist. [L1301.008]
  3. Compare the results. Check the developer, and note that apps developed by Shopify are free. [L1301.008]
  4. Open the app listing and review its demo video, screenshots, description, rating, number of reviews, and available pricing plans. [L1301.008]
  5. Pick a plan and click Install to add the app to the store. [L1301.008]
  • Search by the feature you need, such as wishlist, rather than by brand name. [L1301.007]
  • The store front page has a search bar, a Popular with stores like yours section at the top, and trending and spotlighted app lists. [L1301.007]
  • Search results can be narrowed with the checkbox See only compatible apps and with a pricing filter set to Free or Paid. The default sort order is Most relevant. [L1300.005]
  • The Shopify App Store is organised into these categories: Store design, Orders and shipping, Sales and conversion, Marketing, Inventory management, Productivity, Reporting, Finances, Customer support, Finding products, Places to sell and Trust and security. Customer support, for example, contains support ticket apps. [L1300.004]

Ratings and reviews

  • Before choosing a third-party app, check its ratings, the number of reviews and whether the reviews are recent. Constant Contact's Shopify connector was reported at $5 per month with 4.3 stars from 58 reviews. (older advice, 2021) [L0469.060]
  • To pick a Shopify app, search the Shopify App Store for the task and sort by the number of reviews and star ratings. The app with the most five-star reviews is a good first option. [L0667.046]
  • A wishlist app with a rating of 4.9 out of 5 stars from more than 1,900 reviews is an example of a well-reviewed app. Ratings and review counts together help compare competing apps for the same feature. [L1301.009]
  • Shopify app search results show each listing's star rating, review count and free trial length, which helps compare apps in the same category. In 2021, the Easy Tabs - Product Tabs listing by NexusMedia showed 4.9 stars from 742 reviews, a 7-day free trial and a price of $5 per month. Compare several listings before installing one. (older advice, 2021-22) [L1300.036]
  • Poor apps usually show bad reviews in the Shopify App Store. (older advice, 2022) [L0429.021]

Vetting procedure for a wholesale or sourcing app

  1. Compare ratings of candidate apps in the Shopify App Store. [L0671.010]
  2. Read the actual written reviews to see whether they look genuine. [L0671.010]
  3. Look for video reviews on YouTube before installing. [L0671.010]

(older advice, 2021) [L0671.010]

Developer and integration

  • Choose tools with the deepest Shopify integration, such as Klaviyo. [L0469.061]
  • Augmented reality room-preview apps are not necessary for most niches. They need extra apps, coding skill and budget, and the preview may not match the product photos. [L0469.064]

Installing an app

Procedure as taught by Source B

  1. In the Shopify admin, open the Apps menu. If no apps are installed, click Visit Shopify app store, which opens in a new tab. [L1300.006]
  2. If Shopify asks you to choose an account, select the store account again. [L1300.006]
  3. Type the app name in the search bar and open the correct listing. In the example, Easy Tab, Easy Tabs - Product Tabs by NexusMedia. [L1300.006]
  4. Click Add app. [L1300.006]
  5. On the confirmation screen, read the list of access rights and click Install app. [L1300.006]
  6. Open the app. It loads its own admin interface, where you start the free trial if needed and complete the setup. [L1300.006]

Procedure as taught by Source C

  1. Open the Shopify search bar, go to Apps, then All recommended apps, and scroll down to the Shopify App Store. [L1297.001]
  2. Search for the app by name and open the listing. [L1297.001]
  3. Click Add app, then Install app. [L1297.001]
  4. Log in to an existing account or sign up, which connects the app to your store. [L1297.001]
  • To install a Shopify app, open Apps in the Shopify admin, click all recommended apps, scroll down and open the Shopify app store. Search the app name, click Add app and then Install app. [L0477.034]

Permissions and data

  • On the Shopify app install confirmation screen, clicking Install app also accepts Shopify's Terms of Service. Read the list of access rights on that screen before you confirm. [L1300.035]
  • The install confirmation lists what the app may access: view Shopify account data, view products, manage your Online Store and view details. Removing the app starts a request to erase your customers' personal data after 48 hours. (older advice, 2021-22) [L1300.008]
  • Some apps place features into the main Shopify areas, while most run through their own admin interface. After installation, open the app and manage its settings there. (older advice, 2021-22) [L1300.009]
  • To remove an app, go to Shopify admin > Apps, open the app, and click Uninstall. [L1301.012]

Working with app developers

  • Contact the developer named on the app's store listing for any change to how the app displays on your site, instead of editing code yourself if you are not a coder. For Easy Tabs the developer's support address is support@nexusmedia-ua.com. (older advice, 2021-22) [L1300.011]
  • Procedure for a placement change:
    1. Find the developer's contact details on the app's store listing. [L1300.012]
    2. Reply to the developer's welcome email, which keeps the earlier conversation in one thread. [L1300.012]
    3. Ask the developer to install the app in a way that fits your theme and places it where it should appear on the product pages. [L1300.012]
    4. Wait for the developer to complete the change, which in the example took up to 12 hours. [L1300.012]
  • In the example, the app developer carried out the requested placement change within 12 hours and at no charge. (older advice, 2021-22) [L1300.013]

Page speed and app weight

How apps slow a store

  • Apps that place content on the storefront inject extra code and JavaScript that must load with every page. A large number of such apps slows page load, which can lower conversion rates and hurt organic search rankings. (older advice, 2021-22) [L1298.002]
  • Each installed app adds JavaScript that runs on every page load, which slows the page. Keep the number of apps low and remove unused apps along with their code. [L1345.035, L1410.011]
  • Some apps use lazy loading to defer their scripts so they do not slow the first view. Every installed app still adds JavaScript, so check the impact on load time before installing. [L1410.048]
  • Many stores run around 30 apps while only 2 or 3 are fundamental. Remove apps that are not essential to the business. Each app adds code and load time, especially on the cart and checkout pages. [L0390.036]
  • Each app added can slow the store, so use as few as possible. [L1283.082]
  • Apps can slow page load and add monthly cost. [L1116.020]
  • The number of Shopify apps does not determine slowdown. One poorly coded app can damage performance and user experience, while many lightweight, well-coded apps may have almost no effect. (older advice, 2022) [L0429.021]
  • Use lightweight apps that add little code and do not change how the site operates. Apps that alter the site structure can drastically increase load times. [L1098.012]
  • Within one app category, page-speed impact differs. When features are similar, choose the app that is lighter on the site. (older advice, 2021-22) [L1298.003]
  • Apps with similar functions differ hugely in speed, so test alternatives before choosing. Talk To is a light chat app with minimal page speed impact, while TDO Chat was described as the slowest chat app on Shopify. Pop-up apps that load asynchronously (separately from the page) have less impact than those that block loading. (older advice, 2021-22) [L1266.019]
  • Chat apps on Shopify differ greatly in page speed impact even when they offer the same function. For a budget-limited early-stage store, a light and cheaper option such as Talk To is a reasonable choice. Replacing a slow chat app is usually the single biggest quick speed fix. (older advice, 2021-22) [L1266.038]

Speed check after installing

  1. Install the app. [L1098.013]
  2. Run a speed check on the store. [L1098.013]
  3. Test the load on a 3G connection. [L1098.013]
  4. Confirm the site is still easy to use. [L1098.013]
  5. If it slows the store, remove the app. [L1098.013]

[L1098.013]

App audit

  • Apps are almost always the biggest cause of slow page speed on Shopify. Remove apps that are not used. Remove the leftover code of uninstalled apps from the theme, because uninstalling an app does not remove its script from the site. (older advice, 2021-22) [L1266.017]
  • Removing an app from Shopify does not always remove its injected code. Contact the app developer to ask where code must be deleted. [L1283.082]

Audit procedure

  1. List every app that adds front-end code: chat widgets, upsell widgets, option apps, filters, header bars, pop-ups, JavaScript-based tools. Back-end apps such as accounting connectors do not affect page speed. [L1266.018]
  2. For each app, ask whether it is still used regularly. If not, delete it. [L1266.018]
  3. If it is needed, check whether a faster alternative with similar function and cost exists, and replace it. [L1266.018]
  4. Check the theme code after deletion to confirm no script of the removed app remains. [L1266.018]
  5. Consider replacing simple app functions, such as banners or simple elements, with code written into the theme, which is more efficient. Keep apps only for complex functions such as live chat. [L1266.018]

(older advice, 2021-22) [L1266.018]

  • Hire a Shopify developer with page speed experience to audit the store once and fix the technical issues: apps, code, lazy loading and theme. This is treated as a worthwhile one-time investment rather than something to learn yourself. (older advice, 2021-22) [L1266.021]

Uninstalling an app

  • When uninstalling an app that slowed the store, message the app developer through the Shopify App Store first. They can confirm whether extra code was added that must be removed to restore load speed. [L1098.014]
  • Removing an app does not always remove its injected code, so ask the developer where code must be deleted. [L1283.082]
  • Remove apps that are not essential to the business. [L0390.036]
  • Remove an app that conflicts with other apps. [L0694.027]
  • Remove costly bundle or gift apps once revenue is good enough to switch. [L0694.028]
  • Cancel apps that do not lead to sales. [L0359.056]

Finding apps that competitors use

Browser inspection procedure

  1. Open the competitor's store in Chrome. [L1345.089]
  2. Right-click and choose Inspect. [L1345.089]
  3. Use the select-element tool and click the bundle block on the page. [L1345.089]
  4. Read the element's code and search for the app name, such as 'bundle' or the app's name in the script. [L1345.089]
  5. Note the app name and check its listing on the Shopify App Store. [L1345.089]

Tools that show competitor apps

  • Ali Hunter (Chrome extension), PPSpy, and Koala Inspector show which apps competitor stores use. Koala Inspector may require an upgrade for full app data. [L1345.090]

Theme features, custom code or a freelancer

Use the theme first

  • Use the built-in theme features before paying for a separate app or a custom developer job for the same function. Review collection still needs a separate app, because the theme does not provide it. [L0973.015]
  • Some features built into a theme can replace functions that would otherwise need separate paid Shopify apps. Checking a theme's native features before buying apps can reduce monthly app costs. [L0974.008]
  • Simple site elements such as banners or small on-page features can often be coded directly into the theme by an inexpensive developer. This is usually more efficient than a script-heavy app. Complex functions such as live chat still normally require an app. (older advice, 2021-22) [L1266.039]

Custom code for simple features

  • For a simple custom feature, ask an LLM for custom Shopify section code instead of installing an app or hiring a developer. [L1116.020]
  • Use apps only for features that would be too hard to code yourself. Build simple features with on-site code. (older advice, 2021) [L0853.089]

Hiring a freelancer

  • Get a custom feature built when paid apps are too expensive:
    1. Post a job for a Shopify developer on Upwork. [L0968.051]
    2. Describe the function you need and link to the apps you want to emulate. [L0968.051]
    3. Hire a developer to build it into your store for a one-time cost. [L0968.051]

(older advice, 2021) [L0968.051]

  • Platforms for hiring Shopify developers for custom code, such as custom buttons and external service integration, include Fiverr.com and StoreTasker.com. [L0276.063]
  • Stack Overflow is a technical Q&A site useful for finding fixes to specific coding problems. Reddit can also be used to ask for recommendations from developers, though answers can be harsh for beginners. [L0709.037]
