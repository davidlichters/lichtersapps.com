Conversion Testing: Prerequisites

  • Testing tools named in the sources include Optimizely, VWO, Convert and Google Optimize. [L0423.011]
  • Tools for finding conversion problems include Google Analytics with Shopify Analytics, Usertesting.com for user tests, and session recording tools such as Hotjar, Smartlook and FullStory. [L0423.018]
  • VWO and Google Optimize-style platforms are for running controlled tests. They are only worth the investment once traffic and basic best-practice fixes are in place. [L0886.023]
  • Track conversion rate tests and planned future tests in a Trello board or a spreadsheet, Google Sheet, Asana or similar project management tool. A downloadable Trello template can be used as a starting point. (Older advice, 2021-22.) [L0399.002]

Conversion Testing: Tools

Visually (Shopify A/B testing)

  • Visually is a Shopify A/B testing platform available risk-free through Source E: no charges until reaching 1.5x to 3x return on investment, which creates zero upfront app cost. [L0197.001]
  • Its recommendation engine uses Shopify purchase data, customer order history and on-site browsing behavior. [L0197.001]
  • Most tests are set up in 3-4 clicks, with toggles for magnifying glass, reviews and design elements. Custom options are available through the Visually team. [L0197.001]
  • Visually runs no-code A/B tests and on-site experiences: promotion bars, social proof, product recommendations, product upsells, custom HTML/CSS/JS components, redirects, Fake Click, and global CSS or JavaScript files. [L0389.017]
  • Results are sent to Google Analytics when the event box is ticked. [L0389.017]
  • The Redirect feature sends visitors to a different URL. This lets you compare two pages, such as two landing pages, and optimize conversions without code. It sits alongside Fake Click, Global CSS and Global JavaScript in the element list. [L0389.025]

Lively

  • Lively is an app for A/B split testing on a Shopify store. After major website changes, run the new version against the old one in a controlled test, so each version gets enough visitors to show a clear result. [L1225.086]

Lomio

  • Lomio is used for price and image testing, and for description testing, rather than full page tests. It is a quick way to shift prices and visuals on one product. [L0524.042]

Neat

  • The Neat A/B testing tool is an option for Shopify stores to run conversion tests. It can be used alongside another testing tool to compare results. (Older advice, 2021-22.) [L0399.004]
  • Neat AB Testing is a split-testing app from the Shopify App Store. It pulls conversion data from the Shopify checkout and links it to each page version, so results are collected inside the app. (Older advice, 2021-22.) [L1364.033]

Google Optimize (discontinued)

  • Google discontinued Google Optimize in September 2023. It can no longer be used, and current alternatives must be checked before setup. [L0399.003, L0423.011, L1259.068, L1364.032]
  • Older sources (2021-22) describe Google Optimize as a free split-testing tool linked to Google Analytics for on-page tests. That method no longer works as described, so a current alternative is needed. (Older advice.) [L0399.003, L1364.032]
  • For landing page split tests in 2026, use a current A/B testing app that works with Shopify instead. [L1259.068]

Session Recording: Lucky Orange

  • Lucky Orange records your visitors' mouse movements and clicks on store pages in real time. It creates heatmaps showing where visitors interact. [L0293.007]
  • You can watch individual visitor sessions to see scrolling patterns, cursor movements and interaction points. [L0293.007]
  • Lucky Orange records visitor sessions and shows country and location. It can be used to measure average time on site. [L0363.029]
  • Lucky Orange offers a 7-day free trial. If you continue after the trial ends, the subscription costs $10 per month. [L0293.008]
  • Use Lucky Orange to show why people bounce. A free trial or free account is enough to start. (Older advice, 2022.) [L0665.047]
  • Use it to spot frustrating elements, such as things visitors try to click that are not clickable, which increase bounce rate. (Advice from 2023.) [L0804.048]
  • It shows where visitors click, where they stop and whether something on the site looks broken. (Older advice, 2018.) [L1085.044]
  • A free trial is available for testing. (Older advice, 2019.) [L0663.064]
  • Lucky Orange shows how visitors behave on a store, so you can make optimizations based on what they actually do. [L0837.029]
  • Microsoft Clarity is a free alternative that offers similar behavior tracking. [L0837.029]
  • It shows how long a visitor has looked at a product before leaving. You can use that information to personalize abandoned cart messages. [L1472.055]

Bot traffic and IP addresses (Lucky Orange)

  • Lucky Orange shows visitor IP addresses. This lets you block bot traffic that inflates visitor counts. [L0941.043]
  • A seven-day free trial is enough to collect this data. You can cancel afterwards. [L0941.043]
  • Repeated visits from one IP address with no purchases are most likely a bot. [L1114.037]
  • To check, search the IP address on Google. Others often identify it as a Google, Microsoft or Meta bot. [L1114.037]

Session Recording: Other Tools

  • Hotjar offers heatmaps, scroll maps, user recordings and exit-intent feedback polls. [L0390.020]
  • Smartlook is a similar session recording tool. [L0390.020]
  • FullStory is the most expensive option of this group. [L0390.020]

Daily recording review routine (Hotjar, Smartlook or similar)

  1. Install the tool on the store. [L0390.021]
  2. Once a day, spend about 10 to 15 minutes watching about 5 recordings. [L0390.021]
  3. Prioritize visitors who added products to cart but did not complete the purchase. [L0390.021]
  4. Look for buttons that are hard to find, checkout buttons hidden by scrolling, elements visitors click that are not clickable, and rage clicking. [L0390.021]
  5. Record each flaw and fix the most frequent ones first. [L0390.021]

User Testing

  • User testing services let you buy recorded sessions with real users matching a chosen audience, such as age range or interests. [L0390.019]
  • Assign them a task, such as buying a specific product. You receive recordings with spoken thoughts and notes on why tasks were easy or hard. [L0390.019]
  • Usertesting.com is named as the tool for user tests when looking for conversion problems. [L0423.018]

Speed Measurement: Which Numbers to Trust

  • Shopify's built-in speed test is not a reliable measure. Use Google PageSpeed Insights and GTmetrix for speed checks. (Older advice, 2022.) [L0665.051]
  • A Shopify speed score is less useful than the GTmetrix breakdown for finding the cause. (Advice from 2023.) [L1283.080]
  • GTmetrics and Shopify can show different load times because the tests run from different locations. [L0807.037]
  • The slowest item in the GTmetrics waterfall is usually the same slow element that shows up in Shopify. [L0807.037]

Speed Measurement: GTmetrix

  • GTmetrix is a free speed test that reports page load performance and a waterfall of every page element with its load time. Use it to find the element slowing a product page. (Older advice, 2021.) [L0801.110, L0851.002]
  • GTmetrix reports a performance score and a waterfall chart. The waterfall shows how each element of the page loads, from fastest to slowest. [L1446.018]
  • It shows the scores, the elements slowing the page, and the code loaded on the site. (Advice from 2023.) [L0970.089]
  • A free account with no credit card is enough for these tests. [L0857.060]
  • The free GT Metrics account needs no credit card and allows about 3 speed tests per day. Enter the product or store URL and run the test to get a starting score. [L1190.006]
  • The free version also shows which installed apps or tracking scripts slow the page. (Older advice, 2020.) [L0551.029]

Reading the waterfall

  • The GT Metrics Waterfall view lists every loaded resource from fastest to slowest. [L1190.008]
  • Scroll down to the lines that stretch furthest to the right on the timeline. These are the slowest items. [L1190.008, L0272.015]
  • Optimize or remove the apps or resources that cause them. [L1190.008]
  • Check the waterfall to find slow images or app code, then remove or reduce them. (Older advice, 2021.) [L0962.046]

Speed check procedure (GTmetrix)

  1. Run the store URL through GTmetrics. [L1283.081]
  2. Open the waterfall view. [L1283.081]
  3. Find the item loading slowest, such as a large image or an app script. [L1283.081]
  4. Fix it or send the code to the developer for identification. [L1283.081]

Finding a slow app (GTmetrix)

  1. Create a free GTmetrics account. [L0807.036]
  2. Enter your store URL and run the test. [L0807.036]
  3. Open the waterfall view. [L0807.036]
  4. Scroll to the bottom of the waterfall to see the slowest-loading items. [L0807.036]
  5. Note any app or developer names you do not need. [L0807.036]
  6. Remove the unneeded app from the store. [L0807.036]
  7. Retest the store speed. [L0807.036]
  8. Contact the app developer to ask them to remove any leftover code. [L0807.036]

Speed Measurement: PageSpeed Insights

  • Google PageSpeed Insights often returns generic speed recommendations that are impractical for a Shopify store. [L0390.057]
  • Filter its results against your actual app list and image sizes. Start with the heaviest elements, such as apps and unoptimized images. [L0390.057]
  • The "Remove unused JavaScript" entry lists each script with its host domain, such as a chat widget, pop-up, analytics or finance vendor. (Older advice, 2021-22.) [L1266.036]
  • Use those domains to match each slow script to the installed app that injects it before deciding to remove or replace it. (Older advice, 2021-22.) [L1266.036]
  • Use Google PageSpeed Insights, GTmetrix and Pingdom to test page speed regularly. They list suggested fixes, though many of those fixes are technical. (Older advice, 2021-22.) [L1522.037]

WebPageTest waterfall

  • In a WebPageTest waterfall, one slow third-party request, such as a chat widget that stalls on connection, can hold back every request that follows it. This can push the Largest Contentful Paint out by tens of seconds. (Older advice, 2021-22.) [L1266.046]
  • Locate the stalled item by its position in the waterfall. Removing that one script can change the result more than any other fix. (Older advice, 2021-22.) [L1266.046]

Apps, Scripts and What You Control

  • Installed apps add code that slows a store. The impact depends on how each app is built, not only on how many are installed. [L1190.003]
  • Remove apps that are not needed so their code is removed as well. [L1190.003]
  • Shopify's hosting, CDN and base platform scripts cannot be changed. Focus optimization effort on images, apps, custom code, CSS, HTML and JavaScript that the store controls. (Older advice, 2021-22.) [L1266.020]
  • The standard Shopify plan at about 29 dollars per month serves assets from cdn.shopify.com. The store does not need a separate CDN for normal speed. (Older advice, 2020.) [L0551.029]
  • Check hosting-level items in PageSpeed Insights, including Google Tag Manager and tracking tools. Hotjar, Privy, Zotabox, Klaviyo, Facebook and Google Analytics scripts add JavaScript cost. Check whether each is still needed, and move tags to Google Tag Manager where possible. (Older advice, 2021-22.) [L1266.027]
  • Financing widgets such as Bread load their scripts on every page, including the homepage. Shoppers only need them on product or checkout pages. For high-ticket stores, check whether the financing app's scripts can be limited to those pages. (Older advice, 2021-22.) [L1266.037]

Image Optimization and Alt Text

  • Add image alt text either manually or with a free Shopify app from the Shopify App Store. Compress product images as well, since large images slow the store down. (Older advice, 2020.) [L0468.087]
  • Minifier adds metatags (alt text) to product photos automatically. It resets once per month. (Older advice, 2022.) [L0272.057]
  • If only some photos get tagged when you expect all to be tagged, contact Minifier's support for a reset, then run it again. (Older advice, 2022.) [L0272.057]
  • Crush Picks is an alternative app if Minifier issues persist. (Older advice, 2022.) [L0272.057]

Smart SEO: optimize images by collection

  1. Open the Collections tab. [L0368.002]
  2. Select all collections. [L0368.002]
  3. Deselect those without images. Only collections that actually have images need this step. [L0368.002]
  4. Click Optimize collection images. [L0368.002]

Path: Smart SEO app > Configure > Image optimization. [L0368.002]

Smart SEO: optimize product images

  1. Open the Shopify admin and open the Smart SEO app. [L1190.009]
  2. Find the Image optimization section and click Configure. [L1190.009]
  3. Open the Products tab. The app pulls in all store products and shows whether each image is optimized. [L1190.009]
  4. Tick the products to optimize, for example all of them. [L1190.009]
  5. Click Optimize product images and wait for the job to finish. [L1190.009]
  6. Check the savings shown afterwards for the combined image size before and after. [L1190.009]

Expected results

  • In one test with 10 products, the combined image size dropped from 60.2 MB to 18.1 MB, which saved about 42 MB. [L1190.010]
  • A store with hundreds or thousands of products may need around 30 minutes or longer. The job can run while you work on other tasks. [L1190.010]

Smart SEO: add alt text to product images

  1. Open Smart SEO, go to the Alt tags section, and click Configure. [L1190.013]
  2. Select all products with the checkbox at the top and click Edit products. [L1190.013]
  3. Set the alt text to the product title as a dynamic value pulled from the store, then click Save. [L1190.013]
  4. Open each product image and rewrite its alt text to describe what the image shows, such as the view angle (for example, front view, front view with model, back view with model). [L1190.013]
  5. Save each change. [L1190.013]

Broken Links: Check My Links

  • Check My Links is a free Chrome extension offered by pagemodified.com. It checks every link on the page you are viewing and marks broken ones. [L0332.003]
  • It finds 404 links on other sites without clicking each link manually, which is too slow on pages with dozens of outgoing links. (Older advice, 2021-22.) [L0332.003]
  • Use Check My Links for broken link building. Searching the Chrome Web Store for "check my links" returns similar extensions, such as Link Redirect Trace from linkresearchtools.com and Redirect Link Checker. Use the extension offered by pagemodified.com. (Older advice, 2021-22.) [L0332.026]
  • Page Modified also offers a crawl of an entire website instead of only the open page. Use the full-site crawl when you need to audit every page of a site for broken links. (Older advice, 2021-22.) [L0332.025]

Installation

  1. Install Check My Links from the Chrome Web Store. [L0332.004]
  2. Chrome asks to add it with the permission to read and change all data on the websites you visit. Accept this to add the extension. [L0332.004]
  3. The default options can be left unchanged. [L0332.004]

Valid Link Caching Enable it so the extension stops re-checking good links that return HTTP 200. It only checks new links or links that were previously broken. This greatly reduces the time needed to recheck a page. The Clear Cache button resets it. L0332.008

Uptime Monitoring: Pingdom

  • Pingdom monitors the website every minute and sends SMS or email alerts on downtime. [L0575.023]
  • The base plan costs about $10 per month or $100 per year and covers up to five sites. [L0575.023]
  • A common alert threshold is 10 or 20 minutes of downtime, to avoid noise from brief hiccups. [L0575.023]
