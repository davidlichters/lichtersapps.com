5.10 Design, branding and image tools

Choosing the design tool

  • Canva is the fastest option for simple social posts, product graphics and quick exports. It ships with templates, animated icons, graphics, and stock photos and videos inside the app, so beginners can build without outside assets [L0754.001].
  • Canva is weak at layering and blending. Shadows and gradients come only as presets, and you have little control over how one object blends into another. Plan designs that do not need deep blending when working in Canva [L0754.002].
  • Canva has no pen tool and no real brush, and its draw tool does not auto-correct, so straight lines and custom hand-drawn shapes are hard to make. Build custom shapes in Illustrator or Photoshop [L0754.003].
  • Photoshop works mainly with pixels and is built for image manipulation such as cutouts, colour grading and photo compositing. It can also create vector shapes, which is why many designers choose it when they can learn only one of the two programs [L0754.005].
  • Illustrator creates scalable vector graphics from mathematical paths, so enlarging a logo or shape does not pixelate it. It is the right tool for logos, icons and custom drawn shapes [L0754.004].
  • Choose the tool by the job: Canva for speed and ready-made elements, Photoshop for image manipulation and advanced compositing, Illustrator for custom graphics and shape building. One designer can combine all three and move files between them [L0754.006, L0754.064].
  • Photoshop and Illustrator have a steep learning curve. Do not try to learn every tool first. Learn the basic controls, then look up the specific technique you need for the current problem [L0754.009, L0754.065].
  • Older advice (Source B, 2021 to 2022): professional software has unnecessary complexity for basic ecommerce tasks such as resizing and cropping, so simpler online tools are more practical for non-designers [L0300.005].
  • Online editor PicMonkey (older, 2021 to 2022): resizes, crops and adds text to images with no software installation or design experience needed. Free trial available; $7 per month for the basic plan [L0300.004].
  • Snappa is a simple online tool for custom article images. It has a free version and a paid version with extra features, is much simpler than Photoshop, and includes a curated set of stock photos [L0382.037].
  • Canva is browser-based. Its free plan is enough for basic store assets such as logos, favicons, banners and icons. Beginners without design training can use it; experienced designers can use Photoshop or another editor [L0342.001].

  2. Click Create API key.
  3. Choose the Gemini API Key option.
  4. Select an existing project or create a new one.
  5. Click Create key.
  6. Copy the key from the API keys list when a tool needs it. [L0794.001]
  • Treat the Gemini API key like a password. Never share it, paste it only into tools you control, and keep tool files private because the key is embedded in them. If a key leaks, revoke it in Google AI Studio and create a new one before running anything else [L0794.002].
  • Downloading course HTML tool files from Google Drive: click the three-dot menu on each file and choose Download. Do not open the raw code. Download every file of the set before first use, then open the HTML file locally in a browser [L0794.004].
  • Gemini image generation (Nano Banana) runs in the browser tools on the model gemini-3.1-flash-image-preview. Model names change. If a request returns a 404 error, check the Gemini API models documentation and update the model field in the tool [L0794.005].

Adding the key through a skill file (source procedure):

  1. In Claude, open Settings > Customize skills, click Add, and add the image skill folder.
  2. Open https://aistudio.google.com/apikey and sign in with a Google account.
  3. Click Create API key.
  4. Copy the key, which starts with AIza.
  5. Open the SKILL.md file and find the API Config section.
  6. Replace the placeholder line API KEY = 'YOUR GEMINI API KEY HERE' with your key, then save the file. [L0794.051]
  • Conflict: the skill-file procedure above places the key inside a file. The same key placed in a skill file travels with that file, so anyone you share the skill with can run jobs on your key and your billing account. Brand foundations: colours, fonts and brand kit

Colour

  • Color Hunt (colorhunt.co) shows pre-made palettes. Search by colour name or browse trending palettes. Hover over a palette to see all its hex codes, ready for design tools and websites [L0317.004].
  • Canva's free resource page at canva.com/learn/100-color-combinations offers curated palettes with hex codes, mood associations and design examples. Useful when unsure of brand colours. Older advice (Source B, 2021 to 2022) [L0323.014].
  • Canva palettes are arranged around the hue at the top. Tint moves the hue toward white, tone moves it toward grey, and shade moves it toward black. Use these controls to soften a colour instead of choosing a random new one [L0754.018].
  • Browser colour-picker extensions read the exact button colour from a store's website, so a pop-up button can match it [L0418.018].
  • The Eyedropper in the Canva colour palette picks any colour from an image [L0754.017].
  • Photoshop: press X to swap foreground and background colours and press D to reset them to black and white. Brushes, masks and gradients use these colours, so resetting avoids painting in the wrong colour [L0754.044].

Canva Brand Kit

  • The Brand Kit is available on the free plan and allows three brand colours. Path: Brand Kit > Brand colours > add colours. Black and white can be used alongside them. Saved colours then appear under the text colour option, so exact codes do not need to be remembered [L0342.004].
  • The Brand Kit lets you upload a logo, a colour scheme and fonts, then apply them to any design with one click. When a brand colour is missing, Canva can pull colours from an uploaded image [L0754.017].

Fonts

  • Google Fonts (fonts.google.com) offers free fonts licensed for commercial use. Search by name or filter by style such as serif, sans-serif or display. Download and upload them to design tools or Shopify themes without licence risk [L0317.011].
  • Canva's Text panel lets you search fonts by style, such as handwriting, corporate, display, serif, sans serif, luxury, elegant or vintage, and includes most popular Google Fonts. Speaker favourites named in the lesson were Lato, Montserrat, Open Sans and Rubik [L0754.026].
  • Use Open Sans as a plain sans-serif font for readable ad copy, and swap in your brand font if you have one. Keep body copy in a clean sans-serif rather than decorative fonts so text stays legible on small screens [L0343.009].
  • Use the brand serif font for packaging text so the packaging matches the brand's typography [L0884.036].

Kittl brand guidelines

  • Kittl has free brand guidelines templates. Workflow: Templates > search "brand guidelines" > choose a free template > open it. In the left sidebar, open the Project Colors panel, click a colour, replace its hex code with your new one and press Enter. All instances of that colour update automatically [L0317.009].
  • Hold Option (Mac) or Alt (Windows) and drag an element to duplicate it. This is faster than copy-paste when creating multiple texture variations in brand guidelines [L0317.023].
  • Brand guidelines templates do not support batch font replacement across the document. Update each text instance individually and plan for manual font updates [L0317.024].
  • The Brand Guidelines template shows project colours in code format. The lesson's screenshot shows the values 540863 and 24984o, which must be checked before use. The Browse Color Palettes option gives more palettes [L0884.030].

Brandfetch MCP (brand data extraction)

  • Brand Fetch MCP is a data extraction tool. It has two main functions: get_brand returns the visual identity as JSON (logos, colours, fonts, social handles, company metadata), and get_brand_context returns voice, ICP, positioning, product catalogue, tagline, mission and target audiences [L0318.002].
  • Brandfetch MCP is a Model Context Protocol connector for Claude. It extracts brand identity from any website: logo, hex colour codes, fonts, social media links and brand summary. It generates two files, brandkit.json and voice.md, in 5 to 7 minutes [L0322.001].
  • Processing takes 5 to 7 minutes before the brand kit and voice files are returned [L0322.003].
  • Naming difference: L0318.002 names the two functions get_brand and get_brand_context. L0322.015 lists six tools (Search Brands, Build Logo URLs, Identify Merchant from Transaction, Fetch Asset as Base64, Get Brand Details, Get Brand Context). The read-only tools extract logos, hex colours, fonts, social links and merchant data when you run the brand kit prompt [L0318.002, L0322.015].
  • Competitor research: use Brand Fetch MCP to study competitor brands' positioning, colours and voice. Do not copy their visual identity or tone. Use it as competitive intelligence to understand market positioning [L0318.017].

Install in Claude (setting):

  • Customize > Connectors > click the plus button > enter the name Brandfetch MCP > paste the MCP server URL from developers.brandfetch.com/dashboard into the Remote MCP server URL field > click Add > click Connect and authorise. [L0322.004]

  6. Go to Keys & MCP and copy the Brandfetch MCP URL.

Verification after pulling data:

  • If Brandfetch returns incomplete data or cannot detect a field such as the heading font, offer to have Claude visit the live website to verify and retrieve the missing information. This is faster than asking the user to supply details they may not recall [L0322.016].
  • Verify in this order before saving the final brandkit.json file, and fix any discrepancies:
    1. Primary brand colour: show the hex code and ask the user to confirm it matches the colour on their main buttons.
    2. Heading or title font: if Brandfetch detected it, confirm with the user. If not, request it directly or retrieve it from the live site.
    3. Social media links: confirm each one (Instagram, Facebook, etc.) is current and correct. [L0322.017]

Logos

  • Canva is a simple option for creating a logo yourself when the design is basic [L0357.053, older: 2019].
  • Canva's free plan is enough for logos, favicons and icons [L0342.001].
  • Fiverr is the recommended platform for logo design at startup. It balances affordability with quality and offers a curated marketplace where you can browse portfolios, compare prices and read reviews before buying. Older advice (Source B, 2021 to 2022) [L0323.013].
  • Filter Fiverr's logo section by your maximum budget (set to 100 USD in the source), desired style and delivery time. This narrows the 183,000+ available services to your needs [L0323.019].
  • When evaluating Fiverr designers, prioritise those with 1,000+ completed jobs and 4.8+ star ratings. Designers with 50+ solid reviews are also dependable [L0323.020].
  • Many Fiverr logo designers specialise in one aesthetic: minimalist, mascot, hand-drawn or vintage. With a specific style preference, search for designers who specialise in that style rather than generalists [L0323.027].
  • Request a source file in Photoshop or Adobe Illustrator format from the designer, so the logo can be edited later without starting from scratch [L0323.018].

Fiverr logo procedure:

  1. Choose three hex colour codes (primary, accent, button) and record them.
  2. On Fiverr.com, navigate to Graphics & Design > Logo Design.
  3. Filter by budget (under 100 USD) and review designer portfolios, ratings and reviews.
  4. Click on a designer whose style you like and review their package details and revision policy.
  5. Click Continue to proceed to checkout and provide your business name, colour codes, business description and target market feel.
  6. Complete payment via credit card or PayPal.
  7. Receive your logo files in the specified timeframe.
  8. Request revisions if needed, then download and accept the final files. [L0323.021]

Building logos by hand:

  • Illustrator's Shape Builder merges overlapping shapes into one outline when you drag across them. Hold Alt or Option while dragging to remove unwanted areas. It is the main method for building logos from several overlapping shapes [L0754.056].
  • Use separate shapes for each part of a logo or icon, then combine them with the Shape Builder, rather than drawing the final outline in one go. This makes it easier to correct one part without redrawing the whole mark [L0754.063].
  • Canva logo export: when downloading a logo, choose JPG as the file type and raise the quality slider from the default 80 percent to 100 percent. The default export size shown was 500 by 500 pixels [L0471.063, from 2024].
  • For a logo on coloured backgrounds, a transparent PNG is the cleanest option. Make one by using a free online background remover (search for background image remover), which deletes a white background so the PNG becomes transparent [L0342.011].

Product images: sourcing

  • Use royalty-free image sources for product photos, such as Google's royalty-free image search or the free stock site Pixabay. These are safer than competitor photos. Older advice (Source A, 2020) [L0468.083].
  • Google Image Search with the filter Labeled for commercial reuse (Settings > Usage rights > Labeled for commercial reuse) gives free, legally usable product images for demo stores without buying licences. Older advice (2020) [L0245.033].
  • Stock photo route (older, 2020): start with Google Image Search, then refine with free royalty-free stock sites (20+ options listed in the source). You need at most 10 images for 5 demo products plus a homepage banner [L0268.056].
  • Use Canva for product images and Google royalty-free image search for product images without people when Canva has none. Older advice (2021) [L0834.058].
  • Unsplash offers free stock photos. For a discount pop-up, search a keyword such as gift. For a chat avatar, search man or woman. Download the image and upload it into the app [L0477.043].
  • 123RF has millions of images at $2 to $3 per photo. Use it when supplier images are unavailable or low quality. Older figure (2021) [L0270.054].
  • Snappa includes a curated set of stock photos [L0382.037].
  • Canva's built-in stock photos are paid only on the paid plan (see plans table) [L0342.002].

Background removal and cut-outs

Canva background removal (Edit photo):

  • Select the product photo, open Edit photo and use the background removal option to cut out the product automatically. The result is not always perfect, so use the adjust options to add back or erase parts of the cutout. Select Remove background, then use Adjust for small areas [L0341.007, L0343.005].
  • Edit photo includes a Background remover that removes the background of an uploaded product image automatically. A brush tool then removes leftover parts. Auto-focus blurs the background around a subject, and the Shadow option adds a shadow to an element [L0754.022].

PhotoRoom (AI product scenes):

  • PhotoRoom is an AI app for product photos. It cuts out an object, such as a coffee cup, and places it on instant backgrounds such as wood countertops, bathrooms and jungles. It creates reflections and shadows and is available on mobile and desktop [L0353.030].
  • Product photos in PhotoRoom:
    1. Choose Start from photo, then Camera.
    2. Cut out the product.
    3. Choose Instant backgrounds and pick a background from the list. The app fills in several backgrounds.
    4. Adjust the image with the shadows and highlights controls and with background blur. [L0353.031]
  • A phone snapshot can be pixelated, and a low-resolution source gives a poor result. Use a better source photo [L0353.032].
  • In PhotoRoom's desktop editor, a Shadows drop-down adjusts shadows and highlights across the whole image. The background options include a blur switch that softens the backdrop behind the cut-out, which makes the product stand out [L0353.059].

Photoshop and other cut-out options:

  • Clipping Magic (about $5 per month) removes image backgrounds to produce cut-out product PNGs for floating images [L0418.016].
  • Unscreen (video background removal) and similar tools can extend a background image. A generative fill tool expands a cropped hero background [L0418.019].
  • Photoshop's Select Subject command detects the main subject automatically. The Object Selection tool and Lasso tool add or remove areas. Use them together when the automatic result misses parts of the subject [L0754.034].
  • Cut out a subject with Select and Mask:
    1. Open the Select menu and choose Subject, or use the Select Subject button in the toolbar.
    2. Click Select and Mask to open the refinement panel.
    3. Use the brush to add missing parts, and hold Alt or Option to subtract unwanted areas.
    4. In the edge settings, use Smooth to soften jagged edges, Feather for a soft edge, and Contrast to sharpen the edge.
    5. Drag Shift Edge inward slightly to remove white fringing around the outline.
    6. Click Output To and choose Layer Mask so the cutout stays editable. [L0754.038]
  • Photoshop masks hide or reveal areas of a layer: white reveals, black hides. The invert shortcut is Ctrl+I or Cmd+I. Masks cut an object out without deleting pixels, so the edit can be undone at any time [L0754.039].
  • Painting with the eraser on a normal image layer is destructive: removed pixels cannot be restored. Apply the removal to a layer mask so the original image stays intact [L0754.040].

Product image editing and backgrounds

Canva:

  • To set a photo as a background, drag it onto the page, right-click it (or two-finger click on a trackpad) and choose Set image as background. Then move the image so the important part is visible [L0342.020].
  • Canva's undo reverts the last change, which allows experimenting with fonts, colours and sizes without losing work [L0342.034].
  • Canva templates are ready-made layouts searchable by keyword, for example blog. Use Use Template or Add as new page. Templates speed up designs such as blog headers and sale banners [L0342.033].
  • Canva Source A templates: open the provided link, which opens a template already sized for the Manhattan theme, then click Use Template to start editing [L0098.003].
  • A free online background remover deletes a white background so the PNG becomes transparent. A transparent PNG is the cleanest option for logos and icons on coloured backgrounds [L0342.011].

Photoshop:

  • Generative Fill can add or change elements of an image using AI, and it can be used alongside AI background tools [L0353.033].
  • Generative Fill creates or replaces content from a selection and a text prompt. At the time of recording it was at an early stage with uneven results. Expect several iterations before accepting one [L0754.052].
  • Adding realistic light falloff to a composited subject:
    1. Create an Exposure adjustment layer above the subject and lower the exposure so the subject matches the darker background.
    2. Clip the exposure layer to the subject so it affects only that subject.
    3. Press Cmd+I or Ctrl+I to invert its mask, which fills the mask black and hides the effect.
    4. Set a soft brush with low opacity and paint white over the areas that should be darker, such as parts not lit by the background light.
    5. Add a solid colour or Hue/Saturation layer clipped to the subject to match the colour of the background light.
    6. Set the layer to a blending mode such as Overlay or Color Burn, then use the Blend If sliders to blend the colour into the subject. Hold Alt or Option to split the sliders for a smoother blend. [L0754.046]
  • Blend If sliders (in Blending Options) blend a layer based on the brightness of the layer below. Holding Alt or Option while dragging splits the slider for a smooth transition instead of a hard edge [L0754.047].
  • Clipping mask: hold Alt or Option and click the line between two layers to apply an adjustment layer only to the layer beneath it. Without clipping, an adjustment layer affects the whole artboard [L0754.045].
  • Adjustment layers change colour, brightness, contrast, levels, curves, exposure, hue and saturation, photo filters and colour balance without changing the underlying pixels. Each adjustment can be turned off or edited later, so it counts as a non-destructive edit [L0754.043].
  • Scaling a rasterised pixel image makes it pixelated, while a smart object keeps its quality when resized. Convert the layer to a smart object before scaling. A smart object cannot be painted on directly [L0754.041].
  • Right-click a layer and choose Convert to Smart Object. To edit its contents, click the smart object icon at the bottom right of the layer thumbnail, change the content and save. The change updates everywhere the smart object is used [L0754.042].

Resizing and compressing for the store

  • Canva free has no resize tool. For a different banner size: Canva Home > Create a design > Custom size, enter the dimensions, and recreate the banner [L0098.018].
  • Canva paid resizes existing designs with its built-in resize tool [L0098.005, L0342.002].
  • Bulk Resize is a browser tool with no sign-up and batch processing. It resizes and compresses image files, converts to PNG or JPEG, and can reduce size from about 2.3 MB to about 54 KB [L0418.017].
  • Hero background image: resize to about 1,200 px wide as JPEG with reduced quality (about 40 to 50 KB) for faster load speed. Set the main page size to about 700 px on desktop [L0418.020].
  • Compress image files before uploading to reduce page-load impact. ImageOptim is a free desktop app for Mac [L0300.006, older: 2021 to 2022].
  • Windows has built-in image compression. Setup and usage instructions are in Microsoft's official support documentation [L0300.007, older: 2021 to 2022].
  • Photoshop: to scale safely, convert to a smart object first. Adjust the Free Transform scale with Ctrl+T or Cmd+T, hold Shift to lock the ratio, and right-click the transform to choose Warp [L0754.035, L0754.041].

Batch image tools (Gemini-based)

Set up and run first:

  • Keep the HTML tool files and the key private. Enter the key at run time, not in a shared file [L0794.002, L0794.052].
  • Download the tool files completely and open the HTML locally in a browser [L0794.004].
  • Browser folder linking (Chrome or Edge only):
    • Click Link download folder, pick the target folder in the Select folder dialog, then click Allow when the browser asks Allow this site to edit files? [L0794.050]
    • Without a folder picker, outputs download automatically as JPG files. When a folder is linked, every output is written straight into it, which keeps batch files organised [L0794.015].

Tools:

  • Brand Remap Studio is a local HTML tool with three inputs: 1 to 3 brand reference images, up to 5 competitor layout images and an optional book cover. It returns one rebranded image per competitor layout that keeps the layout and swaps in your colours, logo and typography [L0794.006].
  • Book Scene Studio creates up to 50 scene photos of one book in a single batch, keeping the same cover on every shot. Upload 1 to 3 angles of the cover, enter one scene per line, set the aspect ratio and run the batch. A Shuffle button is available for the scene list [L0794.007].
  • Batch Image Converter (A4) processes up to 50 of your own images in one batch. One reference image teaches the page layout and style. A format prompt is sent with every frame so all outputs look like one set [L0794.008].
  • Image Proofer uses the vision model gemini-2.5-flash to read the text in an image, correct spelling and regenerate the image with the corrected text. It accepts up to 100 PNG files for ad creatives, advertorials, labels and social posts. It has an AUTO or ENGLISH language setting and outputs corrected JPGs [L0794.009].

Procedures:

  • Brand Remap Studio run:
    1. Open the HTML file locally and paste your Gemini API key.
    2. Upload 1 to 3 brand reference images into box 1.
    3. Upload up to 5 competitor layout images into box 2.
    4. Optionally upload one book cover into box 3.
    5. Choose the aspect ratio: match competitor, 4:5, 1:1, 9:16 or 16:9.
    6. Set Concurrent to 2 and Pause (sec) to 0 as a start.
    7. Keep Relax content filters checked.
    8. Optionally click Link download folder.
    9. Click Remap all and watch the total, done, ok and failed counters.
    10. Read every output before using it. [L0794.010]
  • Brand Remap Studio names outputs remap-01.jpg, remap-02.jpg and so on, in the order the competitor layouts were uploaded. If one layout fails, no file is written for that number, so rerun only that layout [L0794.053].
  • Image Proofer run:
    1. Open the HTML file locally and paste your Gemini API key.
    2. Upload up to 100 PNG images (ad creatives, advertorials, labels, social posts).
    3. Set the language to AUTO or ENGLISH.
    4. Keep the vision model at gemini-2.5-flash.
    5. Set the JPG quality and the pause between batches, and keep concurrency low.
    6. Click Proof and regenerate, then check the corrected JPGs before using them. [L0794.011]
  • Batch Image Converter run:
    1. Open the HTML file locally and paste your Gemini API key.
    2. Select the A4 portrait page format (210 x 297 mm).
    3. Upload one reference image that shows the wanted layout and style.
    4. Write the format prompt once. It is sent before every frame.
    5. Upload your own batch of up to 50 images.
    6. Optionally link a download folder.
    7. Click Convert all images and wait.
    8. Check every output and rerun any missing frames.
    9. Run the finished pages through Image Proofer, then assemble them into one PDF. [L0794.012]

Rate limits and output:

  • Concurrency of 2 is the safest setting for the batch tools. Failed requests are retried automatically up to 5 times. If image generation returns 429 rate-limit errors, lower the concurrency or raise the pause in seconds [L0794.013].
  • Repeated 429 errors mean the batch is sending requests too fast. Running at full concurrency wastes time and retries. Lower the concurrent count or add a pause between requests, then restart only the failed items [L0794.014].
  • Image Proofer splits uploads into batches. Concurrent sets how many images run at once inside one batch. Pause sets the wait between batches. On 429 errors, lower Concurrent or raise the pause, then rerun only the failed images [L0794.054].
  • Outputs are saved as JPEG at quality 0.92, with a white background behind any transparent areas. Batch limits: Remap up to 5 competitor images, Converter up to 50, Proofer up to 100 [L0794.017].

Packaging and mockups

Packaging workflow:

Canva technique reference

Selecting, moving and sizing:

  • Hold Shift while clicking elements to select several at once, or drag a box across them to select all within it and move them as a group. Pressing Shift again on a selected object removes it from the selection [L0754.011].
  • Drag a corner handle with Shift held to keep the aspect ratio locked while resizing. Corner handles resize both axes; side handles resize one axis. After the ratio is set, release Shift and drag a handle to reshape [L0754.012].
  • Hold Alt on Windows or Option on Mac while dragging an element or handle to work from its centre point instead of an edge. The same key duplicates an element when dragged, which is faster than copy and paste for repeated items [L0754.013].
  • Hold Shift while dragging to lock movement to one axis, so an element does not move up or down while you move it left or right. Zoom with Ctrl (Windows) or Cmd (Mac) while scrolling [L0754.021].

Alignment and grouping:

  • Pink snap lines appear while dragging an element to align it to the left, centre or right edge of another element [L0754.014].
  • Align and space objects:
    1. Hold Shift and click the objects you want to align, or drag a box around them.
    2. Open the Position menu in the top toolbar.
    3. Choose the alignment you need (left, centre, right, top, middle or bottom).
    4. Choose Space evenly horizontally or vertically to make the gaps equal.
    5. If the spacing still looks uneven, group the objects first and then apply Space evenly. [L0754.015]
  • Press Ctrl+G (Windows) or Cmd+G (Mac) to group selected objects so they move as one unit. Double-click an object inside a group to isolate it. Ungroup with Ctrl+Shift+G or Cmd+Shift+G [L0754.016].

Layers:

  • Right-click an element, open Layer, and choose Bring Forward or Send Backward. Ctrl+[ or Cmd+[ moves an element one layer back; Ctrl+] or Cmd+] moves it one layer forward. Adding Alt sends it to the very back or very front [L0754.019].
  • Every element sits on its own layer, and stacking order decides what is on top. Text placed first sits under shapes placed later, so move layers deliberately when a design looks wrong [L0754.020].

Effects and editing:

  • Shadows and gradients: search Elements for "shadow gradient" or "shadow" to get many ready-made options in dark and light, long and short versions. Place them behind text or a product to add depth [L0341.019, L0343.016].
  • Speech bubbles: Canva has fewer layout and text-bubble options than Photoshop, so speech-bubble testimonials are harder to build in it. Plan the layout around that limit, build the bubble parts elsewhere, or keep the Canva version to plain quote cards [L0341.010, L0343.041].
  • Canva Edit photo's Shadow option adds a shadow to an element [L0754.022].

Photoshop technique reference

Shapes and transforms:

  • Free Transform: Ctrl+T (Windows) or Cmd+T (Mac). Hold Shift to lock the ratio while scaling. Right-click the transform to choose Warp to bend or distort the shape [L0754.035].
  • Press V to return to the Selection tool. Hold Alt or Option while dragging to duplicate an object. Hold Shift while drawing a shape to keep it square or circular. Alt or Option while dragging a shape from its centre draws it outward from the centre point [L0754.036].
  • To make a shape blurred, such as a soft shadow, rasterise or convert it to a smart object, then choose Filter > Blur > Gaussian Blur. Lower the Fill opacity in the layer panel to make the shadow subtler [L0754.051].

Layers and blending:

  • Double-click a layer to open Blending Options (Layer Properties). Darken removes whites from the layer above, Lighten removes darks, and Overlay merges the two layers [L0754.037].
  • Drop shadow: add it from the FX panel at the bottom of the Layers panel. Settings include angle, opacity, distance, spread and size, which control direction, strength and softness [L0754.048].

Repair:

  • Spot Healing Brush removes blemishes, dust and small unwanted objects with one click or brush stroke. Clone Stamp copies pixels from a sampled area: hold Alt or Option, click the source, then paint over the spot [L0754.050].

Illustrator technique reference

Select and Mask

  • Heavy Photoshop work with many open files can freeze or slow a laptop. For smooth work, use a more powerful machine, and check that the required Lightroom app is available in the Adobe account before starting. [L1132.017]
  • Select Subject creates a fast automatic selection of the main subject and needs enough RAM to run smoothly. On a weak machine it can lag or stall, so save work often before running it. [L1178.006]
  • The Select and Mask left toolbar includes Quick Selection (add or subtract), the Refine Edge brush for hair and fine edges, and Brush and Lasso tools for manual cleanup. Use the Refine Edge brush mainly on hair or a beard, where simple selection leaves stray pixels. [L1178.007]
  • Object Selection tool (square icon in the left toolbar) selects a whole object in one smart step. Use it to add back an item such as a mirror, or to select a full body. It gives less control than the brush, so use it for rough selections, then refine the edges manually. The brush handles small gaps. [L1132.019, L1178.030]
  • Polygonal Lasso draws straight-line selections, and the freehand Lasso draws free shapes. Both close gaps where enough pixels surround the area. Both leave a jagged, pixelated edge, so smooth the edge only after all cutout edits are finished. [L1132.020, L1178.008]
  • In Select and Mask, the red overlay marks the unselected area. Change its color in the top-right panel, which also offers other view modes. A different overlay color makes hair and edge gaps easier to see against a dark or light product. [L1132.021]
  • Brush add and subtract: the brush should show a plus icon by default, which adds to the selection. Holding Shift switches it to minus to remove. [L1132.022] The lesson's modifier keys conflict, so check the icon before each stroke. In Select and Mask, Alt subtracts and Shift adds. [L1178.026] If the icon appears flipped, add and remove are reversed. Check the icon before painting to avoid cutting away parts you want to keep. [L1132.022, L1178.026]
  • Output To setting: choose Selection only to keep the background out without hiding it. Choose Layer Mask to hide the background non-destructively. Use Layer Mask for cutouts that can be re-edited later. [L1178.005]

Brush and retouching

  • Brush size and feather shortcut: hold Alt, hold right-click, move left or right to change brush size, and move up or down to change feather. Alt plus mouse wheel zooms in and out. [L1178.004]
  • Spot Healing Brush removes small spots, hairs and blemishes by blending them with the surrounding area. Feather it slightly so the fix blends in. Work with short, sharp clicks instead of dragging, since dragging smooths the area out. [L1178.009]
  • Use the Spot Healing Brush with the same Alt plus right-click drag as the brush. Keep the brush small and use a little feather so the repaired spot blends with its surroundings. [L1132.025]
  • Using Spot Healing with a large brush or on high-contrast edges changes the texture around it too much. Keep the brush small and check each click in areas with strong contrast. [L1178.011]
  • Clone Stamp copies pixels from one area to another. Hold Alt to set the source point, release Alt, then paint over the target area. The copied area keeps its lighting, so it can look too bright or too dark when moved. Watch the light direction. [L1178.010]
  • The Clone Stamp source moves with the cursor, so a long stroke copies the sampled spot repeatedly and creates visible duplicates. Sample a new source area with Alt-click often, and avoid dragging across the same sampled spot for a long distance. Sample from different points, and drag the source from the side where the light falls on the same surface. [L1132.026, L1178.012]

Adjustments

  • Adjustment layers (circle icon at the bottom of the Layers panel) apply changes such as exposure, hue/saturation, black and white, or whites and blacks above the photo without altering its pixels. Dragging the adjustment layer to the trash removes the change and restores the original image. [L1132.023]
  • In Hue/Saturation, hue sets the color itself, and saturation sets how strong that color is. To reduce a color cast on a garment against a white background, lower saturation so the color moves toward grey or black instead of changing the hue. [L1132.024]
  • Lowering Saturation on a tinted area, such as a blue cast on a white T-shirt, neutralizes it. Used as an adjustment layer, the original photo stays unchanged. [L1132.024, L1178.031]

Lightroom and Photoshop round-trip

  • Edit the image in Photoshop and save with Control+S so the edited version syncs back into Lightroom. Keep the originals in the cloud, so only picked images are downloaded temporarily to the laptop. [L1132.016]
  • After editing in Photoshop, save with Ctrl+S, close the file, and the edited version returns to Lightroom. Quick crops and basic adjustments are faster in Lightroom. [L1178.021]
  • Export a finished Photoshop image as PNG: File > Export > Export As, choose PNG, and save. [L1132.015]
  • Without Lightroom, export with File > Export > Export As > PNG. This keeps the cutout with transparency for use in a store or design file. [L1178.022]
  • Lightroom photos stored in the cloud download only temporarily when you open them. A laptop with limited storage can still work through a large shoot. Open only the shots you are editing. Lightroom must be installed and linked to the Adobe account. [L1178.032]
  • Lightroom Crop tool: grab a corner and rotate or move the image within the frame to straighten a skewed photo. Use this to level the product before applying a 1:1 square crop. [L1199.033]
  • Round-trip from Lightroom to Photoshop and back for a product image:
    1. Select the photo in Lightroom and send it to Photoshop to cut out the product. [L1199.035]
    2. Make the cut-out and background in Photoshop. [L1199.035]
    3. Save the file. [L1199.035]
    4. Close the Photoshop document, so the edited version updates in Lightroom. [L1199.035]
    5. Apply the final 1:1 square crop and light corrections in Lightroom. [L1199.035]
  • Create a square product canvas in Photoshop:
    1. Select the Artboard tool and draw a square artboard. [L1199.036]
    2. Set the artboard size to 1080 by 1080 pixels, the standard for product images. [L1199.036]
    3. Move the cut-out product into the center of the artboard and draw the artboard around it. [L1199.036]
    4. Save so the file updates in Lightroom. [L1199.036]

Image Resizing, Compression and Export

  • Pixlr is a free web-based image editor that crops images to exact sizes. It is a free alternative to the more expensive Photoshop and is useful for resizing images before upload. Older (2019). [L0960.047]
  • PicMonkey is an online image editor for resizing and cropping. Its resize function is called Smart resize. Older (2021-22). [L1310.012]
  • In PicMonkey, open Edits > Canvas Edits > Smart resize. Enter Width and Height, use the percentage option if needed, then click Apply, or Cancel to discard the change. Older (2021-22). [L1310.013]
  • ImageOptim is a desktop app for Mac that compresses images. Drag the image into its window, and it reduces file size without a noticeable loss in quality. Older (2021-22). [L1310.014]
  • ImageOptim's default lossy minification is JPEG 84%, PNG 80% and GIF 80%. In the tested case, a JPEG of nearly 300 KB dropped to 102 KB, a saving of about 65 percent. Older (2021-22). [L1310.015]
  • ImageOptim is an offsite tool for compressing images before upload. It is more reliable than Shopify apps that compress images inside the store. Older (2021-22). [L1522.038]
  • Image processing on a Shopify store can be handled by an outsourced Photoshop automation rather than an app. On-site image apps can slow the store and reduce image quality. Older (2021-22). [L1456.027]
  • Compress exported PNG or SVG logo files after the design is final. [L0952.050]
