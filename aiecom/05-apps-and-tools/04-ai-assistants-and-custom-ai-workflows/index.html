5.4 AI assistants and custom AI workflows

Choosing and starting with AI chat tools

  • ChatGPT is the most widely used AI chat tool. It works well for writing copy, generating marketing ideas, explaining concepts and learning new topics, and it is very beginner friendly. [L0887.001]
  • Claude is a strong AI chat tool for longer written content, more structured answers, analysing information, deep thinking and problem solving. Choose it when a task needs careful analysis or a clearly organised output. [L0887.002]
  • One AI chat tool, either ChatGPT or Claude, is enough to start. Pick one and begin using it daily instead of overthinking the choice. [L0887.003]
  • For long, structured prompts that must analyse customer reviews, Claude tends to outperform ChatGPT. When the output matters, run the same prompt and inputs in both tools and keep the better result. [L0887.004]
  • Use AI chat as the first point of contact for any store, marketing or business question, before asking a community or coach. It is available around the clock and can be used whenever a problem appears. [L0887.005]
  • ChatGPT and Gemini produce equivalent brand name suggestions for dropshipping stores. Choose by personal preference or current access, because output quality does not differ. [L0320.006]
  • The free version of ChatGPT contains all functions needed for niche brainstorming, so no paid plan is required. It can expand a broad category into specific product ideas. [L1056.011]
  • The free version of ChatGPT is used to create content outlines and bullet points, not finished articles. The output is a starting structure that a person writes out in their own words. [L1321.008]
  • The operator in one lesson reported that ChatGPT is free to use and keeps earlier conversation context, so later requests can build on earlier topics. [L0440.022]
  • ChatGPT Professional cost about 20 dollars per month at the time the lesson was recorded (2023). It gives access to browsing and plugins that can pull data such as Amazon reviews. Use the base version when you only need copy generated from your own inputs. [L0516.048]
  • The free plan of Claude has a message limit that can cut off a long generation mid-output. This happened when an ebook HTML file was truncated. Retry later, or use a paid plan and generate a full ebook in several steps. [L0862.021]
  • Gemini asks for a login before it imports files. Attach the competitor video and exported brand data from a logged-in account, because file upload in the chat does not work without it. [L0374.006]
  • ChatGPT Playground at platform.openai.com/playground is a free-to-use alternative when regular ChatGPT sign-up is blocked. It handles the same text tasks: product descriptions, ad copy, ad strategies, and preset answers for live chat. [L1428.001]
  • Chat-based research works best with product context. When asking about any product, describe your current work first (for example that you run a Shopify store) to get more relevant output. [L0972.034]

Prompting rules and inputs

Giving the AI the right context

  • A large language model answers from its training material. Always state the exact sources, definitions and step-by-step method the AI should follow, because it otherwise falls back on safe, generic answers. [L1478.007, L1478.003]
  • Give the model as much product information as possible before asking for specific outputs. [L0321.022]
  • When asking AI for help with a store problem, always state the platform (for example Shopify), the theme you use (for example the Elixir theme), the exact element involved and what happens instead. Without this context the answer will be generic. [L0887.008]
  • When a prompt asks for Amazon listing data, take the title and bullet points from the product's Amazon listing and collect 3-5 detailed real customer reviews. Output quality depends on these inputs, so do not skip them. [L0887.007]
  • Standard ChatGPT ad writing needs the product facts, the problem, the feeling and the benefit supplied in the prompt. [L1427.064]
  • Brand guidelines given to a chat AI: provide only the cover page as a screenshot and the colour palette, not the full PDF. The AI may not read PDFs visually well, and too much information can confuse it. [L0884.023]
  • Do not upload more than two PDF pages to ChatGPT. Upload only what the AI needs to see, because large PDFs reduce the quality of its output. [L0884.024]

Working in threads

  • ChatGPT keeps earlier messages in the same chat, so follow-up requests can refine earlier output without restating the product or business name. Keep one chat per topic so the context stays relevant. [L0440.067]
  • ChatGPT keeps the conversation context, so follow-up requests such as making text funnier or more emotional work without repeating the product details. It is useful for copywriting, ad copy, headlines, product descriptions, bullet points, video captions, brand name ideas, and colour palettes or hex codes. [L0605.010]
  • ChatGPT retains context throughout a thread, so you can refer to previous examples and ask for variations. [L0321.023]
  • An AI chat assistant works well as a sounding board. Describe your current work and ask for feedback or ideas, including through phone voice mode. For each specific task, ask the AI to write a detailed prompt for you, then edit it. [L0972.105]

Reusable prompt patterns

  • Use a short, concrete prompt that names the problem, the goal and the number of options you want, so the AI proposes several solutions instead of one guess. Pattern: state the problem, state the desired outcome, then ask for three options. Examples: "My export file opens with broken characters; I need a clean CSV for Excel; what are three ways to fix this?" and "My agent keeps skipping the scoring step; I need every candidate scored; what are three changes I could make to the instructions?" [L0366.017]
  • Beginner prompt for a stuck problem, which asks for options and then for changes to agents.md so the problem does not recur:
I am a beginner and I am stuck on this problem: [describe the problem]. I need this solution: [describe the goal]. What are three options you could give me, with the pros and cons of each? Once I choose one, tell me which lines to add or change in agents.md so the same problem does not happen again.

[L0366.018]

  • Regularly put these kinds of prompts to an AI tool and tailor the specifics to the product you sell:
Regularly put these kinds of prompts to an AI tool and tailor the specifics to the product you sell: ask it to break down a dropshipping idea for someone new to the field, ask it to draft a description for a given item, ask it for five marketing angles worth testing on that product, and ask it why your ads might not be turning visitors into buyers. The more of these questions you ask, the more helpful the AI becomes for your business.

[L0887.011]

  • Using a ready-made prompt from the course library:
    1. Find the prompt that matches your task, for example the one for store building. [L0887.006]
    2. Copy the complete prompt, including all instructions and section names. [L0887.006]
    3. Paste it into ChatGPT or Claude as a new chat. [L0887.006]
    4. Fill every required input: the Amazon listing title and bullets, the product description and 3-5 detailed customer reviews. Add your brand name and product name where the prompt asks for them. [L0887.006, L0887.007]
    5. Press send and wait for the full output. [L0887.006]
    6. Use the sections in the order the prompt generates them. [L0887.006]

Checking generated prompts

  • A generated prompt must make sense before it is run. Read it, check it against your brand and product, and fix anything unclear. If you are unsure how to phrase a prompt, ask Claude to draft it and review the draft instead of running it blindly. [L0794.042]
  • Dictating your brand, product and process aloud and having Claude turn that into a prompt is faster than typing. Check that the resulting prompt matches your brand before running it. [L0794.043]

Structure for product page and ad prompts

  • Structure for using ChatGPT to generate product page copy:
Structure for using ChatGPT to generate product page copy:
1. Provide product category and name.
2. List product benefits found from competitor research.
3. Define your role: "You are a professional copywriter."
4. Ask specific question: "Provide a one-line USP for this product that shows the benefit and differentiates from normal [alternative]." Then iterate on the response.
5. For bullet points: "Provide four benefit-driven bullet points (not features) describing what customers will experience when using this product."
6. For FAQ: "Generate four common questions and answers for our product."
7. For paragraphs: "Provide a two-to-three-line paragraph that describes [specific aspect] in a benefit-driven tone."
8. For rewrites using another product as reference: "I have this copy for another product [paste example]. Generate similar copy for our product [product name]." ChatGPT retains context throughout the thread, so you can refer to previous examples and ask for variations.

[L0321.023]

Custom AI assistants and Claude projects

What a custom assistant is

  • A custom AI assistant is a general LLM such as Claude or ChatGPT loaded with your own instructions, product information, templates and step-by-step processes. At minimum it can read and produce any text task. Visuals depend on the platform and LLM used. [L0485.017]
  • In Claude, a project holds the assistant's instructions and reference files. The instructions specify how to create particular ad types or how to research ideas, and the files provide brand-specific information. [L0485.018]
  • A custom assistant's output quality depends on the instructions: a large body of detailed instructions, based on a proven system, keeps the output on the right path. The assistant then produces research documents, scripts and visual assets from the information it was given. [L0485.021]
  • A generic LLM without brand-specific instructions and files produces generic research based on general sources such as platform guidelines or old top search results. This dilutes the messaging and can lead to a poor creative path. [L0485.020]
  • Example kickoff prompt for a market study. Before sending it, upload the product description and the brand's internal strategy documents into the assistant's workspace, so the study follows your own methodology rather than generic sources. Specify that the results arrive in the layout your templates prescribe.
Hello Magnus. First go through the attached product description, and afterwards run a market study for our label.

[L0485.019]

Files and capacity

  • Reference files for a Claude project can be uploaded as Markdown (.md) or Word (.docx) files. The format affects how easily the assistant reads them. Markdown is generally easier for AI to parse, so mixing formats is workable, but plain-text files are the better default. [L0485.032]
  • The Files panel of a Claude project shows a capacity indicator with the percentage of project capacity in use. In the example, about ten brand files used 15% of capacity. [L0485.033]
  • For the script prompt to produce a usable script, add five reference files to the Claude project: a voice guide, a structure library, a banned word list, an avatar, and a psychology lens. Without these files the script stays generic and must be checked by hand. [L1140.028]

AI agent folders (Codex and Claude Code)

Concepts and set-up

  • Codex is a desktop app from ChatGPT that can run AI agent folders on your computer. As of May 2026 it was recommended for beginners over Claude Code, because you link your existing ChatGPT account and set-up is simpler. [L0366.001]
  • Codex and Claude Code can be compared as follows. Claude Code is the folder-instruction tool with claude.md, and Codex uses agents.md. For the email workflow, the two are comparable in level. [L0366.002, L1361.002]
  • The agents.md file is the most important file in an agent folder. It holds the standing instructions that shape how the AI behaves in that folder. [L0366.003]
  • Agent folders can be downloaded from GitHub, which also makes it possible to deploy and update them later. A downloaded folder is then opened locally in Codex. [L0366.004]
  • Create one dedicated AI folder on your computer and place agent folders inside it. Anything dragged into that folder structure is visible to the AI, so keep sensitive data such as credit card details out of it. [L0366.005]
  • Keep one master AI folder on your computer and place each agent folder inside it as a subfolder. Open each agent folder separately in Codex, because each opening starts its own chat scoped to that folder. [L0366.027]
  • To connect an agent folder, open Codex and go to File > Open folder, then select the agent folder. Codex starts a new chat scoped to that folder. [L0366.007]
  • In the Codex chat window, the access setting is at the bottom and set to Full access for this agent, so the agent can run without asking for each action. The model is set to 5.5 with reasoning effort at Extra High, shown in the same selector. [L0366.008]
  • In the Codex chat composer there is a Toggle /Fast option that makes responses faster. Codex may suggest enabling it based on past usage, and it increases plan usage. Keep Extra High reasoning for careful agent work where depth matters more than speed. [L0366.025]
  • Review and Undo: after an agent edits files, Codex shows a count such as Edited 3 files with Undo and Review buttons. Review lists each changed file with its line changes, for example +9 -2 for nine lines added and two removed. Check every change before keeping it, and use Undo to revert. [L0366.009, L0366.026]

  1. Download the agent folder, for example from GitHub, and place it inside your dedicated AI folder. [L0366.010]
  2. Open Codex and go to File > Open folder, then select the agent folder. [L0366.010]
  3. Set access to Full access and the model to 5.5 with Extra High reasoning. [L0366.010]
  4. Start a new chat and send the security-check prompt before anything else runs. [L0366.010, L0366.011]
  5. Open the handoff document and the startup prompt file yourself and read them, if you want to see them directly. [L0366.010]
  6. Read the agent's explanation of what will happen and check that it matches what you want. [L0366.010]
  7. Click go to load the agent and start its workflow. [L0366.010]
  8. Answer the setup questions the agent asks before it begins searching. [L0366.010, L0366.013]

Security-check prompt:

Please explain what is inside this folder and what it is for. It is a project I want to start working on. Check whether anything in it is malicious or could harm my computer or my data. Then explain step by step what will happen when we start, beginning with an analysis of the handoff document and the startup prompt, so I know what I am agreeing to before anything runs. Do not change, send, or delete any files yet.

[L0366.011]

  • Running an unfamiliar agent folder with Full access before checking its contents for malicious instructions or files is risky. Always read the handoff and startup files and ask the AI to explain the workflow first. [L0366.012]

Setup questions and what agents do

  • The agent's setup questions show what it needs before it searches: the target role or candidate type, what a strong fit and a disqualifier look like, where proof of work can be found, and any example people, companies, websites or keywords to start from. Clear answers make the first pass more useful. [L0366.013]
  • Recruiting-style agents are built to search public sources only, unless you explicitly approve something else. They add qualified candidates to a tracking CSV with evidence, scores, rankings, risks and next steps. [L0366.014]
  • The agent must not contact anyone, submit forms, share lists, change permissions or update outside systems unless you explicitly approve that exact action. Ask for this approval in writing for each external step. [L0366.015]
  • Scope file searches and reads to the agent folder unless you explicitly ask for a wider search. Writing this rule into agents.md keeps the agent from browsing unrelated files on your computer. [L0366.024]

Getting unstuck and improving agents

  • When an agent keeps giving wrong answers or misunderstands the task, the fix is usually a change to agents.md rather than repeated prompting. Asking the agent to update agents.md after each repeated error makes its later responses more accurate. [L0366.020]
  • Standing safety prompt for a beginner, which also makes the agent keep agents.md up to date:
I am a beginner. Please always run the security checks before doing any work in this folder, and explain each step in simple language. Add these instructions to agents.md so you follow them in future sessions. Update agents.md whenever the same mistake repeats or when we learn something new in this process.

[L0366.019]

  • When you get stuck, ask the AI first, for example when a folder asks for an integration that does not exist, before asking a mentor. Agents can usually propose a workaround or a custom tool. [L0366.021]
  • Example: an agent may report that it cannot push files to Google Drive because no Google Drive integration exists. Ask the AI how to work around this, for example by saving a local file that is then uploaded manually or by building a small custom tool. [L0366.022]
  • An agent folder can be used for YouTube scripts, creative ideas and recruiting. A recruiting scraper can search LinkedIn, YouTube and Twitter for potential clients. Any agent can be used for a new project, provided its instructions are set up correctly. [L0366.023]

AI limits and verification

How AI produces answers

  • A large language model such as ChatGPT or Claude predicts the most useful next output based on the text it was trained on. It does not produce original insight from nothing, so its answers are only as good as its source material. [L1478.002]
  • AI output quality depends entirely on the training material it is given. If the sources are wrong, outdated or unproven, the answers will be unreliable even when they sound confident. [L1478.003]
  • When a general AI model draws on many conflicting marketing opinions, it averages them into a watered-down answer that commits to no clear path. Broad questions without a defined source for marketing topics produce this diluted result. [L1478.004]
  • Because AI is trained to avoid mistakes, it falls back on safe, generic answers when it is unsure which source is best. Always state the exact sources, definitions and step-by-step method the AI should follow instead of leaving this open. [L1478.007]
  • A single trained person can only do one task at a time, whereas trained AI agents can apply the same proven instructions across many tasks at once. This is the main reason to build a repeatable, well-instructed system for AI. [L1478.010]
  • Generative AI works by predictive generation: the model outputs what would be most useful to say next, based on the question and everything it was trained on. Terms such as predictive modelling describe the same process, so a different label does not change how the answer is produced. [L1478.013]
  • Large language models such as ChatGPT and Claude are trained on mixed text sources, including books, blogs, essays, forum and social media posts, Wikipedia, and other web pages. Their answers reflect that mix, so topics with conflicting opinions, like marketing, produce inconsistent results. [L1478.014]
  • A model trained only on a 300-year-old science book can answer questions from that book well, but it cannot propose new experiments or ideas beyond what the book contains. Its output is limited to the scope of its training material. [L1478.015]
  • Chat assistants perform well on general questions largely because they can draw on the wider internet. Broad access to sources does not mean the answer is proven for a specific business task, so the source material for that task still needs to be chosen deliberately. [L1478.016]

Verification

  • Every generated list, email or statement must be checked before publishing. AI tools such as ChatGPT and Gemini sometimes produce incorrect answers. [L1287.036]
  • ChatGPT is not reliable for current trend data, such as lists of the top dropshipping products for the coming period or exact market numbers. Verify any figures it gives before using them, and use it mainly for text and ideas. [L0605.011]
  • Many prepackaged AI dropshipping tools are thin wrappers around general chat models such as ChatGPT, Claude, Copilot or Grok, and are often built on outdated technology. Using the general models directly is usually cheaper and more current. [L0972.104]
  • Do not use an unfamiliar agent folder with Full access before checking its contents. [L0366.012]

Changing features and limits

  • ChatGPT's web browsing was switched off temporarily after users found ways to bypass privacy controls through links. AI tool features such as web search can be removed or changed without notice, so check current availability before building a workflow on them. [L0353.060]
  • Pro plans have character limits, so long documents may need to be shortened. [L1427.064]
  • The four AI tools recommended in this lesson (ChatGPT Playground, Runway ML, Compose.ai and DALL-E) were presented as free to use. Free tiers and access terms can change, so verify each platform before relying on it. [L1428.015]
  • Free-plan limits and file import rules, such as the Gemini login requirement and the Claude free-plan message cap, change over time. Check them on the platform before planning a large job around them. [L0374.006, L0862.021]

Security and sources

  • Download AI apps only from the official site. Look-alike sites are used for phishing. [L1506.005]
  • Scope agent access to the folder you opened, and keep sensitive data out of any folder the AI can read. [L0366.005, L0366.024]
