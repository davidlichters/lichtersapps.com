### Finding apps that competitors use

#### Browser inspection procedure

1. Open the competitor's store in Chrome. [L1345, 2021+]
2. Right-click and choose Inspect. [L1345, 2021+]
3. Use the select-element tool and click the bundle block on the page. [L1345, 2021+]
4. Read the element's code and search for the app name, such as 'bundle' or the app's name in the script. [L1345, 2021+]
5. Note the app name and check its listing on the Shopify App Store. [L1345, 2021+]

#### Tools that show competitor apps

- Ali Hunter (Chrome extension), PPSpy, and Koala Inspector show which apps competitor stores use. Koala Inspector may require an upgrade for full app data. [L1345, 2021+]

### Theme features, custom code or a freelancer

#### Use the theme first

- Use the built-in theme features before paying for a separate app or a custom developer job for the same function. Review collection still needs a separate app, because the theme does not provide it. [L0973, 2020-26]
- Some features built into a theme can replace functions that would otherwise need separate paid Shopify apps. Checking a theme's native features before buying apps can reduce monthly app costs. [L0974, 2020-26]
- Simple site elements such as banners or small on-page features can often be coded directly into the theme by an inexpensive developer. This is usually more efficient than a script-heavy app. Complex functions such as live chat still normally require an app. ** [L1266, 2021-22]

#### Custom code for simple features

- For a simple custom feature, ask an LLM for custom Shopify section code instead of installing an app or hiring a developer. [L1116, 2025]
- Use apps only for features that would be too hard to code yourself. Build simple features with on-site code. ** [L0853, 2021]

#### Hiring a freelancer

- Get a custom feature built when paid apps are too expensive:
  1. Post a job for a Shopify developer on Upwork. [L0968, 2021]
  2. Describe the function you need and link to the apps you want to emulate. [L0968, 2021]
  3. Hire a developer to build it into your store for a one-time cost. [L0968, 2021]

** [L0968, 2021]

- Platforms for hiring Shopify developers for custom code, such as custom buttons and external service integration, include Fiverr.com and StoreTasker.com. [L0276, 2024]
- Stack Overflow is a technical Q&A site useful for finding fixes to specific coding problems. Reddit can also be used to ask for recommendations from developers, though answers can be harsh for beginners. [L0709, 2017+]
