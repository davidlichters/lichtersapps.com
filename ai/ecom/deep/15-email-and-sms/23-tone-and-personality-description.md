### Email body copy and calls to action

- an email has one job, which is to get the reader to visit the website. Trying to close the sale inside the message misses that job, because the purchase decision belongs to the site. [L1460, 2021-22]
- Length matters less than whether each paragraph keeps the reader's interest. Long copy can outperform short copy when the reader is already interested, because he will read several pages to learn more. [L1369, undated]
- A short promotional email that produced a single tracked result used this structure [L1356, 2019+]:
  1. The headline is used as the subject line.
  2. Two or three one-line payoff sentences follow.
  3. One big promise.
  4. One quote from an authority figure.
  5. One link, as the only call to action.

  The email revealed no product details, so readers had to click to learn more. In that tracked campaign, roughly 11 out of every 100 recipients clicked. This is a single result to watch, not a guaranteed benchmark. [L1356, 2019+]
- Place social proof directly beside each unique value proposition, such as a review, a bestseller or a customer story. Claims alone persuade less than claims shown with evidence. [L1470, 2025-26]
- Remove text that repeats information already in the email header, such as a brand name next to a logo. This keeps the email shorter and easier to scan. [L1470, 2025-26]
- Compose.ai is a tool for writing marketing emails, useful when a store needs many email drafts without hiring a copywriter. [L1416, 2023+]

### Brand colors in the email

- Keep the email text and background colors black and white, and use only the brand color for the button fill, so the emails match the store's look without being distracting. [L1317, 2020-26]
- The Chrome extension "ColorPick Eyedropper" (named "color picker" in the lesson) copies the six-digit hex code of any color on a page to the clipboard, so the exact brand color can be pasted into Shopify's color fields. [L1317, 2020-26]

### Brand voice and project files

- Keep the brand kit, tone-of-voice files, templates and campaign work in one permanent project that the AI can always access. Files in a one-off chat are lost when the chat closes, and then the AI guesses at the brand instead of using the real files. [L1506, 2025-26]
- Build the work in a fixed order: brand kit and tone of voice first, then the email templates and universal content blocks built from them, then campaigns built from both. Each step reads the output of the previous one, so every file must sit in the same place for this hand-off to work. [L1506, 2025-26]
- A tidy project folder for this email workflow uses numbered folders for each stage, such as workspace setup, brand context, template from scratch and building campaigns, plus a stack setup folder and an archive folder for older files. [L1506, 2025-26]

### Claude Cowork workspace setup

Workspace setup for Claude Cowork and Klaviyo [L1506, 2025-26]:

1. Download the Claude desktop app from claude.com and install it like any other program.
2. Open the app, which starts on the Chat tab, and switch to Cowork.
3. Go to Projects and click New project, then choose to start from scratch.
4. Name the project, for example Email Template Project, and optionally add a short description such as building email templates to push to Klaviyo. No detailed instructions are needed.
5. Choose the project location folder and click Create.
6. Confirm that Memory is switched on for the project.
7. Select the model (Opus is used in this setup) and choose the approval mode (see the approval setting).
8. Create a dedicated folder inside the project location and put all downloaded course files into it.
9. Always start new chats from inside the project, never from a standalone chat or a new Cowork task.

- Creating a project: in Cowork, go to Projects, click New project and choose to start from scratch. Give it a name and a short description, then choose the project location folder and click Create. The Memory toggle is shown in the same dialog and must be on. [L1506, 2025-26]
- The project instructions field is optional. A short line of context describing the goal, such as building email templates to push to Klaviyo, is enough to start. [L1506, 2025-26]
- Project memory must be switched on so Claude keeps the conversation history across all chats in the same project. Without it, the brand and background must be re-explained in every new chat. [L1506, 2025-26]
- In a project, the page shows an Instructions section, a Context section where files are added with the plus button, and a Memory section where you can ask Claude to remember something. All chats started in the project appear there with their history. [L1506, 2025-26]
- The workspace setup for AI-written Klaviyo email templates takes about five minutes and is done once. If it is skipped, the AI loses access to the brand kit and image files and starts guessing at the brand. [L1506, 2025-26]

### Modular content blocks and master template

- Universal content blocks are reusable email building blocks. A set of them with a master template lets the same modules power welcome flows, campaigns and one-off sends, and templates built this way stay consistent across all sends. [L1361, 2025-26]
- Universal content blocks are created with the email template builder skill from two reference images, an anatomy image and a module library image, together with brand-kit.json. The output is a set of blocks and a master template pushed into Klaviyo. [L1361, 2025-26]
- Once universal content blocks exist in Klaviyo, new emails are built quickly by swapping images and reordering a few modules, which keeps every send consistent in look. [L1361, 2025-26]
- After the foundation stage (universal content blocks and master template), a brand can already stop and use working templates for sales postcards, product showcases and editorial emails, because later stages only add flows, audits and segmentation. [L1361, 2025-26]
- Do not push an AI-written email into Klaviyo as one large raw HTML block, because the result cannot be edited in Klaviyo and must be re-exported to change it. Push templates and universal content blocks as structures that stay editable in Klaviyo. [L1506, 2025-26]

### AI-assisted build sequence

Planned sequence of the AI email build [L1361, 2025-26]:

1. Set up the tech stack and install all tools (Claude Cowork, Klaviyo MCP, Brandfetch MCP, optional image tools).
2. Create a brand context document from the brand kit (brand-kit.json with voice, colors and fonts).
3. Build the universal content blocks and master template with the email template builder skill, then push them into Klaviyo.
4. Build flows such as the welcome flow using the same blocks, then map the flows.
5. Run an email deliverability audit across Gmail, Hotmail and Yahoo accounts with DNS access to the brand domain.
6. Audit Klaviyo send data and build audience segments.
7. Create a campaign calendar with the email strategy planning skill and feed it into Klaviyo.
8. Optionally add SMS opt-in flows and copywriting.

- The AI-to-email stack changes very fast, so specific tools and workflows must be re-checked regularly. Klaviyo is releasing its own AI composer tools that will change the workflow. [L1361, 2025-26]
- Campaigns created through the campaign skill are saved in Klaviyo as drafts, not as live campaigns, so they still need to be reviewed and scheduled inside Klaviyo. [L1506, 2025-26]

### Welcome flow

- Welcome flow design uses Excalidraw for flow maps, Claude Cowork with the Klaviyo MCP, and the email flow builder skill, with brand-kit.json and the master template as inputs. The target result is one live welcome flow and four flow maps. [L1361, 2025-26]

### Rendering and testing

- Email templates must render well in major email clients such as Gmail, Yahoo and Hotmail, on mobile devices and in dark mode. Test each template across these before using it in production. [L1361, 2025-26]

### Hero image, layout and links in Klaviyo

- Use a welcome email hero image of 1250 x 2335 px. Check the file quality after downloading and before uploading, since blurry images reduce trust. [L1470, 2025-26]
- Check a hero image's dimensions and file size in the file properties before uploading it. The example welcome hero measured 1250 x 2335 px at 309 KB and looked sharp at that size. [L1470, 2025-26]
- Set the top padding of the email content block to 30 px so the first element does not sit against the top edge. A text block that is not full width on mobile is acceptable for this layout. [L1470, 2025-26]
- In Klaviyo's email builder, select the hero image block, choose Upload image, and drag the file in to replace the old one. The Image block settings include Link address, Image size with Width set to auto, Fill column on mobile, Alignment, Background color, Border, and Padding. Preview the email before saving to confirm the image and padding render correctly on desktop and mobile. [L1470, 2025-26]
- To link an email or SMS button to a bestseller page on most Shopify stores, open storedomain.com/collections to see the store's pre-built collection list. Open the bestseller collection there and copy its URL into the link field. [L1470, 2025-26]
- In the greeting, insert the first_name profile property with a default fallback so subscribers without a stored name still get a natural opening line. Open Preview profile info to check how the greeting renders with a real subscriber profile before going live. [L1470, 2025-26]

- To prevent image distortion in Shopify email templates on mobile: 1. Click the Mobile Preview tab while editing the email. 2. Check how images render on mobile. 3. Select each image and add padding, typically 10 pixels on each side. 4. This provides space between images and the email borders. [L0278, 2025]
