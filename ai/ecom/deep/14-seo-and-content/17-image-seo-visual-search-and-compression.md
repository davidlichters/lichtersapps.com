## Image SEO, Visual Search and Compression

### File names and image metadata

#### Filename rules

- Every image on a website must have a unique filename containing relevant keywords and a descriptive phrase, not generic defaults like "screenshot" or "image123". [L0301, 2021-22]
- Every image on a page should have a descriptive file name, and at least one image file name on the page should include the focus keyword. Google reads file names as one of several signals for what the page is about. [L0881, 2021-22]
- Every image on the site needs a short, descriptive file name, for example "black dog running" for a photo of a black dog running. Random strings of letters and numbers as file names are not allowed. [L1467, undated]
- Image filenames help Google understand both what the image depicts and what the page is about, improving both image search and traditional search rankings. [L0301, 2021-22]
- Image file names should describe the product, such as the brand, model, product type and colour, instead of generic supplier names like "image 5467". A detail such as "side view" can be added for close-up shots. [L1163, 2021-22]

#### Filename patterns by page type

- **Product pages:** Name the first image with just the product name. Name subsequent images by combining the product name with what each image emphasizes. Example: "widget-blue-packaging" for the packaging detail, "widget-lifestyle-use" for the in-use shot. [L0301, 2021-22]
- **Products with several angles:** Use variations of the product name and include synonyms across different images. [L0301, 2021-22]
- **Target keyword:** Include the page's primary target keyword in at least one image filename. Use related synonyms and variations in the filenames of other images. [L0301, 2021-22]
- **Blog post images:** The filename should simply describe what the image shows (what it demonstrates, depicts or contains), not forced keywords. [L0301, 2021-22]
- **** The source describes these patterns as current practice for Google Images. Treat the filename patterns as older advice and check them against current guidance. [L0301, 2021-22]

#### Images already published

1. Update the filename and alt tag of the existing image file.
2. Re-upload the modified image file to the site. Re-uploading applies the changes. [L0301, 2021-22]

#### Images in the product description

- Images placed in the product description area need unique file names and alt tags, just like the main product images. This is often skipped. [L1191, 2021-22]

### Alt text

#### Rules

- Write descriptive alt text for every product image on the product page. This improves SEO, supports accessibility, and provides context if images fail to load. [L0176, undated]
- Each image on a page must have a unique alt tag describing that specific image. Using the same alt text for multiple images wastes the optimization opportunity and provides no additional ranking benefit. [L0301, 2021-22]
- Each image's alt tag must be unique and feature target keywords and synonyms related to that specific image, similar to how filenames should include keywords, to optimize both traditional search and visual search rankings. [L0301, 2021-22]
- Each product image needs a unique alt tag, a short descriptive phrase of what the image shows. Alt tags serve screen readers, display when an image fails to load, and help search engines including Google Images rank the page. [L1163, 2021-22]
- Give every product image its own alt text that names the product, its key feature and the view shown, kept short. [L1166, 2021-22]
- Add alt image tags to all images. [L1227, 2020-26]

#### What alt text does

- Alt text describes what an image shows. It helps screen readers for visually impaired users and gives Google more context. Accurate alt text can also help product images rank in Google image search. [L1190, 2020-26]
- Alt text displays when an image cannot load and helps screen reader users. It should describe the image and can include the focus keyword. [L0881, 2021-22]
- Google reads image file names and alt text to understand the page topic. [L0881, 2021-22]

#### Entering alt text in the editor

1. Click the image in the media section.
2. Enter the alt text.
3. Click out to save. [L1166, 2021-22]

### Image size and dimensions

- Product images should be 800x800 pixels. Never go below 600x600 pixels. [L0301, 2021-22]
- Cropping example: take a 3000x4000 supplier image and crop it to 800x800, focusing on a product detail. [L0301, 2021-22]

### File size and compression

#### Targets

- Compress images to reduce file size while maintaining quality. [L0226, 2017]
- Aim for images under 100 KB each. Images must not reach hundreds of megabytes. [L0226, 2017]
- Multi-megabyte product images make product pages load slower, which hurts page speed and organic rankings. Compress them; well-built compression keeps the visible quality unchanged. [L1190, 2020-26]
- Keep images small enough to load quickly. [L1227, 2020-26]

#### Compression principles

- Compress all images as far as possible without visibly degrading visual quality. Balance page speed against conversion-friendly image appearance. [L0301, 2021-22]
- The optimal compression point is when image quality begins to noticeably degrade. Most compression tools provide settings to identify this threshold. [L0301, 2021-22]
- Optimized images look the same to a visitor on a desktop but have smaller file sizes, so pages load faster. In one blog post, image optimization reduced the image file size by 64%. [L1321, 2020-26]

#### Formats and delivery

1. Compress images to reduce file size.
2. Use web-friendly formats: JPG, PNG, WebP. [L0226, 2017]
3. Keep images under 100 KB each. [L0226, 2017]
4. Use image CDNs or lazy loading to improve page speed. [L0226, 2017]

#### Tools

- **Image Optim:** A free desktop application for offline bulk image compression. Drag and drop images into it and adjust compression settings until quality is acceptable. [L0301, 2021-22]
- **Smart SEO (Shopify app):** Use it for bulk optimization of store files and blog posts (see procedure below). [L1321, 2020-26]

#### What not to use

- Do not use Shopify or other on-site image compression applications. Some inject JavaScript into the page code, which harms SEO. Compress images offline before uploading. [L0301, 2021-22]

#### Smart SEO procedure for pages and blog posts

1. Open the Smart SEO app.
2. Click Image optimization, then click Configure.
3. Open the Files section, which contains images used on the store, on pages and in other parts of the site.
4. Select all images and click Optimize file images. Let it run in the background.
5. Open the Articles section, which lists blog posts. Unoptimized posts are shown as not optimized.
6. Click optimize on each blog post. Posts added later appear in the Articles section and are optimized the same way. [L1321, 2020-26]

### Originality and image sourcing

#### Why unique images matter

- Use unique, original images rather than stock images when possible. Google's algorithm gives preferential ranking treatment to unique images. [L0301, 2021-22]
- For resellers and dropshippers selling products also offered by competitors, the first person to publish an image is typically considered to have the original version. Unique variations are weighted more heavily than duplicated stock images. [L0301, 2021-22]
- Original product photography taken with a smartphone produces high-definition images and is more effective for search rankings than stock images already used by other competitors. [L0301, 2021-22]
- While Google shows preferential treatment to unique images, it is not a major ranking factor. Prioritize domain authority and quality content first, then pursue unique images where practical rather than treating it as a critical optimization. [L0301, 2021-22]

#### Creating unique images from supplier files

- Crop specific sections from high-resolution supplier images to highlight particular features or angles. Example: take a 3000x4000 image from a supplier and crop it to 800x800, focusing on a product detail. This avoids the generic images all competitors use. [L0301, 2021-22]

#### Permitted sources (company rule)

- Images for content come from the company's shared image library or its Adobe Stock account. Do not use images from other sources. [L1467, undated]

| Pinterest Lens visual searches | Over 600 million per month | [L0301, 2021-22] |
| US consumers who had used visual search at least once, as of 2020 | 36% | [L0301, 2021-22] |
| Objects Google Lens can recognize | Over 1 billion | [L0301, 2021-22] |

#### How visual search affects product discovery

- Visual search through Google Lens and Pinterest Lens is now a primary search method alongside text-based search. Image optimization is essential for product discovery. [L0301, 2021-22]
- Customers can use Google Lens to scan physical products in their environment and immediately find purchasing options. This works through shopping ads and organic search results, without knowing the product name or retailer. [L0301, 2021-22]

#### Ranking signals for Google Images

- Google maintains a separate ranking algorithm for image search. It operates independently from text-based search, so image optimization benefits rankings separately from standard on-page SEO. [L0301, 2021-22]
- Search engines use information from images to determine which search terms an entire page should rank for in traditional results. [L0301, 2021-22]
- Domain authority is a more important ranking signal in Google Images results. Building site authority through quality content, backlinks and technical SEO improves image search rankings automatically. [L0301, 2021-22]
- Google Images prioritizes fresher content. Recently updated pages rank higher for image searches than unchanged older pages. [L0301, 2021-22]
- Position images centrally on the page and place them higher up. Google Images prioritizes product pages where images are central to the content over category pages displaying several products. [L0301, 2021-22]
