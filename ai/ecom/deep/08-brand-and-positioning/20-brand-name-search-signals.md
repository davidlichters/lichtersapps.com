### Brand name search signals

*Older advice (2022).*

Procedure for a store name that resembles a well-known store:

1. Create profiles on Facebook, Instagram, Pinterest, YouTube, TikTok and Snapchat, even if you post little. [L0963, 2022]
2. Write a 100-character description of the store with a link to the homepage on each profile. [L0963, 2022]
3. Get listed in shopping directories with the store name as link text pointing to the homepage. [L0963, 2022]
