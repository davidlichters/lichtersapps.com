### Tidio setup

**Installation and setup, version A (as taught)**

1. Install the app and customize the chatbot (name, blue color, avatar image). [L0477, undated]
2. Answer the setup questions: main focus = increase sales, number of agents, industry = online store, customers last month. [L0477, undated]
3. Choose talk to customers and automate conversations. [L0477, undated]
4. Choose greet warmly (recommended when a Klaviyo pop-up already captures emails) or offer a discount in exchange for email. [L0477, undated]
5. Set a password. [L0477, undated]
6. Turn on the Tidio chat widget in the Shopify theme editor and click save. [L0477, undated]
7. Settings: set the online status name to customer support. [L0477, undated]
8. Team > Operators: add a VA as chat agent if hired. [L0477, undated]
9. Turn on operating hours and set hours per weekday, e.g. Monday until 6 p.m., Tuesday until 4 p.m. [L0477, undated]
10. Save. [L0477, undated]

**Installation and setup, version B (as taught)**

1. Search for Tidio live chat in the Shopify App Store, click Add app, then Install app. [L1297, 2023]
2. Name the chatbot, choose the colors, and upload an avatar from unsplash.com. [L1297, 2023]
3. Set the main focus to increase sales, the number of support agents to 1, the industry to online store, and customers last month to just getting started. [L1297, 2023]
4. Agree to the terms and select both talk to customers and automate conversation. [L1297, 2023]
5. Choose to greet visitors warmly, since the Klaviyo pop-up already collects emails. [L1297, 2023]
6. Set a password and turn the Tidio chat widget on in the Shopify theme editor, then save. [L1297, 2023]
7. Under Settings, rename the online status message to customer support. [L1297, 2023]

**Tidio team and tools**

- Tidio is a live chat tool that can be installed on the store so support staff can answer customer questions in real time. [L1360, undated]
- Add a VA or other helper as a chat agent in Tidio under Team > Operators, using their name and email, so you do not need to answer every chat yourself. [L1297, 2023]
- Chat support is recommended; the lesson names Tidio as an app for live chat. Handle refunds for damaged or defective items quickly, since after-sales service affects feedback score and customer loyalty. [L1259, undated]

### tawk.to setup

**Widget appearance** (Administration > Chat Widget > Widget Appearance in the tawk.to dashboard; older advice, 2021-22) [L1298, 2021-22]

| Field | Default or note |
|---|---|
| Desktop Widget: Width | 350 |
| Desktop Widget: Height | 520 |
| Desktop Widget: Widget Position | Set position |
| Desktop Widget: Minimized Width | Set size |
| Desktop Widget: Minimized Height | Set size |
| Desktop Widget: Top Radius | Set corner radius |
| Desktop Widget: Bottom Radius | Set corner radius |
| Desktop Widget: Attention Grabber | Enabled toggle |
| Mobile Widget | Has its own appearance settings |
| Widget Colors | Header, Header Text, Agent Text, Agent Message, Visitor Message, Visitor Text |

- Enter brand colours as hex codes, then click Save. [L1298, 2021-22]
- The attention grabber is a teaser that draws visitors' attention to the chat. Switch it off if it looks weak, and keep one of the available styles only if it draws attention without clashing with the brand. [L1298, 2021-22]

**Inbox and staff**

- tawk.to Messaging works as a shared inbox where chats and tickets are stored. Emails sent to the tawk.to ticket address are also delivered to this inbox. [L1298, 2021-22]
- Staff and virtual assistants can be added to the tawk.to dashboard so they answer chats from the Shopify app during daily store management. [L1298, 2021-22]

### Quick replies, instant answers and chatbots

**Quick replies**

- Quick replies can be saved in Shopify Inbox for frequently asked questions. Pre-created discount codes from the store can be shared directly in the chat, and images can also be sent to shoppers. [L0948, 2020-26]
- The Inbox reply box supports quick replies (saved answers), discount codes, product links, image uploads and emojis. Quick replies are useful for repeated answers, and product links help the visitor move straight to the item in question. [L1311, 2020-26]

**Tidio chatbots: three bots**

1. Open chatbots and choose the cart abandoned template. Enter the discount, for example 15%, and the coupon code name, for example SAVE15, then save. Tidio creates the coupon in Shopify, so click Save and activate. [L1297, 2023]
2. Use the product recommendation template without changes and click Save and activate. [L1297, 2023]
3. Use the AI responder template for order status. Add conversation topics such as "hi where is my order", "hello where is my tracking number" and "when will my product arrive". [L1297, 2023]
4. Paste the order status reply, which says orders ship in 4 to 7 days of processing, and add your email at the end so customers can write to you. [L1297, 2023]
5. Click Save and activate and confirm the bot is on. [L1297, 2023]
