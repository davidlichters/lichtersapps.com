### Shrine Pro setup

- Premium themes are worth choosing when they include conversion elements, so the store needs fewer paid apps. [L1330, 2025-26]
- Shrine Pro was chosen because it has the most sections of the Shrine theme versions. One license is enough for one store. [L1330, 2025-26]
- The email address entered at checkout for a Shrine license must be correct, because the license keys are delivered to that address. A wrong address can prevent access to the keys. [L1330, 2025-26]
- Set up a premium Shrine Pro theme in Shopify, in this order:

1. Open the Shrine Pro page and click Get started.
2. Select one license, because only one store is being built, and click Add to cart.
3. Click Checkout.
4. Check that the email address entered at checkout is correct.
5. Accept the terms and conditions, click Complete purchase, and then click Continue.
6. Open the email from Shrine that contains the license keys, and click Open Shrine Dashboard.
7. If there is no Shrine account yet, click register and create an account, then log in.
8. Click Next step, then click Add key, and enter the license key to activate it.
9. In Shopify, go to Settings > Domains and copy the myshopify.com URL.
10. In Shrine, go to Settings > Accounts > Whitelist your URLs and paste the myshopify.com URL into the Shopify URL field, with https:// in front.
11. Copy the custom domain of the store from Shopify Settings > Domains and paste it into the Main URL field, with https:// in front. If a second website URL exists, add it in the Secondary URL field the same way.
12. Click Save and generate token, then copy the authentication token and store it safely.
13. Download the theme zip file from Shrine.
14. In Shopify, go to Online Store > Themes, click Import theme, upload the zip file, and select the Shrine Pro theme file. Wait until the upload has finished. To import the theme, go to Online Store > Themes, click Import theme, upload the zip file of the Shrine Pro theme, and wait for the upload to finish.
15. Click Publish to make the theme live, even though the store is still password protected.
16. Click Customize to open the theme editor and add sections.

### Choosing a theme

- Start with a free Shopify theme and keep the store simple: a clear product page, a short homepage, and clean images. [L1380, 2022]
- A beginner should start with a simple, quickly built store theme, such as a basic version of Shrine, rather than spending time on advanced themes. [L1454, 2026]
- Elixir suits operators who already know how to build a proper website. [L1454, 2026]
- Beautify is a popular paid theme, but its look is common among dropshipping stores, so it is not required. [L1380, 2022]

| Theme | Cost | Look | When it fits | Units |
|---|---|---|---|---|
| Free Shopify theme | Free | Simple, with a clear product page and short homepage | Starting point for a new store | [L1380, 2022] |
| Shrine (basic version) | Not stated in the source | Used by a large share of stores, so it stands out less | Beginners who need a store built quickly | [L1454, 2026] |
| Elixir | About half the price of Shrine when bought without a discount code | More branded | Operators who already know how to build a proper website | [L1454, 2026] |
| Beautify | Paid | Popular, but common among dropshipping stores | Not required | [L1380, 2022] |

- The choice of theme matters much less than launching fast. Small custom code changes on a simple theme are enough to make a store look distinct from the average store. [L1454, 2026]

### Buying themes safely

- Cracked or pirated store themes carry a risk of hidden bugs or malicious code that can break the store. Buy themes from the official source or a verified reseller. [L1454, 2026]

### Uploading a theme zip file

- After a Shrine Pro zip file is uploaded to Shopify, it appears in the theme library as shrine-theme-pro, version 1.5.4, labeled Just added. [L1330, 2025-26]
- Shopify states that uploaded themes are visible only to the store team until one of them is published. [L1330, 2025-26]

### Draft and published themes and password protection

- A theme can be published while the store is still password protected, so the theme can be prepared before the store opens to visitors. The password protection stays active until it is removed. [L1330, 2025-26]
- In Shopify, the password protection of a store is managed on the theme card under Online Store > Themes. [L1330, 2025-26]
- The theme card shows the buttons Edit password and Remove password, and displays Password protected while the protection is active. [L1330, 2025-26]

### Moving to a new Shopify store while reusing content

Moving to a new Shopify store while reusing content:

1. Create the new store with another email. [L1382, undated]
2. Export the theme from the online store section and import it into the new store. [L1382, undated]
3. Export and import the customer and SMS lists, and set up the email settings and apps again (Shopify's export and import buttons handle the data). [L1382, undated]
4. Rebuild any settings that do not transfer, such as logos and notification email settings. [L1382, undated]
