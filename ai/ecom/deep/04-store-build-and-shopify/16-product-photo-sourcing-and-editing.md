### Product photo sourcing and editing

**Why photos matter**
- Ecommerce sites depend on images for two core functions: brand identity (logos and graphics) and product visibility, which lets buyers make informed purchase decisions [L0300, 2021-22].
- Images are often the largest elements on a page and the biggest contributor to load time. Compress them offline before upload. Compression apps are less controllable than a dedicated offline tool [L1266, 2021-22].
- Poor product images are a common reason stores do not convert. Find better images before concluding the product is weak [L1345, 2021+].
- Lifestyle images help buyers see the product in use and increase trust. A landing page needs good-quality product and lifestyle images, which make the brand look better and more trustworthy [L1382, undated].

**Supplier and stock images**
- Supplier and stock images come in varying dimensions and file sizes. They usually need editing or resizing to fit specific layout sections [L0300, 2021-22].
- Image sources to check, in order: Pexels, Pixabay, Google Images, Alibaba, AliExpress. If no good image exists, look for a very similar product. Instagram hashtag research can also reveal raw user photos for the niche [L1345, 2021+].
- Check whether the store's product photos are the seller's own. Matching backgrounds, tables and hands across several images show the owner shot them, which is stronger than generic supplier photos. Use this as a quality check when the store looks different from the supplier listing [L0530, 2022].
- Put your own brand name on copied product photos before publishing. This makes them your store's assets, not identical copies of a competitor's [L0600, 2026].
- Supplier product photos can be downloaded from the supplier's website. If the file type is not JPEG, convert it with a free online converter, found by searching for the file type conversion [L1111, 2020].
- Generic lifestyle photos are enough for collection banners before suppliers connect [L0342, 2020-26].

**Editing yourself or outsourcing**
- During setup, editing single images yourself with PicMonkey is often faster than coordinating with a freelance designer. It is practical to learn basic image editing skills early [L0300, 2021-22].
- Standard editing sequence: edit images in PicMonkey by resizing, cropping and adding text as needed. Then selectively compress the larger files with platform-specific tools: ImageOptim for Mac, or Windows' built-in compression [L0300, 2021-22].
- Cropping or resizing in PicMonkey does not change the original file on your computer. Download the edited version as a new file. Download as PNG to keep a transparent background [L1371, 2021-22].
- For bulk processing, outsource it. Give a freelancer a Photoshop automation or batch script that resizes each image, places it on a white background if needed, and compresses it. The speaker paid about $10 per 100 images for this, which he called one of the cheapest things to outsource [L1456, 2021-22].
- Fiverr retouchers can be hired for about $5 to $10 per image to change backgrounds, add pop, and clean up pixelation [L1345, 2021+].
- AI image tools such as DALL-E (transcribed as "Dahl") can create or edit product images that look realistic [L1345, 2021+].
- DALL-E can create new images for a print-on-demand store, and can edit an existing product photo and produce variations from the same source image [L1416, 2023+].

**Supplier file preparation**
1. Rename the file to include the supplier name, product description and model number. Default file names are often gibberish [L1456, 2021-22].
2. Give multiple images of one product distinct file names by adding a word such as front, back, side or in use [L1456, 2021-22].
3. Set the alt text. It can match the file name, but it is a separate field. Apps that copy the title to every image produce duplicate alt text. That is weaker for image search than unique alt text, but better than none [L1456, 2021-22].
4. Resize the image from 2000 × 2000 px to about 800 × 800 or 1000 × 1000 px. This keeps good resolution while loading fast on mobile [L1456, 2021-22].
5. Save as JPEG, which is smaller than PNG [L1456, 2021-22].
6. Compress the image again with a compressor such as ImageOptim on Mac [L1456, 2021-22].

**Background and layout**
- Keep the background white if the image is not a full-size lifestyle shot [L1163, 2021-22].
- Put no text on the image, except branding that is on the product itself [L1163, 2021-22].
- Apply a unique alt tag to every image, and give every image file a descriptive file name [L1163, 2021-22].
- Product images in a grid should share the same proportions, such as square. Mixed sizes in a grid usually come from the dimensions of the uploaded files, not from a theme setting, so resize them to match [L0971, 2024].

### Product image sizing rules

**Target sizes (sources disagree)**
- Ideal size: 800 × 800 px, square, not rectangular [L1163, 2021-22].
- Minimum size: never smaller than 600 × 600 px. Smaller images may stop a product from being advertised on Google Shopping [L1163, 2021-22].
- Minimum size: at least 1000 × 1000 px. Smaller images look pixelated when customers enlarge them (2023) [L0970, 2023].
- Both values apply to different needs. The 600 px minimum is about Google Shopping eligibility. The 1000 px minimum is about on-site enlargement quality, and is the more recent advice [L1163, 2021-22; L0970, 2023].
- Maximum: do not exceed 1000 × 1000 px. Larger files slow the site, and mobile users cannot see the extra detail, so oversized images hurt site speed, conversions and SEO [L1163, 2021-22].
- A 1024 × 1024 px size was suggested for product images in 2020. It was not confirmed, so check the exact size with the platform or your support contact before uploading the full set [L0961, 2020].
- A 1:1 template works for uniform images. Place a rectangular image on an 800 × 800 canvas and scale it as large as possible without distortion. Square images are not required, but uniform sizes look better side by side (2023) [L0470, 2023].
- A 500 × 500 px canvas was the example Canva size for a product image design [L0036, 2020-26].
- A square product image at 1080 × 1080 px fits square product tiles and social-style grids. Prepare images at this ratio before upload [L1462, undated].

**Very large and very small files**
- Very large supplier images, such as 8000 × 8000 px, slow page loading. Resize them before upload, and keep them at a size that still meets the 1000 × 1000 px minimum [L0970, 2023].
- Product images at 2000 × 2000 px are too large and slow the page on mobile. Resize them before upload [L1456, 2021-22].
- Product photos above about 1 MB are too large and should be compressed. Slow opening of image files or slow uploads is a sign that compression is needed [L1002, 2019].
- Product images above roughly 3000 × 3000 px are usually more than a website needs. A 10,000 × 10,000 px image can be reduced to 1000 × 1000 px with no visible loss on desktop or phone, and about ten times less data [L1002, 2019].

**Consistency**
- All product images on the site should share one consistent size and shape. Mixed sizes make collection pages look messy. Some advertising channels, especially Google Shopping, also require standard image dimensions [L1163, 2021-22].
- Do not resize all product images to one identical size. Suppliers send different aspect ratios, and forced sizing causes cropping. Compress the files to reduce file size instead [L0972, 2025].
- Do not convert product images to different aspect ratios (square or landscape) in bulk. Resizing without keeping proportions crops important parts or distorts the image [L0278, 2025].
- Shopify's product grids and collection layouts depend on consistent proportions, so resize product images to the recommended sizes before upload [L0665, 2022].

### AI image prompts

**Product photo prompt (studio)**

Run this prompt with the product name filled in:

```
Act as a professional product photographer shooting for a high-end Shopify storefront. Create a photorealistic image of this item: [PRODUCT NAME GOES HERE]. These requirements are mandatory and must be followed exactly. The backdrop is flat pure white at #FFFFFF, with no gradient, no texture, no scenery, no floor line, no horizon, and no shadow reaching the frame edges. The item sits centered and fully in view with nothing cut off, shows true-to-life proportions and scale, and displays realistic materials and fine detail in a brand-new state. Logos may appear only if they are generic or unbranded. Light it with soft studio lighting from several directions, with shadow only directly beneath the object. Keep contrast high and edges crisp, in the style of catalog photography comparable to Amazon, Shopify, or premium brand listings. Shoot from a front three-quarter angle, slightly rotated for depth. Deliver ultra-high resolution, sharp focus, no motion blur, no artistic filters, no stylization, and a fully photographic look. Exclude people, hands, props, any text, watermarks, branding overlays, and reflections of the camera or the room. The final image should read as if it came from a professional product studio and be ready to upload directly to a Shopify product page.
```

[L0536, undated]

- Before running the prompt, replace [PRODUCT NAME GOES HERE] with the exact product name plus its key visible traits (colour, material, size category), so the image matches the real item [L0536, undated].
- For sets or multi-part products, place every part together in one frame and keep each part fully visible [L0536, undated].

**Hero shot prompt (uploaded item)**

```
Create a square picture of the uploaded item on a plain, pure white backdrop. Position the item in the middle of the frame with soft shadows that give it a sense of depth. Since this is the product's primary hero shot, keep it sharp, evenly lit, and free of any text, props, or background scenery.

Product fidelity: reproduce the item's exact form, dimensions, colour, texture, and surface finish. Do not invent branding or packaging that is not present in the uploaded photo. If the uploaded photo already displays a logo or label, leave it exactly as it appears.
```

[L0887, 2026]

- The two prompts disagree on shadows. The studio prompt allows shadow only directly beneath the object, with no shadow reaching the frame edges [L0536, undated]. The hero shot prompt asks for soft shadows that give depth [L0887, 2026]. Use the studio prompt for catalogue-style listings with strict rules. Use the hero shot prompt when you start from the supplier's own photo and need to keep its branding and details exactly [L0536, undated; L0887, 2026].
- The studio prompt allows generic or unbranded logos only [L0536, undated]. The hero shot prompt keeps any logo or label already in the uploaded photo unchanged [L0887, 2026].

**AI graphics for store sections**
- AI image generation can make visuals for sections that have no product photo, such as a free-shipping banner. It can also cover product pages, blog posts, and About Us or Contact Us pages. Describe the section's message and the scene or graphic you want. Review the result for accuracy before publishing [L1075, 2025+].
- If the section should match the site, include the store's colour scheme in the prompt [L1075, 2025+].

### Compression and file formats

**Targets**
- Compress images to the smallest possible file size while keeping visual quality. Slow-loading images hurt the site [L0300, 2021-22].
- Uploading uncompressed images of several megabytes significantly slows the site and reduces conversion rates [L0300, 2021-22].
- Product images: under 300 KB, ideally under 50 KB, with quality as close to the original as possible. Compress with TinyPNG or Photoshop before upload [L1345, 2021+].
- Product photos above about 1 MB should be compressed [L1002, 2019].
- GIFs: compress below 800 KB. They can reach 1 MB, but the target is 800 KB. For product pages, create GIFs from one to three second clips of existing video ads [L1345, 2021+].
- Animated GIFs load slowly. A 1.5-5 MB GIF converted to WebP becomes roughly 200-500 KB [L1382, undated].
- JPG, PNG and GIF converted to WebP can reduce a 1-2 MB image to around 200 KB or less. Start with product images, because they load first [L1412, 2023].

**Tools**
- Compress before upload with tinypng.com for one-off images, or with an image compression app that does the same job [L0963, 2022].
- On Mac, ImageOptim compresses images offline [L0300, 2021-22; L1310, 2021-22; L1456, 2021-22].
- Smart SEO app or SEO app: reduces file sizes to improve page load speed without cropping or distorting images [L0278, 2025].
- Conflict on apps: one source advises against Shopify apps that resize and compress images on-site. They slow the store, some run scripts that hurt speed, and some lose quality. Process images outside the store instead [L1456, 2021-22]. one source advises against installing an app only to compress images, because it adds code for little benefit. Use an online converter instead [L1412, 2023]. one source's 2025 recommendation of Smart SEO is the more recent advice, and it applies when you want on-site compression [L0278, 2025].

**Conversion procedure (without an app)**
1. Search for a bulk PNG or JPG to WebP converter website [L1412, 2023].
2. Upload all product images and GIFs at once [L1412, 2023].
3. Download the converted files, which usually come as one zip [L1412, 2023].
4. Upload the WebP images to the store one by one [L1412, 2023].

**Formats**
- Save as JPEG for product photos. JPEG is smaller than PNG [L1456, 2021-22].
- Use PNG only when the image needs a transparent background [L0709, 2017+].
- Prefer progressive JPEG unless the image needs a transparent background, in which case use PNG [L0709, 2017+].
- Resize and compress images for each device. Use Liquid in the theme to serve smaller sizes where needed. Choose file type and quality as needed [L0709, 2017+].
