### Search bar in the header

- Place a large, prominent, sticky search bar in the site header. Returning visitors often land on the homepage looking for a product they already viewed, so the search bar gets them there fastest. [L1522, 2021-22]
- The search bar should show dynamic results as the shopper types, displayed in a dropdown under the bar. [L1522, 2021-22]
- Avoid sending shoppers to a separate search results page because it adds a step. [L1522, 2021-22]

### Footer menu and quick links

#### Setting up the footer menu

1. Go to **Content > Menus**. [L1331, 2025-26]
2. Create or select a footer menu. [L1331, 2025-26]
3. In the theme editor, open the **Footer** section and the **Menu - Quick links** block. [L1331, 2025-26]
4. Select the footer menu instead of the main menu, since the main menu has only three items. [L1331, 2025-26]
5. Add links to About us, a product page, Contact us, and the policy pages. [L1331, 2025-26]
6. Save and refresh the preview to confirm the links appear. [L1331, 2025-26]

### Breadcrumb navigation

- Breadcrumb navigation, the line of links along the top of product and collection pages, adds internal links and should be kept on. Some store owners turn it off because they dislike its look, and that is a mistake. [L1465, 2021-22]
- In most Shopify themes, breadcrumb navigation is an on/off option in the theme's settings. [L1465, 2021-22]
- If a theme has no breadcrumb navigation at all, have a developer add it, which is usually not a major coding job. [L1465, 2021-22]

#### Further details

- To add a mega menu in Shopify, go to Online Store > Themes > Edit theme, open the Header section in the left panel, and click Add mega menu. Name it and set its link to the relevant collection, such as the main category collection. [L1010, 2020-26]

- Shopify menus organize how shoppers move through the store by linking to collections, pages, policy pages and blog posts. Each theme places menus in fixed spaces, so the menus you build are shown in those spaces. [L1319, 2020-26]
