### Blog and content

**What counts as content and when to start**
- Content in this framework means anything on a site that is not a product page or an admin page, such as blog posts, infographics, YouTube videos, images, category or collection pages, eBooks, checklists and user-generated content. Product pages alone cannot fill the gap in the customer journey. [L0414, 2021-22]
- Creating blog posts is optional and not required before supplier approval. [L0310, 2024+]
- Blog content is not needed from day one. Add it only after paid traffic is performing well and profitable. [L1279, 2021]
- Blog content does not bring early sales. Do not copy other sites' articles. If you need content, have it written on freelance platforms such as Upwork or Fiverr, or buy PLR (private label rights) content. [L1277, 2020]
- In the first stage, focus on the store itself, conversion optimisation and paid ads. Content and blog posts come later, and a test site does not need blog posts. [L1277, 2020]
- Blog pages and blog posts should not be built or written during the initial site design. Blogging starts only after the business has launched, because it wastes time before launch. [L1463, 2021-22]
- The blog can be a stated preference on the same domain: run it on the same website as the store, for example on WordPress with WooCommerce, so readers move between articles and products without leaving the domain. This is a stated preference rather than a proven requirement. [L0382, 2017]
- Use the native Shopify blog feature for content. SEO results depend on the theme, post optimisation and plugin speed, not on the platform. [L0962, 2021]

**Blog structure and admin**
- Create one blog per store. Shopify allows multiple blogs, but the standard practice is to use a single blog per store. [L0310, 2024+]
- Blog post creation in Shopify:

  **Navigation:** Admin Panel > Online Store > Blog Posts

  **To create a post:** Click "Create Blog Post"

  **Fields:**
  - **Title:** the blog post headline (example: "Top Stand-Up Paddle Boards, Top Surfboards for 2024")
  - **Document editor:** area to insert text, images, and videos
  - **Excerpt:** summary text displayed on the homepage or main blog directory
  - **Featured Image:** image displayed at the top of the blog post
  - **Author name:** writer's name; can be ghostwritten
  - **Blog:** selection of which blog the post belongs to
  - **Blog post template:** use the default template (do not change)
  - **Comments:** toggle to enable or disable reader comments
  - **Search Engine Preview:** editable SEO metadata

  [L0310, 2024+]
- Shopify Magic is a built-in AI tool marked by a star icon in the blog editor. Use it to rephrase, extend, or simplify blog post content. [L0310, 2024+]
- Shopify automatically creates one default blog category named 'news' when the store is set up. All blog posts go to this category by default unless additional blog categories are created. [L0312, 2023+]
- To find and change a blog post's category, open the blog post in your admin panel, scroll to the Organization section, and select or change the blog category. Blog categories are created by clicking 'create a new blog' in the Organization section. [L0312, 2023+]
- To change the blog author name: go to Online Store > Blog posts, open the post, then in the right sidebar under Organization change the Author field (2023). [L0855, 2023]
- Hidden blog posts do not appear in the blog listing of the theme. Each post must be set to visible before it shows up in the listing. [L1265, 2020-26]
- Create an editorial in Shopify under Online Store > Blog posts by adding a new article in the blog, or under Online Store > Pages for a standalone page. Page builder apps such as PageFly or GemPages can be used to design the layout. [L0578, 2023+]
- Shopify supports both the blog and the pages function for topical authority articles, so either can be used for that content. Collection pages are created as separate category pages in the store. [L1389, 2025-26]
- Shopify has a built-in blog function, so holiday blog posts can be created directly in the Shopify admin without extra apps. [L1224, 2025+]
- Blogs are built into Shopify. Create one from the Shopify admin by clicking create blog and then adding posts. This is the simplest place to publish SEO content for seasonal promotions (2025). [L1287, 2025]

**Help and AI tools for content work**
- Use Shopify live chat for platform-specific setup questions instead of guessing. Ask exactly what you want to do so the answer is correct the first time. [L0963, 2022]
- For Shopify setup steps, follow the official Shopify help documentation because it is kept up to date. The admin AI assistant is trained on Shopify's own help center and can troubleshoot a step you are stuck on (2024). [L1285, 2024]
- Never let an AI tool write directly into the live Shopify store. Do the QA outside Shopify first, and only then apply the changes in bulk. [L1269, 2025-26]
- When using custom rules with Shopify and a Claude MCP connection, set the rules for internal links explicitly, then have the connection apply only what those rules allow. Keep a manual review step before the rules are executed. [L1269, 2025-26]

### Seasonal setup

**Holiday and seasonal stores**
1. Have a store template and product catalogue ready before Q4 begins. [L0309, 2024+]
2. Add multiple product categories (Black Friday, Christmas, Valentine's Day, evergreen) to one store. [L0309, 2024+]
3. Run different ad campaigns and creative variations per product, but fulfil all orders through the same store to centralise inventory and customer data. [L0309, 2024+]
- Create a seasonal section and header message before a holiday, such as a Mother's Day gifts section with a note that gifts arrive in time for May 13. Make it visible early enough for buyers to order and receive the gift before the date. [L0355, 2020-26]
- A holiday gift store should look built for the occasion. Use a brand name, logo, colours and wording tied to the holiday, and list only a few products. Shoppers who worry about choosing the wrong gift buy more confidently in a store that looks designed for that purpose. [L1214, 2023+]
- Keep old store versions such as a seasonal Christmas store as saved themes, and republish them later with the same logo and domain setup. [L1131, 2018+]

### Store build or outsourcing

**Two paths and what each delivers**
- A store can be built in two ways: do it yourself by installing the provided theme and modifying it, or outsource the design to a specialised dropshipping web design team. Both paths lead to a store ready for supplier approval. [L1061, 2020-26]
- You can build your demo store yourself by completing all the store-building step lessons, or outsource the entire build to the one source Done-For-You team to receive a finished, supplier-ready store. Either way, you retain 100% ownership. [L0069, undated]
- Outsourcing store design is an acceptable choice, while the owner keeps control of supplier and traffic decisions. Many owners build their first store themselves and outsource design once the business earns money. [L0467, 2019]
- Outsourcing the Shopify store build to a paid setup service is optional and costs extra on top of any training or programme fee. The seller can always build the store personally instead. [L1466, 2021-22]
- A done-for-you store build means a team builds a store from a proven design after checking the niche. Build quality is guaranteed, but revenue or a fixed return is not. An established profitable store sells at a multiple of its monthly net profit rather than at the build price. [L0941, 2022]
- A custom dropshipping store built by an outsourced web design team is typically delivered in about five business days, so the builder does not have to go through the store build steps themselves. [L1061, 2020-26]

- Confirm whether the logo is included before ordering. A done-for-you store build includes logo design, so the buyer does not need to supply a logo, but confirm this is included in the specific package (2024). [L0806, 2024]

**What a done-for-you design changes (2026)**
- A done-for-you design swaps the theme only. Existing products, brands, pages and customisations are kept, and policy pages are updated to meet Google compliance. [L0808, 2026]
- Done-for-you store packages can differ. Some do not include Google account setup, so check what a package includes before buying. [L0808, 2026]
- When a done-for-you design service rebuilds an existing Shopify store, the designer works through a collaborator code in draft mode. The current store is not deleted and no new Shopify account is created. Existing products, brands, pages and customisations carry over, and only the theme and policy pages change. [L0808, 2026]

**Ordering a done-for-you build**
1. Enrol in the web design programme. [L0967, 2020]
2. Receive the intake email and complete it with the Shopify store login, store name, niche, links to sites you like, and what you like about them. [L0967, 2020]
3. The design team builds the store and uploads demo products. [L0967, 2020]
- Web design is ordered from the members area sidebar, through the option labelled "let my team build you a beautiful e-commerce website". This starts the intake process for the store build. [L0967, 2020]
- Before ordering a web design build, completing the first two training modules is enough. The remaining modules do not need to be finished before the store is built. [L0967, 2020]
- For the first store, do not build two stores at once. Start with one store, because mistakes made with the blueprint steps can only be fixed once. [L0967, 2020]
- Learn Shopify while doing a task:
  1. Open the training video on one side of the screen and the Shopify admin, logged in, on the other side. [L0967, 2020]
  2. Watch about 30 to 60 seconds of the video, then pause it. [L0967, 2020]
  3. Repeat each click in Shopify while the video is paused. [L0967, 2020]
  4. Continue segment by segment until the task is done. [L0967, 2020]

**Starting a done-for-you design after purchase**
1. Open the order confirmation email sent after buying. [L1281, 2022]
2. Click the link in it and fill in the web design questionnaire with details about the new store. [L1281, 2022]
3. If the email cannot be found, search the inbox for 'web design questionnaire'. [L1281, 2022]
4. If it is still missing, email support and request the form. [L1281, 2022]
5. The build starts once the questionnaire is submitted, at the time the buyer is ready. [L1281, 2022]

**Queue and timing rules**
- Web design orders are queued first come, first served, based on when the client submits the store information form, not when they purchase. (2023) [L0804, 2023]
- A store cannot be rebuilt for a different niche once the web design has been built from scratch. A new niche would require a second store, which is effectively a second job. Small tweaks are still possible (2023). [L0804, 2023]
- Delay the store build until content shows some traction, such as a few thousand views, since a store built before any demand can waste about 10 hours. Build the store in parallel with content only if you have no web-building experience. [L1380, 2022]
- A beginner's full build: learn first, then build one reusable store personally (procedure):
  1. Build the store yourself rather than paying a freelancer for each product. [L1212, undated]
  2. Use the free course section about building a store with the Refresh team. [L1212, undated]
  3. Watch the video on building a branded product page with PageFly and implement it at the same time. [L1212, undated]
  4. Use a free website template from the course (Website Building channel, Paper Loop template). [L1212, undated]
  5. Create a landing page with PageFly, which is free. [L1212, undated]
  6. Run ads to the store. [L1212, undated]

**Build yourself first, then delegate**
- Learn to build a Shopify store yourself first, including theme, colour scheme, branding, copywriting and apps, so you know which design gets the best results. Only then delegate the build, giving the person your exact structure. [L1358, undated; L1360, undated]
- Learning Shopify store building is a lasting skill, not only for your current dropshipping business. Owning it lets you judge a store build and decide what to change in the theme, branding and copy. [L1358, undated]
- A delegated store build can save a day or two of work. That time can be used to prepare creatives and set up Facebook or TikTok ad campaigns. [L1358, undated; L1360, undated]
- A delegated store setup can include the theme, logos and branding, the copy, the apps you specify, and the payment providers, so the store is ready to run ads. [L1358, undated]
- The best case is a team member who already has a product they want to test. Give them your store structure, the apps to install and the branding requirements so they can set the store up for ads. [L1358, undated; L1360, undated]
- Delegation steps:
  1. Build the store yourself at least once to learn which theme, design, branding and apps work for you. [L1360, undated]
  2. Give the team member a product that you want to test. [L1360, undated]
  3. Tell them to build the store following your structure. [L1360, undated]
  4. Have them create the logos and branding, following your guidelines. [L1360, undated]
  5. Tell them which apps to install and how to configure them, especially Klaviyo and SMS Bump. [L1360, undated]
  6. Once trust is established, have them install the payment providers so the store is up and running. [L1360, undated]

**Freelancers and task services**
- Hiring developers or designers for store builds can be done through freelancers who specialise in Shopify. Expect the developer's skill to matter more than their theme knowledge, since HTML skills transfer across themes and platforms. [L0801, 2021]
- The course's store design and VA sourcing is done via Upwork or Taskrabbit, with one source support for small jobs. No internal VA list is provided. [L0969, 2022]
- Every few months, have a freelancer audit the store for broken pages, page speed problems and oversized images that should be compressed. Use this as a project-based task rather than a permanent staff position. [L0921, 2022]
- For most Shopify store tasks, spend about 30 minutes using Shopify support documentation and search before paying for help. Hire a Shopify developer only for custom coding beyond that (2024). [L1115, 2024]

**Outsourced setup, buyer side**
1. Open the setup service page and click the button to request the service. [L1466, 2021-22]
2. Fill in the request form. [L1466, 2021-22]
3. The provider contacts the buyer and states what it needs. [L1466, 2021-22]
4. The buyer supplies the branding: brand colours, colour schemes and the business name. [L1466, 2021-22]
5. The provider logs into the buyer's Shopify account and configures the store until it is ready to call suppliers. [L1466, 2021-22]

**Page-building tools**
- Custom fields combined with drag-and-drop layouts let team members build pages without hand-coding HTML. This reduces errors such as unclosed div tags and speeds up onboarding of new staff. [L0949, 2021-22]
- Learning Shopify and running the store in-house: a template-based approach uses one tested template for every store, changing only the logo and product images. [L1215, 2023+]

### B2B and trade pages

**Why a trade page**
- For business-to-business buyers such as interior designers, a separate trade page with its own contact form and a list of trade buyers' logos builds trust and repeat orders. Logos can be added as the list of past trade customers grows (2024). [L0360, 2024]
- High-ticket industrial products can be offered to business buyers on a separate page or collection named To The Trade. The page should describe business-to-business sales, list the industrial products, and include a contact form so buyers can request quotes for large orders before buying (2022). [L0963, 2022]

**Adding a trade page**
1. Create a page in Shopify named to the trade. [L0429, 2022]
2. State that bulk orders and trade discounts are available. [L0429, 2022]
3. Add a contact form where buyers can request a custom quote. [L0429, 2022]
- No other change to the marketing approach is needed. [L0429, 2022]

**Adding a trade page (2025)**
1. Create a page that duplicates the contact page, including the contact form. [L0972, 2025]
2. Replace the top heading with To the Trade and add trade copy describing bulk discounts, custom quotes and expedited shipping. [L0972, 2025]
3. Link the page in the footer menu, and sometimes in the header menu. [L0972, 2025]
4. Once business orders arrive, add a list of businesses you have sold to, to show credibility. [L0972, 2025]

**Trade page text template (2025)**

```
To the Trade

We work with [interior designers / businesses / contractors] nationwide for all of their [client / project / office] needs. We offer expedited shipping, bulk discounts and custom quotes.

For a business order, call us at [phone number], email us at [email address], or fill out the form below with your name, email address, phone number, the items you are interested in, the quantity, and the date you need them by. We will reach out to you right away.

Brands we have worked with: [logo list of business customers you have sold to]
```

[L0972, 2025]

**Contact form and wholesale accounts**
- On a "To the Trade" page, use a contact form instead of a separate order form, with these fields: name, email, phone number, business name, product of interest and number of units. Mention that bulk or quantity discounts are available on the page. [L0961, 2020]
- Create B2B wholesale accounts with a Shopify app that assigns account-level pricing. Logged-in trade customers then see lower prices and can add discounted items to their cart. [L1088, 2020]

### Learning resources and help sources

**Free learning resources and reference tools**
- Free learning resources for web development include the YouTube channels Web Dev Simplified and Fireship, plus free online programming courses from Google. Books are also recommended for learners who prefer reading. [L0709, 2017+]
- Stack Overflow is useful for finding fixes to specific technical problems, though its answers are very technical for beginners. Reddit can be used to ask which developers people recommend, but beginners should expect blunt replies. [L0709, 2017+]
- The Shopify Help Center at help.shopify.com documents adding products, product details, variants, product media, collections and importing and exporting. Use it to check small questions about fields or variants. [L1166, 2021-22]
- Build an operations resource list for each team member by collecting the Shopify Help Center guides for these tasks: creating collections, creating orders, and creating discounts. Add the links to the corporate board so staff can learn on their own. [L1396, 2021-22]

**Task-based services for small jobs**
- Task Husky is a marketplace for small, one-off site jobs such as installing a widget on a product page. Prices start from about US$39 per task, which is far cheaper than hiring an agency for a full site relaunch. [L0719, 2021-22]
- Freelance marketplaces such as Upwork often focus on full site relaunches, so they can be a poor fit for minor updates. Use task-based services for small refreshes and check the price before committing. [L0719, 2021-22]
